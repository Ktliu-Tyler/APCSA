ArrayList Algorithms

今天的核心不是背更多 methods，而是選對 traversal pattern。

Core Idea

ArrayList 難在 size 和 index 會變

set(i, value)
不改 size
remove(i)
size - 1，後方左移
add(i, value)
size + 1，後方右移
add(value)
加到尾端

任何 add/remove tracing 題，都要同步追蹤 list、index、size。

Traversal

Traditional for：需要 index 時使用

for (int i = 0; i < list.size(); i++)
{
    int value = list.get(i);
    System.out.println(value);
}

ArrayList 用 size() 和 get(i)，不是 .length 或 []。

Enhanced For

Enhanced for：只讀取每個元素時最乾淨

int total = 0;
for (int score : scores)
{
    total += score;
}

只需要 value，不需要 index，不改 list structure，enhanced for 很適合。

Quick Check

這段程式回傳什麼？

ArrayList<Integer> nums = new ArrayList<Integer>();
nums.add(4);
nums.add(9);
nums.add(4);

int count = 0;
for (int n : nums)
{
    if (n == 4)
    {
        count++;
    }
}

count 是 2。這是 read-only count algorithm。

Filter

Filter Pattern 1：建立新的 List

ArrayList<Integer> result = new ArrayList<Integer>();

for (int n : nums)
{
    if (n >= 0)
    {
        result.add(n);
    }
}

return result;

這個 pattern 不會改原本 list，所以沒有 index shift 問題。

Prompt Reading

看到 return new list，就不要破壞原 list

Return new list

getPassingScores、validReadings、wordsOfLength

建立 result，符合條件就 add。

Modify original list

removeLowScores、removeInvalid、deleteShortWords

直接對參數 list 做 remove。

Remove Bug

最直覺的 forward remove 可能錯

for (int i = 0; i < nums.size(); i++)
{
    if (nums.get(i) < 0)
    {
        nums.remove(i);
    }
}

刪掉 index i 後，下一個元素會左移到 index i；for loop 又讓 i++。

Index Shift Trace

為什麼會漏掉元素？

StepListi狀態
start[4, -2, -5, 7]1-2 要刪
remove[4, -5, 7]1-5 移到 index 1
update[4, -5, 7]2下一輪檢查 7

連續符合刪除條件的元素，是 forward remove bug 最常出現的地方。

Quick Check

以下程式最後 list 是什麼？

ArrayList<Integer> nums = new ArrayList<Integer>();
nums.add(2);
nums.add(2);
nums.add(3);

for (int i = 0; i < nums.size(); i++)
{
    if (nums.get(i) == 2)
    {
        nums.remove(i);
    }
}

[2, 3]。第一個 2 被刪後，第二個 2 左移到 index 0，但 i++ 跳到 index 1。

Safe Forward

Forward while：remove 後不要增加 i

int i = 0;
while (i < nums.size())
{
    if (nums.get(i) < 0)
    {
        nums.remove(i);
    }
    else
    {
        i++;
    }
}

remove 後，同一個 index 要再檢查一次，因為新元素剛移過來。

Backward Traversal

Backward remove 是最穩定的 remove-all pattern

for (int i = nums.size() - 1; i >= 0; i--)
{
    if (nums.get(i) < 0)
    {
        nums.remove(i);
    }
}

從後面刪，左移只影響右側已經走過的位置。

Choose Pattern

刪除題先問：我要刪掉所有符合條件的元素嗎？

remove all
backward traversal
remove until one condition
可能用 while / return
return valid items
filtered copy
replace invalid values
set

不要只看到 filter 就立刻 remove，先讀 prompt。

Enhanced For Limits

Enhanced for 不適合 add/remove/set by index

Not enough

for (int x : nums)
{
    x = 0;
}

只改變 loop variable。

Use set

for (int i = 0; i < nums.size(); i++)
{
    nums.set(i, 0);
}

真的修改 list 裡的位置。

Transform

set 是 replace，不是 remove

for (int i = 0; i < nums.size(); i++)
{
    if (nums.get(i) < 0)
    {
        nums.set(i, 0);
    }
}

set 不會改 size，也不會造成 index shift。

Data Analysis

Above-average count 常需要兩次 traversal

int total = 0;
for (int score : scores)
{
    total += score;
}

double avg = (double) total / scores.size();

int count = 0;
for (int score : scores)
{
    if (score > avg)
    {
        count++;
    }
}

第一次算 average；第二次才知道誰大於 average。

Insert While Looping

add(index, value) 也會造成 index shift

for (int i = 0; i < words.size(); i++)
{
    if (words.get(i).equals("stop"))
    {
        words.add(i, "before");
    }
}

插入會讓原本 index i 的元素右移；若不調整，可能重複處理或造成無限成長。

AP-Style Trace

以下程式印出什麼？

ArrayList<Integer> list = new ArrayList<Integer>();
list.add(1);
list.add(4);
list.add(4);
list.add(2);

for (int i = list.size() - 1; i >= 0; i--)
{
    if (list.get(i) % 2 == 0)
    {
        list.remove(i);
    }
}
System.out.println(list);

[1]。從後往前刪除所有 even values，兩個 4 和 2 都會被刪掉。

FRQ Template

Remove-all 題可以先套這個骨架

public static void removeMatches(ArrayList<String> list, String target)
{
    for (int i = list.size() - 1; i >= 0; i--)
    {
        if (list.get(i).equals(target))
        {
            list.remove(i);
        }
    }
}

String 比較內容要用 .equals()。
