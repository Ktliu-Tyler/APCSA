Lesson Flow

本課路線

Primitive Review

Primitive variable 直接存 value

前幾堂課已經學過 int、double、boolean、char。 這些是 primitive types。當我們寫 int age = 18; 時，可以先把 age 想成直接儲存數值 18 的位置。

Primitive type 可以儲存 範例
int 整數 10
double 小數或可轉成小數的數值 3.14
boolean 真或假 true
char 單一字元 'A'

Primitive Copy

int a = 10;
int b = a;

a = 30;

System.out.println(a);
System.out.println(b);

Output 是 30 和 10。int b = a; 只在當下把 a 裡的 primitive value 複製給 b，不會讓兩個變數永久連動。

a = 10 b = 10 a = 30 b remains 10

Class and Object

Class 是設計規格，Object 是實際建立出來的個體

Java 是 object-oriented programming language。大量資料與操作會被組織成 objects。 但在理解 object 之前，要先分清楚 class 和 object。

Class Object
類別、設計規格、blueprint。 根據 class 建立出來的 instance。
描述每個物件應具有什麼 state 與 behavior。 真正存在、可以被程式操作的個體。
Scanner class 某一個 Scanner object
String class 某一個 String object
BlueprintCar class 可以規定 color、speed、battery。
InstanceToyota Corolla、Tesla Model 3、Honda Civic 可以各自是 object。
Many objects一個 class 可以建立很多不同 objects。
AP wordinginput refers to an instance of Scanner。

看到 instance of a class 時，可以先理解成「根據某個 class 建立出來的 object」。

Object Creation

new 通常表示建立新的 object

Lesson 2 已經寫過 Scanner input = new Scanner(System.in);。 現在可以更精確地理解：new Scanner(System.in) 會建立一個新的 Scanner object。

Constructor Call Pattern

new ClassName(arguments)
片段 意思
new 建立新的 object。
Scanner 要根據哪個 class 建立 object。
Scanner(System.in) constructor call，用來建立並初始化 object。
System.in 傳給 constructor 的 argument，代表標準輸入來源。

Constructor 看起來很像 method call，因為也有 parentheses，但目的不同：constructor 是建立 object 時用來初始化 object；method 則是對既有 class 或 object 執行某個操作。

Scanner Breakdown

重新拆解 Scanner input = new Scanner(System.in);

這一行其實同時做了三件事：宣告 reference variable、建立 object、把 object reference 存進 variable。

Scanner Object Creation

Scanner input = new Scanner(System.in);
部分 角色 AP CSA 說法
Scanner 變數的 type reference type / class name
input 變數名稱 reference variable
new 建立 object object creation
Scanner(System.in) constructor call 建立並初始化 Scanner object
建立 Scanner object 取得 reference 把 reference 存進 input input 指向 object

Reference Variable

Reference 是用來找到某個 object 的資訊

在學習階段，可以把 reference 畫成箭頭。重點是：input 並不是整個 Scanner object 本身；input 是一個儲存 reference 的變數。 

input
  |
  v
Scanner object

input stores a reference to the Scanner object.

Primitive Variable Reference Variable
儲存 primitive value。 儲存 object reference。
int x = 5; Scanner input = new Scanner(System.in);
x 直接存 5。 input 存的是找到 Scanner object 的 reference。
Assignment 複製 value。 Assignment 複製 reference。

Reference assignment 不會複製 object。這是本課最重要的一句話。

Copying

Primitive copy 複製 value；reference copy 複製 reference

Primitive Copy

int a = 5;
int b = a;

a = 20;

a 和 b 是兩份獨立的 primitive values。最後 a = 20，b = 5。

Reference Copy

Scanner first = new Scanner(System.in);
Scanner second = first;

second = first 只複製 reference。first 和 second 指向同一個 Scanner object。

first  ----\
           > Scanner object
second ----/

兩個 reference variables 指向同一個 object 時，稱為 aliases。

Scanner Alias Example

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner first = new Scanner(System.in);
        Scanner second = first;

        int a = first.nextInt();
        int b = second.nextInt();

        System.out.println(a);
        System.out.println(b);
    }
}

如果輸入 10 20，output 是 10 和 20。 因為 first 和 second 操作的是同一個 Scanner object。

Alias and State

多個 references 可以看到同一個 object state

每個 object 都可以有 state，也就是 object 目前內部資料的狀態。例如一個 Car object 可能有 speed = 50、battery = 80、gear = 3。

概念 意思 例子
State object 目前儲存的資料狀態。 speed、battery、direction
Behavior object 可以執行的操作。 accelerate()、brake()、turn()
Method Java 中常用 method 表現 behavior。 input.nextInt()

如果 a 和 b 都指向同一個 object，透過 a 修改 object state， 之後透過 b 看到的也是修改後的同一個 object。

不是「a 的 object」和「b 的 object」。如果兩個 references 指向同一個 object， 根本只有一個 object。

Dot Operator

Math.sqrt(25) 與 input.nextInt() 的角度不同

Lesson 3 學過 Math.sqrt(25)。這一課可以補上另一半：Math.sqrt 是 static method，可以透過 class name 呼叫；input.nextInt() 是對 input 指向的 Scanner object 呼叫 method。

寫法 概念 說明
Math.sqrt(25) Class.method(...) sqrt 是 static method，不需要 new Math(...)。
input.nextInt() objectReference.method(...) 對 input 指向的 Scanner object 呼叫 nextInt()。

Dot operator . 在 input.nextInt() 中，可以先理解成： 對 input 所指向的 object 使用某個 method。

Reference Reassignment

Reference variable 可以改指向別的 object

Reference variable 和 object 是兩件不同的事情。重新 assignment 會改變變數裡存的 reference， 但不會把 object 本身搬來搬去，也不會自動複製 object。

Assignment Copies Reference

SomeClass a = new SomeClass();
SomeClass b = new SomeClass();

a = b;

執行 a = b; 後，a 和 b 指向同一個 object B。

What about Object A?

a ----\ 
       > Object B
b ----/

Object A has no reference

如果沒有其他 reference 指向 Object A，程式就再也無法使用它。Java 之後可能透過 garbage collection 回收記憶體。

AP CSA 不需要你控制 garbage collection，但需要理解：object 和 reference variable 不是同一件事。

null

null 表示沒有 reference 到任何 object

Reference variable 可以儲存特殊值 null。這不是一個叫做 null 的 object， 而是表示這個 reference variable 目前沒有指向任何 object。

Code 是否合法 原因
Scanner input = null; 合法 Scanner 是 reference type。
String name = null; 合法 String 是 reference type。
int x = null; 不合法 int 是 primitive type。

null 不是 0

0 是 numeric value。null 是沒有 object reference。

null 不是空字串

String s = null; 沒有 String object；String s = ""; 有一個長度為 0 的 String object。

NullPointerException

String name = null;

System.out.println(name.length());

這段程式可以通過 declaration，但執行到 name.length() 時會出現 NullPointerException，因為沒有 String object 可以執行 length()。

錯誤類型 例子 原因
Compile-time error int x = null; 編譯時就知道 primitive type 不能儲存 null。
Runtime error String s = null; s.length(); 宣告合法，但執行 method call 時沒有 object。

AP 題目看到 SomeClass obj = null; 不要立刻說 compile error。 真正危險的是後面如果 obj 仍然是 null，卻呼叫 obj.someMethod()。

Reference Diagram Strategy

遇到 object tracing 題，請直接畫箭頭

Reference 題不要只在腦中想。最穩定的方法是畫 variables、objects 和 arrows。

Step 做法 例子
1 找 new。 每次執行 new SomeClass() 通常建立新 object。
2 畫 object。 Object A、Object B。
3 畫 reference variables。 a、b、c。
4 根據 assignment 畫箭頭。 b = a; 表示複製 a 的 reference。
5 遇到 null 就移除箭頭。 a = null; 讓 a 不再指向 object。
6 檢查 object 是否還有其他 reference。 不要看到 a = null 就以為 object 一定消失。

Trace Challenge

Scanner a = new Scanner(System.in);
Scanner b = a;
Scanner c = b;

b = null;
a ----\
       > Scanner object
c ----/

b -> null

最後 Scanner object 仍然存在，因為 a 和 c 還 reference 到它。

AP Patterns

AP CSA 常見題型與陷阱

Class / Object / Reference

Scanner keyboard = new Scanner(System.in);

Scanner 是 class/type，keyboard 是 reference variable，new Scanner(System.in) 是 object creation + constructor call。

Primitive Copy

int a = 7;
int b = a;
b = 20;

a 仍是 7，b 是 20。Primitive values 是獨立 copy。

Reference Copy

Scanner one = new Scanner(System.in);
Scanner two = one;

one 和 two 儲存相同 reference，指向同一個 object。

Count Objects

Scanner a = new Scanner(System.in);
Scanner b = a;
Scanner c = b;

明確建立 1 個 Scanner object，有 3 個 reference variables。

null Is Legal for Reference Types

String word = null;

這行合法，沒有立即 runtime error，也沒有建立空字串。

NullPointerException

String word = null;
System.out.println(word.length());

執行到 word.length() 時出現 runtime error，因為 word 沒有指向 String object。

常見迷思 正確觀念
a = b; 會複製整個 object。 Reference assignment 只複製 reference。
兩個變數就一定有兩個 objects。 多個 reference variables 可以指向同一個 object。
使用 new 就會建立 reference variable。 new 建立 object；variable declaration 建立 variable。
Reference variable 就是 object。 Reference variable 儲存 reference，不是 object 本身。
null 是 object 或空字串。 null 表示沒有 object reference。
Reference 一定要理解成裸記憶體位址。 AP CSA 只需要你能畫 reference 指向 object。
