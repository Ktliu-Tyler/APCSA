Opening Question

這一行到底先算什麼？

double x = Math.sqrt(25) + 3;

先想一想

Math.sqrt(25) 是一個 statement、expression，還是 output？

Math.sqrt(25) 是 method call，也是 expression 的一部分。它先回傳 5.0，整行才變成 double x = 5.0 + 3;。

Method Call Shape

常見形式：ClassName.methodName(arguments)

MathClass name
powMethod name
2, 3Arguments
Math.pow(2, 3)

到 Math 這個 class 裡呼叫 pow method，並把 2 和 3 傳進去。Return value 是 8.0。

Argument vs Parameter

呼叫時傳入的是 argument，定義時接收的是 parameter

這兩個字描述的是同一個資料傳遞過程，但位置不同。

Parameter

int x 在 method 定義中接收資料。

Argument

square(7) 中的 7 是實際傳入的資料。

Mental Model

呼叫 square(7) 時，可以想成 x = 7。

Return Value

Method call 可以被 return value 取代

Math.sqrt(81) 9.0 9.0 + 1 10.0

Return value 可以存進 variable、印出來，也可以放進更大的 expression。

Return Value vs Output

Math.sqrt(25) 不會自己印出來

Return only

Math.sqrt(25); 產生 return value，但沒有 output。

Print output

System.out.println(Math.sqrt(25)); 才會印出 5.0。

void

println 的工作是印出東西，不是回傳一個可計算的 value。

int x = System.out.println("Hello"); 不合法，因為 println 沒有可以存進 x 的 return value。

Math Class

AP CSA 前段最常見的四個 Math methods

abs絕對值
pow次方
sqrt平方根
random隨機 double
Math.直接用 class 呼叫

目前先記住：使用 Math.sqrt(25)，不是 sqrt(25)，也不需要 new Math()。

Math.abs

Math.abs() 回傳絕對值

int score = 83;
int difference = Math.abs(score - 100);

difference 是多少？

A. -17 B. 17 C. 83 D. 100

答案是 B。score - 100 是 -17，Math.abs(-17) 回傳 17。

Math.pow

Math.pow() 回傳 double

Math.pow(2, 3)

Return value 是 8.0。

合法

double x = Math.pow(2, 3);

不合法

int x = Math.pow(2, 3);

可以寫 int x = (int)Math.pow(2, 3);。這次是明確 casting，結果是 8。

Math.sqrt

Math.sqrt() 也回傳 double

double result = Math.sqrt(9) + Math.sqrt(16);

Math.sqrt(9) 是 3.0，Math.sqrt(16) 是 4.0，所以 result = 7.0。

Nested Method Calls

從最內層開始 trace

double d =
    Math.sqrt(
        Math.pow(3, 2) + Math.pow(4, 2)
    );

Math.pow(3, 2) = 9.0，Math.pow(4, 2) = 16.0，合起來是 25.0，最後 Math.sqrt(25.0) = 5.0。

Integer Division Still Matters

Method 不會救回已經發生的 integer division

Math.sqrt(9 / 4)

9 / 4 = 2，所以是 Math.sqrt(2)。

Math.sqrt(9.0 / 4)

9.0 / 4 = 2.25，所以結果是 1.5。

Math.random

Math.random() 的範圍是 [0.0, 1.0)

可能0.0
不可能1.0
Return typedouble

它是 random integer 題型的起點，但本身不是 integer。

Random Integer

(int)(Math.random() * 10) 是 0 到 9

0.0 <= r < 1.0 0.0 <= r * 10 < 10.0 (int) 0 through 9

它不是 1 through 10。要 1 through 10，需要再 + 1。

Dice

模擬一顆六面骰

int roll = (int)(Math.random() * 6) + 1;
0 through 5 + 1 1 through 6

Range Formula

產生 min through max 的公式

(int)(Math.random() * (max - min + 1)) + min

數字個數

max - min + 1

起點位移

+ min

包含兩端

inclusive range

Reverse Design

想產生 12 through 20，怎麼寫？

先算數字個數

20 - 12 + 1 = ?

一共有 9 個數，所以寫 (int)(Math.random() * 9) + 12。

Casting Trap

這兩個看起來像，但結果完全不同

正確

(int)(Math.random() * 10)
0 through 9

陷阱

(int)Math.random() * 10
永遠 0

原因

(int)Math.random() 會先把小於 1 的 double 變成 0。

AP-style Check

快速檢核：method return type

int value = Math.sqrt(49);

What happens when this code is compiled?

A. Prints 7 B. Prints 7.0 C. Stores 49 D. Compile-time error

答案是 D。Math.sqrt(49) 回傳 double，不能直接存進 int。

AP-style Check

快速檢核：random range

int x = (int)(Math.random() * 8) + 5;

Which set contains all possible values of x?

A. 0 through 7 B. 5 through 12 C. 5 through 13 D. 6 through 13

答案是 B。乘以 8 後 cast 得到 0 through 7，再加 5 得到 5 through 12。

Final Trace Challenge

綜合追蹤：method、integer division、random

int a = 11;
int b = 4;

double x = Math.sqrt(a / b + Math.pow(b - 1, 2));
int y = (int)(Math.random() * (b + 2)) + 3;
int z = Math.abs((int)x - y);

a / b = 2，Math.pow(3, 2) = 9.0，所以 x = Math.sqrt(11.0)，約 3.3166。y 是 3 through 8，(int)x 是 3，因此 z 是 0 through 5。
