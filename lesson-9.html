Learning Goals

這堂課結束後，你應該能做到什麼

讀懂 while (condition) 的執行順序：先判斷，再執行 body，再回頭重新判斷。
分辨 if 最多執行一次，而 while 可能執行 0 次、1 次、很多次或永遠不停。
用 initialization、condition、update、termination 四個元素分析一個 loop。
使用 trace table 追蹤 loop control variable、counter、accumulator、output 與最後變數值。
判斷 loop body 執行幾次，並找出 < / <= 造成的 off-by-one error。
寫 counter-controlled loops：往上數、倒數、每次增加 2 或依條件 count。
使用 accumulator 計算 sum、product、count matches 與 average 前置資料。
理解 sentinel value、priming read 與「sentinel 本身通常不被處理」。
寫 input validation：通常是 while (invalidCondition)。
辨識 infinite loop：控制變數沒有更新、更新方向錯、或 update 不一定會執行。
使用 % 10 取得最後一位 digit，使用 /= 10 移除最後一位 digit。
搭配 Boolean flag 與 short-circuit 寫 search-until-found 類型的 loop。

Lesson Flow

本課路線

Syntax

while 的意思：只要 condition 還是 true，就繼續執行

Basic while Pattern

initialization;

while (condition)
{
    statement;
    update;
}

while 每次進入 body 前都會重新檢查 condition。只要 condition 是 true，body 就會再執行一次；當 condition 變成 false，程式離開 loop。 

initialize
check condition
true  -> body -> update -> check condition again
false -> exit loop

if vs while

if 是選擇一次；while 是條件成立就重複

Structure 最多執行幾次 body？ 用途
if (x < 5)一次根據條件選一條路徑。
while (x < 5)不固定只要條件成立就重複執行。

if

int x = 1;

if (x < 5)
{
    x++;
}

只判斷一次，最後 x 是 2。

while

int x = 1;

while (x < 5)
{
    x++;
}

一直重複到 x == 5，最後 x 是 5。

Loop Tracing

AP CSA 常考：loop 執行幾次、輸出什麼、最後變數是多少

First while Trace

int x = 1;

while (x <= 5)
{
    System.out.println(x);
    x++;
}
Iteration x before condition condition output x after update
111 <= 5 true12
222 <= 5 true23
333 <= 5 true34
444 <= 5 true45
555 <= 5 true56
stop66 <= 5 false--

Iteration 是 body 完整執行一次。上例 body 執行 5 次，最後 x 是 6。

Four Parts

一個正確的 while loop 通常要看四件事

Initialization

Loop 開始前設定控制變數，例如 int count = 1;。

Condition

while 括號中的 Boolean expression，例如 count <= 5。

Update

每輪改變會影響 condition 的值，例如 count++。

Termination

說明為什麼 condition 最後會變 false，例如 count 會到 6。

Annotated Loop

int count = 1;          // initialization

while (count <= 5)      // condition
{
    System.out.println(count);
    count++;            // update
}

// termination: count becomes 6, so count <= 5 is false

Pre-Test Loop

while 可能執行 0 次

while 是 pre-test loop：先檢查 condition，才決定要不要執行 body。 如果 condition 一開始就是 false，body 一次都不會跑。

Zero Iterations

int x = 10;

while (x < 5)
{
    System.out.println(x);
    x++;
}

System.out.println("Done");

10 < 5 一開始就是 false，所以只會輸出 Done。

Counter-Controlled Loops

Counter loop：已知大概要重複幾次時最常用

從 1 印到 10

int i = 1;

while (i <= 10)
{
    System.out.println(i);
    i++;
}

從 10 倒數到 1

int i = 10;

while (i >= 1)
{
    System.out.println(i);
    i--;
}

印偶數 2, 4, 6, 8, 10

int i = 2;

while (i <= 10)
{
    System.out.println(i);
    i += 2;
}

如果是 int i = a; 搭配 while (i <= b) 和 i++， 當 a <= b 時，執行次數是 b - a + 1。但遇到 i += 3、 i *= 2、i /= 2 時，最好真的 trace。

Off-by-One

< 和 <= 可能只差一個字，卻差一輪

Code body 對哪些 i 執行 次數
int i = 1; while (i < 5)1, 2, 3, 44
int i = 1; while (i <= 5)1, 2, 3, 4, 55
int i = 0; while (i < 10)0 到 910
int i = 0; while (i <= 10)0 到 1011

0-based counter int i = 0; while (i < n) 會執行 n 次，這也是之後 String indexing、arrays、ArrayList traversal 很常見的形式。

Accumulator

Accumulator 用 loop 不斷累積結果

Sum：1 + 2 + 3 + 4 + 5

int i = 1;
int sum = 0;

while (i <= 5)
{
    sum += i;
    i++;
}

System.out.println(sum);  // 15

sum 從 0 開始，因為 0 是加法 identity。

Product：1 * 2 * 3 * 4 * 5

int i = 1;
int product = 1;

while (i <= 5)
{
    product *= i;
    i++;
}

System.out.println(product);  // 120

product 通常從 1 開始；若從 0 開始，永遠會是 0。

Count and Sum Matches

int i = 1;
int count = 0;
int sum = 0;

while (i <= 10)
{
    if (i % 2 == 0)
    {
        count++;
        sum += i;
    }
    i++;
}

最後 count 是 5，sum 是 30。

Sentinel Loops

Sentinel loop：不知道要讀幾筆，直到特殊值出現

Sentinel value 是代表「資料結束」的特殊值。例如成績合法範圍是 0 到 100，輸入 -1 結束就很合理，因為 -1 不會和正常成績混淆。

Sentinel Pattern

int value = input.nextInt();   // priming read

while (value != -1)
{
    System.out.println("Read: " + value);
    value = input.nextInt();   // read next value
}
輸入 是否進 body？ 處理結果
5是印 5，讀下一筆
8是印 8，讀下一筆
3是印 3，讀下一筆
-1否停止；sentinel 本身不處理

Priming read 是 loop 前先讀第一筆，因為 while 必須先有值才能判斷是否進入 loop。

Input Validation

Input validation 通常寫成：不合法就繼續問

如果合法分數是 0 到 100，合法 condition 是 score >= 0 && score <= 100。要「不合法時重問」，所以 while condition 應該寫反： score < 0 || score > 100。

While Invalid

System.out.print("Enter score: ");
int score = input.nextInt();

while (score < 0 || score > 100)
{
    System.out.println("Invalid score.");
    System.out.print("Enter score again: ");
    score = input.nextInt();
}

System.out.println("Accepted: " + score);
目的 Condition 意思
valid scorescore >= 0 && score <= 100分數在範圍內。
invalid scorescore < 0 || score > 100分數超出任一邊界。
while invalidwhile (score < 0 || score > 100)不合法就繼續要求輸入。

Infinite Loops

判斷 infinite loop：控制 condition 的值有沒有往 false 前進？

錯誤類型 例子 為什麼不會停
忘記 update while (i < 10) { System.out.println(i); } i 永遠不變。
update direction 錯 while (i < 10) { i--; } i 越來越小，離 false 更遠。
update 不一定執行 while (x < 10) { if (x % 2 == 0) { x++; } } 若 x 一開始是奇數，x++ 不會發生。
多一個 semicolon while (x < 5); loop body 變成 empty statement。

檢查 while 的兩句話：condition 裡的變數有改嗎？改變方向會讓 condition 最後變 false 嗎？

Digit Algorithms

處理整數每一位 digit：% 10 取得，/= 10 移除

取得最右 digit

int digit = number % 10;

移除最右 digit

number /= 10;

Preserve original

如果後面還需要原數字，先寫 int temp = number;。

Sum Digits

int number = 58321;
int sum = 0;

while (number > 0)
{
    int digit = number % 10;
    sum += digit;
    number /= 10;
}

sum 是 5 + 8 + 3 + 2 + 1 = 19。

Count Digits

int number = 58321;
int count = 0;

while (number > 0)
{
    count++;
    number /= 10;
}

count 是 5。若 number 可能是 0，要另外處理。

Reverse Number

int number = 58321;
int reversed = 0;

while (number > 0)
{
    int digit = number % 10;
    reversed = reversed * 10 + digit;
    number /= 10;
}

reversed * 10 + digit 把新 digit 接到結果右側。

Boolean Flags

Boolean flag 可以控制「找到就停」或「還沒達成就繼續」

Search Until Found

int number = 7421;
boolean found = false;

while (number > 0 && !found)
{
    int digit = number % 10;

    if (digit == 7)
    {
        found = true;
    }

    number /= 10;
}

這個 condition 使用 Lesson 8 的 short-circuit 思想：number > 0 且 !found 都成立時才繼續。找到 7 後，found 變 true， 下一輪 !found 是 false，loop 停止。
