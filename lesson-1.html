Big Picture

從問題到程式：電腦科學不是先從語法開始

在學 Java 之前，我們先把三個名詞分清楚。Problem 是我們想解決的事情， Algorithm 是解決問題的一系列清楚步驟，Program 則是把演算法用程式語言寫出來， 讓電腦能夠執行。

概念 意思 例子
Problem 想解決的事情 找出兩個數字中較大的數字
Algorithm 解決問題的步驟 比較 A 與 B，選出較大者
Program 用程式語言實作演算法 使用 Java 的 if 寫出比較邏輯

因此，一段 Java 程式不是從空中掉下來的答案。它通常來自這條路徑：

Problem Algorithm Source Code Program Output

AP CSA 很常考的不是「你有沒有背過某個語法」，而是你能不能讀懂一段程式、追蹤它的狀態， 並判斷最後輸出或變數值會是什麼。

Java Flow

Java 如何把文字變成執行結果

我們在編輯器裡寫的 Java 程式稱為 source code。電腦不會直接把這些文字當成機器指令執行。 Java 會先透過 compiler 檢查語法與型別，產生 bytecode，最後由 JVM 執行。

Compiler

檢查程式碼是否符合 Java 語法與型別規則。少分號、型別不合、大小寫錯誤，都可能在這裡被抓出來。

JVM

JVM 是 Java Virtual Machine，負責執行編譯後的 bytecode，最後產生我們看到的 output。

First Program

第一個完整 Java 程式

在線上 Java 執行器中，最常見的起手式是 public class Main。現在不需要一次理解每個關鍵字， 先記住：程式從 main 方法開始執行，我們的第一批指令會寫在它的大括號裡。

Hello World

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
程式片段 現在需要理解的意思
public class Main 建立一個名為 Main 的 class。線上 Java 執行器通常要求 class 名稱是 Main。
public static void main(String[] args) Java 程式開始執行的位置。第一階段先把它當作固定入口。
{ } 大括號包住一段程式區塊；我們目前的 statements 會寫在 main 的大括號裡。
; 大部分 Java statement 的結尾。少了分號通常會造成 compile-time error。

System.out.println() 會輸出內容並換行。大部分 Java statement 的最後都需要分號。 如果少了分號，程式在 compiler 階段就會停下來。

第一堂課最重要的習慣：不要急著按 Run。先預測 output，再執行，再比較你的預測與真實結果。

Variables and Types

變數：有名字、有型別、能存 value 的位置

Variable 可以想成一個有名字的儲存位置。Java 是 strongly typed language，建立變數時要說清楚它能存哪一種資料。 

int age = 18;

int 是資料型別，age 是變數名稱，18 是存進去的 value。

概念 範例 重點
Declaration int score; 建立變數名稱與型別，但還沒有可讀取的 value。
Initialization int score = 80; 第一次把 value 放進變數。
Assignment score = 90; 把右邊 expression 的結果存進左邊變數。
Reassignment score = 100; 變數已經有值之後，再用新的 value 取代舊的 value。

Data type 和 data structure 不一樣。Data type 描述單一資料的種類，例如 int、double、boolean、String； data structure 則描述多個資料如何被組織，例如之後會學的 array、ArrayList、2D array。

Type 可以存什麼 範例 AP CSA 提醒
int 整數 5, -3, 100 int 不能直接存 3.14
double 小數或可轉成小數的整數 3.14, 5.0, 5 double x = 5; 合法，結果是 5.0
boolean 真或假 true, false Java 不用 1 或 0 表示 boolean
String 文字 "Hello", "5" String 不是 primitive type

變數名稱稱為 identifier。AP CSA 題目通常使用 Java 命名慣例 camelCase， 例如 studentAge、averageScore、numberOfStudents。 變數名稱不能用數字開頭，也不能使用 Java keyword，例如 class。

Variables Demo

public class Main {
    public static void main(String[] args) {
        int age = 18;
        double height = 175.5;
        boolean isStudent = true;
        String name = "Alex";

        System.out.println(name);
        System.out.println(age);
        System.out.println(height);
        System.out.println(isStudent);
    }
}

Assignment

= 在 Java 裡不是數學等號

在 Java 中，= 是 assignment operator。它的意思不是「左右永遠相等」，而是 先算右邊，再把結果存進左邊。

x = x + 1

public class Main {
    public static void main(String[] args) {
        int x = 5;
        System.out.println(x);

        x = x + 1;
        System.out.println(x);
    }
}

執行 x = x + 1; 時，Java 先讀取舊的 x，算出 5 + 1，得到 6， 再把 6 存回 x。這個思考方式會一路出現在 loops、arrays、FRQ 裡。

Primitive variable 的 copy 也要注意。int b = a; 是把 a 當下的 value 複製給 b， 之後 a 改變，不會自動改變 b。

Arithmetic

運算式與優先順序

Expression 是可以被計算出一個 value 的程式片段。AP CSA 中常見的 arithmetic operators 有 +、-、*、/、%。優先順序大致和數學相同：先括號，再乘除與餘數，最後加減。

Expression 計算方式 Result
2 + 3 * 4 先 3 * 4，再加 2 14
(2 + 3) * 4 括號先算 20
10 - 3 - 2 同優先順序由左到右 5
20 / 5 * 2 / 與 * 同優先順序，由左到右 8

Division and Modulo

整數除法與餘數：AP CSA 的高頻陷阱

如果除法的兩邊都是 int，Java 會做 integer division，結果仍然是 int。 小數部分會被直接移除，不是四捨五入。

Code Result 原因
5 / 2 2 int / int
5.0 / 2 2.5 其中一邊是 double
double x = 5 / 2; 2.0 右邊先做 integer division，再存進 double
5 / 2 + 0.0 2.0 5 / 2 先變 2

% 是 modulo operator，意思是取餘數，不是百分比。它很常用來判斷奇偶數或拆解數字。

Digit Decomposition

public class Main {
    public static void main(String[] args) {
        int number = 583;

        int hundreds = number / 100;
        int tens = (number / 10) % 10;
        int ones = number % 10;

        System.out.println("Hundreds: " + hundreds);
        System.out.println("Tens: " + tens);
        System.out.println("Ones: " + ones);
    }
}

Output and Strings

print、println 與字串串接

println() 會輸出後換行，print() 不會自動換行。當 + 遇到 String 時， 它可能不再是數學加法，而是 string concatenation。

Concatenation Traps

public class Main {
    public static void main(String[] args) {
        System.out.println("Result: " + 2 + 3);
        System.out.println(2 + 3 + " Result");
        System.out.println("Result: " + (2 + 3));
        System.out.println("A" + 2 * 3 + 4);
    }
}

第一行會印出 Result: 23，因為 Java 從左到右先把 "Result: " + 2 變成文字。 第三行用括號讓 2 + 3 先做數學加法，所以才會印出 Result: 5。

Errors

錯誤不是結束，是下一步線索

初學 Java 一定會遇到錯誤。好的程式設計者不是不犯錯，而是能快速判斷錯誤類型，知道下一步該看哪裡。

Error Type 意思 例子
Compile-time Error 編譯前就不通過 少分號、int x = "Hello";
Runtime Error 可以編譯，但執行中出錯 之後學 array 時取不存在的位置
Logic Error 可執行但答案錯 面積應該乘法，卻寫成加法

Intentional Compile Error

public class Main {
    public static void main(String[] args) {
        int score = 85
        System.out.println("Score: " + score);
    }
}

除錯順序：先看 line number，再看該行與上一行，接著找分號、括號、引號、大小寫與型別。

Question A

int a = 7;
int b = 2;
double result = a / b;

result 儲存的值是多少？

A. 3　B. 3.0　C. 3.5　D. 4.0

Question B

輸出結果是什麼？

A. Value: 7　B. Value: 34　C. 7　D. 34

System.out.println((number / 10) % 10);

輸出結果是什麼？

A. 6　B. 4　C. 7　D. 64

Answers

練習答案與本課總結

AP-style answers

Question A：B。a / b 先做 int / int，得到 3，再存進 double，所以是 3.0。

Question B：B。字串先出現後，後面的 3 與 4 會被串接成文字。

Question C：B。647 / 10 得到 64，64 % 10 得到 4。

Variable有名稱、有型別、可以存 value 的位置。
Declarationint score; 建立名稱與型別，但尚未放入可讀取的值。
Assignment永遠先算右邊，再存進左邊。
Integer Division5 / 2 得到 2，不是 2.5。
Modulo583 % 10 可以取得個位數 3。
Naming使用 camelCase，不能用數字開頭，也不能使用 Java keyword。
String Concatenation"A" + 2 + 3 得到 A23。
Error Reading先看行號，再看分號、括號、引號、大小寫與型別。
