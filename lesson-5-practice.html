A. Concepts

名詞與觀念

先確認 String 的 type、literal、constructor 與 char 差異。

Q1Reference Type

String 是 primitive type 嗎？

不是。String 是 class / reference type。String name = "Alice"; 中的 name 是 reference variable。

Q2Literal

String literal 使用單引號還是雙引號？

使用雙引號，例如 "Hello"。單引號用於 char，例如 'A'。

Q3char vs String

'A' 和 "A" 有什麼不同？

'A' 是 char，使用單引號。"A" 是 String，使用雙引號。即使只有一個字元，"A" 仍是 String。

Q4Import

使用 String 需要 import java.lang.String; 嗎？

不需要。String 位於 java.lang，而 java.lang 中的 classes 預設可直接使用。

Q5Constructor

哪一行使用 constructor 建立 String object？

A. String a = "cat"; B. String b = new String("cat"); C. char c = 'c'; D. int x = 5;

答案是 B。new String("cat") 是 Lesson 4 中學過的 constructor call。

B. Index and length

Index 與 length()

每題都先標 index。第一個 index 是 0，最後 index 是 length() - 1。

Q6Index

"computer" 的最後一個合法 index 是多少？

"computer" 長度是 8，最後 index 是 8 - 1 = 7。

Q7length

預測 output。

String s = "AP CSA";
System.out.println(s.length());

Output 是 6。中間的 space 是一個 character。

Q8Empty String

預測 output。

String s = "";
System.out.println(s.length());

Output 是 0。"" 是 empty string，是存在的 String object，只是長度為 0。

Q9Syntax

word.length 和 word.length() 哪個是本課正確 method call？

word.length()。length() 是 method，所以需要 parentheses。

Q10null

null、""、" " 的 length() 差異是什麼？

null 沒有 String object，呼叫 length() 會 error。"" 長度是 0。" " 有一個 space，長度是 1。

C. substring

substring()

看到 substring(a, b) 就寫 a <= index < b。

Q11substring

預測 output。

String str = "computer";
System.out.println(str.substring(2, 6));
A. mpu B. mput C. mpute D. ompu

答案是 B。substring(2, 6) 取 index 2、3、4、5，也就是 "mput"。

Q12substring

"abcdef".substring(2) 的結果是什麼？

結果是 "cdef"。index 2 是 c，substring(2) 從 index 2 取到最後。

Q13Empty String

"abcdef".substring(2, 2) 的結果是什麼？

結果是 ""。start 和 end 相同，沒有任何 character 被取出，但這是合法的。

Q14Empty String

"abcdef".substring(6) 的結果是什麼？

結果是 ""。6 == s.length()，從結尾取到結尾是合法 empty string。

Q15Runtime Error

"abcdef".substring(5, 7) 會發生什麼？

Runtime error，可能是 StringIndexOutOfBoundsException。因為 length 是 6，但 ending index 7 超出 length()。

Q16Single Character

使用 substring 取得 String word = "computer"; 中 index 4 的單一字元 String。

寫 word.substring(4, 5)，結果是 "u"。注意回傳 type 是 String，不是 char。

Q17Last Character

如何取得 String s 的最後一個 character 所形成的 String？

可以寫 s.substring(s.length() - 1)，或 s.substring(s.length() - 1, s.length())。

Q18Formula

substring(from, to) 的合法條件是什麼？

0 <= from <= to <= s.length()。注意 to 可以等於 length()，因為 to 是停止位置，不是最後一個被取出的 index。

D. indexOf

indexOf()

只回傳第一次出現的位置，找不到回傳 -1。

Q19indexOf

預測 output。

String str = "banana";
System.out.println(str.indexOf("na"));
A. 1 B. 2 C. 3 D. 4

答案是 B。"na" 第一次從 index 2 開始。

Q20Not Found

"banana".indexOf("x") 的結果是什麼？

結果是 -1。找不到時不是 0，因為 0 表示從第一個位置就找到。

Q21First Occurrence

"banana".indexOf("a") 為什麼不是 3 或 5？

indexOf() 只回傳第一次出現的位置。"a" 第一次出現在 index 1。

Q22Case Sensitive

"Computer".indexOf("com") 的結果是什麼？

結果是 -1。indexOf() 是 case-sensitive，"C" 和 "c" 不同。

Q23Space

"AP CSA".indexOf(" ") 的結果是什麼？

結果是 2。space 也是 String 的一部分。

Q24indexOf + substring

預測 output。

String email = "student@example.com";
int at = email.indexOf("@");
System.out.println(email.substring(0, at));

Output 是 student。at 是 7，substring(0, 7) 不包含 index 7 的 @。

E. Comparison

equals()、==、compareTo()

比較文字內容用 equals()；比較 references 是否同一個 object 才是 ==。

Q25equals

"hello".equals("Hello") 的結果是什麼？

結果是 false。equals() 是 case-sensitive。

Q26== vs equals

預測 output。

String a = new String("AP");
String b = new String("AP");

System.out.println(a == b);
System.out.println(a.equals(b));
A. true true B. true false C. false true D. false false

答案是 C。兩次 new 建立兩個不同 objects，所以 a == b 是 false；內容相同，所以 a.equals(b) 是 true。

Q27compareTo

下列何者一定正確？

String a = "apple";
String b = "banana";
int result = a.compareTo(b);
A. result == -1 B. result < 0 C. result > 0 D. result == 1

答案是 B。"apple" 排在 "banana" 前面，所以結果是 negative。不要假設一定是 -1。

Q28compareTo

預測 output。

String a = "dog";
String b = "cat";
System.out.println(a.compareTo(b) > 0);

Output 是 true。"dog" 排在 "cat" 後面，所以 compareTo() 回傳正數。

Q29compareTo

"car".compareTo("card") 的結果應該判斷成什麼？

結果是 negative，也就是 < 0。"car" 是 "card" 的 prefix，較短的 String 排在前面。

Q30null

這段程式會發生什麼？

String s = null;
System.out.println(s.equals("hello"));

會造成 NullPointerException。s 是 null，沒有 String object 可以呼叫 equals()。

F. Concatenation and Immutability

String Concatenation 與 Immutability

注意 + 的左到右 evaluation，以及 String method 不會修改原 String object。

Q31Concatenation

預測 output。

System.out.println("Result: " + 2 + 3);

Output 是 Result: 23。String 先出現，所以後面的 2 和 3 依序做 concatenation。

Q32Concatenation

預測 output。

System.out.println(2 + 3 + "4");

Output 是 54。先做 2 + 3 = 5，再和 "4" 串接。

Q33Concatenation

"A" + (1 + 2) 的結果是什麼？

結果是 "A3"。parentheses 讓 1 + 2 先做 numeric addition。

Q34Immutability

預測 output。

String s = "hello";

s.substring(1);

System.out.println(s);

Output 是 hello。String 是 immutable，substring(1) 回傳新的 String result，但沒有被保存。

Q35Immutability

預測 output。

String s = "hello";

s = s.substring(1);

System.out.println(s);

Output 是 ello。這次 return value 被 assignment 回 s。

Q36+=

s += "!" 是否代表原本的 String object 被修改？

不是。可以把它想成 s = s + "!"。它會產生新的 String result，然後讓 s reference 到新的結果。

G. Errors and AP Tracing

錯誤與 AP-style Tracing

每次產生新的 String，都要重新標 index。

Q37Runtime Error

這段程式會發生什麼？

String s = "cat";
System.out.println(s.substring(0, 4));

Runtime error，可能是 StringIndexOutOfBoundsException。s.length() 是 3，但 ending index 4 超出範圍。

Q38Compile Error

String s = 10; 是哪一種錯誤？

Compile-time error。10 是 int value，不能直接存進 String variable。

Q39Logic Error

如果想取前三個 characters，這行哪裡錯？

String s = "computer";
String firstThree = s.substring(0, 2);

這是 logic / off-by-one error。substring(0, 2) 只取 index 0、1，得到 "co"。前三個應寫 substring(0, 3)。

Q40Method Chaining

預測 output。

String s = "banana";
System.out.println(s.substring(2).indexOf("a"));

Output 是 1。s.substring(2) 得到 "nana"，新的 String index 從 0 開始，第一個 "a" 在 index 1。

Q41Tracing

完整 trace，預測三行 output。

String str = "mississippi";

int a = str.indexOf("iss");
String b = str.substring(a, a + 4);
int c = b.length();

System.out.println(a);
System.out.println(b);
System.out.println(c);
1
issi
4

"iss" 第一次從 index 1 開始。substring(1, 5) 得到 "issi"，長度是 4。

Q42Re-index

預測 output。

String s = "abcdefgh";

s = s.substring(2, 7);
s = s.substring(1, s.length() - 1);

System.out.println(s);

第一行得到 "cdefg"。重新標 index 後，s.length() 是 5，第二行是 substring(1, 4)，得到 "def"。

Q43AP-style

預測 output。

String s = "AP CSA";

int x = s.indexOf("C");
String result = s.substring(x);

System.out.println(result);

"C" 在 index 3，所以 s.substring(3) 得到 CSA。

Q44AP-style

預測 output。

String s = "abcdefgh";

int x = s.length() / 2;

System.out.println(s.substring(0, x));

s.length() 是 8，所以 x = 4。substring(0, 4) 得到 abcd。

Q45Coding

取得姓名縮寫

設定 String firstName = "Alice"; String lastName = "Brown";，輸出 AB。

public class Main {
    public static void main(String[] args) {
        String firstName = "Alice";
        String lastName = "Brown";

        String initials = firstName.substring(0, 1)
                        + lastName.substring(0, 1);

        System.out.println(initials);
    }
}
Q46Coding

取 Email Username

設定 String email = "student@example.com";，輸出 student。

public class Main {
    public static void main(String[] args) {
        String email = "student@example.com";

        int at = email.indexOf("@");
        String username = email.substring(0, at);

        System.out.println(username);
    }
}

substring(0, at) 不包含 @。

Q47Coding

取副檔名

設定 String file = "report.pdf";，輸出 pdf。

public class Main {
    public static void main(String[] args) {
        String file = "report.pdf";

        int dot = file.indexOf(".");
        String extension = file.substring(dot + 1);

        System.out.println(extension);
    }
}
Q48Coding

取前後字元

設定 String word = "computer";，輸出第一個和最後一個 character 組成的 String：cr。

public class Main {
    public static void main(String[] args) {
        String word = "computer";

        String first = word.substring(0, 1);
        String last = word.substring(word.length() - 1);

        System.out.println(first + last);
    }
}
Q49Challenge Trace

預測三行 output。

String s = "APComputerScience";

int x = s.indexOf("Computer");
String a = s.substring(x);
String b = a.substring(0, a.indexOf("Science"));

System.out.println(x);
System.out.println(a);
System.out.println(b);
2
ComputerScience
Computer

"Computer" 從 index 2 開始。a 是 "ComputerScience"。重新標 index 後，"Science" 從 index 8 開始，所以 a.substring(0, 8) 是 "Computer"。

Q50Final Challenge

完整綜合考題，預測 output。

String s = "programming";

String a = s.substring(0, 4);
String b = s.substring(4);
int c = b.indexOf("m");
boolean d = a.equals("prog");
int e = a.compareTo("test");

System.out.println(a);
System.out.println(b);
System.out.println(c);
System.out.println(d);
System.out.println(e < 0);
prog
ramming
2
true
true

a 是 "prog"。b 是 "ramming"，其中第一個 "m" 在 index 2。a.equals("prog") 是 true。"prog" 排在 "test" 前面，所以 e < 0 是 true。
