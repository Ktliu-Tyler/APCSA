ArrayList：可變長度的 List 與常用 Methods

Array 的長度固定，insert/remove 只能靠搬動與 logical size 模擬。ArrayList 提供可變長度的 list，能直接 add、remove，但也帶來新的規則： 使用 generic type、只能存 object type、用 size() 而不是 .length。

ArrayList tracing checklist

Why ArrayList

Array 長度固定，ArrayList 長度可變

Array 一旦建立，.length 就固定。若資料數量會改變，ArrayList 讓你直接加入或移除元素，list 會調整自己的 size。

Array

String[] names = new String[3];
names[0] = "Amy";

長度固定，用 [] 存取，用 .length。

ArrayList

ArrayList<String> names = new ArrayList<String>();
names.add("Amy");

長度可變，用 methods 存取，用 size()。

Create ArrayList

使用 ArrayList 前要 import

create ArrayList 
import java.util.ArrayList;

public class Demo
{
    public static void main(String[] args)
    {
        ArrayList<String> names = new ArrayList<String>();
        names.add("Amy");
        names.add("Ben");
        System.out.println(names);
    }
}

AP CSA 常見寫法是 new ArrayList<String>()。Java 也允許 diamond operator new ArrayList<>()，但課堂上先用完整型別比較清楚。

Generic Type

ArrayList<E> 的 E 代表元素型別

ArrayList<String> 表示 list 中每個元素都應該是 String。 ArrayList<Student> 表示每個元素是 Student reference。

generic type examples 
ArrayList<String> words = new ArrayList<String>();
ArrayList<Student> roster = new ArrayList<Student>();
ArrayList<Integer> scores = new ArrayList<Integer>();
Generic type 不能是 primitive。 不能寫 ArrayList<int>；要寫 ArrayList<Integer>。

Wrapper Classes

Primitive 要放進 ArrayList 時，使用 wrapper class

ArrayList 只能存 object reference。Java 提供 wrapper classes 讓 primitive values 可以被當作 objects 使用。

PrimitiveWrapper ClassArrayList 寫法
intIntegerArrayList<Integer>
doubleDoubleArrayList<Double>
booleanBooleanArrayList<Boolean>

Autoboxing 讓 scores.add(90); 自動把 int 包成 Integer； unboxing 讓 int score = scores.get(0); 自動取出 primitive value。

Core Methods

AP CSA ArrayList 必熟 methods

Method效果回傳值
size()取得目前元素數量int

add(index, obj)插入指定 index，原本元素右移void
get(index)取得指定 index 元素元素型別
set(index, obj)取代指定 index 元素被取代的舊元素
remove(index)移除指定 index 元素，後面左移被移除的元素

add

add 可以加到尾端，也可以插入中間

add examples 
ArrayList<String> names = new ArrayList<String>();
names.add("Amy");          // [Amy]
names.add("Cara");         // [Amy, Cara]
names.add(1, "Ben");       // [Amy, Ben, Cara]

add(index, obj) 會把原本位於該 index 和後面的元素往右移。合法插入 index 可以是 0 到 size()，其中 size() 表示插到最後。

get / set

get 讀取元素，set 取代元素

get and set 
ArrayList<String> names = new ArrayList<String>();
names.add("Amy");
names.add("Ben");

String first = names.get(0);          // Amy
String old = names.set(1, "Cara");    // old is Ben

System.out.println(names);            // [Amy, Cara]

set 不會改變 size，只是用新元素取代舊元素。

remove

remove(index) 會刪除並回傳舊元素

remove example 
ArrayList<String> names = new ArrayList<String>();
names.add("Amy");
names.add("Ben");
names.add("Cara");

String removed = names.remove(1); // removed is Ben
System.out.println(names);        // [Amy, Cara]

移除後，右邊的元素會往左移，size 減少 1。

Index Shift

新增或移除中間元素時，後面元素 index 會改變

這是 ArrayList 題目最常考的 trace。每次 add(index,...) 或 remove(index) 後，都要重新寫出 list。

index shift trace 
ArrayList<String> words = new ArrayList<String>();
words.add("A");
words.add("C");
words.add(1, "B");     // [A, B, C]
words.remove(0);       // [B, C]
words.set(1, "D");     // [B, D]

Traversal

ArrayList traversal 使用 size() 和 get(i)

ArrayList traversal 
for (int i = 0; i < names.size(); i++)
{
    System.out.println(names.get(i));
}

for (String name : names)
{
    System.out.println(name);
}

只讀每個元素可用 enhanced for。若需要 index、呼叫 set、或之後要移除元素， traditional for 更清楚。移除 while looping 的細節會在 Lesson 20 深入。

考前必背十二句

ArrayList is in java.util.

ArrayList size can change.

Use size(), not .length.

Use get(index), not brackets.

Use set(index, obj) to replace an element.

set does not change size.

add(obj) adds at the end.

add(index, obj) shifts elements right.

remove(index) shifts elements left.

Generic type must be a reference type.

Use Integer, not int, in ArrayList.

Re-trace indexes after every add or remove.
