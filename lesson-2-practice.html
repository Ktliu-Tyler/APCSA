A. Concepts

名詞與觀念

這一區確認你是否理解 assignment、initialization、RHS/LHS 與型別相容。

Q1Assignment

請排出 assignment 的正確執行順序。

Store in LHS、Check type、Evaluate RHS、Produce value

正確順序是 Evaluate RHS → Produce value → Check type → Store in LHS。Java 會先把右邊 expression 算完，確認結果能放進左邊變數，再完成 assignment。

Q2Vocabulary

請把三個名詞配對到正確意思。

Declaration?
Initialization?
Reassignment?

選項：建立變數名稱與型別、第一次給 value、之後再次修改 value。

Declaration 是建立變數名稱與型別。Initialization 是第一次給 value。Reassignment 是把新的 value 存進已存在的變數。

Q3Compile-time Error

這段程式的問題是什麼？

int x;
System.out.println(x);

這是 compile-time error。Local variable x 已經宣告，但尚未初始化。Java 不能讀取一個沒有 value 的 local variable。

Q4RHS/LHS

在 x = y + 5; 中，哪一邊是 RHS？哪一邊是 LHS？

x 是 LHS，也就是要被存入的 destination。y + 5 是 RHS，也就是會先被計算的 expression。

Q5Type

下列哪一行是合法 Java？

A. int x = 5.5; B. double y = 5; C. boolean ok = 1; D. int z = "7";

答案是 B。int value 可以自動 widening 成 double。A 是把 double 放進 int；C 的 boolean 不能用 1；D 是把 String 放進 int。

Q6Input

為什麼 int age = input.nextInt(); 也是 assignment？

右邊的 input.nextInt() 會讀取 input 並產生一個 int value。接著這個 value 被存進左邊的 age。所以它仍然符合「先算右邊，再存左邊」。

B. Assignment Trace

逐行追蹤

先不要執行。請在紙上或腦中建立 trace table，再點開詳解。

Q7Trace

最後 x 是多少？

int x = 5;
x = x + 4;
x = x * 2;

答案是 18。初始 x = 5。第一個 reassignment 讓 x 變成 9。第二行使用新的 9，所以 9 * 2 = 18。

Q8Copy

預測 output。

int a = 5;
int b = a;
a = 10;
System.out.println(a);
System.out.println(b);
10
5

int b = a; 是把 a 當下的 value 複製給 b。之後 a 變成 10，b 不會跟著變。

Q9Trace

最後 x 與 y 是多少？

int x = 4;
int y = 2;
x = x + y;
y = x * 2;
x = y - x;

初始 x = 4、y = 2。執行 x = x + y; 後 x = 6。執行 y = x * 2; 時使用新的 x，所以 y = 12。最後 x = 12 - 6，所以 x = 6。最後 x = 6、y = 12。

Q10Precedence

最後 x 是多少？

int x = 5;
int y = 3;
x = x + y * 2;

答案是 11。右邊先遵守 operator precedence：y * 2 是 3 * 2 = 6，再做 x + 6，也就是 5 + 6 = 11。

Q11Trace

預測 output。

int x = 10;
x = x - 4;
x = x / 3;
x = x + 8;
System.out.println(x);
10

x 先從 10 變 6。接著 6 / 3 得到 2。最後 2 + 8 得到 10。

Q12Trace

這段程式是否成功交換 a 與 b？

int a = 3;
int b = 8;
a = b;
b = a;

沒有。執行 a = b; 後，a 變成 8，原本的 3 已經不在 a 裡。接著 b = a; 只是把 8 存進 b。最後 a = 8、b = 8。

Q13Trace Table

預測 output。

int x = 10;
int y = 4;
x += y;
y = x / y;
x %= 5;
y++;
System.out.println(x);
System.out.println(y);
4
4

初始 x = 10、y = 4。x += y 後 x = 14。y = x / y 是 14 / 4，integer division 得到 3。x %= 5 是 14 % 5，得到 4。最後 y++ 讓 y 變 4。

C. Scanner Input

輸入與 Scanner

這一區檢查 Scanner 的基本架構，以及 input 如何變成 variable value。

Q14Scanner

如果要使用 Scanner，程式最前面通常需要哪一行？

A. import java.util.Scanner; B. new java.Scanner; C. include Scanner; D. Scanner.import();

答案是 A。Scanner 在 java.util package 裡，所以要使用 import java.util.Scanner;。

Q15Scanner

哪一行會建立從 keyboard 讀取資料的 Scanner？

A. Scanner input = new Scanner(System.in); B. Scanner input = System.out; C. int input = new Scanner(); D. input.Scanner(System.in);

答案是 A。System.in 代表標準輸入，常見情況就是鍵盤輸入。input 是這個 Scanner 物件的變數名稱。

Q16nextInt

如果使用者輸入 18，最後 output 是什麼？

System.out.print("Age: ");
int age = input.nextInt();
System.out.println(age + 2);
Age: 20

print 不換行，接著 input 讀到 18。age + 2 是數字加法，得到 20。許多線上執行器會把 prompt 與輸入顯示在同一行。

Q17nextDouble

讀取身高 175.5 時，應該使用哪個 method？

A. nextInt() B. nextDouble() C. nextBoolean() D. println()

答案是 B。175.5 是 double value，所以用 nextDouble() 讀取。

Q18Input Type

如果程式執行 input.nextInt()，但輸入是 Hello，最合理的結果是什麼？

nextInt() 期待讀到可以解析成 int 的 input。Hello 不是整數，因此程式在執行讀取時會出錯。重點是 input method 與輸入資料型態要符合。

D. Casting and Rounding

Casting、整數除法與四捨五入

這一區是 AP CSA 常考陷阱。請特別注意運算順序與 casting 位置。

Q19Casting

(int) 9.8 的結果是什麼？

答案是 9。(int) 會 truncate toward zero，移除小數點右側，不會四捨五入。

Q20Negative Casting

(int) -9.8 的結果是什麼？

答案是 -9。Casting 不是 floor。它會朝 0 截掉小數部分，所以 -9.8 變成 -9，不是 -10。

Q21Integer Division

double x = 7 / 2; 中，x 是多少？

x 是 3.0。右邊先做 int / int，7 / 2 得到 3，接著才存入 double 變成 3.0。

Q22Casting Position

double x = (double) 7 / 2; 中，x 是多少？

x 是 3.5。(double) 7 先變成 7.0，接著 7.0 / 2 做 double division。

Q23Casting Position

double x = (double) (7 / 2); 中，x 是多少？

x 是 3.0。括號裡的 7 / 2 先做 integer division，得到 3。之後再 cast 成 double，所以是 3.0。

Q24Average

哪兩種寫法能得到真正的小數平均？

int score1 = 80;
int score2 = 90;
int score3 = 95;

可以寫 double avg = (score1 + score2 + score3) / 3.0;，或 double avg = (double) (score1 + score2 + score3) / 3;。重點是 division 發生前，至少一邊要是 double。

Q25Widening

double x = 5; 為什麼合法？

這是 automatic widening。int value 5 可以安全轉成 double value 5.0，不會失去數值資訊。

Q26Narrowing

int x = 5.8; 為什麼不合法？如何修正？

5.8 是 double。把 double 放進 int 會失去小數資訊，Java 不會自動 narrowing。可以寫 int x = (int) 5.8;，此時 x 是 5。

Q27Rounding

double x = 4.8;，用哪個 expression 可以四捨五入成 5？

使用 (int) (x + 0.5)。先得到 5.3，再 cast 成 5。

Q28Rounding

double x = -4.8;，用哪個 expression 可以四捨五入成 -5？

使用 (int) (x - 0.5)。先得到 -5.3，再 truncate toward zero 成 -5。

E. Range and Precision

數值範圍與精度

這一區檢查 int range、integer overflow 與 double round-off error。

Q29int Range

Java int 的最大值可以用哪個 constant 取得？

使用 Integer.MAX_VALUE。最小值則是 Integer.MIN_VALUE。

Q30Overflow

預測 output。

int x = Integer.MAX_VALUE;
x++;
System.out.println(x);
-2147483648

Integer.MAX_VALUE 是 2147483647。再加 1 超過 int range，發生 integer overflow，結果會繞到 Integer.MIN_VALUE。

Q31Overflow

這段程式為什麼危險？

int x = 1500000000;
int y = 2;
int result = x * y;

x 與 y 各自都在 int range 內，但 expression x * y 的數學結果是 3000000000，超過 Integer.MAX_VALUE。Overflow 是 expression 的結果超出範圍，不是只有單一變數本身超出才會發生。

Q32Error Type

Integer overflow 一定會造成 runtime error 嗎？

不一定。很多 int overflow 會讓程式繼續執行，但 value 已經不是數學上預期的結果。這就是它危險的地方：程式看起來沒有當場壞掉，但結果可能錯。

Q33Round-Off

為什麼 0.1 + 0.2 可能不是剛好 0.3？

double 使用有限的 binary bits 儲存小數。某些十進位小數，例如 0.1，無法用有限 binary representation 精確表示，所以計算後可能出現 0.30000000000000004 這類 round-off error。

F. Compound Assignment

簡寫更新

這一區練習 +=、/=、%=、x++ 與 x--。

Q34Compound

x += 5; 可以先理解成什麼？

可以先理解成 x = x + 5;。它會讀取舊的 x，加上 5，再把結果存回 x。

Q35Integer Division

預測 output。

int x = 5;
x /= 2;
System.out.println(x);
2

x /= 2; 對 int 來說可以先理解成 x = x / 2;。5 / 2 是 integer division，得到 2，不是 2.5。

Q36Modulo

預測 output。

int x = 17;
x %= 5;
System.out.println(x);
2

x %= 5; 可以理解成 x = x % 5;。17 % 5 的餘數是 2。

Q37Increment

預測 output。

int x = 4;
x++;
x--;
x++;
System.out.println(x);
5

x++ 讓 x 加 1，x-- 讓 x 減 1。Trace：4 → 5 → 4 → 5。

Q38Trace

最後 x 是多少？

int x = 5;
x += 3;
x *= 2;
x--;
x %= 4;

答案是 3。5 + 3 = 8，8 * 2 = 16，x-- 後變 15，最後 15 % 4 = 3。

Q39AP-style

What value is stored in total?

int total = 17;
total /= 5;
total += 4;
A. 3 B. 7 C. 7.4 D. 8

答案是 B。total /= 5 是 17 / 5，integer division 得到 3。接著 total += 4 得到 7。

Q40Coding

Temperature Converter

讀取攝氏溫度，使用公式 fahrenheit = celsius * 9.0 / 5 + 32，輸出華氏溫度。

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter Celsius: ");
        double celsius = input.nextDouble();

        double fahrenheit = celsius * 9.0 / 5 + 32;
        System.out.println("Fahrenheit: " + fahrenheit);
    }
}

使用 9.0 可以確保 division 使用 double calculation，不會被 integer division 影響。

Q41Coding

Average Calculator

讀取三個整數分數，輸出真正的小數平均。

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Score 1: ");
        int score1 = input.nextInt();

        System.out.print("Score 2: ");
        int score2 = input.nextInt();

        System.out.print("Score 3: ");
        int score3 = input.nextInt();

        double average = (score1 + score2 + score3) / 3.0;
        System.out.println("Average: " + average);
    }
}

重點是 / 3.0。如果寫成 / 3，右邊會先做 integer division，小數部分會消失。

Q42Coding

Seconds Converter

設定 int totalSeconds = 3725;，輸出 hours、minutes、seconds。

public class Main {
    public static void main(String[] args) {
        int totalSeconds = 3725;

        int hours = totalSeconds / 3600;
        int remaining = totalSeconds % 3600;
        int minutes = remaining / 60;
        int seconds = remaining % 60;

        System.out.println("Hours: " + hours);
        System.out.println("Minutes: " + minutes);
        System.out.println("Seconds: " + seconds);
    }
}

/ 用來取得完整的小時或分鐘數，% 用來取得剩下的秒數。3725 秒是 1 小時、2 分鐘、5 秒。

Q43Debugging

這段程式想得到 2.5，但 output 是 2.0。請修正。

int x = 5;
int y = 2;
double answer = x / y;
System.out.println(answer);

問題是右邊 x / y 是 int / int，先得到 2。可以改成 double answer = (double) x / y;，或 double answer = x / 2.0;。

Q44Debugging

這段程式能否 compile？如何修正？

double price = 19.99;
int wholePrice = price;

不能 compile。price 是 double，不能自動 narrowing 成 int。可以寫 int wholePrice = (int) price;，結果是 19。

Q45Final Challenge

完整 trace，預測四行 output。

int a = 17;
int b = 4;

double x = (double) a / b;

a %= b;
b += 2;
a *= b;
a++;

int y = (int) x;

System.out.println(a);
System.out.println(b);
System.out.println(x);
System.out.println(y);
7
6
4.25
4

x = (double) a / b 是 17.0 / 4，得到 4.25。a %= b 是 17 % 4，讓 a = 1。b += 2 讓 b = 6。a *= b 讓 a = 6，接著 a++ 變 7。最後 (int) x 把 4.25 truncate 成 4。
