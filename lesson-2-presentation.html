Assignment、Input、Casting 與數值範圍

今天會把變數與運算推進成 AP CSA 常考的 trace 題型：assignment 執行順序、 Scanner input、casting、rounding、integer overflow、double round-off 與 compound assignment。

Opening Question

x = x + 1; 為什麼在 Java 裡合法？

在數學方程式裡，x = x + 1 看起來不可能成立。但在程式裡，這是一個非常常見的更新操作。

先想一想

Java 會先讀左邊的 x，還是先計算右邊的 x + 1？

Assignment 會先計算右邊 expression，產生 value，再把結果存進左邊 variable。所以 x = x + 1; 是「把舊的 x 加 1 後存回 x」。

Mental Model

Assignment 的四步驟

Evaluate RHS Produce Value Check Type Store in LHS

RHS 是 Right-Hand Side，右邊要先算。LHS 是 Left-Hand Side，左邊是最後要存入的目的地。

x = y + 5; 會先取得 y 的 value，計算 y + 5，再把結果存進 x。出現在 RHS 的 y 不會因此被改變。

Declaration vs Initialization

宣告變數，不等於可以讀取它

Local variable 必須先有 value 才能被讀取。只寫 int x; 是 declaration； 它建立變數，但還沒有初始化。

Declaration

int score; 建立名稱與型別。

Initialization

int score = 80; 第一次給 value。

Reassignment

score = 90; 修改已存在的 variable。

Compile-time Error

沒有初始化的 local variable 不能使用

Uninitialized Variable

public class Main {
    public static void main(String[] args) {
        int x;
        int y = x + 5;

        System.out.println(y);
    }
}

x + 5 需要先讀取 x 的 value，但 x 還沒有初始化。這會在 compile-time 被抓到。

Sequential Execution

逐行執行：每一行都使用最新 value

Trace This

int x = 5;

x = x + 2;
x = x * 3;
x = x - 4;

初始 x = 5。第一行變 7，第二行使用新的 7 得到 21，第三行得到 17。

Copy Value

Primitive variable 不會永久連動

Copy or Link?

int a = 5;
int b = a;

a = 10;

System.out.println(a);
System.out.println(b);
10
5

int b = a; 只是把當下的 5 複製給 b。之後 a 變成 10，b 仍然是 5。

Compatible Types

Assignment 還要通過型別檢查

合法

int x = 5;

合法

double y = 5;

不合法

int z = 5.5;

int 可以安全放進 double，因為會變成 5.0。但 double 放進 int 可能失去小數部分，Java 不會自動做這件事。

Input

Input 讓程式使用外部資料

程式可以接收 keyboard、file、sensor、network 等資料。Java 入門時最常用 Scanner 讀取鍵盤輸入，讓 value 在執行時才進入程式。

Input Produce value Store in variable Use in calculation

Scanner Pattern

Scanner 的基本架構

Read an int

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter age: ");
        int age = input.nextInt();

        System.out.println("Age: " + age);
    }
}

nextInt() 讀取下一個整數。若要讀小數，使用 nextDouble()。讀到的 input value 會被 assignment 存入變數。

Input as Assignment

int age = input.nextInt(); 仍然是 assignment

input.nextInt() reads input produces int value stores in age

如果使用者輸入 18，這一行就像在執行 int age = 18;。

AP Focus on Input

AP CSA 對 input 的重點：資料如何進入變數

Input 不只可能來自 keyboard，也可能來自 file、sensor、device 或 network。 本課用 Scanner 練習 keyboard input，是為了看懂「外部資料 → value → variable → calculation」這條路徑。

nextInt()

讀取下一個可以解析成整數的 input，產生 int value。

nextDouble()

讀取下一個可以解析成小數的 input，產生 double value。

AP Reading

重點是 input method 產生什麼型別，以及這個 value 如何參與 expression。

Casting

Casting 是暫時改變 value 的型別

(int)把 numerical value 轉成 int
(double)把 numerical value 轉成 double
Wideningint 到 double 通常自動允許
Narrowingdouble 到 int 需要 explicit casting

Widening vs Narrowing

型別轉換不是都能自動發生

Conversion 是否自動允許 原因
int 到 double 可以 5 可以安全表示成 5.0。
double 到 int 不可以 5.8 放進 int 會失去小數資訊。
double 到 int with casting 可以 (int) 5.8 明確告訴 Java 你接受資訊被截掉。

看到 assignment 時先看 RHS 的型別，再看能不能放進 LHS。double x = 5; 合法；int x = 5.8; 不合法；int x = (int) 5.8; 合法但結果是 5。

Truncation

(int) 不是四捨五入

請先預測：

System.out.println((int) 3.9);
System.out.println((int) -3.9);
A. 4 and -4 B. 3 and -3 C. 3 and -4 D. Compile Error

答案是 B。(int) 會 truncate toward zero，直接移除小數部分。3.9 變 3，-3.9 變 -3。

Common Trap

(int) 也不是 floor function

正數時 (int) 和 floor 很容易看起來一樣；真正會暴露差異的是負數。

Expression Java Casting Math floor
(int) 3.9 3 3
(int) -3.9 -3 -4

AP 題目常用負數確認你是否真的知道 casting 是 truncate toward zero。

Casting and Division

Casting 的位置會改變結果

Compare

double a = (double) (7 / 2);
double b = (double) 7 / 2;

a 是 3.0，因為 7 / 2 先得到 3。b 是 3.5，因為 7 先變 7.0，再做 double division。

Average Calculation

平均值最常見的錯誤：小數太晚出現

Average

int score1 = 80;
int score2 = 90;
int score3 = 95;

double average = (score1 + score2 + score3) / 3;

右邊是 int / int，所以 265 / 3 先得到 88，最後才存進 double 成為 88.0。可以改成 / 3.0 或 (double) (score1 + score2 + score3) / 3。

Fixing Integer Division

正確平均值：讓 division 發生前出現 double

方法一

(score1 + score2 + score3) / 3.0

方法二

(double) (score1 + score2 + score3) / 3

容易錯

(double) ((score1 + score2 + score3) / 3)

第三個寫法會先在括號內做 int / int，小數部分已經消失，再 cast 成 double。Casting 不能把已經消失的小數救回來。

Rounding

用 casting 四捨五入：先加或減 0.5

x >= 0

(int) (x + 0.5)

x < 0

(int) (x - 0.5)

4.8 + 0.5 得到 5.3，再 cast 成 5。-4.8 - 0.5 得到 -5.3，再 cast 成 -5。

int Range

int 有固定範圍

Java 的 int 使用 32 bits。它不是可以放任意大的整數。

MinimumInteger.MIN_VALUE = -2147483648
MaximumInteger.MAX_VALUE = 2147483647
Overflowexpression 結果超過 range

Integer Overflow

Overflow 不一定會報錯

Overflow

int x = Integer.MAX_VALUE;

System.out.println(x);
x = x + 1;
System.out.println(x);
2147483647
-2147483648

程式可能繼續執行，但 value 已經不是數學上預期的結果。這是 logic risk，不一定是 runtime error。

Overflow in Expressions

變數本身合法，不代表 expression 安全

Multiplication Overflow

int x = 1500000000;
int y = 2;

int result = x * y;

x 和 y 都是合法 int，但 x * y 的數學結果是 3000000000，超過 Integer.MAX_VALUE。Overflow 看的是 expression result 是否超出範圍。

double Precision

double 也有精度限制

Round-Off

double result = 0.1 + 0.2;
System.out.println(result);

可能印出 0.30000000000000004。原因是某些十進位小數無法用有限 binary bits 精確表示，這稱為 floating-point round-off error。

Round-Off Meaning

這不是 Java 算錯，而是表示法有限

double 用有限的 binary bits 儲存 floating-point numbers。 有些十進位小數，例如 0.1，無法被有限二進位精確表示。

int

整數精確，但範圍有限；超出範圍可能 overflow。

double

可表示小數與較廣範圍數值，但可能有 tiny round-off error。

AP View

看懂為什麼 output 可能有很多尾數，而不是把它當成 syntax error。

Compound Assignment

簡寫更新：compound assignment

這些 operator 都是在讀取原本的 x，完成右邊運算，再把結果存回 x。

x += 5x = x + 5
x -= 3x = x - 3
x *= 2x = x * 2
x /= 2x = x / 2
x %= 3x = x % 3

Increment and Decrement

x++ 與 x--

x++ 可以先理解成 x = x + 1;。 x-- 可以先理解成 x = x - 1;。 之後在 for loop 裡會大量看到這種寫法。

目前先把 x++ 和 x-- 當成獨立 statement 使用，不需要先鑽研 int y = x++; 這種 evaluation-order 題型。

Trace Check

快速檢核：compound trace

int x = 5;

x += 3;
x *= 2;
x--;
x %= 4;

最後 x 是多少？

A. 0 B. 1 C. 2 D. 3

答案是 D。5 到 8，到 16，再 x-- 變 15，最後 15 % 4 得到 3。

AP-style Check

快速檢核：casting position

int a = 7;
int b = 3;

double result = (double) (a / b);

What value is stored in result?

A. 2 B. 2.0 C. 2.3333333333333335 D. 3.0

答案是 B。括號內 a / b 先做 int / int，7 / 3 得到 2，再 cast 成 2.0。

Misconceptions

本課最容易被 AP 題目利用的迷思

Assignment不是左右相等；永遠先算 RHS，再存入 LHS。
Casting(int) 不是 rounding，也不是 floor；它是 truncate toward zero。
Divisiondouble result = 5 / 2; 仍然先做 integer division。
Overflow不一定會 runtime error；可能只是得到錯的 int value。
Compound Assignmentx /= 2 仍然遵守 x 的型別規則。

Final Trace Challenge

綜合追蹤：casting、modulo、compound、increment

Final Challenge

int a = 17;
int b = 4;

double x = (double) a / b;

a %= b;
b += 2;
a *= b;
a++;

int y = (int) x;

x = 4.25。a %= b 讓 a = 1，b += 2 讓 b = 6，a *= b 讓 a = 6，a++ 讓 a = 7，y = (int) x 讓 y = 4。
