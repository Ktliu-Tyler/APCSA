A. Concepts

概念確認

先確認 array 的核心語言：固定長度、相同型別、0-based index、reference type。

Q1Definition

Array 是什麼？

Array 是一種儲存固定數量、相同資料型別元素的資料結構。

Q2Same Type

int[] nums = {3, 7, "hello"}; 合法嗎？

不合法。int[] 的每個 element 都必須是 int，不能放 String。

Q3Fixed Length

Array 建立後，length 可以直接改變嗎？

不可以。Array 長度固定。若需要不同大小，要建立新的 array；若需要可變長度，後面會學 ArrayList。

Q4Index

Java array 的第一個 index 是多少？

是 0。Java array 是 0-based indexing。

Q5Reference Type

int[] nums 中的 nums 直接存整排數字，還是存 reference？

nums 存的是 array object 的 reference。Array 是 reference type。

Q6Element Type

若 double[] data 是一個 array，data[2] 的型別是什麼？

data[2] 的型別是 double。data 是 double[]，單一元素是 double。

B. Declaration / Creation

宣告、建立與 initializer list

分清楚 declaration 只是 reference variable，new 才真的建立 array object。

Q7Declaration

寫出一個可以指向 int array 的 variable scores 宣告。

int[] scores;

這只宣告 reference variable，尚未建立 array。

Q8Create

建立一個長度為 6 的 boolean array，變數名稱是 flags。

boolean[] flags = new boolean[6];
Q9Creation Meaning

new int[8] 中的 8 是什麼？

是元素數量，也就是 array length。不是最大 index。

Q10Initializer

以下 array 的 words.length 是多少？

String[] words = {"red", "blue", "green"};

words.length 是 3。Initializer list 有三個元素。

Q11Valid Code

int[] nums = {10, 20, 30}; 是否需要額外寫 new int[3]？

不需要。Initializer list 會自動建立 array 並決定長度。

Q12Variable Size

以下 code 合法嗎？

int n = 10;
int[] nums = new int[n];

合法。Array 建立時的 size 可以是整數型 variable 或 expression，只要執行時是非負整數。

Q13Zero Length

int[] nums = new int[0]; 合法嗎？nums.length 是多少？

合法。這是 empty array，nums.length 是 0，但 nums[0] 會越界。

Q14Length Field

nums.length = 10; 可以用來改變 array 長度嗎？

不可以。Array 的 length 不能被 assign。若需要新長度，要建立新 array 並讓 reference 指向它。

C. Index / Length

0-based index 與 .length

這組題目專練長度、最後一格、index expression、array vs String length。

Q15Max Index

若 int[] nums = new int[8];，最後一個合法 index 是多少？

是 7，也就是 nums.length - 1。

Q16Last Element

寫出讀取 array arr 最後一個元素的標準 expression。

arr[arr.length - 1]
Q17Output

以下程式印出什麼？

int[] nums = {10, 20, 30, 40};
System.out.println(nums[2]);

印出 30。Index 2 是第三個元素。

Q18Index Expression

以下程式印出什麼？

int[] nums = {4, 8, 12, 16, 20};
int x = 1;
System.out.println(nums[x + 2]);

先算 x + 2 得到 3，所以讀 nums[3]，印出 16。

Q19Array vs String

int[] nums 和 String word 取得長度的語法分別是什麼？

Array 用 nums.length；String 用 word.length()。

Q20Mutation Trace

以下程式最後 nums[2] 是多少？

int[] nums = {10, 20, 30};
nums[1] = 100;
nums[0]++;
nums[2] = nums[0] + nums[1];

最後是 111。Array 依序變成 {10, 100, 30}、{11, 100, 30}、{11, 100, 111}。

Q21Swap

為什麼交換 nums[0] 與 nums[2] 時通常需要 temp？

如果先做 nums[0] = nums[2];，原本 nums[0] 的值會被覆蓋。temp 用來暫存舊值。

Q22Index Type

nums[2.5] 合法嗎？

不合法。Array index 必須是整數型 expression。

D. Defaults / Bounds

預設值與越界錯誤

看到 new 型別[size]，立刻想預設值；看到 arr.length 當 index，立刻想越界。

Q23int Default

以下程式印出什麼？

int[] nums = new int[4];
System.out.println(nums[2]);

印出 0。int[] 的 default element value 是 0。

Q24double Default

double[] data = new double[3]; 中 data[1] 初始值是多少？

是 0.0。

Q25boolean Default

boolean[] flags = new boolean[3]; 中 flags[1] 初始值是多少？

是 false。

Q26Object Default

String[] names = new String[4]; 中 names[2] 初始值是多少？

是 null，不是空字串。

Q27Bounds

以下程式會發生什麼？

int[] nums = {5, 10, 15};
System.out.println(nums[3]);

會發生 ArrayIndexOutOfBoundsException。合法 index 只有 0、1、2。

Q28Negative Index

nums[-1] 在 Java 中合法嗎？

不合法。Java array index 不能是負數，執行時會造成 bounds error。

Q29Classic Loop Error

以下 loop 的問題是什麼？

for (int i = 0; i <= nums.length; i++)
{
    System.out.println(nums[i]);
}

最後一圈會有 i == nums.length，因此存取 nums[nums.length]，造成 ArrayIndexOutOfBoundsException。

Q30null

以下程式會發生什麼？

int[] nums = null;
System.out.println(nums.length);

會發生 NullPointerException，因為 nums 沒有指向任何 array object。

E. References / Aliasing

Reference copy、mutation 與 reassignment

看到 int[] b = a;，先畫成兩個 reference 指向同一個 array。

Q31Aliasing

以下程式印出什麼？

int[] a = {2, 4, 6};
int[] b = a;
b[1] = 9;
System.out.println(a[1]);

印出 9。a 和 b 指向同一個 array。

Q32Primitive Copy

以下程式印出什麼？

int x = 10;
int y = x;
y = 50;
System.out.println(x);

印出 10。Primitive assignment 是 value copy，y 改變不會影響 x。

Q33Reassignment

以下程式印出什麼？

int[] a = {1, 2};
int[] b = a;
b = new int[2];
b[0] = 10;
System.out.println(a[0]);

印出 1。b = new int[2] 讓 b 改指向新 array，沒有修改 a 指到的 array。

Q34Mutation vs Reassign

b[0] = 100; 和 b = new int[5]; 差在哪裡？

b[0] = 100; 修改 b 指向的 array element；b = new int[5]; 是改變 b 這個 reference variable 指向哪個 array。

Q35Reference Trace

以下程式印出什麼？

int[] x = {1, 2, 3};
int[] y = x;
y[0] = 8;
x[2] = y[0];
System.out.println(x[0] + " " + x[2]);

印出 8 8。x 和 y 是 aliases，修改的是同一個 array。

Q36Object Array

String[] names = new String[3]; 是否建立了三個 String object？

沒有。它建立三個可以存 String reference 的位置，預設值都是 null。

Q37Method Parameter

以下 method 呼叫後，caller 的 array 第一格會變嗎？

public static void change(int[] arr)
{
    arr[0] = 99;
}

會。Parameter copy 了 reference value，透過 arr[0] 修改的是同一個 array object 的 element。

Q38Parameter Reassign

以下 method 會讓 caller 的 variable 改指向新 array 嗎？

public static void replace(int[] arr)
{
    arr = new int[3];
}

不會。這只改變 local parameter arr 的 reference，caller 的 variable 不會被重新指定。

F. Enhanced For

讀值方便，但沒有 index

Enhanced for 適合只看每個 value；需要修改元素或需要 index 時，回到 traditional for。

Q39Output

以下程式印出什麼？

int[] nums = {4, 8, 12};

for (int x : nums)
{
    System.out.println(x + 1);
}

依序印出 5、9、13。

Q40Primitive Copy

以下程式執行後 nums 是什麼？

int[] nums = {1, 2, 3};

for (int x : nums)
{
    x = 10;
}

仍然是 {1, 2, 3}。x 是 primitive value copy，改 x 不會改 array element。

Q41Modify Correctly

把 nums 每一格都改成 10，應該用哪種 loop？

for (int i = 0; i < nums.length; i++)
{
    nums[i] = 10;
}

需要修改 array element 時，用 index 和 nums[i]。

Q42No Index

Enhanced for loop 裡是否自動提供 index i？

不會。Enhanced for 只提供當前 element value。如果需要 index，通常用 traditional for。

Q43Object Mutation

Enhanced for loop 走訪 object array 時，呼叫物件的 mutator method 可能改到 object state 嗎？

可能。Loop variable 是 reference 的 copy，但它仍可能指向同一個 mutable object；呼叫 mutator 會改 object state。

Q44Reassign Object Loop Variable

在 enhanced for 裡寫 obj = new SomeClass(); 會改掉 array 裡那一格嗎？

不會。這只是讓 loop variable obj 改指向新 object，不會重新指定 array element。

G. Coding / Trace

程式練習與 final tracing

最後六題把建立、讀取、修改、交換、reference tracing 與 enhanced for 串起來。

Q45First / Last

寫出程式碼，印出 scores 的第一個與最後一個元素。

System.out.println(scores[0]);
System.out.println(scores[scores.length - 1]);
Q46Print Indexes

寫一個 loop，印出每個元素的 index 與 value。

for (int i = 0; i < nums.length; i++)
{
    System.out.println("index " + i + ": " + nums[i]);
}
Q47Swap

寫程式交換 nums[0] 和 nums[nums.length - 1]。

int last = nums.length - 1;
int temp = nums[0];
nums[0] = nums[last];
nums[last] = temp;
Q48Set All

寫程式把 nums 每一格都設成 0。

for (int i = 0; i < nums.length; i++)
{
    nums[i] = 0;
}
Q49Trace

以下程式最後印出什麼？

int[] a = {3, 6, 9, 12};
a[0] = a[2];
a[2] = a[1];
System.out.println(a[0] + a[2]);

先變成 {9, 6, 9, 12}，再變成 {9, 6, 6, 12}，所以印出 15。

Q50Final Challenge

以下程式最後印出什麼？

int[] nums = {4, 8, 12, 16};

for (int i = 0; i < nums.length; i++)
{
    nums[i] = nums[i] + i;
}

for (int value : nums)
{
    System.out.print(value + " ");
}

Array 依序變成 {4, 9, 14, 19}，所以印出 4 9 14 19 。
