A. Concepts

概念確認

先確認 selection、condition、branch、execution path 的語意。

Q1Selection

Selection / conditional execution 是什麼？

根據 condition 的 true / false 決定要執行哪一段程式。

Q2Condition

if 括號裡的 expression 必須是什麼 type？

必須是 boolean。也就是最後要得到 true 或 false。

Q3Java Rule

如果 x 是 int，if (x) 合法嗎？

不合法。Java 不會把 0 當 false 或把非零數字當 true。

Q4Legal Condition

哪一個 condition 合法？

A. if (score) B. if (score >= 60) C. if ("true") D. if (5)

答案是 B。score >= 60 是 Boolean expression。

Q5False Condition

當 if condition 是 false，程式會怎樣？

只會跳過該 if body，並繼續執行後面的程式。不是停止整個程式。

Q6if / else

if / else 一次最多會執行幾個 branch？

只會執行一個 branch。if 和對應的 else 是互斥路徑。

Q7else if

else if chain 如何判斷？

從上往下檢查，第一個為 true 的 branch 執行後，後面全部跳過。

C. else if / Range

else if 與範圍分類

從上往下檢查。第一個 true 執行後，其餘 branch 不再檢查。

    System.out.println("C");

{
    System.out.println("F");

為什麼 score invalid check 通常要放在 grade classifier 前面？

對整數 x 分成 positive、zero、negative，最後的 else 需要寫條件嗎？

D. Independent if

獨立 if vs else if

先確認它是不是同一條 chain。獨立 if 可能多個都執行。

Q26Independent if

預測 output。

int x = 10;

if (x >= 5)
{
    System.out.print("A");
}

if (x >= 10)
{
    System.out.print("B");
}

if (x >= 15)
{
    System.out.print("C");
}

Output 是 AB。三個都是獨立 if。

Q27else if

預測 output。

int x = 15;

if (x > 5)
{
    System.out.print("A");
}
else if (x > 10)
{
    System.out.print("B");
}
else
{
    System.out.print("C");
}

Output 是 A。第一個 condition 已經 true，後面的 else if 不檢查。

E. Nested if

Nested if 追蹤

先處理 outer condition。只有 outer branch 進入，inner 才有機會被判斷。

Q31Nested

預測 output。

int x = 12;

if (x > 0)
{
    System.out.println("Positive");

    if (x > 10)
    {
        System.out.println("Large");
    }
}
Positive
Large

外層和內層 condition 都是 true。

Q32Outer false

如果上一題 x = -20，會輸出什麼？

沒有輸出。外層 -20 > 0 false，內層根本不會判斷。

Q33Nested if / else

預測 output。

int score = 75;

if (score >= 60)
{
    if (score >= 90)
    {
        System.out.println("Excellent");
    }
    else
    {
        System.out.println("Pass");
    }
}
else
{
    System.out.println("Fail");
}

Output 是 Pass。外層 true，內層 75 >= 90 false，走 inner else。

Q34Nested trace

預測 output。

int x = 4;

if (x > 0)

    System.out.print("A");

    }

    }

System.out.print("D");

Q35Nested update

預測 output。

int x = 5;
int y = 10;

if (x < y)
{
    x += 5;

    if (x == y)
    {
        y++;
    }

System.out.println(x + " " + y);

x 先變 10，內層 x == y true，所以 y 變 11。Output 是 10 11。

F. Errors

錯誤與陷阱

有些題目不是單純算 output，而是要找 bug、unreachable branch 或錯誤的 case order。

Q36= vs ==

這行為什麼不對？

if (x = 5)
{
    System.out.println("Five");
}

= 是 assignment，不是 comparison。檢查相等要寫 x == 5。如果 x 是 int，x = 5 也不是 boolean condition。

Q37String

比較 String contents 時，這行有什麼問題？

if (password == "abc123")
{
    System.out.println("Correct");
}

String contents 應使用 password.equals("abc123")。== 對 objects 比較 reference。

Q38Semicolon

這段程式的陷阱是什麼？

if (x > 5);
{
    System.out.println("Large");
}

if (x > 5); 後面多了一個分號，表示 if 控制 empty statement。後面的 block 不是 if body。

Q39Missing braces

如果 x = 3，這段輸出什麼？

if (x > 5)
    System.out.println("A");
    System.out.println("B");

只輸出 B。沒有 braces 時，if 只控制下一個 statement。

Q40Unreachable

哪個 branch 永遠不會執行？

if (x >= 50)
{
    System.out.println("A");
}
else if (x >= 70)
{
    System.out.println("B");
}
else
{
    System.out.println("C");
}

B 永遠不會執行。任何 x >= 70 的值也都符合前面的 x >= 50。

Q41Wrong order

這段想分類 90+ A、80+ B、70+ C，bug 是什麼？

if (score >= 70)
{
    System.out.println("C");
}
else if (score >= 80)
{
    System.out.println("B");
}
else if (score >= 90)
{
    System.out.println("A");
}

threshold 順序錯。用 >= 分類時應從高到低：90、80、70。

Q42Boundary testing

分類邊界是 60、70、80、90，應該特別測哪些值？

至少測每個 boundary 附近，例如 59、60、69、70、79、80、89、90。

Q43Boolean variable

這樣寫是否多餘？

boolean isReady = true;

if (isReady == true)
{
    System.out.println("Go");
}

合法但多餘。isReady 本身已經是 Boolean expression，通常寫 if (isReady) 更清楚。

G. Coding

程式練習

把 Boolean expressions 放進 if / else，完成小型分類器。

Q44Coding

Odd / Even：判斷 number 是偶數或奇數。

public class Main {
    public static void main(String[] args) {
        int number = 7;

        if (number % 2 == 0) {
            System.out.println("Even");
        } else {
            System.out.println("Odd");
        }
    }
}

Q47Coding

Ticket Price：依 age 決定票價。

規則：age < 6 免費、age < 18 100、age < 65 200、否則 120。

public class Main {
    public static void main(String[] args) {

            price = 0;

            price = 100;
        } else if (age < 65) {
            price = 200;
        } else {
            price = 120;
        }

    }
}
Q48Coding

Grade + Invalid：先處理不合法輸入。

public class Main {
    public static void main(String[] args) {
        int score = 85;

        if (score < 0) {
            System.out.println("Invalid");
        } else if (score > 100) {
            System.out.println("Invalid");
        } else if (score >= 90) {
            System.out.println("A");
        } else if (score >= 80) {
            System.out.println("B");
        } else if (score >= 70) {
            System.out.println("C");
        } else if (score >= 60) {
            System.out.println("D");
        } else {
            System.out.println("F");
        }
    }
}

還沒學 ||，所以可以先用兩個 invalid branches。

Q50Final Challenge

預測完整 output。

int score = 72;
String status;

if (score < 0)
{
    status = "Invalid";
}
else if (score >= 90)
{
    status = "A";
}
else if (score >= 80)
{
    status = "B";
}
else if (score >= 70)
{
    status = "C";
    score += 5;
}
else if (score >= 60)
{
    status = "D";
}
else
{
    status = "F";
}

if (score >= 75)
{
    System.out.println(status + "+");
}
else
{
    System.out.println(status);
}

72 走 score >= 70 branch，所以 status = "C"，接著 score 變 77。第二個獨立 if 使用新 score，所以 output 是 C+。
