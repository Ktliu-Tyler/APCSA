練習目錄

A. Concepts

名詞與觀念

這一區先確認本課最基本的 vocabulary。

Q1Class

Class 和 object 的差別是什麼？

Class 是設計規格或 blueprint；object 是根據 class 建立出來、實際存在並可被程式操作的 instance。例：Scanner 是 class，某一個透過 new Scanner(System.in) 建立的實體是 object。

Q2Instance

instance of a class 是什麼意思？

可以理解成「根據某個 class 建立出來的 object」。例如某個 Scanner object 是 an instance of the Scanner class。

Q3Reference

Reference variable 儲存的是什麼？

Reference variable 儲存 object reference，也就是讓程式找到某個 object 的資訊。它不是直接儲存整個 object。

Q4Primitive

Primitive variable 和 reference variable 最大差異是什麼？

Primitive variable 直接儲存 primitive value，例如 int x = 5;。Reference variable 儲存 object reference，例如 Scanner input 儲存的是指向 Scanner object 的 reference。

Q5State

Object state 是什麼？請舉一個例子。

Object state 是 object 目前內部資料的狀態。例如 Car object 可能有 speed = 50、battery = 80、gear = 3。

Q6Behavior

Object behavior 在 Java 中通常用什麼表示？

通常用 methods 表示。例：Car object 可能有 accelerate()、brake()；Scanner object 有 nextInt()、nextDouble()。

B. Class, Object, new

Class / Object / new / Constructor

這一區練習拆解 object creation 與 constructor call。

Q7Scanner

拆解這一行：Scanner input = new Scanner(System.in);

Scanner 是 reference type / class name。input 是 reference variable。new 建立 object。Scanner(System.in) 是 constructor call。整行把新 Scanner object 的 reference 存進 input。

Q8Constructor

Constructor call 和 method call 的差異是什麼？

Constructor call 用於建立並初始化 object，通常和 new 一起出現，例如 new Scanner(System.in)。Method call 是對 class 或 object 執行某個操作，例如 input.nextInt()。

Q9Object Creation

下列哪一行一定會建立新的 Scanner object？

A. Scanner b = a; B. Scanner b; C. b = null; D. Scanner b = new Scanner(System.in);

答案是 D。關鍵是 new Scanner(System.in)。A 只複製 reference，B 只宣告 reference variable，C 讓 reference variable 不指向 object。

Q10Declaration

這三行宣告了幾個 reference variables？建立了幾個 Scanner objects？

Scanner a;
Scanner b;
Scanner c;

宣告了 3 個 reference variables，但建立了 0 個 Scanner objects。沒有 new Scanner(...)，就沒有明確建立 Scanner object。

Q11Count

這段程式建立了幾個 Scanner objects？

Scanner a = new Scanner(System.in);
Scanner b = new Scanner(System.in);

建立了 2 個 Scanner objects，因為 new Scanner(System.in) 執行兩次。實際程式通常不建議刻意建立多個 Scanner 讀同一個 System.in，這裡只用來練習 reference tracing。

C. Copying

Primitive Copy vs Reference Copy

請先在紙上追蹤 value 或畫 reference diagram。

Q12Primitive Copy

預測 output。

int x = 4;
int y = x;

x = x + 3;

System.out.println(x + " " + y);
A. 4 4 B. 7 4 C. 7 7 D. 4 7

答案是 B。int y = x; 複製的是 primitive value 4。之後 x 變成 7，y 仍然是 4。

Q13Primitive Copy

最後 a 和 b 是多少？

int a = 7;
int b = a;

b = 20;

a = 7，b = 20。修改 b 不會影響 a，因為它們是兩份獨立 primitive values。

Q14Reference Copy

哪個敘述正確？

Scanner first = new Scanner(System.in);
Scanner second = first;
A. Java 建立兩個 Scanner objects B. first 是 object，second 是 variable C. first 和 second reference 到同一個 object D. second 是 first 的 primitive copy

答案是 C。Scanner second = first; 複製的是 reference，不是 object。

Q15Diagram

請畫出最後的 reference diagram。

Scanner a = new Scanner(System.in);
Scanner b = a;
Scanner c = b;
a ----\
b -----> Scanner object
c ----/

new 只有一次，因此只有一個 Scanner object。b = a 和 c = b 都只是複製 reference。

Q16Count

有幾個 Scanner objects？有幾個 Scanner reference variables？

Scanner a = new Scanner(System.in);
Scanner b = a;
Scanner c = b;

有 1 個 Scanner object，3 個 Scanner reference variables。變數數量不等於 object 數量。

Q17new

這段程式最後有幾個 Scanner objects？

Scanner a = new Scanner(System.in);
Scanner b = a;

a = new Scanner(System.in);

建立了 2 個 Scanner objects。第一個由第一行 new 建立，第二個由第三行 new 建立。最後 a 指向第二個 object，b 指向第一個 object。

D. Alias and Reassignment

Alias、State 與 Reassignment

這一區練習「多個 references 指向同一 object」和「reference variable 可以改指向別處」。

Q18Alias

什麼是 aliases？

當兩個或多個 reference variables 指向同一個 object 時，它們稱為 aliases。例如 Scanner second = first; 之後，first 和 second 是同一個 Scanner object 的 aliases。

Q19State

如果 a 和 b 指向同一個 object，透過 a 修改 object state，透過 b 看到什麼？

透過 b 看到的是修改後的同一個 object state。因為根本只有一個 object，只是有兩個 references 指向它。

Q20Reassignment

執行 a = b; 後發生什麼？

SomeClass a = new SomeClass();
SomeClass b = new SomeClass();

a = b;

Java 把 b 裡的 reference 複製給 a。最後 a 和 b 指向原本 b 指向的 object。原本 a 指向的 object 如果沒有其他 reference，就再也無法被程式使用。

Q21Object

a = b; 會把 Object B 搬進 a 嗎？

不會。Object 本身沒有被搬動，也沒有被複製。變的是 a 裡儲存的 reference。

Q22Static vs Instance

Math.sqrt(25) 和 input.nextInt() 的呼叫方式差在哪？

Math.sqrt(25) 是透過 class 呼叫 static method。input.nextInt() 是對 input 指向的 Scanner object 呼叫 method。

E. null and Errors

null 與錯誤類型

這一區練習 reference type 的特殊值 null。

Q23null

null 代表什麼？

null 表示 reference variable 目前沒有 reference 到任何 object。它不是 object，不是 0，也不是空字串。

Q24Compile

下列何者可以合法 compile？

A. int x = null; B. double x = null; C. boolean x = null; D. String x = null;

答案是 D。String 是 reference type，所以可以儲存 null。int、double、boolean 是 primitive types，不能儲存 null。

Q25Runtime

這段程式的錯誤類型最接近哪一個？

String text = null;
System.out.println(text.length());
A. Syntax error B. Compile-time type error C. Runtime error D. Logic error only

答案是 C，更具體是 NullPointerException。宣告 String text = null; 是合法的，但執行 text.length() 時沒有 String object 可用。

Q26Empty String

null、""、" " 差在哪？

null 表示沒有 String object。"" 是有一個 String object，長度為 0。" " 也是 String object，內容是一個空白字元，長度為 1。

Q27null Reassignment

最後 Scanner object 是否仍存在？

Scanner a = new Scanner(System.in);
Scanner b = a;

a = null;
a -> null

b -> Scanner object

Scanner object 仍可透過 b 使用。a = null 只讓 a 不再指向 object。

Q28null to Object

這段程式最後 input 是什麼狀態？

Scanner input = null;
input = new Scanner(System.in);

最後 input 指向一個新建立的 Scanner object。Reference variable 可以從 null 變成指向 object。

F. AP-style

AP-style 綜合題

這一區把本課觀念混在一起，請用 reference diagram 解題。

Q29Vocabulary

在這行程式中，keyboard 最精確是什麼？

Scanner keyboard = new Scanner(System.in);
A. class B. object C. reference variable D. constructor

答案是 C。keyboard 是 reference variable，儲存對新 Scanner object 的 reference。

Q30Constructor

在 new Scanner(System.in) 中，Scanner(System.in) 是什麼？

它是 constructor call。配合 new 建立並初始化 Scanner object。

Q31Diagram

最後的 reference diagram 是哪一個概念？

Scanner a = new Scanner(System.in);
Scanner b = a;
Scanner c = b;

b = null;
a ----\
       > Scanner object
c ----/

b -> null

b = null 只改變 b。a 和 c 仍指向原本 object。

Q32Count

總共執行了幾次 new Scanner(...)？建立幾個 Scanner objects？

Scanner a = new Scanner(System.in);
Scanner b = a;

a = new Scanner(System.in);
Scanner c = a;

new Scanner(...) 執行 2 次，所以建立 2 個 Scanner objects。最後 b 指向第一個 object，a 和 c 指向第二個 object。

Q33Compile vs Runtime

判斷這兩段分別是 compile-time error、runtime error，還是合法執行。

int a = null;
String b = null;
System.out.println(b.length());

第一段是 compile-time error，因為 int 不能儲存 null。第二段是 runtime error，宣告合法，但執行 b.length() 時 b 沒有指向 String object。

Q34Misconception

「兩個 reference variables 就一定有兩個 objects」這句話對嗎？

不對。例如 Scanner b = a; 會讓兩個 reference variables 指向同一個 object。要看建立 object 的 new 實際執行幾次。

Q35Dot Operator

input.nextInt() 可以怎麼理解？

可以理解成對 input 指向的 Scanner object 呼叫 nextInt() method。input 是 reference variable，不是 Scanner object 本身。

Q36Debugging

這段程式為什麼危險？如何修正？

String name = null;
System.out.println("Length: " + name.length());

name 是 null，沒有 String object，所以 name.length() 會造成 NullPointerException。可以先讓 name 指向真正的 String，例如 String name = "Alex";，或在呼叫 method 前檢查 name != null。

Q37Trace

請畫最後 reference diagram。

SomeClass x = new SomeClass();
SomeClass y = x;

x = null;
x -> null

y -> Object A

Object A 還存在，因為 y 仍然 reference 到它。

Q38Reverse Explanation

解釋為什麼 Scanner b = a; 不會建立新的 Scanner object。

因為這行沒有 new Scanner(...)。它只是宣告 b，並把 a 裡的 reference 複製給 b。

Q39Final Challenge

完整追蹤：建立幾個 objects？最後誰指向誰？

SomeClass a = new SomeClass();
SomeClass b = a;
SomeClass c = new SomeClass();

b = c;
c = null;

建立 2 個 objects。先是 Object A：a 和 b 指向它。接著 Object B：c 指向它。執行 b = c; 後，b 指向 Object B。執行 c = null; 後，c 不指向任何 object。最後 a 指向 Object A，b 指向 Object B，c 是 null。

Q40Exit Ticket

用一句話總結本課最重要的差異。

Primitive variable 裡放的是 value；reference type variable 裡放的是找到 object 的 reference。因此 int b = a; 複製 value，而 SomeClass b = a; 複製 reference，不複製 object。
