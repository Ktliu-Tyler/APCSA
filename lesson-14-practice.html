A. Concepts

概念確認

先確認 constructor 的用途與它和 ordinary method 的差異。

Q1Purpose

Constructor 的主要目的為何？

Constructor 在 object 被建立時執行，用來初始化 newly created object 的 initial state。

Q2Timing

Constructor 什麼時候執行？

當 new ClassName(...) 建立新 object 時執行。

Q3Runs Once

Object 建立後呼叫 accessor 或 mutator，constructor 會自動重跑嗎？

不會。Constructor 只在 new 建立 object 時執行。

Q4State

Constructor 通常會設定哪些東西？

通常會設定 instance variables 的初始值，讓 object 進入合理、合法的 initial state。

Q5new

Student s = new Student("Amy", 95); 中，哪一段是 constructor call？

Student("Amy", 95) 是 constructor call；整個 new Student("Amy", 95) 是 new expression。

Q6Identity

以下兩行會建立幾個 objects？

Student a = new Student("Amy", 90);
Student b = new Student("Amy", 90);

兩個。每個 new expression 都建立一個新的 object。

B. Syntax

Constructor Syntax

AP 最常考：constructor 名字、沒有 return type、和 ordinary method 的差別。

Q7Name

Class Book 的 constructor 必須叫什麼？

必須叫 Book，名稱要和 class 完全相同，包含大小寫。

Q8No Return Type

哪一個是 class Book 的 constructor？

A. public void Book()
B. public Book()
C. public int Book()
D. public book()

B。Constructor 名字等於 class name，且沒有 return type。

Q9Method Trap

public void Student(String name) 是 constructor 嗎？

不是。因為它有 return type void，所以是 ordinary method。

Q10Case

在 public class Student 裡，public student() 是 constructor 嗎？

不是。Java 大小寫敏感，constructor name 必須是 Student。

Q11Syntax

以下哪個 header 最可能是 Car constructor？

A. public Vehicle(String model)
B. public Car(String model)
C. public void Car(String model)
D. private String Car(String model)

B。名稱 match class Car，沒有 return type。

Q12Return

Constructor 是否需要 return this;？

不需要，而且不應這樣寫。new expression 會得到 object reference，不是靠 constructor return。

C. new / Matching

Constructor Call Matching

Arguments 必須在數量、順序與型別上 match constructor parameter list。

Q13Matching

以下 constructor call 是否合法？

public Student(String name, int score)
{
    this.name = name;
    this.score = score;
}

Student s = new Student("Amy", 95);

合法。Arguments 是 String, int，剛好 match。

Q14Order

以下 constructor call 是否合法？

public Student(String name, int score)
{
    this.name = name;
    this.score = score;
}

Student s = new Student(95, "Amy");

不合法。順序錯了，constructor 需要 String, int，但給的是 int, String。

Q15Count

以下 constructor call 是否合法？

public Rectangle(double width, double height)
{
    this.width = width;
    this.height = height;
}

Rectangle r = new Rectangle(5.0);

不合法，除非 class 另外有 Rectangle(double) constructor。這裡只看到 two-parameter constructor。

Q16Types

new Rectangle("5", "3") 能 match Rectangle(double width, double height) 嗎？

不能。"5" 和 "3" 是 String，不是 double。

Q17Arguments

以下 constructor 中，studentScore 的值是多少？

public Student(String studentName, int studentScore)
{
    name = studentName;
    score = studentScore;
}

Student s = new Student("Amy", 95);

studentScore 是 95。

Q18Arguments

上題 constructor 執行後，name 和 score 是什麼？

name = "Amy"，score = 95。

D. Defaults

Field Default Values 與 Default Constructor

Default value 和 default constructor 是兩個不同概念。

Q19Field Default

Constructor 執行前，int instance variable 的 default value 是什麼？

0。

Q20Field Default

Constructor 執行前，String instance variable 的 default value 是什麼？

null。

Q21Default Constructor

以下 class 可以呼叫 new Thing() 嗎？

public class Thing
{
    private int x;
}

可以。因為 class 沒有宣告任何 constructor，compiler 會提供 no-argument default constructor。

Q22No Default

以下 class 可以呼叫 new Thing() 嗎？

public class Thing
{
    private int x;

    public Thing(int value)
    {
        x = value;
    }
}

不可以。自己寫了 constructor 後，compiler 不再自動提供 no-arg constructor。

Q23No-Arg

Programmer-defined no-argument constructor 和 compiler-provided default constructor 是完全同義嗎？

不完全同義。No-argument constructor 是沒有 parameters 的 constructor；default constructor 通常指 compiler 在沒有任何 constructor 時自動提供的 no-arg constructor。

Q24Defaults

如果 constructor 沒初始化 private boolean active;，它會是什麼？

false。但如果 specification 要求 true，就應在 constructor 明確設定。

E. Shadowing / this

Parameter Shadowing 與 this.field

這一段是本課最容易錯、也最常考的地方。

Q25Shadowing

以下 constructor 有什麼問題？

private String name;

public Student(String name)
{
    name = name;
}

Parameter name shadows field name。name = name 只是把 parameter assign 給自己，field 沒有被設定。

Q26this

上題正確寫法是什麼？

public Student(String name)
{
    this.name = name;
}
Q27this.field

this.score 表示什麼？

目前這個 object 的 instance variable score。

Q28Trace

以下 constructor 執行後，field value 是多少？

private int value;

public Test(int value)
{
    value = value + 5;
}

Test t = new Test(8);

Field value 仍是 0。改的是 parameter 自己，不是 field。

Q29Trace

以下 constructor 執行後，field value 是多少？

private int value;

public Test(int value)
{
    this.value = value + 5;
}

Test t = new Test(8);

13。

Q30No Shadowing

如果 parameter 叫 studentScore，一定需要 this.score 嗎？

不一定。若沒有同名 shadowing，score = studentScore; 已經很清楚。不過有些人仍習慣寫 this.score。

F. Overloading / Trace

Overloaded Constructors 與 Constructor Trace

Overloading 看 parameter type list，不看 parameter name，也不靠 return type。

Q31Overload

以下 overloaded constructors 合法嗎？

public Example()
{
}

public Example(int x)
{
}

合法。Parameter lists 不同：一個沒有 parameters，一個是 int。

Q32Invalid Overload

以下 overloaded constructors 合法嗎？

public Box(int width)
{
}

public Box(int height)
{
}

不合法。Parameter names 不影響 signature，兩個都是 Box(int)。

Q33Order

以下 two constructors 合法嗎？

public Example(String text, int number)
{
}

public Example(int number, String text)
{
}

合法。Parameter type order 不同：String, int vs int, String。

Q34Matching

以下 call 會使用哪個 constructor？

public Rectangle()
{
    width = 1;
    height = 1;
}

public Rectangle(double side)
{
    width = side;
    height = side;
}

Rectangle r = new Rectangle(5);

會使用 one-parameter constructor Rectangle(double side)。

Q35Trace

以下 constructor 執行後，value 是多少？

private int value;

public NumberBox(int x)
{
    value = x + 5;
}

NumberBox b = new NumberBox(6);

11。

Q36Trace

以下 constructor 執行後，x 和 y 是多少？

private int x;
private int y;

public Point(int a, int b)
{
    x = a;
    y = b;
}

Point p = new Point(3, 7);

x = 3，y = 7。

Q37Trace

以下 constructor 執行後，quantity 和 price 是多少？

private int quantity;
private double price;

public Item(int quantity, double price)
{
    this.quantity = quantity + 1;
    this.price = price * 2;
}

Item item = new Item(4, 3.5);

quantity = 5，price = 7.0。

Q38Two Objects

以下建立幾個 Counter objects？

Counter a = new Counter(5);
Counter b = new Counter(2);

兩個 objects。每個 object 的 count field 各自初始化。

G. Coding Practice

程式練習

這一段適合直接寫 constructor skeleton。

Q39Coding

為 Book 寫 constructor，使用 parameters 初始化 title 與 pages。

private String title;
private int pages;
public Book(String title, int pages)
{
    this.title = title;
    this.pages = pages;
}
Q40Coding

為 Player 寫 constructor：caller 提供 name，health 設 100，score 設 0。

public Player(String name)
{
    this.name = name;
    health = 100;
    score = 0;
}
Q41Coding

為 Player 寫 constructor：若 level 小於 1，設為 1。

private int level;
public Player(int level)
{
    if (level >= 1)
    {
        this.level = level;
    }
    else
    {
        this.level = 1;
    }
}
Q42Coding

為 Tracker 寫 no-argument constructor：count = 0，active = true。

public Tracker()
{
    count = 0;
    active = true;
}
Q43Coding

為 Point 寫兩個 constructors：Point() 設為 origin，Point(int x, int y) 設定 fields。

public Point()
{
    x = 0;
    y = 0;
}

public Point(int x, int y)
{
    this.x = x;
    this.y = y;
}
Q44Debug

修正 shadowing bug。

public Car(String model)
{
    model = model;
}
public Car(String model)
{
    this.model = model;
}
Q45Debug

以下 Account 的 constructor 寫錯在哪？

public void Account(double balance)
{
    this.balance = balance;
}

它有 void，所以不是 constructor。應改成：

public Account(double balance)
{
    this.balance = balance;
}
Q46Design

若 specification 說 Player(String name) initializes points to 0，constructor 是否應該加 int points parameter？

不應該。Constructor header 必須照 specification，只接收 String name，並在 body 中設定 points = 0。

Q47Chaining

this(name, 0); 在 constructor 中代表什麼？

它呼叫同一個 class 的另一個 constructor，稱為 constructor chaining。若使用，必須是 constructor body 的第一個 statement。

Q48Trace

以下結果是什麼？

private int x;

public Example(int x)
{
    this.x = x;
    x = x + 1;
}

Example e = new Example(5);

Field this.x 是 5。後面的 x = x + 1 只改 parameter。

Q49Trace

以下結果是什麼？

private int x;

public Example(int x)
{
    x = x + 1;
    this.x = x;
}

Example e = new Example(5);

Field this.x 是 6。先把 parameter 改成 6，再 assign 給 field。

Q50Final Challenge

找出以下 class 的三個 constructor 問題。

public class Score
{
    private String name;
    private int points;

    public void Score(String name)
    {
        name = name;
    }

    public Score(int points)
    {
        points = this.points;
    }
}

問題 1：public void Score(String name) 有 void，不是 constructor。問題 2：name = name 是 shadowing bug。問題 3：points = this.points assignment 方向反了。

public Score(String name)
{
    this.name = name;
}

public Score(int points)
{
    this.points = points;
}
