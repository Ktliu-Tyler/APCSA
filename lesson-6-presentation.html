Why It Matters

boolean

boolean 只有兩種值

trueBoolean value
falseBoolean value
"true"String，不是 boolean

Java 不使用 0 / 1 代替 Boolean。

Boolean Expression

執行後得到 true 或 false

5 > 3

true

10 == 4

false

"cat".equals("cat")

true

Operators

六個 relational operators

==equal to
!=not equal to
<less than
>greater than
<=less than or equal
>=greater than or equal

每一個 relational expression 的結果都是 boolean。

Boundary Check

< 和 <= 差在邊界

int score = 80;
System.out.println(score > 80);
System.out.println(score >= 80);

兩行 output 是什麼？

A. true / true B. true / false C. false / true D. false / false

答案是 C。> 不包含等於；>= 包含等於。

= vs ==

= 是 assignment，== 是 comparison

x = 5;

修改 x

x == 5

產生 true / false

AP rule

看到等號先問：改值還是比較？

Evaluation Order

先算左右 expression，再比較

int x = 4;
int y = 5;

boolean result = x + 3 < y * 2;

result 是什麼？

A. true B. false C. 7 D. Compile error 
x + 3 = 7
y * 2 = 10
7 < 10 -> true

Not Auto Update

Boolean variable 不會自動重新計算

int x = 5;
boolean result = x > 3;

x = 1;

System.out.println(result);

Output 是 true。result 在第二行已經被計算並保存。

Primitive

Primitive == 比較 value

int a = 10;
int b = 10;

System.out.println(a == b);

Output 是 true，因為 primitive 比較實際值：10 == 10。

Integer Division

Boolean 題常混入 integer division

System.out.println(5 / 2 == 2.5);

Output 是什麼？

A. true B. false C. 2.5 D. Compile error

答案是 B。5 / 2 是 2，所以 2 == 2.5 是 false。

Casting

Casting 會改變比較結果

System.out.println((double) 5 / 2 == 2.5);

Output 是什麼？

A. true B. false C. 2 D. Compile error

答案是 A。(double) 5 / 2 是 2.5。

Modulo

% 常用來做整除與奇偶判斷

x % 2 == 0

通常表示偶數

x % 2 != 0

通常表示奇數

x % 5 == 0

可以被 5 整除

Reference

Object == 比較 reference

String a = new String("cat");
String b = new String("cat");

System.out.println(a == b);
System.out.println(a.equals(b));
false
true

兩次 new 是不同 objects；equals() 比較 contents。

Alias

Reference copy 後，== 通常是 true

String a = new String("cat");
String b = a;

System.out.println(a == b);
a --+
    +--> "cat"
b --+

a == b -> true

null

== null 是安全比較

name == null

合法；安全

name != null

合法；安全

name.equals(...)

如果 name 是 null，runtime error

null Check

判斷是安全比較還是 runtime error

String name = null;
System.out.println(name == null);

結果是什麼？

A. true B. false C. NullPointerException D. Compile error

答案是 A。== null 不需要呼叫 object method，所以安全。

String Boolean

String methods + relational operators

s.length() >= 8

int 比較

s.indexOf("AP") >= 0

找得到

s.equals("yes")

直接是 Boolean

s.compareTo("cat") < 0

排序在前面

String Check

indexOf() 找不到回傳 -1

String s = "computer";
boolean result = s.indexOf("xyz") >= 0;

result 是什麼？

A. true B. false C. -1 D. Runtime error

答案是 B。indexOf("xyz") = -1，所以 -1 >= 0 是 false。

compareTo

只看正負號，不要硬背精確數字

String a = "dog";
String b = "cat";
boolean result = a.compareTo(b) < 0;

result 是什麼？

A. true B. false C. 0 D. Compile error

答案是 B。"dog" 排在 "cat" 後面，所以 compareTo() 是 positive。

AP SOP

Boolean tracing 固定流程

Find types Evaluate method calls Evaluate arithmetic Compare Write true/false Draw references

不要跳步；很多錯誤都藏在 return type 和 reference diagram。

AP-style Trace

綜合追蹤

String a = new String("APCSA");
String b = a;
String c = new String("APCSA");

boolean x = a == b;
boolean y = a == c;
boolean z = a.equals(c);
x = true
y = false
z = true

b 是 a 的 alias；c 是不同 object，但 contents 一樣。
