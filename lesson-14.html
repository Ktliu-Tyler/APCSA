Constructor Purpose

Constructor 在 object 建立時執行，用來設定 initial state

Lesson 13 中我們已經有 fields，例如 name 與 score。 但 object 剛建立時，這些 fields 要怎麼得到合理值？答案是 constructor。

Student Constructor

public class Student
{
    private String name;
    private int score;

    public Student(String studentName, int studentScore)
    {
        name = studentName;
        score = studentScore;
    }
}
Student s = new Student("Amy", 95);

new Student object
  name = "Amy"
  score = 95

Constructor 的主要工作是：建立 object 後，設定 instance variables，讓 object 進入合法、可使用的 initial state。

Constructor Syntax

Constructor 名字必須和 class 相同，而且沒有 return type

Constructor Header

public Student(String name, int score)
{
    this.name = name;
    this.score = score;
}
規則 正確 錯誤或陷阱
名稱等於 class name public Student(...) public Person(...)
沒有 return type public Student(...) public void Student(...)
通常 public public Student(...) AP FRQ 通常照 specification 寫。
public void Student(...) 不是 constructor。它是一個 ordinary method， 只是 method name 剛好叫 Student。

new Expression

new 建立 object，然後呼叫 matching constructor

new + Constructor Call

Student s = new Student("Amy", 95);
1. allocate a new Student object
2. create fields with default values
3. pass "Amy" and 95 into the constructor
4. execute constructor body
5. return the object reference to s

Constructor 只在 object 被 new 建立時執行。之後呼叫 methods 不會讓 constructor 自動重跑。 兩個 new expressions 通常代表兩個不同 objects。

Constructor Parameters

Arguments 必須 match constructor 的 parameter list

Parameter Order and Types

public Student(String name, int score)
{
    this.name = name;
    this.score = score;
}

Student a = new Student("Amy", 95);   // OK
Student b = new Student(95, "Amy");   // compile error

Parameter order 是 API 的一部分。new Student("Amy", 95) 會把 "Amy" 對到 name，把 95 對到 score。

Validation

Constructor 可以保護 object 的初始狀態

Constructor body 就像一般 method body，可以有 assignment、if statement、計算與 method calls。 常見用途是拒絕不合法的 initial state。

Constructor Validation

public Student(String name, int score)
{
    this.name = name;

    if (score >= 0 && score <= 100)
    {
        this.score = score;
    }
    else
    {
        this.score = 0;
    }
}

Object 一旦 constructor 完成，應該盡可能處於合法、可使用的 state。

Field Defaults

Constructor 執行前，fields 已經有 Java default values

Field Type Default Value
int 0
double 0.0
boolean false
String 或其他 reference type null

Uninitialized Field

public class Student
{
    private String name;
    private int score;

    public Student(String name)
    {
        this.name = name;
    }
}

如果建立 new Student("Amy")，score 會是 0。 但「Java 有 default value」不代表你應該偷懶。若 specification 要求特定 initial state，就要在 constructor 明確設定。

Shadowing And this

Parameter 和 field 同名時，用 this.field 指明 instance variable

當 parameter 與 instance variable 同名時，parameter 會 shadow field。 因此單獨寫 name 會先指到 parameter，不是 field。

Shadowing Bug

public class Student
{
    private String name;

    public Student(String name)
    {
        name = name; // bug: parameter assigned to itself
    }
}

Correct this.field Pattern

public class Student
{
    private String name;
    private int score;

    public Student(String name, int score)
    {
        this.name = name;
        this.score = score;
    }
}
this.name  -> current object's field
name       -> constructor parameter

this.score -> current object's field
score      -> constructor parameter

Default Constructor

Java 只在你沒有寫任何 constructor 時，才提供 default no-arg constructor

Compiler-Provided Default Constructor

public class Thing
{
    private int x;
}

Thing t = new Thing(); // OK: no constructor was declared

No Automatic No-Arg After You Write One

public class Thing
{
    private int x;

    public Thing(int value)
    {
        x = value;
    }
}

Thing a = new Thing(5); // OK
Thing b = new Thing();  // compile error

如果你想同時支援 new Thing() 和 new Thing(5)， 就要自己寫 no-argument constructor。

Overloaded Constructors

同一個 class 可以有多個 constructors，只要 parameter lists 不同

Rectangle Constructors

public class Rectangle
{
    private double width;
    private double height;

    public Rectangle()
    {
        width = 1.0;
        height = 1.0;
    }

    public Rectangle(double side)
    {
        width = side;
        height = side;
    }

    public Rectangle(double width, double height)
    {
        this.width = width;
        this.height = height;
    }
}
Call Matching Constructor Result
new Rectangle() Rectangle() 1 by 1
new Rectangle(5) Rectangle(double side) 5 by 5
new Rectangle(5, 3) Rectangle(double width, double height) 5 by 3
Parameter names 不屬於 signature。Student(String name) 和 Student(String nickname) 不是兩個合法 overload，因為 parameter type list 相同。

Constructor Design

Constructor design 的核心問題

Caller Provides哪些 state 必須由 caller 提供？
Class Decides哪些 state 應該由 class 自己決定？
Validation哪些 values 需要檢查是否合法？
SpecificationAP FRQ 的 constructor header 必須完全照題目。

ScoreTracker Initial State

public class ScoreTracker
{
    private String playerName;
    private int score;
    private int gamesPlayed;

    public ScoreTracker(String playerName)
    {
        this.playerName = playerName;
        score = 0;
        gamesPlayed = 0;
    }
}

Caller 只需要提供 player name；score 和 games played 應該由 class 初始化為 0。 不要讓 caller 提供不應該控制的初值。

Common Errors

Constructor 常見錯誤

錯誤 常見樣子 修正想法
加了 return type public void Book(...) Constructor 沒有 return type。
名字和 class 不同 public Books(...) inside Book Constructor name 必須完全 match class name。
shadowing name = name; 使用 this.name = name;。
assignment 方向反了 studentName = name; field 在左邊：name = studentName;。
以為 no-arg constructor 永遠存在 已寫 Student(String name)，又呼叫 new Student() 自己寫任何 constructor 後，Java 不再自動提供 no-arg constructor。
只改 parameter name 來 overload Box(int width) 和 Box(int height) Signature 看 parameter type list，不看 parameter name。
以為 constructor 會重跑 呼叫 setter 後以為 constructor 自動重新初始化 Constructor 只在 new 建 object 時執行。

考前必背十二句

A constructor initializes a newly created object.

A constructor name must match the class name.

A constructor has no return type.

public void Student(...) is a method, not a constructor.

new creates an object and calls a matching constructor.

Constructor arguments must match the parameter list.

Fields have default values before the constructor body runs.

Constructor validation helps build valid objects.

name = name usually indicates shadowing.

this.name = name assigns the parameter into the current object's field.

If you write any constructor, Java does not automatically add a no-arg constructor.

Overloaded constructors must have different parameter type lists.
