Lesson Flow

Counted Loop

for 最適合「明確次數」的重複工作

Counted loop 是事先知道或可以清楚描述執行次數的 loop。例如印 1 到 10、重複 100 次、 從 10 倒數到 1、處理 String 的每一個 index、把 1 到 n 加總、執行 n 次模擬。

Repeat n times

for (int i = 0; i < n; i++)

1 through n

for (int i = 1; i <= n; i++)

All indexes

for (int i = 0; i < length; i++)

Syntax

for 把 initialization、condition、update 放在同一行

Basic for Pattern

for (initialization; condition; update)
{
    // loop body
}

Print 1 to 5

for (int i = 1; i <= 5; i++)
{
    System.out.println(i);
}
Header part 例子 作用
Initializationint i = 1從哪裡開始，只執行一次。
Conditioni <= 5每輪 body 前檢查，true 才繼續。
Updatei++每輪 body 後執行，改變 loop variable。

Execution Order

for 的 update 不是一開始執行，而是在 body 之後

1. initialization
2. condition
3. body
4. update
5. 回到 condition
6. condition false 時離開 loop
Step i condition body update
111 <= 3 trueprint 1i++ → 2
222 <= 3 trueprint 2i++ → 3
333 <= 3 trueprint 3i++ → 4
stop44 <= 3 false--

第一次進 body 前不會先 update，所以 for (int i = 1; i <= 3; i++) 的第一個 output 是 1，不是 2。

Equivalent Loops

for 可以看成 counted while 的集中寫法

while version

int i = 1;

while (i <= 5)
{
    System.out.println(i);
    i++;
}

for version

for (int i = 1; i <= 5; i++)
{
    System.out.println(i);
}

轉成 while 時最容易忘記 update。少了 i++， i 永遠不變，就可能變成 infinite loop。

Common Patterns

四個最重要的 for loop pattern

0-based n 次

for (int i = 0; i < n; i++)

i = 0, 1, ..., n - 1，共 n 次。

1-based n 次

for (int i = 1; i <= n; i++)

i = 1, 2, ..., n，共 n 次。

Countdown

for (int i = n; i >= 1; i--)

從 n 倒數到 1。

Step by 2

for (int i = 0; i < n; i += 2)

走 0, 2, 4, ...；次數取決於 n。

Loop Bounds

Loop bounds 決定 loop variable 會經過哪些值

若 step 是 1，for (int i = a; i <= b; i++) 包含 b，執行次數是 b - a + 1。for (int i = a; i < b; i++) 不包含 b，執行次數是 b - a。前提是 a <= b 且 body 沒有修改控制變數或 bound。

Loop i 的值 次數
for (int i = 0; i < n; i++)0 ... n - 1n
for (int i = 0; i <= n; i++)0 ... nn + 1
for (int i = 1; i < n; i++)1 ... n - 1n - 1
for (int i = 1; i <= n; i++)1 ... nn

看到題目寫 through 或 inclusive，通常想到 <=。看到 up to but not including，通常想到 <。

Off-by-One

Off-by-one：loop 比預期多一次或少一次

目標 錯誤 正確
執行 10 次for (int i = 0; i <= 10; i++)for (int i = 0; i < 10; i++)
印 1 到 5for (int i = 0; i < 5; i++)for (int i = 1; i <= 5; i++)
處理 n 個 indexfor (int i = 0; i <= n; i++)for (int i = 0; i < n; i++)
倒數 10 到 1for (int i = 10; i >= 1; i++)for (int i = 10; i >= 1; i--)

Boundary test 的方法很簡單：列出第一個值、最後一個允許進 body 的值，再問自己是否多包含了一個不該出現的值。

Accumulator

for 很常搭配 accumulator、counter 與 nested if

Sum 1 to 5

int sum = 0;

for (int i = 1; i <= 5; i++)
{
    sum += i;
}

System.out.println(sum);  // 15

Product 1 to 5

int product = 1;

for (int i = 1; i <= 5; i++)
{
    product *= i;
}

System.out.println(product);  // 120

Count Multiples of 7

int count = 0;

for (int i = 1; i <= 100; i++)
{
    if (i % 7 == 0)
    {

    }
}

Scope

Loop variable 的 scope：在 header 宣告，通常 loop 外不能用

Compile error

for (int i = 0; i < 5; i++)
{
    System.out.println(i);
}

System.out.println(i);  // compile error

i 是在 for header 宣告，只存在於這個 loop 的範圍內。

Loop 後還需要 i

int i;

for (i = 0; i < 5; i++)
{
    System.out.println(i);
}

System.out.println(i);  // 5

如果真的需要在 loop 外使用，可以先在外面宣告。

Index Pattern

處理 index 時，最常見 pattern 是 i = 0; i < length; i++

Java 的 index 通常是 0 到 length - 1。String 還沒全面進入 traversal，但從現在開始要建立： length 不是最後 index，最後 index 是 length - 1。

String Index Preview

String word = "JAVA";

for (int i = 0; i < word.length(); i++)
{
    String letter = word.substring(i, i + 1);
    System.out.println(i + ": " + letter);
}
word length 合法 index 正確 condition
"JAVA"40, 1, 2, 3i < word.length()

若寫 i <= word.length()，最後會讓 i 等於 length，通常造成 index out of bounds。

AP Tracing

不要只看 header 猜次數：body 可能修改 i 或 bound

Body modifies i

for (int i = 0; i < 10; i++)
{
    i++;
}

每輪 body 中 i++，header update 又 i++，所以實際每輪 +2，body 執行 5 次。

Bound changes

int n = 8;

for (int i = 0; i < n; i++)
{
    n -= 2;
}

不能直接說 8 次。Trace：(i,n) 是 (0,8)、(1,6)、(2,4)，接著 (3,2) 停止，共 3 次。

Statement count

int count = 0;

for (int i = 0; i < 10; i++)
{
    if (i % 3 == 0)
    {
        count++;
    }
}

Loop body 10 次，但 count++ 只在 i = 0, 3, 6, 9 執行，共 4 次。

考前必背十二句

for is best for counted loops.

The initialization runs once.

The condition is checked before every iteration.

The update runs after the body.

for (int i = 0; i < n; i++) executes n times.

for (int i = 0; i <= n; i++) executes n + 1 times.

for (int i = 1; i <= n; i++) executes n times.

Inclusive bounds usually use <=.

Exclusive upper bounds usually use <.

The last valid index is length - 1.

Loop iterations and statement executions can be different.

If the body modifies i or the bound, trace carefully.
