A. Concepts

概念確認

先把 traversal、index、enhanced for、reference copy 這幾個核心語言釐清。

Q1Traversal

Array traversal 是什麼？

Traversal 是逐一走訪 array 中的元素，通常用 loop 檢查或更新每一格。

Q2Bounds

若 arr.length 是 5，valid indexes 是哪些？

Valid indexes 是 0、1、2、3、4。最後一格是 arr.length - 1。

Q3Loop Bound

為什麼 traversal 常寫 i < arr.length，不是 i <= arr.length？

因為 arr.length 不是 valid index。若用 <=，最後會嘗試存取 arr[arr.length]，造成 bounds error。

Q4Enhanced For

Enhanced for loop 適合哪類 array algorithms？

適合只需要讀取每個元素值的 algorithm，例如 sum、count、average、max/min、檢查是否存在某個值。

Q5Traditional For

何時通常需要 traditional for loop？

需要 index、修改 array、比較相鄰元素、reverse、shift、insert/remove-like logic、parallel arrays 時，通常需要 traditional for loop。

Q6Reference Copy

int[] b = a; 會複製整個 array 嗎？

不會。這只複製 reference value，讓 a 和 b 指向同一個 array。

B. Traversal

走訪與 bounds tracing

這組題目練習每一圈 loop 會走到哪些 indexes，以及哪些寫法會越界。

Q7Output

以下程式印出什麼？

int[] nums = {4, 7, 2, 9};

for (int i = 0; i < nums.length; i++)
{
    System.out.print(nums[i] + " ");
}

印出 4 7 2 9 。Loop 依序走訪 index 0、1、2、3。

Q8Every Other

以下程式印出什麼？

int[] nums = {4, 7, 2, 9, 5};

for (int i = 0; i < nums.length; i += 2)
{
    System.out.print(nums[i] + " ");
}

印出 4 2 5 。Indexes 是 0、2、4。

Q9Reverse Traversal

以下程式印出什麼？

int[] nums = {4, 7, 2};

for (int i = nums.length - 1; i >= 0; i--)
{
    System.out.print(nums[i] + " ");
}

印出 2 7 4 。Index 從 2 走到 0。

Q10Bounds Error

以下 loop 有什麼問題？

for (int i = 0; i <= nums.length; i++)
{
    System.out.println(nums[i]);
}

最後一圈 i == nums.length，會存取 invalid index，造成 ArrayIndexOutOfBoundsException。

Q11Adjacent

若要比較 arr[i] 和 arr[i + 1]，loop 條件應該到哪裡？

通常寫 i < arr.length - 1。這樣最大的 i + 1 才會是 arr.length - 1。

Q12Mutation

以下程式執行後 array 內容是什麼？

int[] nums = {1, 2, 3};

for (int i = 0; i < nums.length; i++)
{
    nums[i] *= 2;
}

Array 變成 {2, 4, 6}。這是直接修改每一格元素。

C. Sum / Count / Average

Accumulator 和 counter

Sum 是加值，count 是加次數；average 要小心 casting 和除以 0。

Q13Sum Trace

以下程式最後 sum 是多少？

int[] nums = {4, 7, 2, 9};
int sum = 0;

for (int value : nums)
{
    sum += value;
}

sum 是 22。

Q14Conditional Sum

以下程式最後 sum 是多少？

int[] nums = {4, 17, 2, 19};
int sum = 0;

for (int value : nums)
{
    if (value > 10)
    {
        sum += value;
    }
}

只加 17 和 19，所以 sum 是 36。

Q15Count Trace

以下程式最後 count 是多少？

int[] nums = {4, 17, 2, 19};
int count = 0;

for (int value : nums)
{
    if (value > 10)
    {
        count++;
    }
}

count 是 2，因為有兩個元素大於 10。

Q16Even Count

寫出條件：計算偶數數量時，if 裡應該放什麼？

if (value % 2 == 0)
{
    count++;
}
Q17Average

若 sum 是 5，nums.length 是 2，sum / nums.length 的結果是什麼？

若兩者都是 int，結果是 2，不是 2.5。這是 integer division。

Q18Casting

如何讓平均得到 2.5？

double average = (double) sum / nums.length;

至少把其中一個 operand 轉成 double。

Q19Conditional Average

Conditional average 為什麼通常需要 sum 和 count 兩個變數？

因為要加總符合條件的元素，也要知道符合條件的元素有幾個，最後才除以符合條件的 count。

Q20Divide by Zero

Conditional average 在除以前要檢查什麼？

要檢查 count > 0，避免沒有符合條件的元素時除以 0。

D. Max / Min / Search

Best-so-far 與 sentinel index

最大/最小值通常用第一格初始化；搜尋 index 常用 -1 代表未找到。

Q21Max Init

為什麼 int max = 0; 不一定安全？

如果 array 全是負數，0 可能根本不在 array 裡，答案會錯。通常用 max = arr[0]。

Q22Max Trace

以下程式最後 max 是多少？

int[] nums = {-8, -3, -10};
int max = nums[0];

for (int value : nums)
{
    if (value > max)
    {
        max = value;
    }
}

max 是 -3。

Q23Min Condition

找 minimum 時，if 條件應該用 > 還是 <？

用 <。若目前元素比 best-so-far 更小，就更新 min。

Q24Max Index

為什麼找最高分學生時，常追蹤 maxIndex 而不是只追蹤 maxScore？

因為 maxIndex 可以同時拿到 scores[maxIndex] 和 names[maxIndex]，特別適合 parallel arrays。

Q25First vs Last Max

在 max index algorithm 中，使用 > 和 >= 對 duplicate maximum 有什麼差別？

> 保留第一次出現的最大值；>= 會更新到最後一次出現的最大值。

Q26Search Boolean

以下 method 找到 target 時應回傳什麼？

public static boolean contains(int[] arr, int target)

找到時回傳 true；走完整個 array 都沒找到才回傳 false。

Q27Search Index

找 target index 時，為什麼常初始化 index = -1？

因為 -1 不是 valid index，可以當作 not found 的 sentinel value。

Q28Early Return Bug

為什麼下面這個 search method 錯了？

public static boolean contains(int[] arr, int target)
{
    for (int value : arr)
    {
        if (value == target)
        {
            return true;
        }
        return false;
    }
    return false;
}

return false; 放在 loop 裡，第一個元素不是 target 時就提早結束，沒有檢查後面的元素。

E. Copy / Reverse / Shift

Index mapping 和搬移方向

Copy 要建立新 array；reverse 要想對稱 index；shift 要避免覆蓋還沒搬的資料。

Q29Reference Copy

以下程式印出什麼？

int[] a = {1, 2, 3};
int[] b = a;
b[0] = 99;
System.out.println(a[0]);

印出 99。a 和 b 指向同一個 array。

Q30Element Copy

真正複製 array 的標準步驟是什麼？

int[] copy = new int[arr.length];
for (int i = 0; i < arr.length; i++)
{
    copy[i] = arr[i];
}
Q31Reverse Mapping

建立 reversed copy 時，result[i] 應該對應原 array 的哪一格？

result[i] = arr[arr.length - 1 - i];。這是反轉時最重要的 index mapping。

Q32In-place Reverse

In-place reverse 為什麼只需要跑到 arr.length / 2？

因為每次交換左右對稱兩格。若跑完整個 array，會把已經交換好的元素又交換回去。

Q33Right Shift

Right shift 時應該從哪個方向開始搬？

從右往左。這樣才不會先覆蓋還沒搬走的資料。

Q34Left Shift

Left shift 時應該從哪個方向開始搬？

從左往右。通常寫 for (int i = 0; i < arr.length - 1; i++)。

Q35Right Shift Trace

以下 right shift 後 array 前四格變成什麼？

int[] arr = {1, 2, 3, 4};

for (int i = arr.length - 1; i > 0; i--)
{
    arr[i] = arr[i - 1];
}

變成 {1, 1, 2, 3}。最左邊的格子通常要另外放新值或保留。

Q36Left Shift Trace

以下 left shift 後 array 前四格變成什麼？

int[] arr = {1, 2, 3, 4};

for (int i = 0; i < arr.length - 1; i++)
{
    arr[i] = arr[i + 1];
}

變成 {2, 3, 4, 4}。最後一格通常要另外清除或視為無效。

F. Insert / Remove / Parallel

固定長度與同步 index

Array 的 length 不會變；parallel arrays 必須讓同一個 index 永遠對應同一筆資料。

Q37Fixed Length

Array remove-like operation 會讓 arr.length 變小嗎？

不會。Array length 固定。通常用 logical size 追蹤目前有效元素數量。

Q38Insert Direction

在 index 2 插入元素前，為什麼要先 right shift？

因為要空出 index 2 的位置。Right shift 必須從右往左，避免覆蓋資料。

Q39Remove Direction

移除 index 2 的元素後，為什麼要 left shift？

因為要用右邊元素蓋掉被移除的位置，讓有效元素保持連續。

Q40Logical Size

若 array capacity 是 10，但目前只有 6 個有效元素，應該用哪個變數控制 insert/remove？

應用 logical size，例如 size。arr.length 只是 capacity，不是有效元素數量。

Q41Parallel Arrays

Parallel arrays 的核心關係是什麼？

相同 index 對應同一筆資料，例如 names[i] 和 scores[i] 是同一個學生的名字與分數。

Q42Max Index

若 scores[maxIndex] 是最高分，如何印出最高分學生名字？

System.out.println(names[maxIndex]);

Parallel arrays 用相同 index 連結資料。

Q43Parallel Remove

從 parallel arrays 移除一筆資料時，只移動 names 不移動 scores 會怎樣？

資料會不同步，同一個 index 不再代表同一個學生。所有 parallel arrays 都要同步 shift。

Q44Array Parameter

以下 method 執行後 caller 看到的 array 會改變嗎？

public static void change(int[] arr)
{
    arr[0] = 99;
}

會。這是透過 parameter 修改同一個 array object 的元素。

G. Coding / Trace

方法撰寫與 final tracing

最後六題把本課 pattern 寫成 AP-style methods。

Q45Write Sum

寫 sumArray，回傳 array 中所有元素總和。

public static int sumArray(int[] arr)
{
    int sum = 0;
    for (int value : arr)
    {
        sum += value;
    }
    return sum;
}
Q46Write Count

寫 countPositive，回傳正數數量。

public static int countPositive(int[] arr)
{
    int count = 0;
    for (int value : arr)
    {
        if (value > 0)
        {
            count++;
        }
    }
    return count;
}
Q47Write Find Index

寫 findIndex，找到 target 回傳 index，找不到回傳 -1。

public static int findIndex(int[] arr, int target)
{
    for (int i = 0; i < arr.length; i++)
    {
        if (arr[i] == target)
        {
            return i;
        }
    }
    return -1;
}
Q48Write Reversed Copy

寫 reversedCopy，回傳新的反轉 array，不修改原 array。

public static int[] reversedCopy(int[] arr)
{
    int[] result = new int[arr.length];
    for (int i = 0; i < arr.length; i++)
    {
        result[i] = arr[arr.length - 1 - i];
    }
    return result;
}
Q49Write Reverse In Place

寫 reverseInPlace，直接修改原 array。

public static void reverseInPlace(int[] arr)
{
    for (int i = 0; i < arr.length / 2; i++)
    {
        int opposite = arr.length - 1 - i;
        int temp = arr[i];
        arr[i] = arr[opposite];
        arr[opposite] = temp;
    }
}
Q50Final Challenge

以下程式最後印出什麼？

public static void mystery(int[] arr)
{
    for (int i = arr.length - 1; i > 0; i--)
    {
        arr[i] = arr[i - 1];
    }
    arr[0] = 0;
}

int[] nums = {3, 5, 7, 9};
mystery(nums);

for (int value : nums)
{
    System.out.print(value + " ");
}

印出 0 3 5 7 。Method 做 right shift，再把第一格設成 0。Array parameter mutation 會被 caller 看見。
