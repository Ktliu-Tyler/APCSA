Lesson Flow

本課路線

Assignment Statement

= 不是「左右相等」，而是「把結果存進去」

Java 的 assignment statement 通常長這樣：variable = expression;。 左邊稱為 LHS，也就是要被存入的目的地；右邊稱為 RHS， 也就是會先被計算的 expression。

Evaluate RHS Produce value Check type Store in LHS

這四步驟是 AP CSA 很常用來設計選擇題的地方。題目通常不會只問「這段程式能不能跑」， 而是要求你追蹤每個 statement 執行後，某個 variable 目前儲存的 value 是什麼。 只要你先把 RHS 算完，再把結果放進 LHS，就能避免把 assignment 誤解成數學等式。

看到 x = x + 3; 時，不要把它想成數學方程式。它的意思是： 先讀取目前的 x，把右邊的 x + 3 算完，再把新的 value 存回 x。

Assignment Trace

public class Main {
    public static void main(String[] args) {
        int x = 5;

        x = x + 3;
        System.out.println(x);
    }
}

Output 是 8。因為右邊先算：舊的 x 是 5， 5 + 3 得到 8，最後才存回 x。

Statement RHS 如何計算 LHS 存入什麼
x = y + 5; 讀取目前的 y，再加 5 把結果存入 x
average = total / 3.0; 先計算 total / 3.0 把 double 結果存入 average
x = x + y * 2; 先做 y * 2，再加目前的 x 把新結果覆蓋舊的 x

Declaration, Initialization, Reassignment

變數不是宣告後就自動有可用的值

Declaration 是建立變數名稱與型別，例如 int score;。 Initialization 是第一次給它 value，例如 int score = 80;。 之後再次修改，稱為 Reassignment。

Code 概念 意思
int score; Declaration 建立一個 int 變數名稱，但還沒有可讀取的 value。
int score = 80; Initialization 宣告並第一次存入 value。
score = 90; Reassignment 把新的 value 存入已存在的變數。

Uninitialized Variable

public class Main {
    public static void main(String[] args) {
        int x;
        int y = x + 5;

        System.out.println(y);
    }
}

這段程式會產生 compile-time error。Local variable x 還沒有被初始化， Java 不能拿一個沒有 value 的變數去計算 x + 5。

Sequential Execution

AP CSA 很重視逐行追蹤

Java statement 通常會由上到下執行。當同一個變數被更新多次，每一行都要使用「當下最新」的 value。 Trace table 可以把這件事變得很清楚。

Trace Table Example

int x = 4;
int y = 2;

x = x + y;
y = x * 2;
x = y - x;
Statement x y 說明
Initial 4 2 初始值。
x = x + y; 6 2 右邊是 4 + 2。
y = x * 2; 6 12 這一行使用新的 x，所以是 6 * 2。
x = y - x; 6 12 右邊是 12 - 6，所以 x 仍是 6。

另一個常見陷阱是「變數會不會永久連動」。int b = a; 只是在當下把 a 的 value 複製給 b。之後 a 改變，b 不會自動跟著改。

如果想交換兩個 primitive variables 的值，不能只寫 a = b; 再寫 b = a;。 第一行會先覆蓋掉 a 原本的 value，所以你需要第三個暫存變數保存舊值。

Swap with a Temporary Variable

int a = 3;
int b = 8;

int temp = a;
a = b;
b = temp;

Input and Scanner

Input 讓程式不只使用寫死的資料

到目前為止，很多 value 都直接寫在程式裡，例如 int age = 18;。 真正的程式通常會接收 input，再依照輸入內容計算。Input 可以來自鍵盤、檔案、感測器或網路； 在 Java 入門階段，最常見的是使用 Scanner 讀取鍵盤輸入。

Keyboard輸入年齡、分數、溫度等文字或數字。
File之後可能從文字檔讀取資料，AP CSA 新版內容也更重視資料處理。
Sensor / Device滑鼠、觸控、麥克風、相機或其他裝置也都能是 input 來源。
Network網站或伺服器傳來的資料，也可以成為程式處理的 input。

Scanner Age Input

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your age: ");
        int age = input.nextInt();

        System.out.println("Your age is " + age);
    }
}

import java.util.Scanner; 讓程式可以使用 Scanner 這個 class。 Scanner input = new Scanner(System.in); 建立一個從鍵盤讀取資料的物件。 input.nextInt() 會讀取下一個整數，並產生一個 int value。

Method 讀取的資料 產生的型別
nextInt() 下一個可以解析成整數的 input int
nextDouble() 下一個可以解析成小數的 input double
System.in 標準輸入來源 通常可以先理解為鍵盤輸入

Rectangle Calculator

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter length: ");
        double length = input.nextDouble();

        System.out.print("Enter width: ");
        double width = input.nextDouble();

        double area = length * width;
        System.out.println("Area = " + area);
    }
}

Input 也是 assignment。int age = input.nextInt(); 的右邊會先產生一個 int value， 再存進左邊的 age。

AP CSA 需要你理解 program 可以取得 input，並把 input 轉成 variable value 後進行 calculation。 考試通常不會要求你背大量輸入裝置的特殊 API；更重要的是看懂 input method 產生什麼型別， 以及這個 value 之後如何參與 expression。

Casting

Casting 是暫時把 value 轉成另一種型別

AP CSA 最常見的 casting 是 (int) 與 (double)。 int 轉成 double 通常可以自動完成，稱為 widening conversion。 double 轉成 int 可能失去小數資訊，所以需要明確寫出 casting，稱為 narrowing conversion。

Conversion 是否自動允許 Example
int 到 double 可以 double x = 5;
double 到 int 不可以 int x = 5.5; 會 compile error
double 到 int with casting 可以 int x = (int) 5.5;

(int) 不是四捨五入，而是直接移除小數點右側的部分。這個動作稱為 truncate toward zero，所以 (int) 3.9 是 3， (int) -3.9 是 -3。

Expression Result 原因
(int) 3.9 3 移除小數部分。
(int) 3.1 3 不是四捨五入。
(int) -3.9 -3 朝 0 truncate，不是 floor。
(int) -3.1 -3 小數部分被截掉。

Casting Position

public class Main {
    public static void main(String[] args) {
        double a = (double) (7 / 2);
        double b = (double) 7 / 2;

        System.out.println(a);
        System.out.println(b);
    }
}

第一個 expression 先做括號裡的 7 / 2，得到 3，再轉成 3.0。 第二個 expression 先把 7 轉成 7.0，接著做 double division，得到 3.5。

Code Result AP CSA 要看的重點
double r = 5 / 2; 2.0 右邊先做 int / int，小數先消失。
double r = (double) 5 / 2; 2.5 先讓其中一邊變成 double。
double r = (double) (5 / 2); 2.0 括號裡的 integer division 已經先完成。
double r = 5 / 2 + 0.0; 2.0 5 / 2 先變成 2，之後才加 double。

Rounding with Casting

要四捨五入，必須先調整 value 再 casting

因為 (int) 只是 truncation，所以 (int) 4.8 會得到 4。 如果要把非負數四捨五入到最接近的整數，可以先加 0.5，再轉成 int。

Value Technique Example
x >= 0 (int) (x + 0.5) 4.8 + 0.5 變 5.3，再得到 5
x < 0 (int) (x - 0.5) -4.8 - 0.5 變 -5.3，再得到 -5

Round a Score

public class Main {
    public static void main(String[] args) {
        double score = 87.6;

        int roundedScore = (int) (score + 0.5);
        System.out.println(roundedScore);
    }
}

這個技巧只是在 AP CSA 基礎範圍中幫你理解 casting 與 arithmetic 的組合。 它的核心不是背公式，而是理解：先透過 + 0.5 或 - 0.5 把 value 推過整數邊界， 再用 (int) truncate toward zero。

Range and Precision

int 不是無限大，double 也不是完全精確

Java 的 int 使用 32 bits 儲存整數，範圍是 -2147483648 到 2147483647。Java 提供 Integer.MIN_VALUE 與 Integer.MAX_VALUE 表示這兩個邊界。

Print int Range

public class Main {
    public static void main(String[] args) {
        System.out.println(Integer.MIN_VALUE);
        System.out.println(Integer.MAX_VALUE);
    }
}

這兩個常數本身也是合法的 int value。AP CSA 題目常用它們檢查你是否知道： int 不是數學上的無限整數，而是有固定範圍的資料型別。

Integer Overflow

public class Main {
    public static void main(String[] args) {
        int x = Integer.MAX_VALUE;

        System.out.println(x);
        x = x + 1;
        System.out.println(x);
    }
}

數學上最大值加 1 應該變更大，但 int 已經沒有空間表示這個結果，所以會發生 integer overflow。它不一定是 compile-time error 或 runtime error；程式可能繼續執行， 只是得到一個合法但不符合數學直覺的 int value。

Overflow 不只發生在 Integer.MAX_VALUE + 1。只要某個 expression 的結果超過 int range， 就可能 overflow。即使每個 variable 自己都在合法範圍內，expression 的計算結果仍然可能超出範圍。

Overflow in an Expression

public class Main {
    public static void main(String[] args) {
        int x = 1500000000;
        int y = 2;

        int result = x * y;
        System.out.println(result);
    }
}

兩個變數 x 和 y 都是合法的 int，但 x * y 的數學結果是 3000000000，超過 Integer.MAX_VALUE。AP CSA 題目常用這種方式檢查你是否理解 overflow 是 expression result 超出型別範圍。

Floating-Point Round-Off

public class Main {
    public static void main(String[] args) {
        double result = 0.1 + 0.2;
        System.out.println(result);
    }
}

double 使用有限的 binary bits 表示小數，像 0.1 這種十進位小數無法永遠被精確表示。 所以 0.1 + 0.2 可能印出 0.30000000000000004。這不是 Java 算錯， 而是 floating-point representation 的限制。

這件事在 AP CSA 中通常不是要你深入研究二進位浮點標準，而是要知道： double 的計算可能出現 very small round-off error。當程式需要非常精確的 decimal， 例如金額，有些系統會改用整數單位儲存，例如用 cents 儲存 1099，而不是用 dollars 儲存 10.99。

Concept 重點 常見判斷
int 精確表示整數，但範圍有限。 可能 overflow。
double 可以表示小數與更大範圍的數值，但不是所有 decimal 都精確。 可能 round-off error。

Compound Assignment

常見更新可以寫得更短，但規則沒有改變

x += 5; 可以理解成 x = x + 5;。 x -= 3;、x *= 2;、x /= 4;、x %= 3; 也都是同樣的更新概念。注意：如果 x 是 int，x /= 2; 仍然會做 integer division。

這些簡寫看起來像新的語法，但它們沒有取消 assignment 的核心規則：仍然要讀取舊 value、 計算新的 expression、遵守型別規則，最後把結果存回原本的 variable。

Short Form 基本意義 例子
x += y x = x + y 10 += 5 會變成 15
x /= y x = x / y int x = 5; x /= 2; 會讓 x 變 2
x %= y x = x % y 10 % 3 的結果是 1
x++ x = x + 1 常出現在 loops。
x-- x = x - 1 讓數值減少 1。

Compound Trace

public class Main {
    public static void main(String[] args) {
        int x = 10;

        x += 5;
        x -= 3;
        x *= 2;
        x /= 4;
        x %= 3;

        System.out.println(x);
    }
}

Trace：10 到 15，到 12，到 24， 到 6，最後 6 % 3 得到 0。

x++ 與 x-- 在本課先當作獨立 statement 使用。 之後在 for loop 會常看到 i++，代表每次 iteration 後讓 i 增加 1。 目前不需要先深入 int y = x++; 這類 evaluation order 較複雜的寫法。

迷思 正確觀念 典型題型
Assignment 是從左邊算到右邊。 先計算 RHS，再存入 LHS。 Trace variable value after several statements.
宣告 variable 後就可以直接使用。 Local variable 必須先初始化。 判斷 compile-time error。
(int) 是四捨五入或 floor。 (int) 是 truncate toward zero。 預測 (int) -7.9。
Casting 放在哪裡都一樣。 Casting position 會改變 division 的型別。 比較 (double) (a / b) 與 (double) a / b。
double result = 5 / 2; 一定是 2.5。 右邊先做 integer division，結果是 2.0。 修正 average calculation。
int 可以儲存任意大的 integer。 int 有固定 range。 判斷 overflow 是否可能發生。
Overflow 一定會 runtime error。 程式可能繼續執行，但 value 不符合預期。 預測 Integer.MAX_VALUE + 1。
double 可以精確表示所有 decimal。 double 可能有 round-off error。 解釋 0.1 + 0.2 的結果。

Final Trace Challenge

public class Main {
    public static void main(String[] args) {
        int a = 17;
        int b = 4;

        double x = (double) a / b;

        a %= b;
        b += 2;
        a *= b;
        a++;

        int y = (int) x;

        System.out.println(a);
        System.out.println(b);
        System.out.println(x);
        System.out.println(y);
    }
}

這個 challenge 同時檢查 casting position、modulo、compound assignment、increment 與 truncation。 正確 trace 是：x = 4.25，a 先變成 1，b 變成 6， a *= b 後變成 6，a++ 後變成 7，最後 y = 4。 Output 是 7、6、4.25、4。
