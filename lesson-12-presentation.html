From Single Loop

單層 loop 只走一條線；nested loop 可以走一張表

印出方格或表格
印出三角形 pattern
產生乘法表
列出所有 row / column
列出所有 pair
預備 2D arrays

Core Syntax

Nested loop = loop inside loop

for (int row = 0; row < 3; row++)
{
    for (int col = 0; col < 4; col++)
    {
        System.out.println(row + " " + col);
    }
}

outer loop 控制大輪次；inner loop 控制每一輪內部細節。

Execution Rule

Outer 每跑一次，inner 都重新完整跑一次

outer value fixed inner initializes inner completes outer updates inner starts again

j 不會從上一輪結束後的值繼續，它會重新 initialization。

Quick Trace

這段程式輸出幾行？

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 2; j++)
    {
        System.out.println(i + " " + j);
    }
}

6 行。外層 3 次，每次內層 2 次。

Trace Output

完整輸出順序

1 1
1 2
2 1
2 2
3 1
3 2

固定 i = 1，把 j 全部跑完；再進到 i = 2。

Row / Column Thinking

把 nested loops 想成一張表

Outerrow / group / item
Innercolumn / detail / comparison
Totalrows × columns

Pattern 題先問：有幾列？每列幾個？每個位置印什麼？

Counting Iterations

固定範圍：外層次數 × 內層次數

int count = 0;

for (int r = 0; r < 3; r++)
{
    for (int c = 0; c < 4; c++)
    {
        count++;
    }
}

12。3 rows × 4 columns。

Pattern Output

print 留在同一列，println 換到下一列

for (int row = 1; row <= 3; row++)
{
    for (int col = 1; col <= 5; col++)
    {
        System.out.print("*");
    }
    System.out.println();
}

Rectangle Pattern

上一張會印出什麼？

*****
*****
*****

inner loop 印完一整列，outer loop 才進下一列。

Dependent Bounds

inner bound 用到 outer variable，就會改變每列長度

for (int row = 1; row <= 5; row++)
{
    for (int col = 1; col <= row; col++)
    {
        System.out.print("*");
    }
    System.out.println();
}

Increasing Triangle

每列長度是 1, 2, 3, 4, 5

*
**
***
****
*****

總數是 1 + 2 + 3 + 4 + 5 = 15，不是 5 * 5。

Dependent Count

這段 inner body 執行幾次？

for (int i = 1; i <= 4; i++)
{
    for (int j = 1; j <= i; j++)
    {
        System.out.println(j);
    }
}

1 + 2 + 3 + 4 = 10 次。

Decreasing Triangle

反向控制 row，就能縮短每列

for (int row = 5; row >= 1; row--)
{
    for (int col = 1; col <= row; col++)
    {
        System.out.print("*");
    }
    System.out.println();
}

輸出是 5、4、3、2、1 顆星。

Row vs Column Values

印 row 或印 column，pattern 會不同

System.out.print(row);1 / 22 / 333
System.out.print(col);1 / 12 / 123

看到 pattern 請先判斷要使用 outer variable 還是 inner variable。

Multiplication Table

乘法表：每一格都是 row × column

for (int row = 1; row <= 9; row++)
{
    for (int col = 1; col <= 9; col++)
    {
        System.out.print(row * col + "\t");
    }
    System.out.println();
}

All Ordered Pairs

每個 i 都配每個 j

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        System.out.println(i + "," + j);
    }
}

總共有 9 組，包含 self-pair，也包含方向不同的 pair。

Unique Pairs

如果不想重複，讓 j 從 i + 1 開始

for (int i = 1; i <= 4; i++)
{
    for (int j = i + 1; j <= 4; j++)
    {
        System.out.println(i + "," + j);
    }
}
1,2
1,3
1,4
2,3
2,4
3,4

Pair Conditions

完整 nested loops 也能用 if 篩選 pair

int count = 0;

for (int i = 1; i <= 4; i++)
{
    for (int j = 1; j <= 4; j++)
    {
        if (i < j)
        {
            count++;
        }
    }
}

答案也是 6；但用 j = i + 1 可以少寫 if。

Nested Trace

Trace 時要追蹤 i、j、sum

int sum = 0;

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= i; j++)
    {
        sum += i + j;
    }
}

24。加入的值依序是 2、3、4、4、5、6。

Accumulator Scope

放在 outer 外面：總累積；放在 outer 裡面：每列重算

int total = 0;

for (int row = 1; row <= 3; row++)
{
    int rowSum = 0;

    for (int col = 1; col <= 4; col++)
    {
        rowSum += col;
        total += col;
    }
}

rowSum 每列歸零；total 一路累積。

Runtime Intuition

Nested loops 常代表平方級工作量

One loopO(n)
n by nO(n^2)
n by mO(nm)
Triangle仍接近 O(n^2)
Fixed sizes用實際次數計算
AP trace先列前幾輪

Common Bugs

Nested loop 最常見六種錯誤

inner condition 用錯變數
inner update 改錯變數
println 放錯位置
row accumulator 沒有每列歸零
把三角形算成矩形
pair 重複或自己跟自己配對

Debug This

這段 inner loop 的 bug 是什麼？

for (int i = 0; i < 3; i++)
{
    for (int j = 0; i < 4; j++)
    {
        System.out.println(j);
    }
}

inner condition 應該檢查 j，不是 i。

AP SOP

Nested loop 解題流程

Identify outer role Identify inner role List first rows Track state Check bounds Answer output/count

不要急著心算。把前兩個 outer values 寫出來，答案通常會很清楚。
