A. Concepts

概念確認

先確認 loop algorithm 不是只會寫 loop，而是會維護正確狀態。

Q1Structure

大多數 loop algorithm 可以拆成哪三個部分？

Initialization、repeated processing、final result。

Q2State

在 loop algorithm 中，sum、count、found 這類變數的角色是什麼？

它們保存 loop 目前已知的狀態，例如已處理資料的總和、已找到幾個、是否已找到目標。

Q3Sum vs Count

sum += value 和 count++ 差在哪？

sum += value 是把數值加進總和；count++ 是表示又找到一個符合項目。

Q4Initialization

為什麼 initialization 往往決定演算法正確性？

因為 loop 的每次更新都建立在初始狀態上。像 sum 應從 0、product 應從 1、found 應從 false、min/max 通常應從第一筆真實資料開始。

Q5Invariant

Loop invariant 是什麼意思？

每次 iteration 開始時都維持正確的一個敘述，例如 sum 是已處理資料的總和。

Q6Trace

Loop algorithm trace 時，除了 loop variable，還要追蹤什麼？

所有 state variables，例如 sum、count、max、min、found、result。

B. Sum / Count

Sum、Count、Conditional Processing

分辨「把值加進去」和「符合項目數量加一」。

Q7Sum

最後 sum 是多少？

int sum = 0;

for (int i = 1; i <= 4; i++)
{
    sum += i;
}

1 + 2 + 3 + 4 = 10。

Q8Square sum

最後 sum 是多少？

int sum = 0;

for (int i = 1; i <= 5; i++)
{
    sum += i * i;
}

1 + 4 + 9 + 16 + 25 = 55。

Q9Conditional sum

最後 sum 是多少？

int sum = 0;

for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
    {
        sum += i;
    }
}

2 + 4 + 6 + 8 + 10 = 30。

Q10Count

最後 count 是多少？

int count = 0;

for (int i = 1; i <= 20; i++)
{
    if (i % 3 == 0)
    {
        count++;
    }
}

3、6、9、12、15、18，共 6 個。

Q11Sum and count

最後 sum 和 count 是多少？

int sum = 0;
int count = 0;

for (int i = 1; i <= 20; i++)
{
    if (i % 5 == 0)
    {
        sum += i;
        count++;
    }
}

符合的是 5、10、15、20，所以 sum = 50，count = 4。

Q12Bug

想計算偶數有幾個，這段錯在哪？

int count = 0;

for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
    {
        count += i;
    }
}

這是在加總偶數，不是在計數。計數應寫 count++。目前結果會是 30，而不是 5。

Q13Bug

想加總 1 到 5，這段錯在哪？

int sum = 0;

for (int i = 1; i <= 5; i++)
{
    sum++;
}

sum++ 只是在每輪加 1，最後是 5。若要加總 1 到 5，應寫 sum += i，結果是 15。

Q14Trace

最後 sum 是多少？

int sum = 0;

for (int i = 1; i <= 5; i++)
{
    if (i % 2 == 1)
    {
        sum += i * 2;
    }
}

奇數是 1、3、5，加入 2、6、10，所以 sum = 18。

C. Average

Average / Casting / Count Check

平均通常在 loop 後計算，並要避開 integer division 和除以 0。

Q15Average

若 sum = 17、count = 4，double avg = sum / count; 的值是什麼？

4.0。兩邊都是 int，所以先做 integer division：17 / 4 = 4。

Q16Casting

要得到 4.25，應怎麼寫？

double avg = (double) sum / count;。只要其中一邊先變 double，就會做 floating-point division。

Q17Average

最後 average 是多少？

int sum = 0;
int count = 0;

for (int i = 1; i <= 100; i++)
{
    if (i % 10 == 0)
    {
        sum += i;
        count++;
    }
}

double average = (double) sum / count;

10、20、...、100 的總和是 550，count 是 10，所以 average 是 55.0。

Q18Safety

為什麼 conditional average 常需要 if (count > 0)？

如果沒有任何 value 符合條件，count 會是 0，直接 sum / count 會出問題。

Q19Bug

這個 average algorithm 的概念錯在哪？

double average = 0;

for (int i = 1; i <= 5; i++)
{
    average += i / 5;
}

平均通常不應每輪這樣加。且 i / 5 是 int division，1 到 4 都是 0。標準做法是先 sum，再 loop 後除。

D. Min / Max

Running Minimum / Maximum

最重要是比較方向與 initialization。

Q20Max

找 maximum 時，看到新值 value 應使用哪個 condition？

if (value > max)，若新值更大就更新 max = value。

Q21Min

找 minimum 時，看到新值 value 應使用哪個 condition？

if (value < min)，若新值更小就更新 min = value。

Q22Initialization

為什麼 int max = 0; 不一定正確？

如果所有資料都是負數，例如 -8、-3、-20，真正最大是 -3，但 max = 0 會錯誤保留 0。

Q23Initialization

找 min/max 最常見且安全的 initialization 是什麼？

用第一個真實資料初始化，例如 int max = input.nextInt(); 或 int min = firstValue;。

Q24Trace max

資料依序是 8、3、12、5、9，最後 max 是多少？

先設 max = 8，看到 12 時更新，後面 5、9 不更新，所以最後 max = 12。

Q25Trace min

資料依序是 8、3、12、-2、9，最後 min 是多少？

先設 min = 8，看到 3 更新，看到 -2 再更新，所以最後 min = -2。

Q26Bug

這段想找 max，錯在哪？

if (value < max)
{
    max = value;
}

比較方向反了。這會往較小的值更新，接近 minimum。找 max 應使用 value > max。

E. Search

Find Any、Find First、Early Exit

搜尋題要先看題目問「有沒有、第一個、最後一個、還是幾個」。

Q27Find any

Find any 問題通常使用什麼變數？

boolean found = false;。找到 match 時設成 true。

Q28Find any

最後 found 是什麼？

boolean found = false;

for (int i = 1; i <= 20; i++)
{
    if (i % 4 == 0 && i % 6 == 0)
    {
        found = true;
    }
}

true，因為 12 同時是 4 和 6 的倍數。

Q29Flag bug

這段最後 found 是什麼？為什麼這是錯誤 find-any pattern？

boolean found = false;

for (int i = 1; i <= 5; i++)
{
    if (i == 3)
    {
        found = true;
    }
    else
    {
        found = false;
    }
}

最後是 false，因為 i = 5 時 else 把 found 改回 false。Find any 中，找到後通常不要改回 false。

Q30Early exit

這段找到 7 後，loop 結束時 i 是多少？

int i = 1;
boolean found = false;

while (i <= 20 && !found)
{
    if (i % 7 == 0)
    {
        found = true;
    }
    i++;
}

找到時 i = 7，但 body 最後還會 i++，所以 loop 結束時 i = 8。

Q31Find first

找 1 到 100 第一個同時是 7 和 9 的倍數，結果是什麼？

63。它是 7 和 9 的最小共同倍數。

Q32Find first bug

這段找的是 first 還是 last？

int first = -1;

for (int i = 1; i <= 100; i++)
{
    if (i % 10 == 0)
    {
        first = i;
    }
}

它最後得到 100，其實是 last matching value，不是 first。要找 first 應 early exit 或只在尚未找到時更新。

Q33Early exit

哪些題型通常適合 early exit？

Find any、find first、boolean existence check。Sum、count all、average、min/max 通常要掃完整份資料。

F. String

String Traversal / Substring Search

特別注意 bounds、substring end exclusive、overlapping matches。

Q34Bounds

String traversal 為什麼通常用 i < str.length()？

合法 index 是 0 到 length() - 1。若寫 i <= str.length()，最後會跑到非法 index。

Q35Substring

substring(i, i + 1) 取得什麼？

取得 index i 的單一字元字串。End index 是 exclusive。

Q36Count chars

"MISSISSIPPI" 裡 "I" 出現幾次？

4 次。

Q37First char

"MISSISSIPPI" 第一個 "S" 的 index 是多少？

2。Index 0 是 M，1 是 I，2 是 S。

Q38Reverse

最後 result 是什麼？

String s = "CODE";
String result = "";

for (int i = s.length() - 1; i >= 0; i--)
{
    result += s.substring(i, i + 1);
}

"EDOC"。

Q39Filter

最後 result 是什麼？

String s = "ABACADA";
String result = "";

for (int i = 0; i < s.length(); i++)
{
    String letter = s.substring(i, i + 1);

    if (!letter.equals("A"))
    {
        result += letter;
    }
}

"BCD"。所有 A 被過濾掉。

Q40Pair bounds

使用 substring(i, i + 2) 檢查長度 2 的 pair 時，condition 通常是什麼？

i < s.length() - 1。最後起點是 length() - 2。

Q41Pairs

"ABABAB" 中 "AB" 出現幾次？

3 次：index 0~1、2~3、4~5。

Q42Overlapping

"AAAA" 中，overlapping 的 "AA" 有幾個？

3 個：index 0~1、1~2、2~3。

Q44Coding

求 1 到 100 所有 5 的倍數總和。

for (int i = 1; i <= 100; i++)
{
    if (i % 5 == 0)
    {
        sum += i;

Q45Coding

求 1 到 100 中有多少個奇數。

int count = 0;

for (int i = 1; i <= 100; i++)
{
    if (i % 2 != 0)
    {
        count++;
    }

Q46Coding

輸入 5 個整數並找最大值。

int max = input.nextInt();

for (int i = 1; i < 5; i++)
{
    int value = input.nextInt();

    if (value > max)
    {
        max = value;
    }
}
Q47Coding

找 50 到 100 第一個 13 的倍數。

int first = -1;
boolean found = false;
int i = 50;

while (i <= 100 && !found)
{
    if (i % 13 == 0)
    {
        first = i;
        found = true;
    }
    i++;
}

答案是 52。

Q48Coding

計算 "MISSISSIPPI" 中 "I" 出現幾次。

String word = "MISSISSIPPI";
int count = 0;

for (int i = 0; i < word.length(); i++)
{
    if (word.substring(i, i + 1).equals("I"))
    {
        count++;
    }
}
Q49Coding

把 "CODE" 反轉成新字串。

String s = "CODE";
String result = "";

for (int i = s.length() - 1; i >= 0; i--)
{
    result += s.substring(i, i + 1);

Q50Final Challenge

預測 sum、count 和 average。

int sum = 0;
int count = 0;

for (int i = 1; i <= 8; i++)
{
    if (i % 3 != 0)
    {
        sum += i;
        count++;
    }
}

排除 3 和 6，加入 1、2、4、5、7、8。sum = 27，count = 6，average 是 4.5。
