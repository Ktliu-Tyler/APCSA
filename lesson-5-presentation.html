AP Computer Science A｜Lesson 5

String Methods

今天正式操作 String objects：index、length()、substring()、 indexOf()、equals()、compareTo()、concatenation 與 immutability。

開啟 OneCompiler Lesson 5 課後練習

From Lesson 4

String 是 class，不是 primitive type

String name = "Alice";

String

class / reference type

name

reference variable

"Alice"

String object / literal

name 不是直接放著文字本身；它 reference 到一個 String object。

Literal and char

雙引號是 String，單引號是 char

'A'char
"A"String
""empty String

即使 "A" 只有一個字元，它仍然是 String。

Index

String index 從 0 開始

character: c o m p u t e r
index:     0 1 2 3 4 5 6 7
length:    8
first index = 0 length = characters last index = length - 1

length()

length() 回傳 character 數量

String text = "AP CSA";
System.out.println(text.length());

Output 是多少？

A. 5 B. 6 C. 7 D. Compile error

答案是 B。中間的 space 也是 character，所以 "AP CSA" 長度是 6。

Empty vs null

"" 和 null 完全不同

""

有 String object；length() 是 0。

null

沒有 String object；呼叫 method 會 error。

" "

一個 space；length() 是 1。

substring

substring(a, b) 取 a <= index < b

String word = "computer";
System.out.println(word.substring(2, 5));
c o m p u t e r
0 1 2 3 4 5 6 7
    ^ ^ ^

取 index 2、3、4，結果是 "mpu"。不包含 index 5。

substring Formula

合法條件：0 <= from <= to <= length()

Result length

substring(a, b) 長度通常是 b - a。

Full String

s.substring(0, s.length())

Single character String

s.substring(i, i + 1)

第二個 parameter 是停止位置，不是最後一個被取出的 index。

substring(from)

substring(from) 從 from 取到最後

String s = "abcdef";
System.out.println(s.substring(2));

Output 是什麼？

A. ab B. bcdef C. cdef D. def

答案是 C。index 2 是 c，所以從 c 取到最後得到 "cdef"。

Special but Legal

有些 substring 會得到 empty string，但合法

s.substring(s.length())

從結尾取到結尾，結果是 ""。

s.substring(3, 3)

start 等於 end，沒有取出 character。

Not legal

from > to 或超出 length。

indexOf

indexOf() 回傳第一次出現的位置

String s = "banana";
System.out.println(s.indexOf("an"));

Output 是多少？

A. 0 B. 1 C. 3 D. 4

答案是 B。"an" 第一次從 index 1 開始。

Not Found

indexOf() 找不到回傳 -1

"computer".indexOf("com")

0，因為在開頭找到。

"computer".indexOf("xyz")

-1，因為找不到。

Trap

找不到不是 0。0 代表在第一個位置找到。

indexOf + substring

重要組合：取 Email username

String email = "student@gmail.com";
int at = email.indexOf("@");
String username = email.substring(0, at);

substring(0, at) 不包含 ending index at，所以剛好取到 @ 前一個 character。

equals

equals() 比較 String 內容

System.out.println("hello".equals("Hello"));

Output 是什麼？

A. true B. false C. 0 D. Runtime error

答案是 B。equals() 是 case-sensitive，h 和 H 不同。

== vs equals

== 比較 references；equals() 比較 contents

String a = new String("cat");
String b = new String("cat");

System.out.println(a == b);
System.out.println(a.equals(b));
false
true

兩次 new 建立兩個不同 objects，所以 == 是 false；內容相同，所以 equals() 是 true。

compareTo

compareTo() 看正負號，不要假設 ±1

< 0

前面的 String 排在前面。

0

兩個 Strings 相同。

> 0

前面的 String 排在後面。

"apple".compareTo("banana") < 0，但不一定等於 -1。

compareTo Check

快速檢核

String a = "dog";
String b = "cat";
System.out.println(a.compareTo(b) > 0);

Output 是什麼？

A. true B. false C. 1 D. -1

答案是 A。"dog" 排在 "cat" 後面，所以 compareTo 回傳正數。

Concatenation

+ 遇到 String 會做串接

System.out.println("A" + 1 + 2);
System.out.println(1 + 2 + "A");

兩行 output 是什麼？

A12
3A

+ 左到右。String 先出現就串接；數字先相加則先算數字加法。

Immutability

String objects are immutable

String s = "hello";
s.substring(1);
System.out.println(s);

Output 是 hello。substring(1) 回傳新 String，但沒有修改原本的 s。

Save Return Value

要保存 String method 的結果，需要 assignment

String s = "hello";
s = s.substring(1);
System.out.println(s);

Output 是 ello。這不是原本 object 被修改，而是 s 被重新 assignment 到新的 String result。

Method Chaining

一次只算一個 method call

String s = "banana";
System.out.println(s.substring(2).indexOf("a"));

s.substring(2) 得到 "nana"。新的 String 重新從 index 0 開始，所以 "nana".indexOf("a") 是 1。

Runtime Errors

兩個常見 runtime errors

NullPointerException

String s = null; s.length();

StringIndexOutOfBoundsException

"cat".substring(0, 4)

Logic error

想取前三個，卻寫 substring(0, 2)。

AP SOP

String tracing 固定流程

Write String Mark index Mark length One method Re-index new String

產生新 String 後，index 必須重新從 0 開始。

AP-style Check

綜合追蹤

String str = "mississippi";

int a = str.indexOf("iss");
String b = str.substring(a, a + 4);
int c = b.length();

"iss" 第一次從 index 1 開始，所以 a = 1。substring(1, 5) 得到 "issi"，所以 c = 4。

Mini Coding

今天可以完成的五個小程式

Initials：用 substring(0, 1) 取姓名縮寫。
Email Username：用 indexOf("@") 加 substring。
File Extension：找到 "." 後取後半段。
First and Last：取第一個與最後一個 character String。
String Trace：每次 substring 後重新標 index。
