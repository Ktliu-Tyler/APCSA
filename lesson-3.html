Method call 會變成 expression 裡的一個 value

Lesson 1 和 Lesson 2 已經建立了 variable、expression、assignment、 casting、integer division。從這一課開始，expression 裡面會開始出現 method call。

Method Call in an Expression

double x = Math.sqrt(25) + 3;

這行不是直接背答案，而是先把 method call 換成它的 return value：

Math.sqrt(25) 5.0 5.0 + 3 8.0 x = 8.0

AP CSA 看到 method call 時，不要只看 method name。請同時問三件事： 它需要哪些 arguments？它回傳什麼 value？它的 return type 是什麼？

Method Call

Method 是可以被呼叫執行的一段功能

在 Java 中，method 是一段具有特定功能、可以被呼叫執行的程式碼。 例如 Math.sqrt(25) 會計算 25 的平方根，回傳 5.0。

形式 例子 意思
ClassName.methodName(arguments) Math.pow(2, 3) 到 Math class 裡呼叫 pow method。
method name pow 要執行哪個功能。
arguments 2, 3 呼叫時實際傳入的資料。
return value 8.0 method 執行完產生的結果。
Input把 arguments 傳進 method。
Processmethod 內部執行某段功能。
Return如果 method 有回傳值，就能放進 expression。
Trace把 method call 替換成 return value 繼續算。

Argument vs Parameter

Argument 是呼叫時傳入的資料，parameter 是定義時接收資料的變數

AP CSA 很喜歡考這兩個字。它們都跟資料傳遞有關，但出現位置不同。 Argument 出現在 method call。Parameter 出現在 method definition。

Parameter and Argument

public static int square(int x)
{
    return x * x;
}

int result = square(7);
名稱 出現位置 在例子中是什麼 意思
Parameter method 定義 int x 接收資料的變數。
Argument method call 7 實際傳進 method 的 value。

呼叫 square(7) 時，可以把它想成 x = 7， 接著 method 內部執行 return x * x;，所以 return value 是 49。

精準說法：argument 和 parameter 不是完全一樣的東西。它們描述同一個資料傳遞過程中的不同位置。

Return Value

Return value 可以被儲存、印出，也可以繼續參與 expression

很多 methods 執行完會產生一個結果，稱為 return value。例如 Math.sqrt(81) 的 return value 是 9.0。

寫法 作用 結果
double answer = Math.sqrt(81); 把 return value 存進變數。 answer = 9.0
System.out.println(Math.sqrt(81)); 把 return value 印出來。 output 是 9.0
Math.sqrt(81) + 1 return value 參與 expression。 10.0

不是每個 method 都有 return value。例如 System.out.println("Hello") 的 return type 是 void， 它的目的是把東西印出來，不是回傳一個可以放進 expression 的值。

void Method Trap

int x = System.out.println("Hello");

這行不合法。println 沒有 return value，所以不能把它 assignment 給 int x。 也要分清楚：return value 不等於 printed output。

Signature and API Reading

讀懂 method header，就能知道要傳什麼、會回傳什麼

Method signature 主要由 method name 和 parameter types 決定。Return type 不是 Java method signature 的一部分， 但 AP 題目仍然很常用 return type 來考 assignment 是否合法。

Method header Return type Method name Parameter types
double pow(double base, double exponent) double pow double, double
double sqrt(double x) double sqrt double
double random() double random none
Return type 不構成 signatureint calc(int x) 和 double calc(int x) 不能只靠 return type 分開。
Parameter 名稱不構成 signaturecalc(int x) 和 calc(int number) 對 signature 來說相同。
Parameter type 順序會構成 signaturemix(int, double) 與 mix(double, int) 不同。
AP Quick Reference考試時你需要會讀 method 格式，不需要背完整 Java library。

Math Class

Math 是 AP CSA 最常見的 utility class 之一

Math class 提供很多常用數學 methods。AP CSA 前段最常見的是 Math.abs、Math.pow、Math.sqrt、Math.random。 呼叫時通常寫成 Math.methodName(...)，不需要自己建立 Math object。

Method 用途 Example Result
Math.abs(x) absolute value，絕對值。 Math.abs(-8) 8
Math.pow(base, exponent) 次方。 Math.pow(2, 3) 8.0
Math.sqrt(x) 平方根。 Math.sqrt(25) 5.0
Math.random() 產生 random double。 Math.random() 0.0 <= r < 1.0

pow, sqrt, and Tracing

Math.pow 與 Math.sqrt 回傳 double

即使答案看起來像整數，Math.pow 和 Math.sqrt 的 return type 仍然是 double。 所以 Math.pow(2, 3) 是 8.0，Math.sqrt(25) 是 5.0。

Code 是否合法 原因
double x = Math.pow(2, 3); 合法 Math.pow 回傳 double。
int x = Math.pow(2, 3); 不合法 不能自動把 double 放進 int。
int x = (int)Math.pow(2, 3); 合法 明確 casting，結果是 8。

Method call 可以巢狀放在另一個 method call 裡。看到這種 expression，最穩的做法是從最內層開始。

Distance Formula

double result =
    Math.sqrt(
        Math.pow(3, 2) + Math.pow(4, 2)
    );
Math.pow(3, 2) = 9.0 Math.pow(4, 2) = 16.0 9.0 + 16.0 = 25.0 Math.sqrt(25.0) = 5.0

Method 不會自動修正 argument 內已經發生的 integer division。 Math.sqrt(9 / 4) 會先算 9 / 4 = 2，再算 Math.sqrt(2)。

Math.random

Math.random() 會產生 [0.0, 1.0) 的 random double

Math.random() 是 AP CSA 非常重要的 Math method。它可能產生 0.0， 但永遠不會產生 1.0。

Minimum可能是 0.0。
Maximum小於 1.0，不包含 1.0。
Return typedouble。
Range notation[0.0, 1.0)。

Print Random Values

public class Main
{
    public static void main(String[] args)
    {
        System.out.println(Math.random());
        System.out.println(Math.random());
        System.out.println(Math.random());
    }
}

每次執行可能不同，例如 0.1537、0.8234、0.9998。 但不會是 1.0。

Random Integer Range

Random integer 的核心是乘法、casting、位移

Math.random() 本身是 0.0 到小於 1.0 的 double。 乘以 n 後，範圍變成 0.0 到小於 n。 再 cast 成 int，小數部分會被截掉。

Expression 可能產生 AP 重點
(int)(Math.random() * 10) 0 through 9 不是 1 through 10。
(int)(Math.random() * 6) + 1 1 through 6 骰子公式。
(int)(Math.random() * 6) + 5 5 through 10 先產生 0 through 5，再位移到 5 through 10。 
(int)(Math.random() * (max - min + 1)) + min

這個公式會產生 min through max，包含兩端。

數字個數max - min + 1
起點位移+ min
例子：20 through 30(int)(Math.random() * 11) + 20
例子：-5 through 5(int)(Math.random() * 11) - 5

Casting 位置非常重要。(int)Math.random() * 10 會先把 Math.random() cast 成 0， 所以整個 expression 永遠是 0。

AP Patterns

AP CSA 常見題型與解題策略

Tracing Method Return Values

int a = 4;
double b = Math.pow(a, 2) + Math.sqrt(a);

Math.pow(4, 2) 是 16.0，Math.sqrt(4) 是 2.0，所以 b = 18.0。

Integer Division Inside Argument

double x = Math.sqrt(16 / 9);

16 / 9 先得到 1，所以 x = 1.0。

Random Range

int x = (int)(Math.random() * 8) + 4;

(int)(Math.random() * 8) 是 0 through 7，加 4 後是 4 through 11。

Reverse Design

// generate 12 through 20
int x = (int)(Math.random() * 9) + 12;

因為 20 - 12 + 1 = 9。

Final Trace Example

int n = 20;

double result =
    Math.sqrt(
        Math.pow(n / 5, 2)
        +
        Math.abs(n - 29)
    );

System.out.println(result);

Trace：n / 5 = 4，Math.pow(4, 2) = 16.0， Math.abs(20 - 29) = 9，Math.sqrt(25.0) = 5.0。
