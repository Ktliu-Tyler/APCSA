A. Concepts

概念確認

先確認你能說出 outer loop、inner loop、row / column 與 inner reset 的意思。

Q1Definition

什麼是 nested loop？

Nested loop 是一個 loop 的 body 裡面再放另一個 loop，也就是 loop inside a loop。

Q2Outer / Inner

在 pattern 題中，outer loop 和 inner loop 通常各控制什麼？

outer loop 通常控制 row，也就是有幾列；inner loop 通常控制 column，也就是每列有幾個。

Q3Reset

outer loop 每執行一次，inner loop 會發生什麼事？

inner loop 會重新 initialization，然後完整執行。inner variable 不會從上一輪結束後的值繼續。

Q4print

在印 pattern 時，print 和 println 的差異是什麼？

print 留在同一行；println 會換行。通常 inner loop 裡用 print，inner loop 後用 println。

Q5Counting

如果 outer loop 跑 6 次，inner loop 每次跑 4 次，inner body 總共執行幾次？

6 * 4 = 24 次。

Q6Dependent Bound

為什麼 for (int j = 1; j <= i; j++) 不一定能用乘法直接算總次數？

因為 inner loop 次數會隨著 i 改變。例如 i 從 1 到 5 時，總次數是 1 + 2 + 3 + 4 + 5。

D. Counting Iterations

執行次數

固定範圍用乘法；dependent bounds 逐列加總。

Q22Counting

以下 inner body 執行幾次？

for (int r = 0; r < 5; r++)
{
    for (int c = 0; c < 6; c++)
    {
        System.out.println("*");
    }
}

5 * 6 = 30 次。

Q23Counting

以下 inner body 執行幾次？

for (int i = 1; i <= 4; i++)
{
    for (int j = 1; j <= i; j++)
    {
        System.out.println(j);
    }
}

1 + 2 + 3 + 4 = 10 次。

Q24Counting

以下 inner body 執行幾次？

for (int i = 5; i >= 1; i--)
{
    for (int j = 1; j <= i; j++)
    {
        System.out.println(j);
    }
}

5 + 4 + 3 + 2 + 1 = 15 次。

Q25Counting

以下 inner body 執行幾次？

for (int i = 2; i <= 6; i++)
{
    for (int j = 0; j < 3; j++)
    {
        System.out.println(i + j);
    }
}

外層 i = 2, 3, 4, 5, 6 共 5 次；內層 3 次，所以總共 15 次。

Q26Counting

如果 n = 6，以下 inner body 執行幾次？

for (int i = 1; i <= n; i++)
{
    for (int j = 1; j < i; j++)
    {
        System.out.println(j);
    }
}

inner 次數是 0 + 1 + 2 + 3 + 4 + 5 = 15。

Q27Counting

如果外層跑 n 次、內層每次跑 m 次，總次數的 runtime 直覺是什麼？

O(nm)。若 m 也是 n，就會變成 O(n^2)。

E. Pair Algorithms

配對演算法

配對題要先分清楚是否包含自己、是否有方向、是否要去除重複。

Q28Pairs

以下程式印出幾組 pair？

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        System.out.println(i + "," + j);
    }
}

3 * 3 = 9 組，包含 self-pair 和反方向 pair。

Q30Pairs

j = i + 1 的目的通常是什麼？

避免自己跟自己配對，也避免 i,j 和 j,i 重複。

Q31Pairs

若有 5 個項目，要列出所有 unique pairs，總共有幾組？

4 + 3 + 2 + 1 = 10 組。

Q32Pairs

以下程式計算幾個 pair 滿足 i < j？

int count = 0;

for (int i = 1; i <= 4; i++)
{
    for (int j = 1; j <= 4; j++)
    {
        if (i < j)
        {
            count++;
        }
    }
}

System.out.println(count);

答案是 6，也就是 (1,2)、(1,3)、(1,4)、(2,3)、(2,4)、(3,4)。

Q33Pairs

上題若 inner loop 改成 for (int j = i + 1; j <= 4; j++)，還需要 if (i < j) 嗎？

不需要，因為 j 從 i + 1 開始，天然保證 j > i。

F. Scope / Runtime / Debug

變數位置、效率與除錯

AP 題常會考變數放錯位置、condition/update 用錯變數、或錯估 nested runtime。

Q34Scope

以下程式印出什麼？

for (int row = 1; row <= 3; row++)
{
    int rowSum = 0;

    for (int col = 1; col <= 4; col++)
    {
        rowSum += col;
    }

    System.out.println(rowSum);
}
10
10
10

rowSum 每一列都重新設為 0，然後加 1 + 2 + 3 + 4。

Q35Scope

如果想計算全部 rows 的總和，total 應該放在哪裡初始化？

total 應該在 outer loop 前初始化，這樣不會每一列重設。

Q36Runtime

兩層 loop 都跑 n 次，runtime 直覺是什麼？

O(n^2)，因為大約做 n * n 次工作。

Q37Runtime

1 + 2 + ... + n 的 nested loop，在 Big-O 直覺上通常看成什麼？

仍然看成 O(n^2)，因為它大約是 n^2 / 2 等級。

Q38Bug

以下 inner loop 有什麼問題？

for (int i = 0; i < 3; i++)
{
    for (int j = 0; i < 4; j++)
    {
        System.out.println(j);
    }
}

inner condition 用到 i < 4，但 inner loop 更新的是 j。若 i 沒變，inner loop 可能不會停止。通常應該是 j < 4。

Q39Bug

以下 inner loop 有什麼問題？

for (int i = 0; i < 3; i++)
{
    for (int j = 0; j < 4; i++)
    {
        System.out.println(j);
    }
}

inner update 改到 i，但 condition 檢查 j < 4。因為 j 沒有更新，通常會造成無限迴圈或邏輯錯誤。應改成 j++。

Q40Bug

以下程式想印 3 列 4 顆星，但結果不對。原因是什麼？

for (int row = 1; row <= 3; row++)
{
    for (int col = 1; col <= 4; col++)
    {
        System.out.println("*");
    }
}

inner loop 裡用了 println，每顆星都換行。應在 inner loop 裡用 print("*")，inner loop 後再 println()。

Q41Bug

以下程式想每列重新計算 rowSum，但有錯。錯在哪？

int rowSum = 0;

for (int row = 1; row <= 3; row++)
{
    for (int col = 1; col <= 4; col++)
    {
        rowSum += col;
    }

    System.out.println(rowSum);
}

rowSum 放在 outer loop 外面，所以不會每列重設。若要每列重新算，要把 int rowSum = 0; 放進 outer loop body、inner loop 前。

Q42Debug

遇到 nested loop trace 題，最穩的 trace 方法是什麼？

先固定 outer loop 的一個值，再把 inner loop 完整跑完；每一輪記下 outer variable、inner variable 和任何 state variable。

Q50Final Challenge

預測最後輸出，並解釋 inner loop 每列跑幾次。
