Lesson Flow

本課路線

Why Classes

Class 把「資料」和「操作資料的行為」放在一起

前面我們常把資料直接寫在 main 裡。小程式可以運作，但資料一多就很難管理： 哪些變數描述同一個東西？哪些 method 應該負責操作這些資料？

Data scattered in main

public class Main
{
    public static void main(String[] args)
    {
        String name = "Amy";
        int score = 90;

        if (score >= 60)
        {
            System.out.println(name + " passed.");
        }
    }
}

如果要描述一位學生，我們其實想把 name、score， 以及 getName()、setScore(...)、hasPassed() 這些行為放進同一個概念裡。這個概念就是 Student class。

Class vs Object

Class 是 blueprint；object 是依 blueprint 建出的實體

概念 意思 例子
Class 藍圖、型別、設計規格。 Student、Book、BankAccount
Object 實際存在的一個東西，有自己的 state。 Amy 這位學生、某一本書、某個帳戶。 
Student class
  blueprint: each Student has name and score

student1 object
  name = "Amy"
  score = 95

student2 object
  name = "Ben"
  score = 72

兩個 objects 使用同一份 class code，但它們的 instance variables 各自獨立。

Class Anatomy

一個 class 的基本骨架

Student Class

public class Student
{
    private String name;
    private int score;

    public String getName()
    {
        return name;
    }

    public int getScore()
    {
        return score;
    }

    public void setScore(int newScore)
    {
        if (newScore >= 0 && newScore <= 100)
        {
            score = newScore;
        }
    }

    public boolean hasPassed()
    {
        return score >= 60;
    }
}
Class Declaration
│
├── Instance Variables
│   ├── name
│   └── score
│
└── Methods
    ├── getName()
    ├── getScore()
    ├── setScore(...)
    └── hasPassed()
部分 用途
public class Student 宣告 class 名稱與外部可見性。
private String name; 宣告每個 object 都會保存的資料。
public int getScore() 宣告外部可以呼叫的 method。
{ ... } class body 或 method body。

Instance Variables

Instance variables 描述 object state

Instance variables 宣告在 class 裡面、method 外面。每個 object 都有自己的一份 fields， 因此不同 objects 可以有不同 state。

Object State

public class BankAccount
{
    private String owner;
    private double balance;

    public String getOwner()
    {
        return owner;
    }

    public double getBalance()
    {
        return balance;
    }
}

owner 與 balance 合起來就是這個 BankAccount object 目前的 state。

Instance variables 有 default values：int 是 0， double 是 0.0，boolean 是 false， reference type 如 String 是 null。Local variables 則必須先明確給值。

Field / Local / Parameter

三種變數位置，代表三種不同角色

Variable Roles

public class Example
{
    private int value;              // instance variable

    public int calculate(int bonus) // bonus = parameter
    {
        int doubled = value * 2;    // local variable
        return doubled + bonus;
    }
}
種類 宣告位置 角色
Instance variable class 內、method 外 保存 object state。
Parameter method header 的括號中 caller 傳進 method 的 input。
Local variable method 或 block 裡 method 執行時暫時使用。

Encapsulation

Encapsulation：把資料藏起來，讓外部透過方法互動

AP CSA class design 的核心 pattern 是：data private, behavior public when appropriate。 外部不應直接改 field，而是透過 class 提供的 public methods。

Private Data + Public Methods

public class Student
{
    private int score;

    public int getScore()
    {
        return score;
    }

    public void setScore(int newScore)
    {
        if (newScore >= 0 && newScore <= 100)
        {
            score = newScore;
        }
    }
}
Protect State外部不能任意把 score 改成不合理值。
Validationmutator 可以先檢查 input 是否合法。
Implementation Hiding外部不用知道 class 內部怎麼保存資料。
Maintainability規則集中在 class 裡，日後修改更穩。

Accessors

Accessor method 回報 object state 或衍生資訊

Accessor 不修改 object state，通常有 return value。常見命名是 get...； boolean accessor 也常用 is... 或 has...。

Accessor Examples

public String getName()
{
    return name;
}

public int getScore()
{
    return score;
}

public boolean hasPassed()
{
    return score >= 60;
}

public String getDescription()
{
    return name + ": " + score;
}

hasPassed() 與 getDescription() 都不只是直接 return field， 但仍然是 accessor-like behavior，因為它們回報資訊、沒有改變 state。

Mutators

Mutator method 修改 object state

Mutator 常見命名是 set...，但不一定。deposit()、 withdraw()、increment()、reset() 都可能是 mutators。

Mutator with Validation

public class BankAccount
{
    private double balance;

    public double getBalance()
    {
        return balance;
    }

    public void deposit(double amount)
    {
        if (amount > 0)
        {
            balance += amount;
        }
    }

    public void withdraw(double amount)
    {
        if (amount > 0 && amount <= balance)
        {
            balance -= amount;
        }
    }
}
Encapsulation 不等於「每個 private field 都自動給 getter 和 setter」。 Class 應該只開放合理操作，並維護自己的合法狀態。

Method Anatomy

Method header 告訴我們 method 怎麼被呼叫

accessModifier returnType methodName(parameters)

Method Header and Body

public boolean isEligible(int minimumScore)
{
    return score >= minimumScore;
}
部分 例子 意思
Access modifier public 其他 class 可以呼叫。
Return type boolean method 最後會提供 boolean result。
Method name isEligible caller 使用的 method 名稱。
Parameter int minimumScore 呼叫時需要傳入一個 int。
Method body { return ...; } method 實際執行的程式碼。

void 表示 method 不回傳值給 caller。Return method 可以放進 expression； void method 不能當成 value 使用。

Object Responsibility

好的 class 把規則放在擁有資料的地方

Class design 不只是語法。你要問：這個 object 是什麼？它要記住什麼？ 外部需要知道什麼？外部允許改變什麼？哪些規則應該由 object 自己維護？

Rectangle Responsibility

public class Rectangle
{
    private double width;
    private double height;

    public double getWidth()
    {
        return width;
    }

    public double getHeight()
    {
        return height;
    }

    public double getArea()
    {
        return width * height;
    }
}

getArea() 放在 Rectangle 裡很自然，因為面積規則依賴 width 與 height，而這些資料正是 Rectangle 擁有的 state。

Class Tracing

Trace method calls：看 state 如何改變

Counter Trace

public class Counter
{
    private int value;

    public int getValue()
    {
        return value;
    }

    public void increment()
    {
        value++;
    }

    public void reset()
    {
        value = 0;
    }
}
Call Effect value
new object int field default value 0
increment() value++ 1
increment() value++ 2
reset() value = 0 0

不同 objects 呼叫同一個 method 時，method code 是同一份，但 receiver object 不同， 所以被修改的是不同 object 的 state。

Common Errors

Class structure 常見錯誤

錯誤 常見樣子 修正想法
把 field 宣告在 method 裡 private int score; 寫在 method body 中 Instance variable 要直接放在 class body 裡、methods 外。
local variable 加 access modifier private int x = 5; 寫在 method 裡 private/public 主要用在 fields、methods、constructors、classes。
method 寫在 method 裡 nested methods Java methods 直接屬於 class，不放進另一個 method。
return type 不符 public int getName() 卻 return String return value type 必須符合 method header。
void method 還想回傳值 public void getScore() { return score; } 要回傳值就把 return type 改成正確型別。
assignment 方向反了 newScore = score; 要修改 field 應該是 score = newScore;。
把所有 fields 設成 public public int score; AP CSA class design 通常使用 private fields + public methods。
只看 method 名字判斷 accessor/mutator getCount() 裡面偷偷 count++ Accessor/mutator 要看 method body 是否改變 state。
