Why Loops?

有些工作不是做一次，而是「條件成立就一直做」

從 1 印到 100
持續要求輸入直到合法
讀資料直到 sentinel 出現
處理整數的每個 digit
搜尋直到找到目標
計算 sum、count、average

Syntax

while 的基本結構

initialization;

while (condition)
{
    body;
    update;
}

只要 condition 是 true，就執行 body；執行完後回去重新判斷。

if vs while

if 最多一次；while 可以很多次

if

condition true 時 body 最多執行一次。

while

condition true 時 body 會重複執行。

AP trap

while 可能 0 次，也可能 infinite loop。

First Trace

預測 output

int x = 1;

while (x <= 3)
{
    System.out.println(x);
    x++;
}
A. 1 2 B. 1 2 3 C. 2 3 4 D. Infinite loop

答案是 B。x 以 1、2、3 進入 body，更新到 4 後 condition false。

Four Parts

分析 while loop 的四個核心元素

Initialization Condition Body Update Termination

看到 while，先問：哪個值控制 condition？它每輪如何改變？何時會 false？

Zero Iterations

while 一開始 false，就一次也不跑

int x = 10;

while (x < 5)
{
    System.out.println(x);
    x++;
}

System.out.println("Done");
A. 10 Done B. 5 Done C. Done D. Infinite loop

答案是 C。10 < 5 是 false，所以 loop body 0 iterations。

Counter Loop

已知次數時，counter-controlled loop 最常見

Counting up

int i = 1; while (i <= 10) { ... i++; }

Counting down

int i = 10; while (i >= 1) { ... i--; }

Skip by 2

int i = 2; while (i <= 10) { ... i += 2; }

Execution Count

這個 loop body 執行幾次？

int i = 1;

while (i < 10)
{
    i += 2;
}
A. 4 B. 5 C. 9 D. 10

答案是 B。i 以 1、3、5、7、9 進入 body，共 5 次。

Off-by-One

< 和 <= 通常差一輪

LoopValues entering bodyCount
i = 1; i < 51, 2, 3, 44
i = 1; i <= 51, 2, 3, 4, 55
i = 0; i < 100 through 910
i = 0; i <= 100 through 1011

Accumulator

Sum、product、count 都是 loop 的常見用途

Sum

sum += value;，通常從 0 開始。

Product

product *= value;，通常從 1 開始。

Count

count++;，找到符合條件的資料就加一。

AP 題很常同時出現 loop control variable、counter、accumulator。

Order Matters

最後 sum 是多少？

int x = 1;
int sum = 0;

while (x <= 5)
{
    x++;
    sum += x;
}
A. 15 B. 20 C. 21 D. Infinite loop

答案是 B。加進 sum 的是 2、3、4、5、6，所以 sum = 20。

Sentinel

Sentinel loop：讀到特殊值才停止

int value = input.nextInt();   // priming read

while (value != -1)
{
    // process value
    value = input.nextInt();   // read next value
}

Sentinel 本身通常不被處理。成績用 -1 結束很常見。

Validation

Input validation：通常是 while invalid

int score = input.nextInt();

while (score < 0 || score > 100)
{
    System.out.println("Invalid");
    score = input.nextInt();
}

合法是 score >= 0 && score <= 100；重問時要寫不合法條件。

Update Direction

這段會停止嗎？

int x = 1;

while (x < 10)
{
    x--;
}
A. 會，停在 10 B. 會，停在 0 C. 不會，通常 infinite loop D. Compile error

答案是 C。x 越來越小，x < 10 一直 true。

Digit Basics

整數 digit algorithm 兩個動作

Get last digit

int digit = number % 10;

Remove last digit

number /= 10;

Loop condition

while (number > 0)

Digit Sum

最後 sum 是多少？

int number = 6241;
int sum = 0;

while (number > 0)
{
    int digit = number % 10;
    sum += digit;
    number /= 10;
}
A. 10 B. 12 C. 13 D. 6241

答案是 C。6 + 2 + 4 + 1 = 13。

Boolean Flag

找到了就停：flag-controlled loop

boolean found = false;

while (number > 0 && !found)
{
    int digit = number % 10;

    if (digit == 7)
    {
        found = true;
    }

    number /= 10;
}

這把 Lesson 8 的 compound Boolean 和 Lesson 9 的 loop 結合起來。
