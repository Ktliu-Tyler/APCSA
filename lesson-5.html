Lesson Flow

本課路線

String as Object

String 是 class，不是 primitive type

程式中大量資料都是文字：姓名、帳號、Email、網址、地址、車牌、學號、檔案名稱、搜尋關鍵字。 Java 使用 String 表示文字資料。

String Variables

String name = "Alice";
String school = "NTU";
String message = "Hello World";

更精確地說，name 是 reference variable，reference 到一個 String object。 所以不要把 String word = "computer"; 想成 word 裡直接放著整個文字；它是指向 String object 的 reference。 

word
  |
  v
"computer" String object

word stores a reference to a String object.

Lesson 5 的所有 method tracing，都建立在 Lesson 4 的 object/reference 觀念上。

Literal and char

String literal 使用雙引號；char 使用單引號

像 "Hello" 這種使用雙引號建立的文字稱為 String literal。String 可以直接使用， 不需要 import java.lang.String;，因為 java.lang 預設可用。

程式 Type 重點
'A' char 單一字元，使用單引號。
"A" String 即使只有一個 character，仍然是 String。
"Hello" String String literal。
"" String empty string，長度是 0。

String 也可以使用 constructor 建立：

Literal vs Constructor

String a = "hello";
String b = new String("hello");

AP CSA 最常看到的是 literal，但 constructor 形式對理解 == 與 reference comparison 很重要。

Index and length

String 是一串有順序的 characters，index 從 0 開始

String word = "computer"; 包含 8 個 characters。Java 會為每個 character 編號， 第一個位置是 0，不是 1。 

character: c o m p u t e r
index:     0 1 2 3 4 5 6 7
length:    8
last index = length() - 1 = 7

length() 回傳 int，表示 String 中有多少 characters。空白、標點符號、 可見和不可見字元都可能算進長度。

length()

String word = "computer";
String text = "AP CSA";
String empty = "";

System.out.println(word.length());
System.out.println(text.length());
System.out.println(empty.length());
Value length() 說明
"computer" 8 最後 index 是 7。
"AP CSA" 6 中間的 space 也是 character。
"" 0 empty string 是存在的 String object。
null 呼叫會 error 沒有 String object 可以呼叫 method。

length() 是 method，所以要寫 parentheses。word.length 不是本課的正確寫法。

substring

substring(from, to) 包含 from，不包含 to

substring() 是 AP CSA 最重要、也最容易出現 off-by-one error 的 String method。 有兩種版本：substring(int from, int to) 和 substring(int from)。

Method Return 意思
s.substring(from, to) String 取 from <= index < to，也就是 [from, to)。
s.substring(from) String 從 from 取到最後，等同 s.substring(from, s.length())。

substring Basics

String word = "computer";

System.out.println(word.substring(2, 5));
System.out.println(word.substring(3));
System.out.println(word.substring(0, word.length()));
System.out.println(word.substring(word.length()));
substring(2, 5)取 index 2、3、4，結果是 "mpu"。
substring(3)從 index 3 取到最後，結果是 "puter"。
substring(0, length())取得完整 String。
substring(length())合法，結果是 empty string。

對 substring(a, b)，結果長度通常是 b - a。合法條件可以記成： 

0 <= from <= to <= s.length()

如果 from > to、from < 0、或 to > length()，runtime 可能出現 StringIndexOutOfBoundsException。

常用目的 寫法 以 "computer" 為例
取得前 n 個 characters s.substring(0, n) substring(0, 3) 得到 "com"
移除第一個 character s.substring(1) "omputer"
移除最後一個 character s.substring(0, s.length() - 1) "compute"
取得最後 n 個 characters s.substring(s.length() - n) 最後 3 個是 "ter"
取得 index i 的單一字元 String s.substring(i, i + 1) substring(4, 5) 得到 "u"

indexOf

indexOf() 回傳 search string 第一次出現的位置

string.indexOf(searchString) 回傳 int。它找的是第一次出現的位置， 而且回傳的是那段 substring 的開始 index。

indexOf Examples

String word = "computer";
String fruit = "banana";

System.out.println(word.indexOf("put"));
System.out.println(fruit.indexOf("an"));
System.out.println(fruit.indexOf("a"));
System.out.println(word.indexOf("z"));
Expression Result 原因
"computer".indexOf("put") 3 "put" 從 index 3 開始。
"banana".indexOf("an") 1 只回傳第一次出現的位置。
"banana".indexOf("a") 1 雖然 "a" 出現多次，只回傳第一次。
"computer".indexOf("z") -1 找不到時回傳 -1，不是 0。

indexOf() 是 case-sensitive，space 也是 String 的一部分。 例如 "AP CSA".indexOf(" ") 是 2。

Email Username

String email = "student@gmail.com";

int at = email.indexOf("@");
String username = email.substring(0, at);

System.out.println(username);

indexOf() 和 substring() 的組合是 String processing 的高頻模式。 substring(0, at) 剛好不包含 @，因為 ending index 不包含在結果內。

equals and ==

用 equals() 比較 String 內容，不要用 == 取代

string1.equals(string2) 回傳 boolean，比較的是兩個 Strings 的 character sequence 是否相同。它是 case-sensitive。

equals()

String a = "hello";
String b = "hello";
String c = "Hello";

System.out.println(a.equals(b));
System.out.println(a.equals(c));

== 對 object references 比較的是兩個 references 是否指向同一個 object。 這和 String contents 是否相同不是同一件事。

== vs equals

String a = new String("cat");
String b = new String("cat");

System.out.println(a == b);
System.out.println(a.equals(b));
a -> "cat" Object A
b -> "cat" Object B

a == b      -> false
a.equals(b) -> true

String literals 有 internal optimization，像 String a = "hello"; String b = "hello"; 可能讓 a == b 得到 true。但如果目標是比較文字內容， 正確表達仍然是 a.equals(b)。

如果 String s = null;，呼叫 s.equals("hello") 會造成 NullPointerException，因為 s 沒有指向 String object。

compareTo

compareTo() 用來比較排序；重點是正負號

string1.compareTo(string2) 回傳 int。AP CSA 的重點通常不是精確數字， 而是小於 0、等於 0、大於 0 的意義。

Expression Result meaning 說明
"apple".compareTo("banana") < 0 "apple" 排在 "banana" 前面。
"apple".compareTo("apple") 0 兩個 Strings 內容相同。
"dog".compareTo("cat") > 0 "dog" 排在 "cat" 後面。

不要假設 compareTo() 只會回傳 -1、0、1。 考試中通常應判斷 < 0、== 0、> 0。

equals()

回傳 boolean，問 contents 是否相同。

a.equals(b)

compareTo()

回傳 int，問排序前後。

a.compareTo(b)

Prefix 情況也要小心。例如 "car".compareTo("card") 是 negative， 因為 "car" 是較短的 prefix，排序時在 "card" 前面。

String Concatenation

+ 遇到 String 時會做 concatenation

String concatenation 是把 Strings 接在一起。Primitive value 和 String 做 concatenation 時， primitive value 會被轉成 String。

Concatenation

String first = "AP";
String second = "CSA";
int score = 5;

System.out.println(first + " " + second);
System.out.println("Score: " + score);

AP 超高頻陷阱是 + 的左到右 evaluation order。

Expression Result 原因
"A" + 1 + 2 "A12" String 先出現，後面依序做 concatenation。
1 + 2 + "A" "3A" 先做數字加法 1 + 2。
"A" + (1 + 2) "A3" parentheses 先算數字加法。
2 + 3 + "4" "54" 2 + 3 先變 5，再和 "4" 串接。

+= 也可以用在 String，例如 s += "!"。但這會引出下一個核心概念： String 是 immutable。

String Immutability

String objects are immutable

String immutable 的意思是：String object 本身不能被修改。String methods 通常 return 新的結果， 不會改變原本的 String object。

substring Does Not Mutate

String s = "hello";

s.substring(1);

System.out.println(s);

Output 還是 hello。substring(1) 產生了新的 String result，但沒有被保存。 如果想改變 s 這個 variable 指向的結果，需要重新 assignment。

Save the Return Value

String s = "hello";

s = s.substring(1);

System.out.println(s);
Before: s -> "hello"
After:  s -> "ello"

不是原本的 String object 被修改，而是 s 這個 reference variable 被重新指定到新的 String result。

快速心法：看到 s.substring(...); 如果沒有 s = 或其他 variable 接住 result， s 不會改變。

Method Chaining

String method call 可以接著另一個 method call

因為 substring() 回傳 String，所以可以立刻對它呼叫另一個 String method。 解題時一次只算一個 method，產生新 String 後重新標 index。

Chaining Example

String s = "banana";

System.out.println(s.substring(2).indexOf("a"));
s.substring(2) "nana" "nana".indexOf("a") 1

最重要陷阱：新的 String index 從 0 重新開始。不要沿用原本 "banana" 的 index。

Index Relative to Current String

String s = "abcdefgh";

s = s.substring(2, 7);
s = s.substring(1, s.length() - 1);

System.out.println(s);

第一行得到 "cdefg"，此時要重新標 index：c d e f g 是 0 1 2 3 4。第二行 substring(1, 4) 得到 "def"。

Errors

String 題常見錯誤：compile、runtime、logic 都可能出現

Error / Trap 例子 原因
Compile-time error String s = 10; type 不相容。
NullPointerException String s = null; s.length(); s 沒有指向 String object。
StringIndexOutOfBoundsException "cat".substring(0, 4) to = 4 大於 length 3。
Logic / off-by-one error "computer".substring(0, 2) 若本來想取前三個 characters，實際只取得 "co"。
null沒有 String object，method call 會 error。
""empty string，長度是 0。
" "一個 space，長度是 1。
Index triolength = 6、last index 5、full substring end 6。

AP Patterns

AP CSA String 題解題 SOP

Step 做法
1 寫出目前的 String。
2 標 index，從 0 開始。
3 標 length，記住 last index 是 length() - 1。
4 一次只算一個 method call。
5 如果產生新 String，重新標 index。
6 檢查 return type 和 index 是否合法。

substring tracing

String str = "computer";
System.out.println(str.substring(2, 6));

取 index 2、3、4、5，結果是 "mput"。

indexOf not found

String str = "banana";
System.out.println(str.indexOf("x"));

找不到回傳 -1，不是 runtime error。

immutability

String s = "hello";
s.substring(1);
System.out.println(s);

Output 是 hello，因為 result 沒有被保存。

compareTo

String a = "apple";
String b = "banana";
int result = a.compareTo(b);

一定可知 result < 0，不要假設 result == -1。

Final Trace Example

String str = "mississippi";

int a = str.indexOf("iss");
String b = str.substring(a, a + 4);
int c = b.length();

System.out.println(a);
System.out.println(b);
System.out.println(c);

"iss" 第一次出現在 index 1，所以 a = 1。 str.substring(1, 5) 得到 "issi"，所以 c = 4。
