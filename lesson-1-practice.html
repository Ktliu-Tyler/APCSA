A. Concepts

名詞與觀念

這一區先確認你是否理解 Java 程式執行前後的整體流程。

Q1Vocabulary

請把三個名詞配對到正確意思。

Problem?
Algorithm?
Program?

選項：想解決的事情、解決問題的一系列步驟、用程式語言寫出的可執行指令。

Problem 是想解決的事情。Algorithm 是解決問題的一系列步驟。Program 是用程式語言實作 algorithm 後得到的指令集合。

Q2Java Flow

請排出 Java 程式從文字到 output 的順序。

JVM、Source Code、Compiler、Bytecode、Output

正確順序是 Source Code → Compiler → Bytecode → JVM → Output。Source code 是你寫的 Java 文字；compiler 檢查並轉換；bytecode 交給 JVM；JVM 執行後產生 output。

Q3Compiler

Compiler 主要負責哪一件事？

A. 幫你設計 algorithm　B. 檢查 Java 語法與型別　C. 顯示最後 output　D. 儲存網頁密碼

答案是 B。Compiler 會檢查語法與型別，例如少分號、括號不完整、把 "Hello" 存進 int。它不是負責替你設計解法，也不是負責顯示最後 output。

Q4Type

Data type 和 data structure 有什麼不同？

Data type 描述一個 value 是什麼種類，例如 int、double、boolean。Data structure 描述多個資料如何組織，例如之後會學的 array、ArrayList、2D array。

Q5Type Rule

下列哪一行是合法 Java？

A. int x = 3.14;　B. boolean ok = 1;　C. double y = 5;　D. int z = "5";

答案是 C。整數 5 可以安全地放進 double，變成 5.0。A 不合法，因為 3.14 是 double。B 不合法，Java 的 boolean 只能是 true 或 false。D 不合法，"5" 是 String。

Q6Assignment

Java 中的 = 應該怎麼理解？

A. 左右兩邊永遠相等　B. 先算右邊，再存進左邊　C. 比較兩個值是否一樣　D. 建立新的 class

答案是 B。= 是 assignment operator。看到 x = x + 1; 時，先算右邊的 x + 1，再把結果存回左邊的 x。

B. Output Tracing

輸出預測

先不要執行。請自己追蹤每一步，寫下 output，再點開詳解。

Q7println

預測 output。

System.out.println("A");
System.out.print("B");
System.out.println("C");
A
BC

println("A") 輸出 A 後換行。print("B") 不換行，所以接下來 println("C") 會接在 B 後面，形成 BC。

Q8Assignment

預測 output。

int x = 4;
System.out.println(x);
x = x + 3;
System.out.println(x);
4
7

第一次輸出時 x 是 4。執行 x = x + 3; 時，右邊先變成 4 + 3，也就是 7，再存回 x。

Q9Copy

預測 output。

int a = 10;
int b = a;
a = 20;
System.out.println(a);
System.out.println(b);
20
10

int b = a; 是把 a 當下的 value 複製給 b。之後 a 改成 20，不會自動影響 b。

Q10Precedence

預測 output。

System.out.println(2 + 3 * 4);
System.out.println((2 + 3) * 4);
14
20

第一行先做乘法：3 * 4 = 12，再加 2，得到 14。第二行括號先算：2 + 3 = 5，再乘 4，得到 20。

Q11Integer Division

預測 output。

System.out.println(7 / 2);
System.out.println(7.0 / 2);
System.out.println(7 / 2.0);
3
3.5
3.5

7 / 2 是 int / int，結果是 3。只要有一邊是 double，就會做 floating-point division，所以後兩行是 3.5。

Q12Double Storage

預測 output。

double answer = 7 / 2;
System.out.println(answer);
3.0

右邊先算。7 / 2 是 int / int，先得到 3。再把 3 存進 double 變數，所以顯示為 3.0。

Q13String

預測 output。

System.out.println("A" + 1 + 2);
System.out.println(1 + 2 + "A");
System.out.println("A" + (1 + 2));
A12
3A
A3

第一行一開始就是 String，所以後面的 1 和 2 會串接。第二行先做數字加法 1 + 2，得到 3，再接上 A。第三行括號先算，所以是 A3。

Q14Mixed Trace

預測 output。

int x = 10;
int y = 3;
System.out.println("Result: " + x / y);
System.out.println("Left: " + x % y);
Result: 3
Left: 1

x / y 是 10 / 3，integer division 得到 3。x % y 是 10 % 3，餘數是 1。

C. Debugging

錯誤判斷

請先判斷錯誤類型：syntax / compile-time error、runtime error、logic error。

Q15Syntax Error

這段程式會發生什麼錯誤？

int score = 90
System.out.println(score);

這是 syntax error，也屬於 compile-time error。第一行少了分號。Compiler 看到下一行時，無法判斷上一個 statement 是否已經結束。

修正：int score = 90;

Q16Type Mismatch

這段程式會發生什麼錯誤？

int age = "16";
System.out.println(age);

這是 compile-time error。"16" 是 String，不是 int。Java 不會因為它看起來像數字就自動放進 int。

修正：如果要數字，寫 int age = 16;。如果要文字，寫 String age = "16";。

Q17Boolean

這段程式會發生什麼錯誤？

boolean finished = 0;
System.out.println(finished);

這是 compile-time error。Java 的 boolean value 只能是 true 或 false，不能用 0 或 1。

修正：boolean finished = false;

Q18Runtime Error

這段程式會發生什麼錯誤？

int total = 100;
int groups = 0;
int each = total / groups;
System.out.println(each);

這是 runtime error。程式語法與型別都可以通過編譯，但執行到 total / groups 時，groups 是 0，整數除以 0 無法執行。

Q19Logic Error

這段程式想算平均，但結果有什麼問題？

int score1 = 80;
int score2 = 90;
int score3 = 95;
double average = (score1 + score2 + score3) / 3;
System.out.println(average);

這是 logic issue。程式可以 compile，也可以 run，但右邊 (score1 + score2 + score3) / 3 是 int / int，小數部分會被移除。總分是 265，265 / 3 得到 88，存進 double 後是 88.0。

修正：使用 3.0，例如 double average = (score1 + score2 + score3) / 3.0;

Q20Logic Error

這段程式想算長方形面積，但哪裡錯？

int length = 8;
int width = 5;
int area = length + width;
System.out.println("Area: " + area);

這是 logic error。程式語法正確，也能執行，但面積公式寫錯。長方形面積應該是 length * width，不是 length + width。

正確輸出應該是 Area: 40，不是 Area: 13。

D. Arithmetic

運算與數字拆解

這一區練習 integer division、modulo 與三位數拆解。

Q21Modulo

計算下列 expression。

17 % 5

答案是 2。因為 17 = 5 * 3 + 2，餘數是 2。

Q22Digit

如果 int number = 647;，number % 10 的結果是什麼？

答案是 7。對正整數來說，% 10 可以取得個位數。

Q23Digit

如果 int number = 647;，(number / 10) % 10 的結果是什麼？

答案是 4。先做 647 / 10，integer division 得到 64。再做 64 % 10，取得個位數 4。這個結果就是原本的十位數。

Q24Mixed

預測 output。

int n = 586;
System.out.println(n / 100);
System.out.println((n / 10) % 10);
System.out.println(n % 10);
5
8
6

n / 100 取得百位。(n / 10) % 10 取得十位。n % 10 取得個位。

Q25Expression

預測 output。

int x = 23;
System.out.println(x / 10 + x % 10);
5

x / 10 是 2，x % 10 是 3。相加得到 5。

E. AP-style Multiple Choice

AP-style 題

每題先選答案，再打開詳解確認推理。

Q26MCQ

What is printed?

System.out.println("Value: " + 3 + 4);
A. Value: 7 B. Value: 34 C. 7 D. 34

答案是 B。"Value: " + 3 先變成 String "Value: 3"，再接上 4，所以是 Value: 34。

Q27MCQ

Which expression evaluates to 2.5?

A. 5 / 2 B. 5.0 / 2 C. 5 / 2 + 0.0 D. (int) 5.0 / 2

答案是 B。5.0 / 2 有 double 參與，所以結果是 2.5。C 會先做 5 / 2 得到 2，再加 0.0，結果是 2.0。

Q28MCQ

What value is stored in result?

int a = 9;
int b = 4;
double result = a / b;
A. 2 B. 2.0 C. 2.25 D. 3.0

答案是 B。右邊 a / b 是 int / int，先得到 2，再存進 double，所以是 2.0。

Q29MCQ

What is printed?

int x = 4;
x = x + x;
System.out.println(x);
A. 4 B. 6 C. 8 D. 16

答案是 C。右邊先算 x + x，當時 x 是 4，所以右邊是 8。再把 8 存回 x。

Q30MCQ

Which line causes a compile-time error?

int a = 5;
double b = a;
boolean c = false;
int d = "5";
A. Line 1 B. Line 2 C. Line 3 D. Line 4

答案是 D。"5" 是 String，不能直接存進 int。double b = a; 合法，因為 int value 可以安全地轉成 double storage。

Q31MCQ

What is printed?

int n = 345;
System.out.println(n / 10);
System.out.println(n % 10);
A. 34 then 5 B. 35 then 4 C. 345 then 0 D. 3 then 45

答案是 A。345 / 10 做 integer division，得到 34。345 % 10 取得個位數，得到 5。

Q32Coding

個人資訊輸出

建立四個變數：名字、年齡、身高、是否準備好學 Java。最後輸出四行。

Expected format:
Name: Alex
Age: 17
Height: 175.5

        String name = "Alex";
        int age = 17;
        double height = 175.5;
        boolean ready = true;

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
        System.out.println("Height: " + height);
        System.out.println("Ready: " + ready);
    }

這題練習四種常見資料：文字用 String，整數用 int，小數用 double，真假值用 boolean。

Q33Coding

平均分數

有三個分數 80、90、95。請計算平均並輸出 Average: 88.33333333333333 或等價的 double 結果。

public class Main {
    public static void main(String[] args) {
        int score1 = 80;
        int score2 = 90;
        int score3 = 95;

        double average = (score1 + score2 + score3) / 3.0;
        System.out.println("Average: " + average);
    }
}

重點是使用 3.0。如果寫成 / 3，右邊會做 integer division，小數部分會被移除。

Q34Coding

拆解三位數

設定 int number = 742;，輸出百位、十位、個位。

public class Main {
    public static void main(String[] args) {
        int number = 742;

        int hundreds = number / 100;
        int tens = (number / 10) % 10;
        int ones = number % 10;

        System.out.println("Hundreds: " + hundreds);
        System.out.println("Tens: " + tens);
        System.out.println("Ones: " + ones);
    }
}

/ 100 取得百位。/ 10 先移除個位，接著 % 10 取得十位。% 10 直接取得個位。

Q35Challenge

修正錯誤並解釋原因

下面程式想輸出平均，但有兩個問題。請修正並寫出原因。

public class Main {
    public static void main(String[] args) {
        int score1 = 88
        int score2 = 93;
        int score3 = 100;

        double average = (score1 + score2 + score3) / 3;
        System.out.println("Average: " + average);
    }
}
public class Main {
    public static void main(String[] args) {
        int score1 = 88;
        int score2 = 93;
        int score3 = 100;

        double average = (score1 + score2 + score3) / 3.0;
        System.out.println("Average: " + average);
    }
}

第一個問題是 int score1 = 88 少了分號，這會造成 compile-time error。第二個問題是 / 3 會做 integer division，平均值的小數部分會被移除；改成 / 3.0 才會得到 double division。
