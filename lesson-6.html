Lesson Flow

本課路線

boolean

boolean 只有兩種值：true / false

Java 中的 boolean 是 primitive type，用來表示真假。它沒有第三種狀態，也不能用 0 或 1 代替。

Boolean Variables

boolean isReady = true;
boolean gameOver = false;

int score = 90;
boolean passed = score >= 60;
程式 Type 合法嗎？ 重點
true boolean 合法 Boolean literal。
"true" String 不能放進 boolean variable 有雙引號就是文字。
boolean x = 1; int 給 boolean 不合法 Java 不把 1 當 true。
boolean x = score >= 60; boolean 合法 右邊先比較，結果存進 x。

Boolean Expression

Boolean expression 執行後會得到 true 或 false

看到 Boolean expression，不要只看符號，要追蹤它最後的 type 和 value。AP 題目常把數學運算、 String method call、reference comparison 混在同一題。

Numeric comparison

5 > 3

結果是 true。

Equality comparison

10 == 4

結果是 false。

String method

"cat".equals("cat")

equals() 回傳 boolean，結果是 true。

Ordering method

"apple".compareTo("banana") < 0

"apple" 排在前面，所以結果是 true。

Boolean variable 存的是某一次計算後的結果，不會因為原本 expression 中的 variable 之後改變而自動更新。

Boolean Tracing

int x = 5;
boolean result = x > 3;

x = 1;

System.out.println(result);

Output 是 true。result = x > 3; 執行當下 x 是 5，之後 x 改成 1 不會重新計算 result。

Relational Operators

六個 relational operators

Operator 意思 範例 Result
==equal to5 == 5true
!=not equal to5 != 8true
<less than3 < 10true
>greater than10 > 3true
<=less than or equal to10 <= 10true
>=greater than or equal to80 >= 80true

AP 題最喜歡考 boundary value。例如條件是 age >= 18，一定要特別檢查 17、18、19。 

age = 17  -> 17 >= 18 -> false
age = 18  -> 18 >= 18 -> true
age = 19  -> 19 >= 18 -> true

= vs ==

= 是 assignment；== 是 comparison

x = 5;

把 5 assignment 給 x。這會修改 variable。

x == 5

判斷 x 是否等於 5。這會產生 true / false。

AP 看到等號

先問：這裡是在改變值，還是在比較？

Common Error

int x = 5;

boolean wrong = x = 5;   // compile-time error
boolean right = x == 5;  // true

如果 x 是 int，x = 5 是 assignment expression，不是 Boolean comparison；不能拿來存進 boolean。

Evaluation Order

先算 arithmetic / method call，再做 relational comparison

Relational operator 兩邊不一定是單一 variable，也可以是 expressions。解題時要先把左右兩邊算成明確的值。

Arithmetic Before Comparison

int x = 4;
int y = 5;

boolean result = x + 3 < y * 2;
x + 3 = 4 + 3 = 7
y * 2 = 5 * 2 = 10
7 < 10 -> true
目前常用優先順序 例子
()(2 + 3) * 4
* / %7 / 3、12 % 5
+ -x + 2
< <= > >=x + 2 > 9
== !=3 < 5 == true

!、&&、|| 會在 Lesson 8 正式處理；本課先把單一 Boolean expression 追蹤穩。

Primitive Comparison

Primitive 使用 == 比較實際 value

對 int、double、boolean 這些 primitive types 來說， == 比較的是實際值。

int values

int a = 10;
int b = 10;

System.out.println(a == b);

Output 是 true。

copy once

int a = 10;
int b = a;
a = 20;

System.out.println(a == b);

b 仍是 10，所以 output 是 false。

int and double

int x = 5;
double y = 5.0;

System.out.println(x == y);

數值相同，output 是 true。

boolean values

boolean a = true;
boolean b = false;

System.out.println(a == b);

Output 是 false。

Integer division 和 casting 很常被包進 Boolean expression。

Integer Division vs Casting

System.out.println(5 / 2 == 2.5);
System.out.println((double) 5 / 2 == 2.5);
5 / 2 = 2
2 == 2.5 -> false

(double) 5 / 2 = 2.5
2.5 == 2.5 -> true

double 有 round-off error；考試遇到小數運算後的精確 ==，不要假設一定安全。

Reference Comparison

Reference type 使用 == 比較是否指向同一個 object

Lesson 4 學過 reference variable。現在要把它和 Boolean expression 接起來：對 object references， == 不是問 contents 一不一樣，而是問兩個 variables 是否存著相同 reference。

Two Different Objects

String a = new String("cat");
String b = new String("cat");

System.out.println(a == b);
System.out.println(a.equals(b));
a ----> String Object A "cat"

b ----> String Object B "cat"

a == b       -> false
a.equals(b) -> true

Alias

String a = new String("cat");
String b = a;

System.out.println(a == b);
a --+
    +--> String Object "cat"
b --+

a == b -> true
Expression 比較什麼？
primitive a == bprimitive values
object a == bobject references
object a != breferences 是否不同
String.equals()String contents

null

== null 是安全的 reference comparison

null 表示 reference variable 目前沒有指向任何 object。你可以用 == null 或 != null 安全地檢查 reference。

Safe

String name = null;
boolean result = name == null;

合法，result 是 true。

Also safe

String name = "Alice";
boolean result = name != null;

合法，result 是 true。

Runtime error

String name = null;
boolean result = name.equals("Alice");

name 沒有 object 可以呼叫 method，所以會發生 NullPointerException。

看到 null + method call，先警覺 runtime error；看到 == null 則只是安全比較。

String Boolean Expressions

String methods 常常直接產生或組成 Boolean expression

Lesson 5 的 String methods 會在 Boolean 題中大量出現。重點不是背答案， 而是先判斷 method return type，再做比較。

Expression Type 常見用途
s.length()ints.length() >= 8
s.indexOf("AP")ints.indexOf("AP") >= 0 表示找得到。
s.substring(0, 3)Strings.substring(0, 3).equals("pro")
s.equals("yes")boolean直接就是 Boolean expression。
s.compareTo("cat")int< 0 前面，== 0 相同，> 0 後面。

length

String s = "computer";
boolean result = s.length() >= 8;

length() 是 8，所以結果是 true。

indexOf

String s = "computer";
boolean result = s.indexOf("xyz") >= 0;

indexOf("xyz") 是 -1，所以結果是 false。

substring + equals

String s = "computer";
boolean result = s.substring(0, 3).equals("com");

substring(0, 3) 是 "com"，所以結果是 true。

compareTo

String a = "dog";
String b = "cat";
boolean result = a.compareTo(b) < 0;

"dog" 排在 "cat" 後面，compareTo() 為 positive，所以結果是 false。

Common Errors

AP Boolean 題常見錯誤

錯誤寫法 問題 正確觀念
boolean x = 1;Java 不用 1 表示 true。使用 true 或 Boolean expression。
boolean b = 0 < x < 10;Java 不支援 chained comparison。Lesson 8 會用 compound Boolean 改寫。
x => 5沒有 => 這個 operator。使用 x >= 5。
x =< 5沒有 =< 這個 operator。使用 x <= 5。
name < "John"String 不能用 < 比大小。用 name.compareTo("John") < 0。
String a = null; a.equals("x")runtime error。先確認 a != null，或理解 == null 是安全比較。

AP Patterns

AP-style 題型整理

Modulo condition

int x = 12;
boolean result = x % 3 == 0;

12 % 3 = 0，所以 result = true。

Integer division trap

int a = 7;
int b = 3;
boolean result = a / b > 2;

7 / 3 = 2，2 > 2 是 false。

Reference + alias

String a = new String("hello");
String b = a;
boolean result = a == b;

b = a 複製 reference，所以結果是 true。

String method Boolean

String s = "programming";
boolean result = s.substring(0, 3).equals("pro");

結果是 true。

A Boolean expression evaluates to true or false.

= means assignment; == means comparison.

Object == compares references.
