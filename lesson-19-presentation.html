ArrayList

今天從 fixed-size array 走到可變長度的 list：ArrayList<E>、 wrapper classes、add、get、set、remove、 size() 與 index shift。

開啟 OneCompiler Lesson 19 課後練習

From Array

Array 長度固定；ArrayList 長度可變

Array

arr.length fixed after creation。

Use []。

ArrayList

size() changes after add/remove。

Use methods。

Import

ArrayList 在 java.util

import java.util.ArrayList;

忘記 import 是初學 ArrayList 最常見 compile error。

Create

建立空的 ArrayList

ArrayList<String> names = new ArrayList<String>();
names.add("Amy");
names.add("Ben");

ArrayList<String> 表示每個元素都是 String。

Generic Type

ArrayList<E> 的 E 是元素型別

ArrayList<String> words = new ArrayList<String>();
ArrayList<Student> roster = new ArrayList<Student>();
ArrayList<Integer> scores = new ArrayList<Integer>();

Wrapper Classes

Generic type 不能是 primitive

Wrong

ArrayList<int> nums;

Correct

ArrayList<Integer> nums;

int → Integer，double → Double，boolean → Boolean。

Quick Check

要建立存放小數的 ArrayList，型別應該寫什麼？

ArrayList<Double>，使用 wrapper class Double。

Core Methods

AP CSA 必熟六個 ArrayList methods

size()
add(obj)
add(index, obj)
get(index)
set(index, obj)
remove(index)

size

size() 是目前元素數量

ArrayList<String> names = new ArrayList<String>();
names.add("Amy");
names.add("Ben");

System.out.println(names.size()); // 2

ArrayList 用 method call：size()，不是 .length。

add to End

add(obj) 加到最後

names.add("Amy");   // [Amy]
names.add("Ben");   // [Amy, Ben]
names.add("Cara");  // [Amy, Ben, Cara]

add at Index

add(index, obj) 插入並讓後面右移

names.add("Amy");       // [Amy]
names.add("Cara");      // [Amy, Cara]
names.add(1, "Ben");    // [Amy, Ben, Cara]

合法 add index 可以到 size()。

Quick Check

若 list size 是 3，add(3, value) 合法嗎？

合法。add(size(), value) 代表加到尾端。但 get(size()) 不合法。

get

get(index) 讀取元素

String first = names.get(0);

ArrayList 不使用 names[0]。

set

set(index, obj) 取代元素，不改 size

ArrayList<String> names = new ArrayList<String>();
names.add("Amy");
names.add("Ben");

String old = names.set(1, "Cara");
// old is "Ben"
// names is [Amy, Cara]

remove

remove(index) 移除元素並讓後面左移

ArrayList<String> names = new ArrayList<String>();
names.add("Amy");
names.add("Ben");
names.add("Cara");

String removed = names.remove(1);
// removed is "Ben"
// names is [Amy, Cara]

Index Shift

每次 add/remove 後都要重新 trace indexes

add index right shift remove index left shift

Quick Trace

最後 list 是什麼？

ArrayList<String> words = new ArrayList<String>();
words.add("A");
words.add("C");
words.add(1, "B");
words.remove(0);

[B, C]。先插入成 [A, B, C]，再移除 index 0。

Traversal

ArrayList traversal 用 size() 和 get(i)

for (int i = 0; i < list.size(); i++)
{
    System.out.println(list.get(i));
}

Enhanced For

只讀每個元素時，可以用 enhanced for

for (String word : words)
{
    System.out.println(word);
}

若要修改元素，用 traditional for 和 set。

Modify Each Element

修改每一格要用 set

for (int i = 0; i < nums.size(); i++)
{
    nums.set(i, nums.get(i) * 2);
}

Array vs ArrayList

語法對照

Array

arr.length

arr[i]

arr[i] = value

ArrayList

list.size()

list.get(i)

list.set(i, value)

Quick Check

這段錯在哪？

for (int i = 0; i < list.length; i++)
{
    System.out.println(list[i]);
}

ArrayList 要用 list.size() 和 list.get(i)，不是 .length 和 brackets。

Autoboxing

ArrayList<Integer> 可以直接 add int value

ArrayList<Integer> scores = new ArrayList<Integer>();
scores.add(90);

int first = scores.get(0);

Java 自動 boxing / unboxing。

Search in ArrayList

找 target 時常用 equals 比較 objects

for (int i = 0; i < words.size(); i++)
{
    if (words.get(i).equals(target))
    {
        return i;
    }
}
return -1;

Quick Trace

最後印出什麼？

ArrayList<String> list = new ArrayList<String>();
list.add("A");
list.add("C");
list.add(1, "B");
String x = list.set(2, "D");
list.add(x);
list.remove(0);
System.out.println(list);

[B, D, C]。set 回傳舊值 C，後來被加回尾端。

Exit Ticket

ArrayList size can change。
Import java.util.ArrayList。
Generic type must be a reference type。
Use Integer, not int。
Use size(), not .length。
Use get(i), not brackets。
set replaces and returns old value。
set does not change size。
add(index,obj) shifts right。
remove(index) shifts left。
add(size(), obj) is valid。
get(size()) is invalid。
