Array algorithm SOP

Traversal

Array algorithm 的核心是逐一走訪元素

Traversal 是「從 array 的某個位置開始，依序檢查每個需要的元素」。AP CSA 的 array 題， 多半就是在 traversal 中累積答案或修改元素。

array traversal 
int[] nums = {4, 7, 2, 9};

for (int i = 0; i < nums.length; i++)
{
    System.out.println(nums[i]);
}

這個 loop 會使用 index 0 到 nums.length - 1。條件一定是 i < nums.length，不是 i <= nums.length。

Traditional vs Enhanced For

需要 index，就不要硬用 enhanced for

Traditional For

for (int i = 0; i < arr.length; i++)
{
    arr[i] = arr[i] + 1;
}

有 index，適合修改、相鄰比較、reverse、shift、parallel arrays。

Enhanced For

for (int value : arr)
{
    sum += value;
}

只有 value，適合只讀元素：sum、count、max/min、是否存在某值。

Sum / Count

Sum 累加值，count 累加次數

Sum 和 count 是最常見的 accumulator pattern。Sum 的 identity value 是 0； count 也是從 0 開始，但只有條件成立時 count++。

sum and count 
int sum = 0;
int count = 0;

for (int value : nums)
{
    sum += value;

    if (value > 10)
    {
        count++;
    }
}
常見混淆 sum += value; 是把元素值加進去；count++; 是符合條件的元素多一個，不是把元素值加進去。

Average

Average = sum / count，但要注意 integer division

平均需要先加總，再除以元素數量。若希望得到小數，必須至少讓其中一邊是 double。

average with casting 
int sum = 0;

for (int value : nums)
{
    sum += value;
}

double average = (double) sum / nums.length;

Conditional average 需要兩個變數：符合條件的 sum，以及符合條件的 count。除以前要確認 count > 0，避免除以 0。

Max / Min / Search

Best-so-far 和 linear search 是 array 題的主力

找最大值或最小值時，安全初始化通常是第一個元素。不要把 max 設成 0，因為 array 可能全是負數。

max value and max index 
int maxIndex = 0;

for (int i = 1; i < scores.length; i++)
{
    if (scores[i] > scores[maxIndex])
    {
        maxIndex = i;
    }
}

int maxScore = scores[maxIndex];
linear search index 
int index = -1;

for (int i = 0; i < nums.length; i++)
{
    if (nums[i] == target)
    {
        index = i;
        break;
    }
}

-1 常用作 sentinel index，代表「尚未找到」。若題目要找最後一次出現， 就不要在找到後立刻 break。

Copy / Reverse

Array copy 要分清楚 reference copy 和 element copy

int[] b = a; 只複製 reference，兩個 variables 指向同一個 array。 真正複製 array 需要建立新 array，逐格複製元素。

copy and reversed copy 
int[] copy = new int[arr.length];

for (int i = 0; i < arr.length; i++)
{
    copy[i] = arr[i];
}

int[] reversed = new int[arr.length];

for (int i = 0; i < arr.length; i++)
{
    reversed[i] = arr[arr.length - 1 - i];
}

In-place reverse 則會直接修改原 array，通常只跑到 arr.length / 2，每次交換對稱位置。

Shift

Right shift 從右往左；left shift 從左往右

Shift 的核心是避免尚未搬走的資料被覆蓋。Right shift 時，要先從右邊開始搬； left shift 時，要先從左邊開始搬。

shift direction 
for (int i = arr.length - 1; i > 0; i--)
{
    arr[i] = arr[i - 1]; // right shift
}

for (int i = 0; i < arr.length - 1; i++)
{
    arr[i] = arr[i + 1]; // left shift
}

Insert / Remove-like Logic

Array 長度固定，所以 insert/remove 通常是模擬

Java array 的 .length 不會改變。若題目說「insert」或「remove」，常常會搭配一個 logical size，表示目前有效元素數量。

insert and remove-like logic 
for (int i = size; i > index; i--)
{
    arr[i] = arr[i - 1];
}
arr[index] = value;
size++;

for (int i = index; i < size - 1; i++)
{
    arr[i] = arr[i + 1];
}
size--;

Insert 要先右移空出位置；remove 要左移蓋掉要刪的位置。兩者都不會讓 array 本身變長或變短。

Parallel Arrays

Parallel arrays 用相同 index 連結不同資料

若 names[i] 和 scores[i] 描述同一個學生，就需要用 traditional for loop 保留 index。找最高分時，最有用的是 maxIndex，因為它能同時拿到 name 和 score。

parallel arrays max index 
int maxIndex = 0;

for (int i = 1; i < scores.length; i++)
{
    if (scores[i] > scores[maxIndex])
    {
        maxIndex = i;
    }
}

System.out.println(names[maxIndex] + ": " + scores[maxIndex]);

Array Parameters

Array parameter 的 mutation 會被 caller 看見

Array 是 object。Method parameter 拿到的是 reference value 的 copy；透過 parameter 修改元素， 會修改 caller 看到的同一個 array。但重新指定 parameter 只會改 local parameter。

mutation vs reassignment 
public static void mutate(int[] arr)
{
    arr[0] = 99;
}

public static void replace(int[] arr)
{
    arr = new int[] {1, 2, 3};
}

Common Mistakes

Array algorithms 常見錯誤

錯誤原因修法
i <= arr.length最後會用到 invalid index改成 i < arr.length
max = 0若全是負數會錯max = arr[0] 或 maxIndex = 0
Average 用 integer divisionsum / length 兩邊都是 int(double) sum / length
int[] b = a 當成 copy只是 reference copy建立 new array 並逐格複製
Right shift 從左往右資料先被覆蓋從右往左搬
Remove 後以為 .length 變小Array fixed size使用 logical size
Parallel arrays 不同步 shift/remove同一 index 失去對應所有 parallel arrays 同步搬動

Checklist

本課核心觀念總整理

Traversal大多 array algorithms 都是走訪元素並更新答案。
BoundsValid index 是 0 到 arr.length - 1。
Sum初始化 sum = 0，每圈加元素值。
Count初始化 count = 0，條件成立時 count++。
Average需要 casting，conditional average 要避免除以 0。
Max / Min用第一格初始化，或追蹤 best index。
Search-1 常代表 not found。
Copy真正 copy 需要 new array 和 element-by-element copy。
ReverseCopy reverse 用 index mapping；in-place reverse 用 swap。
ShiftRight shift 從右往左；left shift 從左往右。
Parallel相同 index 表示同一筆資料，各 array 必須同步。
Parameters修改元素是 mutation；重新指定 parameter 不會換掉 caller 的 array variable。
考前必背十五句

Most array algorithms are built on traversal.

The last valid index is arr.length - 1.

Use traditional for loops when you need an index.

Enhanced for loops are good when only values are needed.

Sum accumulates values; count accumulates occurrences.

Average requires avoiding integer division.

Maximum and minimum should usually initialize from the array.

Linear search checks elements one by one.

-1 often means not found.

Array assignment copies a reference, not the elements.

Element-by-element copy creates an independent array.

Right shift must move from right to left.

Left shift must move from left to right.

Array length does not change during insert/remove-like operations.

Parallel arrays must keep their indexes synchronized.
