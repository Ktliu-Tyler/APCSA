A. Concepts

概念確認

先確認 while 的基本語意、execution order 與 loop 四元素。

Q1Definition

while loop 的基本語意是什麼？

只要 condition 是 true，就執行 body；執行完後回去重新檢查 condition。

Q2Pre-test

為什麼說 while 是 pre-test loop？

因為它在執行 body 前先檢查 condition。若一開始 false，body 會執行 0 次。

Q3if vs while

if 和 while 最大差異是什麼？

if 最多執行一次 body；while 會在 condition 仍為 true 時一直重複。

Q4Parts

一個典型 while loop 需要哪四個核心元素？

Initialization、condition、update、termination。少了 update 或 termination 方向錯，常會 infinite loop。

Q5Iteration

Iteration 是什麼意思？

Loop body 完整執行一次，稱為 one iteration。

Q6Termination

判斷一個 loop 是否會停止時，最重要的兩個問題是什麼？

控制 condition 的變數有沒有改變？改變方向會不會讓 condition 最後變成 false？

B. Trace

Basic Tracing

逐輪寫出 condition、body、update 後的值。

Q7Output

預測 output。

int x = 1;

while (x <= 3)
{
    System.out.println(x);
    x++;
}
1
2
3

x 分別以 1、2、3 進入 body，更新到 4 後 condition false。

Q8Final value

最後印出什麼？

int x = 2;

while (x < 10)
{
    x += 3;
}

System.out.println(x);

x 變化是 2 → 5 → 8 → 11，接著 11 < 10 false，所以印 11。

Q9Zero iterations

預測 output。

int x = 10;

while (x < 5)
{
    System.out.println(x);
    x++;
}

System.out.println("Done");

只印 Done。一開始 10 < 5 就 false，body 執行 0 次。

Q10Order

預測 output。

int x = 1;

while (x <= 3)
{
    x++;
    System.out.println(x);
}
2
3
4

先 x++ 再 print，所以不是 1、2、3。

Q11Division

預測 output。

int x = 100;

while (x > 1)
{
    x /= 2;
    System.out.println(x);
}
50
25
12
6
3
1

Java integer division 會捨去小數，最後 x 到 1 時下一輪 condition false。

Q12Multiplication

最後印出什麼？

int x = 1;

while (x < 20)
{
    x *= 2;
}

System.out.println(x);

x 變化是 1 → 2 → 4 → 8 → 16 → 32，所以印 32。

Q13Nested if

最後 count 是多少？

int x = 1;
int count = 0;

while (x <= 6)
{
    if (x % 2 == 0)
    {
        count++;
    }
    x++;
}

偶數是 2、4、6，共 3 個，所以 count 是 3。

Q14Short-circuit

這段會發生 division by zero 嗎？Loop 執行幾次？

int x = 0;

while (x != 0 && 100 / x > 1)
{
    x--;
}

不會。x != 0 是 false，右邊不執行。Loop 是 0 iterations。

Q15Order matters

最後 sum 是多少？

int x = 1;
int sum = 0;

while (x <= 5)
{
    x++;
    sum += x;
}

加進 sum 的是 2、3、4、5、6，所以 sum = 20，不是 15。

C. Counter

Counter / Off-by-One

判斷 loop body 執行幾次，並注意 boundary。

Q16Count

這個 loop body 執行幾次？

int i = 0;

while (i < 10)
{
    i++;
}

10 次。i 以 0 到 9 進入 body。

Q17Off-by-one

這個 loop body 執行幾次？

int i = 0;

while (i <= 10)
{
    i++;
}

11 次。i 以 0 到 10 進入 body。

Q18Count

這個 loop body 執行幾次？

int i = 1;

while (i < 10)
{
    i += 2;
}

5 次。i 以 1、3、5、7、9 進入 body。

Q19Countdown

預測 output。

int i = 5;

while (i >= 1)
{
    System.out.print(i + " ");
    i--;
}

5 4 3 2 1 。當 i 更新到 0，condition false。

Q20Even loop

寫出 while loop 印出 2 4 6 8 10。

int i = 2;

while (i <= 10)
{
    System.out.print(i + " ");
    i += 2;
}
Q21Boundary

想執行正好 5 次，哪個比較適合？

A. int i = 1; while (i < 5)
B. int i = 1; while (i <= 5)

B。從 1 開始時，i <= 5 會對 1、2、3、4、5 執行，共 5 次。

Q22Final value

最後 i 是多少？

int i = 4;

while (i <= 15)
{
    i += 4;
}

i 變化是 4 → 8 → 12 → 16，最後 16 <= 15 false，所以 i = 16。

Q230-based

int i = 0; while (i < n) { ... i++; } 通常執行幾次？

當 n > 0 時執行 n 次，i 以 0 到 n - 1 進入 body。

Q24Bug

想印 1 到 5，這段多印了什麼？

int i = 0;

while (i <= 5)
{
    System.out.println(i);
    i++;
}

多印 0。如果想印 1 到 5，應該從 int i = 1; 開始。

D. Accumulator

Accumulator / Count Matches

分辨 count、sum、product，並注意初始化值。

Q25Sum

最後 sum 是多少？

int i = 1;
int sum = 0;

while (i <= 4)
{
    sum += i;
    i++;
}

1 + 2 + 3 + 4 = 10，所以 sum = 10。

Q26Product

為什麼乘法 accumulator 通常從 1 開始？

因為 1 是乘法 identity，1 * x = x。若從 0 開始，0 * anything 都是 0。

Q27Product

最後 product 是多少？

int i = 1;
int product = 1;

while (i <= 4)
{
    product *= i;
    i++;
}

1 * 2 * 3 * 4 = 24。

Q28Count

最後 count 是多少？

int i = 1;
int count = 0;

while (i <= 20)
{
    if (i % 5 == 0)
    {
        count++;
    }
    i++;
}

5、10、15、20，共 4 個，所以 count = 4。

Q29Even sum

最後 sum 是多少？

int i = 1;
int sum = 0;

while (i <= 10)
{
    if (i % 2 == 0)
    {
        sum += i;
    }
    i++;
}

2 + 4 + 6 + 8 + 10 = 30。

Q30Average

若要算平均，為什麼要檢查 count > 0？

避免沒有任何資料時做 sum / count，也就是除以 0。

Q31Trace

最後 y 是多少？

int x = 1;
int y = 0;

while (x <= 8)
{
    y += x;
    x *= 2;
}

x 以 1、2、4、8 進入 body，所以 y = 1 + 2 + 4 + 8 = 15。

Q32Bug

這段想求 1 到 5 的總和，為什麼結果不是 15？

int i = 1;
int sum = 0;

while (i <= 5)
{
    i++;
    sum += i;
}

更新順序錯。先 i++ 後才加，所以加的是 2、3、4、5、6，結果是 20。

E. Sentinel / Validation

Sentinel、Input Validation、Infinite Loops

未知輸入次數時，特別注意 priming read 與每輪讀下一筆。

Q33Sentinel

Sentinel value 是什麼？

用來表示資料結束的特殊值，例如輸入 -1 停止讀取。

Q34Priming read

Sentinel loop 為什麼常在 loop 前先讀一次 input？

因為 while 要先有一個值，才能判斷它是不是 sentinel。這稱為 priming read。

Q35Sentinel count

輸入 5 7 9 -1 時，最後 count 是多少？

int count = 0;
int number = input.nextInt();

while (number != -1)
{
    count++;
    number = input.nextInt();
}

count = 3。Sentinel -1 不進 body，不被計入。

Q36Validation

合法 score 是 0 到 100。Input validation 的 while condition 應該是什麼？

while (score < 0 || score > 100)。不合法時才繼續要求輸入。

Q37Validation bug

這個 validation condition 錯在哪？

while (score >= 0 && score <= 100)
{
    System.out.println("Invalid");
    score = input.nextInt();
}

它在 score 合法時繼續問，邏輯反了。Validation 通常是 while (invalid)。

Q38Infinite loop

這段如果第一次輸入不是 -1，會發生什麼？

int n = input.nextInt();

while (n != -1)
{
    System.out.println(n);
}

Infinite loop。n 在 body 裡沒有更新，也沒有讀下一筆 input。

Q39Infinite loop

這段是否會停止？

int x = 1;

while (x < 10)
{
    x--;
}

通常不會停止。x 越來越小，x < 10 一直 true。

F. Digits

Digit Algorithms / Boolean Flags

用 % 10 取得 digit，用 /= 10 移除 digit。

Q40Digit

若 number = 58321，number % 10 是多少？

1，也就是最右邊的 digit。

Q41Digit

若 number = 58321，執行 number /= 10 後 number 是多少？

5832。Integer division 會移除最右 digit。

Q42Digit sum

最後 sum 是多少？

int number = 6241;
int sum = 0;

while (number > 0)
{
    int digit = number % 10;
    sum += digit;
    number /= 10;
}

6 + 2 + 4 + 1 = 13。處理順序是 1、4、2、6，但總和一樣。

Q43Count digits

最後 count 是多少？

int number = 5070;
int count = 0;

while (number > 0)
{
    count++;
    number /= 10;
}

count = 4。中間的 0 仍然是一個 digit；5070 → 507 → 50 → 5 → 0。

Q44Count specific digit

最後 count 是多少？

int number = 727417;
int count = 0;

while (number > 0)
{
    int digit = number % 10;
    if (digit == 7)
    {
        count++;
    }
    number /= 10;
}

數字 7 出現 3 次，所以 count = 3。

Q45Flag

這段最後 found 是什麼？

int number = 2468;
boolean found = false;

while (number > 0 && !found)
{
    int digit = number % 10;
    if (digit == 7)
    {
        found = true;
    }
    number /= 10;
}

false。沒有任何 digit 是 7，所以 flag 不會變成 true。

Q48Coding

寫 input validation：choice 必須在 1 到 5。

int choice = input.nextInt();

while (choice < 1 || choice > 5)
{
    System.out.println("Invalid.");
    choice = input.nextInt();
}
Q49Coding

寫 sentinel loop：讀入正整數，輸入 0 停止，計算總和。

int total = 0;
int value = input.nextInt();

while (value != 0)
{
    total += value;
    value = input.nextInt();
}

System.out.println(total);
Q50Final Challenge

預測 output。

int n = 6241;
int result = 0;

while (n > 0)
{
    int digit = n % 10;

    if (digit % 2 == 0)
    {
        result += digit;
    }

    n /= 10;
}

System.out.println(result);

偶數 digits 是 2、4、6，所以 result = 12。
