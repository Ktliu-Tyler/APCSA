Lesson Flow

本課路線

Selection

程式不一定永遠從上到下做同一件事

到目前為止，程式大多是一行一行往下執行。但真實程式常常需要根據狀況選擇路徑： 密碼正確才登入、成績達標才顯示 pass、輸入不合法就顯示錯誤。這種能力叫做 selection 或 conditional execution。 

condition
  |
  +-- true  -> execute this branch
  |
  +-- false -> skip or execute another branch

if

if：condition 是 true 才執行 body

Basic if

int temperature = 35;

if (temperature > 30)
{
    System.out.println("Hot");
}

temperature > 30 是 true，所以程式進入 braces 裡面並輸出 Hot。如果 temperature 是 20，condition 是 false， body 會被跳過。

if

關鍵字，開始一個條件判斷。

(condition)

必須得到 true 或 false。

{ body }

condition 是 true 時才執行。

Boolean Condition

if 括號中一定要是 boolean

Java 不會把 0 當 false，也不會把非零數字當 true。if 的 condition 必須真的是 Boolean expression。

Condition 合法嗎？ 原因
if (x > 5)合法x > 5 得到 boolean。
if (x == 10)合法== 是 comparison。
if (name.equals("Tom"))合法equals() 回傳 boolean。
if (isReady)合法isReady 本身是 boolean variable。
if (x)不合法如果 x 是 int，它不是 boolean。

Lesson 7 會大量使用 Lesson 6 的 Boolean expressions；看見 if (...) 先問括號裡最後是不是 Boolean。

Execution Tracing

if 是跳過 body，不是停止整個程式

Trace if

int x = 8;

System.out.println("A");

if (x > 5)
{
    System.out.println("B");
}

System.out.println("C");
x = 8

print A
x > 5 -> 8 > 5 -> true
print B
print C

Output:
A
B
C

如果 x = 3，那麼 x > 5 是 false，B 被跳過， 但 C 仍然會執行。

AP tracing SOP

先寫目前 variable values，再算 condition，決定 execution path，只執行那條路，最後繼續往下。

Variable update

branch 中如果修改 variable，下一個 condition 一定使用更新後的值。

if / else

if / else：條件成立做 A，否則做 B

Two-way Selection

int age = 16;

if (age >= 18)
{
    System.out.println("Adult");
}
else
{
    System.out.println("Minor");
}

if 和對應的 else 是 mutually exclusive paths。每一次執行只會選一條， 不可能同時印出 Adult 和 Minor。 

age >= 18
   |
   +-- true  -> Adult
   |
   +-- false -> Minor

Execution Path

int x = 7;

if (x > 5)
{
    x += 2;
}
else
{
    x -= 2;
}

x *= 3;

System.out.println(x);

7 > 5 是 true，所以 x += 2 讓 x 變 9；else 不執行。最後 x *= 3 得到 27。

else if

else if：多個 case 中選第一個成立的 branch

當情況不只兩種時，可以用 if / else if / else。Java 會從上往下檢查， 一旦遇到第一個 true，就執行那個 branch，後面全部跳過。

Grade Classifier

int score = 87;
String grade;

if (score >= 90)
{
    grade = "A";
}
else if (score >= 80)
{
    grade = "B";
}
else if (score >= 70)
{
    grade = "C";
}
else if (score >= 60)
{
    grade = "D";
}
else
{
    grade = "F";
}

System.out.println("Grade: " + grade);

87 >= 90 是 false，接著 87 >= 80 是 true，所以 grade 是 "B"。後面的 >= 70 和 >= 60 不會再檢查。

score 第一個成立條件 grade
95score >= 90A
87score >= 80B
75score >= 70C
58elseF

用 >= 做等級分類時，threshold 通常要從大到小排：90、80、70、60。

Independent if

兩個 if 不等於 if + else if

這是 AP CSA 非常常考的陷阱。兩個獨立 if 會各自判斷；else if chain 則最多只會執行其中一個 branch。

Two independent if statements

int x = 10;

if (x > 0)
{
    System.out.println("A");
}

if (x > 5)
{
    System.out.println("B");
}

兩個 condition 都是 true，所以輸出 A 和 B。

if / else if chain

int x = 10;

if (x > 0)
{
    System.out.println("A");
}
else if (x > 5)
{
    System.out.println("B");
}

第一個 condition 已經 true，所以 else if 不檢查，只輸出 A。

if (A) { ... }
if (B) { ... }

可能都執行。

if (A) { ... }
else if (B) { ... }

最多只執行一個 branch。

Nested if

Nested if：只有外層成立，內層才有機會判斷

Nested if

int age = 20;
boolean hasTicket = true;

if (age >= 18)
{
    if (hasTicket)
    {
        System.out.println("Enter");
    }
}

這表示兩個條件都必須成立：先檢查 age >= 18，成立後才會檢查 hasTicket。Lesson 8 學到 && 後，可以把這種邏輯寫得更短。

Nested if / else

int score = 75;

if (score >= 60)
{
    if (score >= 90)
    {
        System.out.println("Excellent");
    }
    else
    {
        System.out.println("Pass");
    }
}
else
{
    System.out.println("Fail");
}

75 >= 60 true，內層 75 >= 90 false，所以輸出 Pass。

Dangling else

else 會配對最近一個尚未配對的 if。最好永遠寫 braces，讓結構清楚。

Range Checking

Range checking：條件順序本身就是邏輯的一部分

分類題最常見的錯誤是 boundary 和 threshold order。用 >= 寫分數等級時， 通常從大到小；用 <= 寫年齡分類時，常從小到大。

英文 Java
greater than 10x > 10
less than 10x < 10
at least 10x >= 10
at most 10x <= 10
exactly 10x == 10
not equal to 10x != 10

Temperature Classifier

int temperature = 24;

if (temperature >= 30)
{
    System.out.println("Hot");
}
else if (temperature >= 20)
{
    System.out.println("Warm");
}
else if (temperature >= 10)
{
    System.out.println("Cool");
}
else
{
    System.out.println("Cold");
}

24 >= 30 false，24 >= 20 true，所以輸出 Warm。

Boundary testing：如果條件分界是 80 和 90，請測 79、80、89、90。

Case Analysis

Case analysis：把所有輸入分成清楚且不重疊的情況

AP CSA 很重視 case analysis。好的分類應該 cover all cases、不意外重疊、boundary 清楚。

Sign Classifier

int x = -5;

if (x > 0)
{
    System.out.println("Positive");
}
else if (x == 0)
{
    System.out.println("Zero");
}
else
{
    System.out.println("Negative");
}

最後的 else 不必再寫 x < 0，因為前面已經排除 x > 0 和 x == 0，剩下只可能是 negative。

x 範圍 第一條件 第二條件 輸出
x > 0true不檢查Positive
x == 0falsetrueZero
x < 0falsefalseNegative

Common Errors

Lesson 7 常見錯誤與 AP 陷阱

陷阱 錯誤想法 正確觀念
if (x)非 0 就是 true。Java condition 必須是 boolean。
if (x = 5)檢查 x 是否為 5。= 是 assignment；比較要用 ==。
password == "abc123"比較 String 內容。String contents 用 equals()。
if (x > 5);分號沒影響。if 控制 empty statement，後方 block 可能總是執行。
忘記 braces縮排決定 body。Java 看 syntax，不看縮排；建議永遠寫 { }。
錯誤 threshold order條件順序沒差。else if 是第一個 true 就停止。
unreachable branch每個 branch 都可能跑到。前面條件若比較寬，後面更嚴格條件可能永遠到不了。
branch update後面仍用舊值。branch 中修改後，後面 condition 用新值。

Unreachable Branch

if (x >= 50)
{
    System.out.println("A");
}
else if (x >= 70)
{
    System.out.println("B");
}
else
{
    System.out.println("C");
}

B 永遠不會執行，因為任何 x >= 70 的值都已經先符合 x >= 50。

AP Patterns

AP-style 題型整理

Independent if

int x = 6;

if (x > 3)
{
    x += 2;
}

if (x > 7)
{
    x *= 2;
}

x 先變 8，第二個 if 也成立，最後 x = 16。

else if first true wins

int x = 15;

if (x > 5)
{
    System.out.print("A");
}
else if (x > 10)
{
    System.out.print("B");
}

只輸出 A；x > 10 不會再檢查。

Nested if

int x = 4;

if (x > 0)
{
    System.out.print("A");

    if (x > 5)
    {
        System.out.print("B");
    }
    else
    {
        System.out.print("C");
    }
}

System.out.print("D");

Output 是 ACD。

Boundary

int score = 80;

if (score > 90)
{
    System.out.println("A");
}
else if (score > 80)
{
    System.out.println("B");
}
else if (score > 70)
{
    System.out.println("C");
}

80 > 80 是 false，但 80 > 70 是 true，所以輸出 C。

Final Trace Example

int x = 10;
int y = 5;

if (x > y)
{
    x -= 5;

    if (x == y)
    {
        y *= 2;
    }
}
else
{
    x += 10;
}

System.out.println(x + " " + y);

10 > 5 true，x 變 5，內層 x == y true， y 變 10，output 是 5 10。
