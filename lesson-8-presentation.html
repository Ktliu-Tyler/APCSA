AND Check

兩個條件都必須成立

int age = 20;
boolean hasTicket = false;

System.out.println(age >= 18 && hasTicket);

Output 是什麼？

A. true B. false C. 20 D. Compile error

答案是 B。左邊 true，但右邊 false；true && false 是 false。

OR Check

至少一個成立即可

int score = 120;

System.out.println(score < 0 || score > 100);

Output 是什麼？

A. true B. false C. 120 D. Compile error

答案是 A。左邊 false，右邊 true；false || true 是 true。

Range

範圍內用 &&，範圍外用 ||

Inside

score >= 0 && score <= 100

Outside

score < 0 || score > 100

Java rule

不能寫 0 <= score <= 100

Range Bug

這個 valid score 條件錯在哪？

if (score >= 0 || score <= 100)
{
    System.out.println("Valid");
}

問題是什麼？

A. 應使用 && B. 應使用 ! C. 不能使用 score D. 沒有錯

答案是 A。範圍內要同時符合上下界，所以應寫 score >= 0 && score <= 100。

Precedence

! 先，&& 再，|| 最後

boolean result = true && false || true;

result 是什麼？

A. true B. false C. Compile error D. 取決於 JVM

true && false 先得 false，再 false || true 得 true。

Parentheses

括號會改變結果

A = true
B = false
C = false

(A || B) && C  -> false
A || (B && C)  -> true

遇到混合 && 和 ||，建議寫括號讓邏輯明確。

Short-Circuit

右側 condition 不一定會執行

false && ...

右邊不執行

true || ...

右邊不執行

AP trap

method call、++x、division、null method 可能不會執行

Safe Division

short-circuit 可以避免 division by zero

int x = 0;

if (x != 0 && 100 / x > 1)
{
    System.out.println("Yes");
}

100 / x 會執行嗎？

A. 會 B. 不會 C. 一定 compile error D. 一定印 Yes

答案是 B。x != 0 false，AND 直接 short-circuit。

Safe String

short-circuit 可以避免 NullPointerException

String name = null;

if (name != null && name.equals("Tom"))
{
    System.out.println("Tom");
}

先檢查 name != null，右側 method call 才安全。

Side Effect

OR 左邊 true，右邊不執行

int x = 5;

if (x == 5 || ++x > 10)
{
    System.out.println(x);
}

Output 是什麼？

A. 5 B. 6 C. 7 D. 11

答案是 A。x == 5 true，所以 ++x 不執行。

De Morgan

兩條必背公式

!(A && B)

!A || !B

!(A || B)

!A && !B

Rule

operator 交換，每個 condition 取反

De Morgan Check

化簡這個 expression

!(x > 10 && y <= 5)

等價於？

A. x <= 10 || y > 5 B. x <= 10 && y > 5 C. x > 10 || y <= 5 D. x < 10 || y >= 5

答案是 A。&& 變 ||，x > 10 變 x <= 10，y <= 5 變 y > 5。

Equivalent

用反例快速找出不等價

!(A && B)  vs  !A && !B

A = true
B = false

Left:  !(true && false) -> true
Right: false && true    -> false

結果不同，所以 not equivalent。

Boolean Return

Boolean expression 可以直接 return

public static boolean isValidScore(int score)
{
    return score >= 0 && score <= 100;
}

不必寫 if (...) return true; else return false;。

AP-style Trace

綜合追蹤

int x = 5;
int y = 12;
boolean ready = false;

if ((x >= 1 && x <= 10) && (y > 10 || !ready))
{
    System.out.println("A");
}
else
{
    System.out.println("B");
}

x 在範圍內。y > 10 true，所以右半邊 true。Output 是 A。
