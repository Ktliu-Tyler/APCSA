A. Concepts

Boolean 觀念

先確認 boolean、true、false、Boolean expression 的基本定義。

Q1Type

boolean 是 primitive type 還是 reference type？

boolean 是 primitive type。它只有 true 和 false 兩種值。

Q2Literal

true 和 "true" 有什麼不同？

true 是 boolean literal。"true" 是 String，因為有雙引號。

Q3Java Rule

在 Java 中，boolean x = 1; 合法嗎？

不合法。Java 不把 1 當作 true，也不把 0 當作 false。

Q4Expression

Boolean expression 的結果一定是什麼 type？

一定是 boolean，也就是 true 或 false。

Q5Assignment

預測 output。

boolean ready = false;
ready = true;

System.out.println(ready);

Output 是 true。第二行重新 assignment，讓 ready 變成 true。

Q6Boolean Variable

預測 adult 的值。

int age = 20;
boolean adult = age >= 18;

20 >= 18 是 true，所以 adult 是 true。

Q7Not Auto Update

預測 output。

int x = 5;
boolean result = x > 3;

x = 1;

System.out.println(result);

Output 是 true。result 在第二行已經被算出來，不會因為 x 後來改變而自動更新。

B. Operators

Relational Operators

每一題都先確認 operator 的意思，尤其注意 boundary value。

Q8==

5 == 5 的結果是什麼？

true。兩邊數值相同。

Q9!=

5 != 5 的結果是什麼？

false。!= 是 not equal to，但兩邊其實相等。

Q10<

如果 x = 5，x < 5 的結果是什麼？

false。< 不包含等於。

Q11<=

如果 x = 5，x <= 5 的結果是什麼？

true。<= 包含等於。

Q12Boundary

條件是 score > 80。當 score = 80 時結果是什麼？

false。> 不包含等於。如果條件是 score >= 80 才會是 true。

Q13Boundary

條件是 age >= 18。哪幾個 age 會得到 true？

A. 17 B. 18 C. 19 D. 18 和 19

答案是 D。>= 包含邊界值 18。

Q14= vs ==

x = 5; 和 x == 5 差在哪裡？

x = 5; 是 assignment，會修改 x。x == 5 是 comparison，結果是 boolean。

Q15Return Type

x >= 5 的 return type 是什麼？

boolean。所有 relational expressions 都會得到 true 或 false。

Q16Comparison

預測 output。

int x = 3;
int y = 8;

System.out.println(x + 5 == y);

x + 5 = 8，所以 8 == 8，output 是 true。

C. Numeric Tracing

Arithmetic、Integer Division、Casting

先算左右數值，再做最後比較。

Q17Precedence

預測 result。

int x = 4;
int y = 5;

boolean result = x + 3 < y * 2;

x + 3 = 7，y * 2 = 10，7 < 10 是 true。

Q18Parentheses

預測結果。

(2 + 3) * 4 > 15

(2 + 3) * 4 = 20，20 > 15 是 true。

Q19Integer Division

預測 output。

System.out.println(5 / 2 == 2.5);

Output 是 false。5 / 2 是 integer division，結果是 2，所以 2 == 2.5 是 false。

Q20Casting

預測 output。

System.out.println((double) 5 / 2 == 2.5);

Output 是 true。(double) 5 / 2 是 2.5。

Q21Modulo

預測 result。

int x = 12;
boolean result = x % 3 == 0;

12 % 3 = 0，所以 0 == 0 是 true。

Q22Modulo

預測 result。

int x = 14;
boolean result = x % 5 != 0;

14 % 5 = 4，4 != 0 是 true。

Q23Integer Division

預測 result。

int a = 7;
int b = 3;

boolean result = a / b > 2;

7 / 3 = 2，2 > 2 是 false。

Q24Mixed

預測 result。

int x = 4;
int y = 9;

boolean result = x * 2 + 1 == y;

4 * 2 + 1 = 9，所以 9 == 9 是 true。

Q25int / double

預測 output。

int x = 5;
double y = 5.0;

System.out.println(x == y);

Output 是 true。Java 會進行 numeric comparison，兩邊數值都是 5。

Q26Trace

預測三行 output。

int x = 8;
int y = 3;

boolean a = x / y == 2;
boolean b = x % y == 2;
boolean c = x + y >= 11;

System.out.println(a);
System.out.println(b);
System.out.println(c);
true
true
true

8 / 3 = 2，8 % 3 = 2，8 + 3 = 11。

D. Reference / null

Primitive vs Reference、null

看到 new、assignment、==、null，先畫 reference diagram。

Q27Primitive

Primitive 使用 == 比較什麼？

比較實際 primitive values，例如 int、double、boolean 的值。

Q28Reference

Object reference 使用 == 比較什麼？

比較兩個 variables 是否 reference 到同一個 object，不是比較內容。

Q29Two new Strings

預測 output。

String a = new String("hello");
String b = new String("hello");

System.out.println(a == b);

Output 是 false。兩次 new 建立兩個不同 objects。

Q30equals

延續上一題，a.equals(b) 的結果是什麼？

true。equals() 比較 String contents，兩個 contents 都是 "hello"。

Q31Alias

預測 output。

String a = new String("hello");
String b = a;

System.out.println(a == b);

Output 是 true。b = a 複製 reference，兩個 variables 指向同一個 object。

Q32!=

預測 result。

String a = new String("dog");
String b = new String("dog");

boolean result = a != b;

result 是 true。兩個 reference 不同，所以 a != b 為真。

Q33null

預測 result。

String name = null;
boolean result = name == null;

result 是 true。== null 是安全的 reference comparison。

Q34null

這段程式會輸出什麼或發生什麼？

String name = null;
System.out.println(name.equals("Alice"));

會發生 NullPointerException。name 沒有 reference 到 object，不能呼叫 instance method。

Q35Reference Trace

預測四行 output。

String first = new String("Java");
String second = first;
String third = null;

boolean a = first == second;
boolean b = first == third;
boolean c = third == null;
boolean d = first != null;

System.out.println(a);
System.out.println(b);
System.out.println(c);
System.out.println(d);
true
false
true
true

first 和 second 是 alias。third 是 null。

E. String Boolean

String Methods 形成 Boolean Expression

先判斷 method return type，再看比較運算子。

Q36equals

預測 result。

String answer = "yes";
boolean result = answer.equals("yes");

result 是 true。equals() 本身就回傳 boolean。

Q37length

預測 result。

String s = "computer";
boolean result = s.length() >= 8;

"computer" 長度是 8，所以 8 >= 8 是 true。

Q38indexOf

預測 result。

String s = "computer";
boolean result = s.indexOf("put") == 3;

"put" 從 index 3 開始，所以結果是 true。

Q39indexOf not found

預測 result。

String s = "computer";
boolean result = s.indexOf("xyz") >= 0;

indexOf("xyz") 是 -1，-1 >= 0 是 false。

Q40substring + equals

預測 result。

String s = "computer";
boolean result = s.substring(0, 3).equals("com");

s.substring(0, 3) 得到 "com"，所以結果是 true。

Q41compareTo

預測 result。

String a = "apple";
String b = "banana";

boolean result = a.compareTo(b) < 0;

"apple" 排在 "banana" 前面，compareTo() 是 negative，所以 result 是 true。

Q42compareTo

預測 result。

String a = "dog";
String b = "cat";

boolean result = a.compareTo(b) < 0;

"dog" 排在 "cat" 後面，compareTo() 是 positive，所以 positive < 0 是 false。

Q43String Trace

預測三行 output。

String word = "programming";

int x = word.indexOf("gram");
int y = word.substring(3).length();
boolean c = word.substring(0, 3).equals("pro");

System.out.println(x == 3);
System.out.println(y > 5);
System.out.println(c);
true
true
true

"gram" 從 index 3 開始。word.substring(3) 是 "gramming"，長度是 8。

F. Errors

錯誤判斷

有些題目答案不是 true/false，而是 compile-time error 或 runtime error。

Q44Compile Error

這行是否合法？

boolean result = 0 < x < 10;

不合法。Java 不支援 chained comparison。0 < x 先得到 Boolean，接著不能再拿 Boolean 跟 10 比較。

Q45Compile Error

這行是否合法？

boolean result = name < "John";

不合法。String 不能直接用 < 比較排序，應使用 name.compareTo("John") < 0。

Q46Syntax

x => 5 合法嗎？

不合法。Java 沒有 =>。應寫 x >= 5。

Q47Runtime Error

這段程式會發生 compile-time error、runtime error，還是正常輸出？

String s = null;
System.out.println(s == null);

正常輸出 true。s == null 是安全比較，不是 method call。

G. Coding

程式練習

這些小練習只需要建立 Boolean expressions，下一課才會正式把它們放進 if。

Q48Coding

建立 passed：當 score 大於等於 60 時為 true。

public class Main {
    public static void main(String[] args) {
        int score = 72;
        boolean passed = score >= 60;

        System.out.println(passed);
    }
}
Q49Coding

建立 even：當 number 是偶數時為 true。

public class Main {
    public static void main(String[] args) {
        int number = 14;
        boolean even = number % 2 == 0;

        System.out.println(even);
    }
}

% 2 的 remainder 是 0，代表可以被 2 整除。

Q50Final Challenge

完整綜合考題，預測 output。

String a = new String("APCSA");
String b = a;
String c = new String("APCSA");

int score = 85;
boolean x = a == b;

System.out.println(x);

System.out.println(z);

false
true

true

a 和 b 是 alias；c 是另一個 object，但 contents 相同。85 >= 60 是 true，"CSA" 找得到。
