Array Algorithms

今天把 array 變成可以解題的工具：traversal、sum、count、average、max/min、 linear search、copy、reverse、shift、insert/remove-like logic 與 parallel arrays。

Big Idea

Array 題很少只問一格，更多是問一段 algorithm

sum
count
average
max / min
search
copy / reverse / shift

核心都是 traversal + update rule。

Traversal

最重要的 array loop

for (int i = 0; i < arr.length; i++)
{
    // use arr[i]
}

Valid indexes are 0 through arr.length - 1。

Quick Check

為什麼不能寫 i <= arr.length？

arr.length 不是 valid index。最後會存取 arr[arr.length]，造成 bounds error。

Traditional vs Enhanced For

需要 index，就用 traditional for

Traditional

有 i 和 arr[i]。

適合修改、shift、reverse、parallel arrays。

Enhanced

只有 value。

適合只讀元素：sum、count、max。

Algorithm Model

多數 array algorithms 可以拆成三步

Initialize Traverse Update answer

題目不同，通常只是 update rule 不同。

Sum

Accumulator pattern

int sum = 0;

for (int value : nums)
{
    sum += value;
}

0 是加法 identity value。

Count

Counter pattern

int count = 0;

for (int value : nums)
{
    if (value > 10)
    {
        count++;
    }
}

Sum 加元素值；count 加符合條件的次數。

Quick Check

這段最後 sum 和 count 各是多少？

int[] nums = {4, 17, 2, 19};
int sum = 0;
int count = 0;

for (int value : nums)
{
    if (value > 10)
    {
        sum += value;
        count++;
    }
}

sum = 36，count = 2。符合條件的是 17 和 19。

Average

Average 要小心 integer division

double average = (double) sum / nums.length;

Conditional average 還要檢查 count > 0。

Maximum

Best-so-far 不要亂初始化成 0

int max = nums[0];

for (int value : nums)
{
    if (value > max)
    {
        max = value;
    }
}

若 array 全是負數，max = 0 會錯。

Max Index

需要知道「誰」最大，就追蹤 index

int maxIndex = 0;

for (int i = 1; i < scores.length; i++)
{
    if (scores[i] > scores[maxIndex])
    {
        maxIndex = i;
    }
}

Max index 對 parallel arrays 特別有用。

Linear Search

Search 逐一檢查元素

public static boolean contains(int[] arr, int target)
{
    for (int value : arr)
    {
        if (value == target)
        {
            return true;
        }
    }
    return false;
}

Find Index

-1 常代表 not found

int index = -1;

for (int i = 0; i < arr.length; i++)
{
    if (arr[i] == target)
    {
        index = i;
        break;
    }
}

Quick Check

這個 search method 錯在哪裡？

for (int value : arr)
{
    if (value == target)
    {
        return true;
    }
    return false;
}

return false 放在 loop 裡，第一格不是 target 就提早結束，沒有檢查後面。

Copy Array

Reference copy 不等於 element copy

Reference Copy

int[] b = a;

同一個 array。

Element Copy

int[] b = new int[a.length];
for (int i = 0; i < a.length; i++)
{
    b[i] = a[i];
}

新的 array。

Reversed Copy

Reverse mapping：arr.length - 1 - i

int[] result = new int[arr.length];

for (int i = 0; i < arr.length; i++)
{
    result[i] = arr[arr.length - 1 - i];
}

In-place Reverse

直接修改原 array，要交換對稱位置

for (int i = 0; i < arr.length / 2; i++)
{
    int opposite = arr.length - 1 - i;
    int temp = arr[i];
    arr[i] = arr[opposite];
    arr[opposite] = temp;
}

只跑一半，避免交換回去。

Shift

Shift direction 決定資料會不會被覆蓋

Right shift move right-to-left Left shift move left-to-right

Right Shift

Right shift 從右往左

for (int i = arr.length - 1; i > 0; i--)
{
    arr[i] = arr[i - 1];
}

Left Shift

Left shift 從左往右

for (int i = 0; i < arr.length - 1; i++)
{
    arr[i] = arr[i + 1];
}

Quick Check

Right shift 後這個 array 變成什麼？

int[] arr = {1, 2, 3, 4};

for (int i = arr.length - 1; i > 0; i--)
{
    arr[i] = arr[i - 1];
}

{1, 1, 2, 3}。第一格通常要另外放入新值或保留。

Insert-like Logic

Array 長度固定，insert 通常搭配 logical size

for (int i = size; i > index; i--)
{
    arr[i] = arr[i - 1];
}
arr[index] = value;
size++;

先 right shift 空出位置。

Remove-like Logic

Remove 後 left shift，array length 不會變

for (int i = index; i < size - 1; i++)
{
    arr[i] = arr[i + 1];
}
size--;

Parallel Arrays

相同 index 表示同一筆資料

String[] names = {"Amy", "Ben", "Cara"};
int[] scores = {90, 75, 98};

System.out.println(names[2] + ": " + scores[2]);

Parallel arrays 幾乎一定需要 index。

Parallel Arrays + Max

用 maxIndex 同時取得名字和分數

int maxIndex = 0;

for (int i = 1; i < scores.length; i++)
{
    if (scores[i] > scores[maxIndex])
    {
        maxIndex = i;
    }
}

System.out.println(names[maxIndex]);

Array Parameters

修改 array 元素會被 caller 看見

public static void change(int[] arr)
{
    arr[0] = 99;
}

Array 是 object；parameter copy 了 reference value。

Quick Check

這段最後印出什麼？

int[] a = {1, 2, 3};
int[] b = a;
b[0] = 99;
System.out.println(a[0]);

99。a 和 b reference 同一個 array。

Pattern Map

題目文字到 algorithm pattern

總和 → sum
有幾個 → count
平均 → sum + count
最大 → best so far
在哪裡 → index / -1
同步資料 → parallel arrays

Common Mistakes

Lesson 18 最常見錯誤

i <= arr.length
max = 0
average integer division
reference copy 當成 array copy
right shift 方向錯
parallel arrays 沒同步

Final Trace

最後挑戰：印出什麼？

int[] nums = {3, 5, 7, 9};

for (int i = nums.length - 1; i > 0; i--)
{
    nums[i] = nums[i - 1];
}
nums[0] = 0;

for (int value : nums)
{
    System.out.print(value + " ");
}

0 3 5 7 。先 right shift，再把第一格改成 0。
