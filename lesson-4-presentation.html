Objects & References

今天要把 int x 和 Scanner input 的差異說清楚： primitive variable 直接存 value；reference variable 存的是找到 object 的 reference。

開啟 OneCompiler Lesson 4 課後練習

Opening Question

int x 和 Scanner input 真的都直接存資料嗎？

int x = 10;

x 直接存 primitive value。

Scanner input = ...

input 存的是 object reference。

Today's idea

變數和 object 不一定是同一件事。

答案是：不是。Primitive variable 直接存 value；reference variable 儲存可以找到 object 的 reference。

Primitive Review

Primitive variable 直接存 value

int10
double3.14
booleantrue
char'A'
Copyassignment 複製 value
int a = 10;
int b = a;
a = 30;

b 還是 10。int b = a; 只在當下複製 value，不建立永久連結。

Class vs Object

Class 是藍圖，object 是根據藍圖建立的個體

一個 class 可以建立很多 objects。AP 題目也常說 object 是 an instance of a class。

Class

設計規格、blueprint。

Object

真正建立出來、可以被操作的 instance。

Example

Scanner class；某一個 Scanner object。

Object Creation

new 通常代表建立新的 object

new ClassName(arguments)
new Class name Constructor call New object

new Scanner(System.in) 建立新的 Scanner object，Scanner(System.in) 是 constructor call。

Scanner Breakdown

拆解這一行

Scanner input = new Scanner(System.in);
Scannerreference type / class
inputreference variable
new Scanner(...)object creation

先建立 Scanner object，取得它的 reference，再把 reference 存進 input。

Reference

Reference 可以畫成「變數指向 object」

input
  |
  v
Scanner object

input 不是 Scanner object 本身。input 是儲存 reference 的 variable。

Big Comparison

Primitive variable vs reference variable

Primitive

int x = 5;
變數直接存 5。

Reference

Scanner input = ...
變數存 object reference。

Assignment

primitive 複製 value；reference 複製 reference。

Reference assignment 不會複製 object。

Primitive Copy

兩份獨立的 value

int a = 5;
int b = a;

a = 20;

最後 a 和 b 是多少？

A. 20 and 20 B. 20 and 5 C. 5 and 20 D. Compile error

答案是 B。b = a 只複製當下的 primitive value 5。

Reference Copy

複製 reference，不建立新 object

Scanner first = new Scanner(System.in);
Scanner second = first;
first  ----\
           > Scanner object
second ----/

new Scanner(...) 只出現一次，所以明確建立的是一個 Scanner object。

Aliases

兩個 references 指向同一個 object，稱為 aliases

如果透過其中一個 reference 操作 object，另一個 reference 看到的是同一個 object 的狀態。 

Scanner first = new Scanner(System.in);
Scanner second = first;

first 和 second 是同一個 Scanner object 的 aliases。

Object State

Object 可以有 state 和 behavior

State 是 object 目前內部資料的狀態；behavior 是 object 能執行的操作，Java 通常用 methods 表現。

Statespeed = 50、battery = 80
Behavioraccelerate()、brake()
Aliases多個 references 看到同一個 object state。

Count Objects

數 new，不要只數變數

Scanner a = new Scanner(System.in);
Scanner b = a;
Scanner c = b;

建立了幾個 Scanner objects？有幾個 reference variables？

A. 1 object, 3 variables B. 3 objects, 3 variables C. 0 objects, 3 variables D. 1 object, 1 variable

答案是 A。new Scanner(...) 只執行一次，因此一個 object；a、b、c 是三個 reference variables。

Reference Reassignment

a = b; 不會移動或複製 object

SomeClass a = new SomeClass();
SomeClass b = new SomeClass();

a = b;

a 取得 b 裡的 reference，所以 a 和 b 指向同一個 Object B。Object A 如果沒有其他 reference，就無法再被程式使用。

Math vs Scanner

Math.sqrt 和 input.nextInt 的呼叫角度不同

Math.sqrt(25)

Class.method(...)
static method，不需要 new Math()。

input.nextInt()

objectReference.method(...)
對 Scanner object 呼叫 method。

Dot operator

在 reference 上呼叫 method：reference.method()。

null

null 表示沒有 reference 到任何 object

合法

Scanner input = null;

合法

String name = null;

不合法

int x = null;

null 不是 0，也不是空字串。

null vs Empty String

null、""、" " 是三件不同的事

null

沒有 String object。

""

有 String object，長度是 0。

" "

有 String object，內容是一個空白字元。

NullPointerException

對 null 呼叫 method 會出事

String name = null;
System.out.println(name.length());

最接近的錯誤類型是什麼？

A. Compile-time error B. Runtime error C. Logic only D. No error

答案是 B，更具體是 NullPointerException。name 沒有指向 String object，所以不能呼叫 length()。

Compile vs Runtime

先分清楚錯在什麼時候被發現

Compile-time

int x = null;
primitive type 不能存 null。

Runtime

String s = null; s.length();
執行 method call 時才發現沒有 object。

AP Trap

SomeClass obj = null; 本身通常合法。

null Does Not Delete Object

一個 reference 變 null，object 不一定消失

Scanner a = new Scanner(System.in);
Scanner b = a;

a = null;
a -> null

b -> Scanner object

Scanner object 仍然存在，因為 b 還 reference 到它。

Diagram Strategy

Object tracing 解題流程

Find new Draw objects Draw variables Copy arrows Handle null

不要把 reference 題只放在腦中硬想，畫箭頭通常更快也更穩。

AP-style Check

快速檢核：最後 diagram 是什麼？

Scanner a = new Scanner(System.in);
Scanner b = a;
Scanner c = b;

b = null;
a ----\
       > Scanner object
c ----/

b -> null

b = null 只改變 b。a 和 c 仍然指向原本的 object。

Common Misconceptions

本課最容易被 AP 題目利用的迷思

a = b不複製整個 object，只複製 reference。
Two variables不代表一定有 two objects。
new建立 object，不是宣告 reference variable。
null不是 object，也不是 empty string。
ReferenceAP CSA 只需要能用箭頭追蹤，不需要操作記憶體位址。

Final Challenge

數 objects 並畫出最後狀態

Scanner a = new Scanner(System.in);
Scanner b = a;

a = new Scanner(System.in);

new Scanner(...) 執行兩次，所以建立兩個 Scanner objects。最後 a 指向第二個 object，b 仍指向第一個 object。
