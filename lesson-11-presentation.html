Core Structure

大多數 loop algorithm 都有三個階段

Initialization Repeated Processing Final Result

先建立狀態變數，每一輪更新它，最後使用它回答問題。

State Variables

每個變數都代表目前知道的資訊

sum已處理資料的總和
count已找到 match 的數量
max目前看過最大值
min目前看過最小值
found是否已找到
result目前建立的字串

Sum

Sum pattern：把值加進總和

int sum = 0;

for (int i = 1; i <= 100; i++)
{
    sum += i;
}

sum 從 0 開始，因為 0 不影響加法結果。

Count

Count pattern：找到一個就加一

int count = 0;

for (int i = 1; i <= 20; i++)
{
    if (i % 3 == 0)
    {
        count++;
    }
}

count++ 的意思是「又找到一個」，不是把數值加進去。

Sum vs Count

這段最後 sum 和 count 是多少？

int sum = 0;
int count = 0;

for (int i = 1; i <= 20; i++)
{
    if (i % 5 == 0)
    {
        sum += i;
        count++;
    }
}
A. sum 20, count 4 B. sum 50, count 4 C. sum 4, count 50 D. sum 50, count 5

答案是 B。符合的是 5、10、15、20，所以 sum = 50，count = 4。

Average

Average 通常是 loop 後才算

int sum = 0;
int count = 0;

for (...)
{
    if (match)
    {
        sum += value;
        count++;
    }
}

if (count > 0)
{
    double average = (double) sum / count;
}

Average Trap

Integer division 會先發生

int sum = 17;
int count = 4;

double average = sum / count;
A. 4.0 B. 4.25 C. 5.0 D. Compile error

答案是 A。sum / count 兩邊都是 int，所以先得到 4，再存成 4.0。

Min / Max

Running max / min 記錄「目前看過最好」

Maximum

if (value > max) max = value;

Minimum

if (value < min) min = value;

Initialization

通常用第一個真實資料。

Max Bug

max = 0 不一定安全

Data:
-8, -3, -20, -5

int max = 0;

真正最大是 -3，但程式可能錯誤保留 0。0 根本不是資料的一部分。

Find Any

Find any：有沒有找到？

boolean found = false;

for (int i = 1; i <= 20; i++)
{
    if (i % 4 == 0 && i % 6 == 0)
    {
        found = true;
    }
}

問題只問「有沒有」，所以狀態變數是 boolean flag。

Flag Bug

這段最後 found 是什麼？

boolean found = false;

for (int i = 1; i <= 5; i++)
{
    if (i == 3)
    {
        found = true;
    }
    else
    {
        found = false;
    }
}
A. true B. false C. 3 D. Compile error

答案是 B。i = 5 時 else 又把 found 改回 false。Find any 不應這樣重設 flag。

Find First

Find first：找到後不能被後面覆寫

int first = -1;
boolean found = false;
int i = 1;

while (i <= 100 && !found)
{
    if (i % 7 == 0 && i % 9 == 0)
    {
        first = i;
        found = true;
    }
    i++;
}

第一個同時是 7 和 9 的倍數是 63。

First vs Last

這段找的是 first 還是 last？

String s = "BANANA";
int position = -1;

for (int i = 0; i < s.length(); i++)
{
    if (s.substring(i, i + 1).equals("A"))
    {
        position = i;
    }
}
A. first A B. last A C. count of A D. compile error

答案是 B。A 在 index 1、3、5，每次 match 都覆寫，最後留下 5。

String Traversal

逐字處理 String 的標準 pattern

for (int i = 0; i < word.length(); i++)
{
    String letter = word.substring(i, i + 1);
    ...
}

合法 index 是 0 到 length() - 1，所以不是 i <= word.length()。

String Count

"MISSISSIPPI" 裡 "I" 出現幾次？

String word = "MISSISSIPPI";
int count = 0;

for (int i = 0; i < word.length(); i++)
{
    if (word.substring(i, i + 1).equals("I"))
    {
        count++;
    }
}
A. 2 B. 3 C. 4 D. 5

答案是 C。"I" 出現 4 次。

Reverse Traversal

反向走訪從 length() - 1 開始

String s = "CODE";
String result = "";

for (int i = s.length() - 1; i >= 0; i--)
{
    result += s.substring(i, i + 1);
}

最後 result 是 "EDOC"。

Substring Pairs

長度 2 的 substring：最後起點是 length() - 2

for (int i = 0; i < s.length() - 1; i++)
{
    String pair = s.substring(i, i + 2);
}

例如 "AAAA" 中 overlapping 的 "AA" 有 3 個。

One-Pass

一次 traversal 可以維護多個狀態

int first = input.nextInt();
int sum = first;
int count = 1;
int min = first;
int max = first;

for (int i = 1; i < 5; i++)
{
    int value = input.nextInt();
    sum += value;
    count++;

    if (value < min) { min = value; }
    if (value > max) { max = value; }
}

Complex Trace

最後 sum、count、average 是多少？

int sum = 0;
int count = 0;

for (int i = 1; i <= 8; i++)
{
    if (i % 3 != 0)
    {
        sum += i;
        count++;
    }
}
A. 27, 6, 4.5 B. 36, 8, 4.5 C. 9, 2, 4.5 D. 27, 8, 3.375

答案是 A。排除 3 和 6，加入 1、2、4、5、7、8，sum = 27、count = 6。

Common Errors

今天最常見的錯誤

sum++ 當作 sum algorithm
count += value 當作 count
average 忘記 cast
max = 0 或 min = 0
找到後又把 found 設回 false
find first 被後面 match 覆寫
i <= str.length() 超界
只 trace i，忘記 trace state
