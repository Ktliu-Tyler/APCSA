A. Concepts

概念確認

先確認 ArrayList 和 array 的核心差異。

Q1ArrayList

ArrayList 和 array 最大的差異是什麼？

Array 長度固定；ArrayList 的 size 可以因為 add 和 remove 改變。

Q2Import

使用 ArrayList 前通常需要哪一行 import？

import java.util.ArrayList;
Q3Generic

ArrayList<String> 中的 String 代表什麼？

代表 list 中元素的型別。這個 list 應該存放 String objects。

Q4Wrapper

為什麼不能寫 ArrayList<int>？

Generic type 必須是 reference type，不是 primitive type。要存整數應寫 ArrayList<Integer>。

Q5size

ArrayList 用什麼取得目前元素數量？

使用 size() method，例如 list.size()。

Q6Index

若 list.size() 是 4，最大合法讀取 index 是多少？

最大合法讀取 index 是 3。Valid indexes 是 0 到 size() - 1。

B. Create / Types

建立 ArrayList 與型別規則

這組題目確認 import、generic type、wrapper class 和 autoboxing。

Q7Create

建立一個存放 String 的空 ArrayList。

ArrayList<String> words = new ArrayList<String>();
Q8Integer List

建立一個存放整數的 ArrayList，型別應該寫什麼？

ArrayList<Integer> scores = new ArrayList<Integer>();

用 Integer，不是 int。

Q9Double List

要存 double values 時，wrapper class 是什麼？

Wrapper class 是 Double，所以寫 ArrayList<Double>。

Q10Boolean List

要存 boolean values 時，wrapper class 是什麼？

Wrapper class 是 Boolean，所以寫 ArrayList<Boolean>。

Q11Autoboxing

scores.add(90); 可以加入 ArrayList<Integer> 嗎？

可以。Java 會 autobox，把 int value 包成 Integer object。

Q12Unboxing

int score = scores.get(0); 可以從 ArrayList<Integer> 取值嗎？

可以。Java 會 unbox，把 Integer 取成 int value。

C. Methods

size / add / get / set / remove

這組題目確認每個 method 的效果與回傳值。

Q13add End

以下程式後 names 內容是什麼？

ArrayList<String> names = new ArrayList<String>();
names.add("Amy");
names.add("Ben");

[Amy, Ben]。add(obj) 加到尾端。

Q14add Index

以下程式後 names 內容是什麼？

names.add("Amy");
names.add("Cara");
names.add(1, "Ben");

[Amy, Ben, Cara]。Cara 被往右移。

Q15get

若 names 是 [Amy, Ben, Cara]，names.get(2) 是什麼？

是 "Cara"。

Q16set

以下程式後 list 內容和 old 是什麼？

ArrayList<String> names = new ArrayList<String>();
names.add("Amy");
names.add("Ben");
String old = names.set(1, "Cara");

names 是 [Amy, Cara]，old 是 "Ben"。set 回傳被取代的舊元素。

Q17set Size

set(index, obj) 會改變 size() 嗎？

不會。set 只是取代既有元素，不新增也不刪除元素。

Q18remove

以下程式後 list 內容和 removed 是什麼？

ArrayList<String> names = new ArrayList<String>();
names.add("Amy");
names.add("Ben");
names.add("Cara");
String removed = names.remove(1);

names 是 [Amy, Cara]，removed 是 "Ben"。

Q19remove Size

remove(index) 後 size() 會怎樣？

size() 減少 1，右邊元素往左移。

Q20Valid add index

若 list size 是 3，add(index, obj) 的合法 index 可以到多少？

可以是 0、1、2、3。add(3, obj) 等於加到最後。

D. Index Shift Trace

新增與移除後重新寫出 list

每次 add/remove 之後，index 會改變，請一行一行追蹤。

Q21Trace

以下程式最後印出什麼？

ArrayList<String> words = new ArrayList<String>();
words.add("A");
words.add("C");
words.add(1, "B");
System.out.println(words);

印出 [A, B, C]。

Q22Trace

以下程式最後印出什麼？

ArrayList<String> words = new ArrayList<String>();
words.add("A");
words.add("B");
words.add("C");
words.remove(0);
System.out.println(words.get(0));

印出 B。移除 index 0 後，B 左移到 index 0。

Q23Trace

以下程式最後 list 是什麼？

ArrayList<Integer> nums = new ArrayList<Integer>();
nums.add(2);
nums.add(4);
nums.add(1, 3);
nums.set(0, 1);

[1, 3, 4]。先 [2, 4]，插入 3 變 [2, 3, 4]，再把 index 0 改成 1。

Q24Trace

以下程式最後 nums.size() 是多少？

ArrayList<Integer> nums = new ArrayList<Integer>();
nums.add(10);
nums.add(20);
nums.add(30);
nums.set(1, 99);
nums.remove(2);

size() 是 2。set 不改 size；remove 減少 1。

Q25Trace

以下程式最後印出什麼？

ArrayList<String> list = new ArrayList<String>();
list.add("red");
list.add("blue");
list.add(1, "green");
String x = list.remove(2);
System.out.println(x + " " + list);

先變 [red, green, blue]，移除 index 2 回傳 blue，所以印出 blue [red, green]。

Q26Trace

以下程式最後印出什麼？

ArrayList<Integer> nums = new ArrayList<Integer>();
nums.add(5);
nums.add(10);
nums.add(15);
nums.add(nums.size(), 20);
System.out.println(nums.get(3));

印出 20。add(size(), value) 是加到尾端。

為什麼 enhanced for 不適合用來刪除符合條件的元素？

F. Error Spotting

ArrayList 常見錯誤判斷

這組題目練習 AP 常見 compile error 和 logic error。

Q33.length

以下 code 的問題是什麼？

for (int i = 0; i < list.length; i++)

ArrayList 沒有 .length。應寫 list.size()。

Q34Brackets

以下 code 的問題是什麼？

System.out.println(list[0]);

ArrayList 不用 bracket indexing。應寫 list.get(0)。

Q35Primitive Generic

以下 code 的問題是什麼？

ArrayList<int> nums = new ArrayList<int>();

Generic type 不能是 primitive。應寫 ArrayList<Integer>。

Q36Missing Import

如果 compiler 說找不到 ArrayList symbol，最常見原因是什麼？

忘記寫 import java.util.ArrayList;。

Q37Bounds

若 list.size() 是 3，list.get(3) 合法嗎？

不合法。最大合法 index 是 2。

Q38add Bounds

若 list.size() 是 3，list.add(3, value) 合法嗎？

合法。add(size(), value) 是加到最後。但 get(size()) 不合法。

Q39set vs add

想在尾端新增元素，應使用 set(list.size(), value) 嗎？

不應該。set 只能取代既有 index；尾端新增應使用 add(value) 或 add(list.size(), value)。

Q40Array vs ArrayList

arr.size() 對一般 array 合法嗎？

不合法。Array 用 arr.length，ArrayList 用 list.size()。

G. Coding / Trace

Q41countLong

寫 countLong，回傳長度大於 n 的字串數量。

public static int countLong(ArrayList<String> words, int n)
{
    int count = 0;
    for (String word : words)
    {
        if (word.length() > n)
        {
            count++;
        }
    }
    return count;
}
Q42sumList

寫 sumList，回傳 ArrayList<Integer> 中所有元素總和。

public static int sumList(ArrayList<Integer> nums)
{
    int sum = 0;
    for (int value : nums)
    {
        sum += value;
    }
    return sum;
}
Q43replaceNegatives

寫 replaceNegatives，把所有負數改成 0。

public static void replaceNegatives(ArrayList<Integer> nums)
{
    for (int i = 0; i < nums.size(); i++)
    {
        if (nums.get(i) < 0)
        {
            nums.set(i, 0);
        }
    }
}
Q44firstIndex

寫 firstIndex，找到 target 回傳 index，找不到回傳 -1。

public static int firstIndex(ArrayList<String> words, String target)
{
    for (int i = 0; i < words.size(); i++)
    {
        if (words.get(i).equals(target))
        {
            return i;
        }
    }
    return -1;
}
Q45appendAll

寫 appendAll，把 source 的每個元素加到 target 後面。

public static void appendAll(ArrayList<String> target, ArrayList<String> source)
{
    for (String item : source)
    {
        target.add(item);
    }
}

Q48maxList

寫 maxList，回傳非空 ArrayList<Integer> 的最大值。

public static int maxList(ArrayList<Integer> nums)
{
    int max = nums.get(0);
    for (int value : nums)
    {
        if (value > max)
        {
            max = value;
        }
    }
    return max;
}
Q49copyList

寫 copyList，回傳新的 list，元素和原 list 相同。

public static ArrayList<String> copyList(ArrayList<String> words)
{
    ArrayList<String> copy = new ArrayList<String>();
    for (String word : words)
    {
        copy.add(word);
    }
    return copy;
}
Q50Final Challenge

以下程式最後印出什麼？

ArrayList<String> list = new ArrayList<String>();
list.add("A");
list.add("C");
list.add(1, "B");
String x = list.set(2, "D");
list.add(x);
list.remove(0);
System.out.println(list);

先 [A, B, C]，set(2, "D") 讓 list 變 [A, B, D] 並回傳 C；add(x) 變 [A, B, D, C]；remove(0) 後是 [B, D, C]。
