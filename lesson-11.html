Loop algorithm 的核心：初始化狀態，逐筆處理，最後輸出結果

Sum 1 to 5

int sum = 0;                 // initialization

for (int i = 1; i <= 5; i++)
{
    sum += i;                // repeated processing
}

System.out.println(sum);     // final result

本課的重點不是背某一段程式，而是問清楚：我要保存什麼狀態？每看到一筆資料要怎麼更新這個狀態？

Sum / Count

Sum 是把值加起來；Count 是找到一個就加一

Algorithm Initialization Update 意思
Sumint sum = 0;sum += value;把 value 加進總和。
Countint count = 0;count++;又找到一個符合項目。

Conditional Sum

int sum = 0;

for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
    {
        sum += i;
    }
}

加進去的是 2、4、6、8、10，所以 sum = 30。

Conditional Count

int count = 0;

for (int i = 1; i <= 20; i++)
{
    if (i % 3 == 0)
    {
        count++;
    }
}

3、6、9、12、15、18，共 6 個，所以 count = 6。

Sum and Count Together

int sum = 0;
int count = 0;

for (int i = 1; i <= 20; i++)
{
    if (i % 3 == 0)
    {
        sum += i;
        count++;
    }
}

同時知道符合值的總和與數量，之後就能算 average。

Average

Average 通常是 loop 後才算：average = sum / count

平均不是每輪隨便除一次；標準做法是先累積 sum 和 count， loop 結束後再計算。若 sum 和 count 都是 int， 要注意 integer division。

Average of Matching Values

int sum = 0;
int count = 0;

for (int i = 1; i <= 100; i++)
{
    if (i % 10 == 0)
    {
        sum += i;
        count++;
    }
}

if (count > 0)
{
    double average = (double) sum / count;
    System.out.println(average);
}
陷阱 錯誤 正確
Integer divisiondouble avg = sum / count;double avg = (double) sum / count;
Zero matches直接除以 count先檢查 count > 0。
每輪除avg += value / count;先 sum/count，最後再除。

Min / Max

Running max / min：到目前為止看過的最大或最小

找最大或最小值時，最重要的是 initialization。不要隨便寫 max = 0 或 min = 0，因為資料可能全是負數或全是正數。最常見的安全做法是用第一個真實資料初始化。

Maximum

int max = input.nextInt();

for (int i = 1; i < 5; i++)
{
    int value = input.nextInt();

    if (value > max)
    {
        max = value;
    }
}

第一筆已經用來初始化，所以 loop 再讀 4 筆。

Minimum

int min = input.nextInt();

for (int i = 1; i < 5; i++)
{
    int value = input.nextInt();

    if (value < min)
    {
        min = value;
    }
}

比較方向和 maximum 相反。

Algorithm Invariant Condition Update
Maximummax 是目前看過最大值value > maxmax = value
Minimummin 是目前看過最小值value < minmin = value

Search Algorithms

搜尋題先分清楚：有沒有？第一個？最後一個？有幾個？

題目問法 常見變數 Match 時
有沒有？boolean foundfound = true
第一個是什麼？first + found保存答案，停止搜尋。
最後一個是什麼？last每次 match 都更新。
有幾個？countcount++

Find Any

boolean found = false;

for (int i = 1; i <= 20; i++)
{
    if (i % 4 == 0 && i % 6 == 0)
    {
        found = true;
    }
}

找到 12，所以最後 found 是 true。

Find First

int first = -1;
boolean found = false;
int i = 1;

while (i <= 100 && !found)
{
    if (i % 7 == 0 && i % 9 == 0)
    {
        first = i;
        found = true;
    }
    i++;
}

第一個同時是 7 和 9 的倍數是 63。

Early Exit

答案已經確定時，可以提早停止

Find any 和 find first 適合 early exit，因為找到後答案已經確定。Sum、count all、average、 max、min 通常要看完整份資料，不能隨便停。

Flag-controlled

while (i <= end && !found)

Early return

if (match)
{
    return true;
}

Special result

int first = -1;

如果合法答案不可能是 -1，就可代表 not found。

String Traversal

String traversal：用 index 逐字處理

String 的合法 index 是 0 到 length() - 1。 因此標準 traversal 是 i < word.length()，不是 i <= word.length()。

Count Letter I

String word = "MISSISSIPPI";
int count = 0;

for (int i = 0; i < word.length(); i++)
{
    String letter = word.substring(i, i + 1);

    if (letter.equals("I"))
    {
        count++;
    }
}

Reverse Traversal

String s = "CODE";
String result = "";

for (int i = s.length() - 1; i >= 0; i--)
{
    result += s.substring(i, i + 1);
}

最後 result 是 "EDOC"。

String Filter

String s = "ABACADA";
String result = "";

for (int i = 0; i < s.length(); i++)
{
    String letter = s.substring(i, i + 1);

    if (!letter.equals("A"))
    {
        result += letter;
    }
}

保留 B、C、D，所以 result 是 "BCD"。

Substring Search

搜尋長度 2 的 substring 時，最後起點是 length() - 2

substring(i, i + 2) 需要兩個字元，所以最後一個合法起點是 s.length() - 2。Loop condition 常寫成 i < s.length() - 1。

Count Adjacent Pair

String s = "ABABAB";
int count = 0;

for (int i = 0; i < s.length() - 1; i++)
{
    if (s.substring(i, i + 2).equals("AB"))
    {
        count++;
    }
}

這會檢查 index 0~1、1~2、2~3、3~4、4~5，所以可以找到 overlapping matches。 例如 "AAA" 裡的 "AA" 有 2 個：0~1 和 1~2。

One-Pass Algorithm

同一次 traversal 可以維護多個狀態

AP CSA 常見題會要求一次掃描資料，同時求 sum、count、min、max 或 found。 關鍵是每一輪用目前 value 更新所有需要的狀態。

Sum / Count / Min / Max

int first = input.nextInt();
int sum = first;
int count = 1;
int min = first;
int max = first;

for (int i = 1; i < 5; i++)
{
    int value = input.nextInt();

    sum += value;
    count++;

    if (value < min)
    {
        min = value;
    }

    if (value > max)
    {
        max = value;
    }
}

第一筆已經處理進 sum、count、min、max，所以 loop 從第二筆開始。

Loop Invariant

Loop invariant：每輪開始時都維持正確的狀態描述

Variable Invariant
sum已處理資料的總和。
count已找到 match 的數量。
max已看過資料的最大值。
min已看過資料的最小值。
found已看過資料中是否出現 match。
result目前已建立好的輸出字串。

這種「目前已知資訊」的思考，是後面 arrays、ArrayList、searching、sorting 和 FRQ 的核心。

考前必背十二句

Loop algorithms are about maintaining state.

sum += value adds a value to the total.

count++ means one more match was found.

Average is usually computed after the loop.

Use (double) to avoid integer division.

Check count > 0 before dividing when matches are not guaranteed.

Initialize max and min with real data when possible.

Do not reset found to false after it becomes true.

Find first must stop or avoid overwriting the first match.

String traversal uses indexes 0 through length() - 1.

substring end index is exclusive.

For tracing, track every state variable, not only i.
