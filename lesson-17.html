What Is An Array

Array 用一個 reference 存一整排資料

Array 是一種可以儲存固定數量、相同資料型別元素的資料結構。若有 30 位學生的分數， 不需要寫 30 個變數；可以用一個 int[] 表示整組成績。

array idea 
int[] scores = {90, 85, 73, 100};

System.out.println(scores[0]); // 90
System.out.println(scores[3]); // 100
index 0 → 90 index 1 → 85 index 2 → 73 index 3 → 100

這個 array 的型別是 int[]，裡面每一格 element 的型別是 int。

Declaration

宣告 array variable 不代表已經建立 array

Java array 宣告的基本格式是：資料型別[] 變數名稱;

array declaration 
int[] numbers;
double[] prices;
boolean[] answers;
String[] names;

int[] numbers; 只宣告 numbers 可以存一個 int array 的 reference。 這和 Scanner input; 只是宣告 reference variable 很像，還沒有真正建立物件。

Create With new

new int[5] 建立 5 個元素，不是最大 index 是 5

create array 
int[] numbers = new int[5];

System.out.println(numbers.length); // 5

new int[5] 建立一個長度為 5 的 array。合法 index 是 0、1、2、3、4。 5 是元素數量，不是最後一格的位置。

Array 長度建立後不能改。 若寫 numbers = new int[10];，不是把原本 array 擴大，而是讓 numbers 改指向新的 array。

Initializer List

一開始就知道元素時，可以直接列出來

Initializer list 會依照你列出的元素自動決定 array 長度。

initializer list 
int[] nums = {10, 20, 30, 40};
double[] prices = {3.5, 7.2, 10.0};
String[] names = {"Amy", "Bob", "Chris"};
boolean[] flags = {true, false, true};

AP CSA 常用寫法是 int[] nums = {10, 20, 30, 40};。 不需要同時寫 new int[4] 和 initializer list。

Index / Length

Array index 從 0 開始，.length 沒有括號

Array 用 arrayName[index] 取出某一格，用 arrayName.length 取得元素數量。注意 array 的 .length 是 field，不是 method。

Array

int[] nums = {10, 20, 30};
System.out.println(nums.length);
System.out.println(nums[nums.length - 1]);

Array 使用 nums.length。

String

String word = "hello";
System.out.println(word.length());
System.out.println(word.substring(0, 1));

String 使用 word.length()。

Expression意思型別
arr.lengtharray 元素數量int
arr[0]第一個元素元素型別
arr[arr.length - 1]最後一個元素元素型別
arr[arr.length]越界runtime error

Array Element

Array element 可以像普通變數一樣讀取、賦值與更新

array element assignments 
int[] nums = {10, 20, 30};

nums[1] = 100;                  // {10, 100, 30}
nums[0]++;                      // {11, 100, 30}
nums[2] = nums[0] + nums[1];    // {11, 100, 111}

Index 也可以是 expression。Java 會先算出 index expression，再去取對應元素。

index expression 
int[] nums = {4, 8, 12, 16, 20};
int x = 1;

System.out.println(nums[x + 2]); // nums[3], so 16

Default Values

new 型別[size] 會自動填入 default values

Java array 建立後，每一格都有預設值。Primitive array 和 object array 的預設值不同。

default values 
int[] nums = new int[4];          // {0, 0, 0, 0}
double[] data = new double[3];    // {0.0, 0.0, 0.0}
boolean[] flags = new boolean[3]; // {false, false, false}
String[] names = new String[3];   // {null, null, null}
Array 型別Default element value
int[]0
double[]0.0
boolean[]false
Object array，例如 String[]null

Bounds

合法 index 必須滿足 0 <= index < arr.length

存取不存在的位置會造成 ArrayIndexOutOfBoundsException。這通常是 runtime error， 因為 compiler 不一定能在編譯時知道 index 最後是多少。

bounds error 
int[] nums = {10, 20, 30};

System.out.println(nums[2]); // OK, 30
System.out.println(nums[3]); // ArrayIndexOutOfBoundsException
最經典 off-by-one error for (int i = 0; i <= arr.length; i++) 最後會跑到 arr[arr.length]，一定越界。

Traversal

遍歷 array 的標準寫法

若要依序存取每個元素，最重要的 pattern 是 traditional for loop。 這個 pattern 會剛好走過所有合法 index。

standard traversal 
int[] nums = {10, 20, 30, 40, 50};

for (int i = 0; i < nums.length; i++)
{
    System.out.println(nums[i]);
}

看到 for (int i = 0; i < arr.length; i++)， 你要能立刻讀成：從第一個合法 index 走到最後一個合法 index。

Reference Type

Array variable 存的是 reference，不是整排元素本身

Array 是 object。int[] a = {10, 20, 30}; 中的 a 存的是 array object 的 reference。把 a assign 給 b， 只會複製 reference value，不會複製整個 array。

array reference copy 
int[] a = {10, 20, 30};
int[] b = a;

b[0] = 100;

System.out.println(a[0]); // 100

a 和 b 指向同一個 array，這稱為 aliasing。透過任何一個 reference 修改元素，另一個 reference 也會看見改變。

reassignment is different 
int[] a = {1, 2, 3};
int[] b = a;

b = new int[3];
b[0] = 10;

System.out.println(a[0]); // 1

b = new int[3]; 是讓 b 改指向新的 array，原本 a 指到的 array 沒有被修改。

Object Arrays / null

Object array 存的是 object references

String[] names = new String[3]; 建立的是三個可以存 String reference 的位置，不是三個空字串。預設元素值是 null。

object array and null 
String[] names = new String[3];

System.out.println(names[0]); // null

names[0] = "Amy";
System.out.println(names[0]); // Amy

Array variable 本身也可以是 null。若 int[] nums = null;， 再執行 nums.length，會造成 NullPointerException。

Enhanced For

Enhanced for loop 適合依序讀取每個元素

Enhanced for loop 也叫 for-each loop，可以讀成「對 array 裡每一個 value」。 如果只需要看每個元素的值，它很簡潔。

enhanced for loop 
int[] nums = {10, 20, 30, 40};

for (int value : nums)
{
    System.out.println(value);
}

適合 enhanced for

只讀元素、印出元素、加總、計數、檢查每個 value。

通常要 traditional for

需要 index、修改元素、反向走訪、跳著走、比較相鄰元素。

primitive copy trap 
int[] nums = {1, 2, 3};

for (int x : nums)
{
    x = 100;
}

System.out.println(nums[0]); // still 1

x 只是 primitive value 的 copy。若要真的修改 array element， 必須用 nums[i]。

Type Recognition

分清楚 array reference、array element 與 length 的型別

程式碼型別意義
int[] numsint[]整個 int array 的 reference
nums[0]int第一個 int element
nums.lengthint元素數量
String[] namesString[]String reference array
names[0]String某一格的 String reference

Array index 必須是整數型 expression，例如 nums[2] 或 nums[i + 1]。 nums[2.5] 不合法。

考前必背十句

Arrays store multiple values of the same type.

Array length is fixed after creation.

The first valid index is 0.

The last valid index is arr.length - 1.

Arrays use arr.length, not arr.length().

new int[n] creates n elements initialized to 0.

Object array elements default to null.

Invalid indexes cause ArrayIndexOutOfBoundsException.

Array assignment copies a reference, not all elements.

Enhanced for reads values cleanly, but it does not give you an index.
