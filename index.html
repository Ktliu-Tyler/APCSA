Course Context

這門課在學什麼

AP Computer Science A 是一門以 Java 為核心的大學入門電腦科學課程。你不只是學語法， 更重要的是學會如何把問題拆成清楚的步驟，將步驟轉成可執行的程式，並用測試與除錯確認程式是否符合預期。

這門課會一路從 Java 基礎、method calls、objects、String、boolean、loops， 走到 class design、arrays、ArrayList、2D arrays、searching、sorting、recursion 與 AP 題型訓練。
