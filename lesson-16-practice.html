A. Concepts

概念確認

先把 scope、variable kind、instance/static context 的核心語言釐清。

Q1Scope

Scope 是什麼？

Scope 是一個變數名稱可以被直接使用的程式碼範圍。它回答「這一行看得到這個名字嗎？」

Q2Scope vs Lifetime

Scope 和 lifetime 完全一樣嗎？

不一樣。Scope 是名字可用範圍；lifetime 是 variable 或 object 存在多久。AP CSA 最常考 scope。

Q3Variable Kind

private int score; 宣告在 class 中、method 外，這是什麼 variable？

這是 instance variable，也叫 instance field。每個 object 各自有一份。

Q4Static Variable

private static int count; 屬於 object 還是 class？

屬於 class。Static variable 也叫 class variable，所有 instances 共用同一份。

Q5Parameter

在 public void add(int amount) 中，amount 是什麼？

amount 是 parameter。它的 scope 通常是整個 method body。

Q6Local Variable

宣告在 method body 裡的 int result = 0; 是什麼？

這是 local variable。它通常只在宣告後到所在 block 結束前可用。

B. this / Shadowing

this 與同名變數

看到同名 field 與 parameter，先問：單獨寫名稱時 Java 會先找到誰？

Q7this

this 在 instance method 中代表什麼？

this 代表 current receiver object，也就是目前正在執行這個 instance method 的 object。

Q8Receiver

若執行 a.setScore(90)，在 setScore 裡 this 是誰？

this 是 a 指到的 object。this.score 是那個 object 的 instance variable。

Q9Shadowing Bug

以下 method 會成功修改 field 嗎？

private int score;

public void setScore(int score)
{
    score = score;
}

不會。左右兩邊的 score 都是 parameter，field 被 shadow 了。

Q10Fix Shadowing

修正上一題，讓 parameter 的值存進 instance variable。

public void setScore(int score)
{
    this.score = score;
}

this.score 指 field；score 指 parameter。

Q11No Shadowing

以下 method 中的 score 是 field 還是 parameter？

private int score;

public int getScore()
{
    return score;
}

是 field。沒有同名 local/parameter，所以 instance method 裡的 score 可直接代表 receiver 的 field。

Q12Both Values

以下呼叫 obj.sum(5) 回傳什麼？

private int x = 10;

public int sum(int x)
{
    return this.x + x;
}

回傳 15。this.x 是 field 10；單獨的 x 是 parameter 5。

Q13Constructor

以下 constructor 中，為什麼需要 this.name？

private String name;

public Student(String name)
{
    this.name = name;
}

因為 parameter name shadow field name。this.name 明確指定 current object's field。

Q14Local Shadowing

以下 method 印出什麼？

private int x = 7;

public void method()
{
    int x = 3;
    System.out.println(x);
}

印出 3。Local variable x shadow instance field x。

C. Parameters / Locals / Blocks

Scope、block 與 definite assignment

Local variable 題目常考三件事：宣告前不可用、block 外不可用、使用前必須賦值。

Q15Declaration Before Use

以下 code 合法嗎？

public void method()
{
    System.out.println(x);
    int x = 5;
}

不合法。Local variable 必須先宣告，名稱才進入 scope。

Q16Block Scope

以下 code 中，哪一行 compile error？

int x = 1;

if (x > 0)
{
    int y = 2;
}

System.out.println(x);
System.out.println(y);

System.out.println(y); compile error。y 的 scope 只在 if block 內。

Q17For Loop Scope

以下 code 合法嗎？

for (int i = 0; i < 4; i++)
{
}

System.out.println(i);

不合法。i 在 for header 宣告，通常只能在 loop scope 內使用。

Q18Loop Fix

若 loop 後仍需要使用 i，可以怎麼改？

int i;
for (i = 0; i < 4; i++)
{
}
System.out.println(i);

把 i 宣告在 loop 前，讓它的 scope 包含 loop 後面的程式碼。

Q19Parameter Scope

以下 other method 可以直接使用 x 嗎？

public void method(int x)
{
    System.out.println(x);
}

public void other()
{
    System.out.println(x);
}

不可以，除非 class 另外有 field x。Parameter x 只在 method body 內。

Q20Local Initialization

以下 code 合法嗎？

public void method()
{
    int x;
    System.out.println(x);
}

不合法。Local variable 沒有可直接使用的 default value，使用前必須被賦值。

Q21Field Default

以下 field 若沒有 constructor assignment，預設值是多少？

private int count;
private boolean active;
private String name;

count 是 0，active 是 false，name 是 null。

Q22All Paths

以下 code 是否一定合法？

int x;
if (score > 0)
{
    x = 5;
}
System.out.println(x);

不一定。若 score <= 0，x 沒有被賦值就使用，通常會是 definite assignment compile error。

D. Static Variables

Class-level shared state

Static field 只有一份。看到 constructor 裡 count++，通常是在追蹤 class-wide counter。

Q23Shared Counter

以下程式建立三個 objects 後，Thing.getCount() 回傳什麼？

public class Thing
{
    private static int count = 0;

    public Thing()
    {
        count++;
    }

    public static int getCount()
    {
        return count;
    }
}

回傳 3。count 是 static variable，所有 Thing objects 共用一份。

Q24Instance Counter

若 count 不是 static，以下執行後 a.getCount() 和 b.getCount() 分別是多少？

Thing a = new Thing();
Thing b = new Thing();
a.increment();

若 count 是 instance field，a 和 b 各自有一份。通常 a 是 1，b 是 0。

Q25Bad Static Design

為什麼 private static int score; 通常不適合放在 Student？

學生分數通常每個 object 不同。若宣告成 static，所有 Student objects 會共用同一個 score。

Q26Access Style

Static field / method 通常建議用 object name 還是 class name 存取？

建議用 class name，例如 Thing.getCount()。這樣清楚表示它屬於 class，不屬於某個 object。

Q27Static Mutation

Instance method 可以修改 static variable 嗎？

可以。Instance context 可以使用 instance state，也可以使用 class static state。

Q28Static Default

private static boolean ready; 若沒有 explicit assignment，預設值是什麼？

是 false。Static fields 和 instance fields 一樣有 default values。

E. Static Methods / main

Static context 沒有 receiver object

Static method 不能直接使用 instance members，但可以透過 object reference 使用。

Q29Static Call

Math.sqrt(25) 是 static method call 還是 instance method call？

是 static method call，形式是 ClassName.methodName(...)。

Q30No Receiver

Static method 為什麼不能直接使用 this？

因為 static method 沒有 receiver object。this 只在 constructor 或 instance method 中代表 current object。

Q31Static Context Error

以下 code 合法嗎？

private int score;

public static int getScore()
{
    return score;
}

不合法。score 是 instance field；static method 沒有 receiver object，不能直接使用。

Q32Static Field Success

以下 code 合法嗎？

private static int count;

public static int getCount()
{
    return count;
}

合法。Static method 可以直接使用 static variable。

Q33Object Reference

以下 static method 在 Student class 內是否合法？

public static int readScore(Student s)
{
    return s.score;
}

合法，前提是這段 code 位於 Student class 內。Static method 雖不能直接寫 score，但可以透過 object reference s 指定哪個 object。

Q34main

public static void main(String[] args) 是 static context 嗎？

是。main 是 static method，所以不能直接使用 instance fields 或 this。

Q35main Fix

在 main 中要讀取 instance field，通常要先做什麼？

先建立 object 或取得 object reference，再透過它呼叫 instance method，例如 Example e = new Example(); e.getX();。

Q36Utility Design

為什麼 public static int square(int x) 很適合設計成 static？

它只依賴 parameter x，不需要任何 particular object 的 instance state，因此適合 static utility method。

F. Compile Errors

判斷與修正常見錯誤

這組題目訓練你看見錯誤原因，而不是靠「加 static」硬修。

Q37this in Static

以下 code 的問題是什麼？

public static void reset()
{
    this.score = 0;
}

this 不能在 static context 使用。Static method 沒有 receiver object。

Q38Instance Method Direct Call

以下 static method 為什麼不合法？

public static void print()
{
    System.out.println(getScore());
}

getScore() 是 instance method 時需要 receiver object。Static method 不能直接呼叫它。

Q39Fix with Object

修正 Q38，讓 static method 可以印出某個 Student 的 score。

public static void print(Student s)
{
    System.out.println(s.getScore());
}

透過 parameter s 指定 receiver object。

Q40Do Not Magic Static

把 score 改成 static 來修 static context error，什麼時候是錯誤設計？

若 score 本來應該是每個 object 自己不同的 state，改成 static 會讓所有 objects 共用同一份 score，是錯誤設計。

Q41Duplicate Local

以下 code 是否合法？

public void method()
{
    int x = 1;
    int x = 2;
}

不合法。同一個 local scope 中不能重複宣告同名 local variable。

Q42Separate Blocks

以下兩個 i 宣告通常合法嗎？

for (int i = 0; i < 3; i++)
{
}

for (int i = 0; i < 5; i++)
{
}

通常合法。兩個 i 分屬不同、互不重疊的 for-loop scopes。

Q43Field vs Local

以下 method 印出什麼？

private int x = 4;

public void method()
{
    int x = 9;
    System.out.println(this.x);
}

印出 4。this.x 明確指定 instance field。

Q44Static Call Style

若 getCount 是 static method，Thing.getCount() 和 a.getCount() 哪個較推薦？

Thing.getCount() 較推薦，因為它清楚表明 getCount 屬於 class。

G. Coding / Trace

程式練習與 final tracing

最後六題把 scope、static、this 放進 class tracing。

Q45Write Constructor

為 Player 寫 constructor，fields 是 private String name; 與 private int score;，parameters 同名。

public Player(String name, int score)
{
    this.name = name;
    this.score = score;
}

因為 parameters 和 fields 同名，使用 this.field 避免 shadowing bug。

Q46Static Counter

為 Player 加上 static counter，記錄建立過多少 players。

private static int playerCount = 0;

public Player(String name, int score)
{
    this.name = name;
    this.score = score;
    playerCount++;
}

public static int getPlayerCount()
{
    return playerCount;
}

playerCount 是 class-level shared state，適合 static。

Q47Instance Method

為 Player 寫 instance method hasHigherScore(Player other)。假設 other 不為 null。

public boolean hasHigherScore(Player other)
{
    return score > other.score;
}

score 是 receiver 的 field；other.score 是 parameter object 的 field。

Q48Static Utility

寫一個 static method maxScore(Player a, Player b)，回傳較高的 score。假設兩個 parameters 不為 null。

public static int maxScore(Player a, Player b)
{
    if (a.score > b.score)
    {
        return a.score;
    }
    return b.score;
}

Static method 不能直接寫 score，但可以透過 parameters a 和 b 指定 objects。

Q49Trace Static and Instance

以下程式最後印出什麼？

Thing a = new Thing();
Thing b = new Thing();
a.add();
System.out.println(a.getValue());
System.out.println(b.getValue());
System.out.println(Thing.getCount());

若 constructor 讓 static count++，且 add 只修改 instance field value，結果通常是 1、0、2。Instance state 各自一份，static count 共用一份。

Q50Final Challenge

找出以下 class 的三個問題並修正。

public class Score
{
    private int value;
    private static int count;

    public Score(int value)
    {
        value = value;
        count++;
    }

    public static void reset()
    {
        this.value = 0;
    }
}

問題 1：constructor 中 value = value 是 shadowing bug。問題 2：static method 不能使用 this。問題 3：若 reset 是要重設某個 object 的 value，應改成 instance method 或接受 object parameter。

public Score(int value)
{
    this.value = value;
    count++;
}

public void reset()
{
    value = 0;
}
