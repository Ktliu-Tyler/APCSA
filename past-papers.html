Practice Flow

建議練習流程

考古題最有價值的地方不是「做完」，而是把錯誤整理成下一輪複習清單。

01

先做 MCQ，不查資料

設定 90 分鐘。遇到卡住的題目先標記，最後再回來。作答時記下你不確定的 Java API 或 loop 狀態。

02

對答案並分類錯題

不要只寫 A/B/C/D。把錯題分成 tracing、syntax、method call、object reference、array / ArrayList。

03

完成 FRQ 初稿

先寫 method header、初始化、loop、if 條件、return。就算不完整，也要盡量留下可被 rubric 拆分給分的程式碼。

04

用 rubric 自評

逐點核對 scoring guidelines，把沒拿到的分數轉成下一次要補的觀念或寫法。

Score Log

做完後的紀錄表

每做一次考古題，就把結果留在這裡。下次複習時先看錯題類型，比重做整份更有效率。

項目 完成後要記錄 下一步
MCQ 分數 答對題數、最常錯的三種題型、超時題目。 回到對應 lesson 練 tracing、String、ArrayList 或 2D array。
FRQ 分數 每題 rubric 拿到幾分，以及丟分原因。 補齊 method design、class fields、loop traversal 或 edge cases。
考試策略 哪些題目花太久、哪些題目其實可以先跳過。 下一回練習時設定跳題規則與檢查時間點。
