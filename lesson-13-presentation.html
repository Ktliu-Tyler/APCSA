Class Structure

Why Classes

程式變大後，資料和行為需要被組織起來

哪些資料屬於同一個東西？
哪些 method 負責操作這些資料？
誰負責檢查資料是否合法？
外部應該知道哪些資訊？
外部不該碰哪些細節？
規則應該集中在哪裡？

Class

Class 是建立 object 的 blueprint

public class Student
{
    private String name;
    private int score;
}

Student 不是某一位學生，它描述所有 Student objects 應該有什麼資料。

Class vs Object

Blueprint vs 實體

Class藍圖、型別、設計規格
Object依 class 建出的實體，有自己的 state
student1: name = "Amy", score = 95
student2: name = "Ben", score = 72

Quick Check

Student 是 class 還是 object？

Student 是 class/type。某一個實際學生才是 object。

Class Anatomy

Class 的基本結構

public class Student
{
    private String name;
    private int score;

    public String getName()
    {
        return name;
    }
}

Class declaration、instance variables、methods，都直接放在 class body 裡。

Naming

Java naming conventions

ClassStudent, BankAccount
Variablesscore, studentName
MethodsgetScore(), hasPassed()

Class 用 PascalCase；variables 和 methods 通常用 camelCase。

Instance Variables

Instance variables 描述 object state

public class BankAccount
{
    private String owner;
    private double balance;
}

owner 和 balance 合起來描述一個帳戶目前的 state。

Each Object Has Its Own State

同一個 class，可以有很多個不同 objects

account1: owner = "Amy", balance = 500.0
account2: owner = "Ben", balance = 30.0

Method code 是同一份，但每個 object 的 fields 各自獨立。

Variable Roles

Field / Parameter / Local Variable

public class Example
{
    private int value;              // instance variable

    public int calculate(int bonus) // parameter
    {
        int doubled = value * 2;    // local variable
        return doubled + bonus;
    }
}

Quick Check

哪一個是 parameter？

public int calculate(int bonus)
{
    int doubled = value * 2;
    return doubled + bonus;
}

bonus 是 parameter，因為它在 method header 的括號中。

Default Values

Instance variables 有 default values

int0
double0.0
booleanfalse
Stringnull
Local variable使用前必須明確初始化
AP trapfield 和 local 不一樣

private

Fields 通常 private

public class Student
{
    private int score;
}

private 表示 class 外部不能直接存取，class 自己的 methods 可以使用。

Encapsulation

Private data + controlled public methods

private state public interface validation responsibility

Encapsulation 讓 object 自己保護自己的資料與規則。

Validation

Setter 可以拒絕不合法的值

public void setScore(int newScore)
{
    if (newScore >= 0 && newScore <= 100)
    {
        score = newScore;
    }
}

如果 score 是 public field，外部可以直接把它改成 -999。

Accessors

Accessor 回報資訊，通常不修改 state

public int getScore()
{
    return score;
}

public boolean hasPassed()
{
    return score >= 60;
}

Boolean accessor 常用 is... 或 has...。

Derived Information

Accessor 不一定只是直接 return field

public double getArea()
{
    return width * height;
}

算。它回報 derived information，沒有修改 object state。

Mutators

Mutator 修改 object state

public void deposit(double amount)
{
    if (amount > 0)
    {
        balance += amount;
    }
}

set...、deposit、withdraw、increment、reset 都可能是 mutators。

Method Anatomy

Method header 描述 method 怎麼被呼叫

public boolean isEligible(int minimumScore)
{
    return score >= minimumScore;
}
public boolean isEligible int minimumScore

void

void method 不回傳值

Return methodint x = getScore();
Void methodsetScore(90);

void method 可以修改 state，但不能當成 expression value 使用。

Quick Check

這個 method header 的 return type 是什麼？

public double calculatePrice(int quantity)

double。Method name 是 calculatePrice，parameter 是 int quantity。

Responsibility

好的 class 把規則放在擁有資料的地方

public class Rectangle
{
    private double width;
    private double height;

    public double getArea()
    {
        return width * height;
    }
}

Rectangle 擁有 width 與 height，所以它適合負責面積規則。

State Trace

Trace method calls：看 state 如何改變

public class Counter
{
    private int value;

    public void increment()
    {
        value++;
    }

    public void reset()
    {
        value = 0;
    }
}

Trace Question

value 原本是 0，呼叫兩次 increment 後再 reset，最後是多少？

0。流程是 0 → 1 → 2 → 0。

AP tracing 請建立 state table，不要只看 method name。

Common Bugs

Class structure 常見錯誤

field 宣告在 method 裡
local variable 寫 private
method 寫在 method 裡
return type 不符合 return value
void method return value
assignment 方向反了

Debug This

這段 setter 的 bug 是什麼？

public void setScore(int newScore)
{
    newScore = score;
}

Assignment 方向反了。應該是 score = newScore;。

AP SOP

看到 class 題，照這個順序讀

Class purpose Instance variables Public methods Accessor or mutator State changes Return value

Class tracing 的核心是：哪個 object 的哪個 field 被改變？
