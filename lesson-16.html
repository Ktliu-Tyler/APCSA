Scope / Lifetime

Scope 是「名字在哪裡可以用」

Scope 指的是一個變數名稱可以被直接使用的程式碼範圍。它回答的是： 這一行程式碼看得到 x 這個名字嗎？

local variable scope 
public void method()
{
    int x = 5;
    System.out.println(x); // OK
}

public void other()
{
    System.out.println(x); // compile error
}
Scope 和 lifetime 不完全一樣。 Scope 是名字可用範圍；lifetime 是 variable 或 object 存在多久。AP CSA 最常考的是 scope 與 static context。

Variable Kinds

Java 常見四種變數

four kinds of variables 
public class Example
{
    private int value;          // instance variable
    private static int count;   // static variable

    public void method(int x)   // parameter
    {
        int result = x + value; // local variable
    }
}

Instance Variables

Instance variable 屬於 object

Instance variable 宣告在 class 中、method 外。每個 object instance 都有自己的那一份。 所以同一個 field name，在不同 receiver object 上可以有不同值。

receiver state 
public class Student
{
    private String name;
    private int score;

    public int getScore()
    {
        return score;
    }
}

若呼叫 a.getScore()，method body 裡的 score 是 a 指到的 object 的 score。若呼叫 b.getScore()，就是 b 的 score。

this

this 代表 current receiver object

在 constructor 或 instance method 中，this 代表目前正在執行這段 code 的 object。 也就是 current receiver object。

this in instance context 
public void setScore(int score)
{
    this.score = score;
}
如果執行 a.setScore(100) this 就是 a 指到的 Student object；this.score 就是那個 object 的 instance variable。

Shadowing

同名時，較內層的 parameter/local 會遮住 field

如果 parameter 和 instance variable 同名，在 method body 裡單獨寫 score， Java 會先找到 parameter。這就是 shadowing。

shadowing bug and fix 
private int score;

public void brokenSetScore(int score)
{
    score = score;       // parameter = parameter
}

public void setScore(int score)
{
    this.score = score;  // field = parameter
}

this.field 明確指定 current object's instance variable。若沒有同名 parameter/local， return score; 概念上等同於 return this.score;。

Parameters / Locals

Parameter 和 local variable 的 scope 比 field 窄

Parameter 的 scope 通常是整個 method 或 constructor body。Local variable 的 scope 從宣告之後開始， 到所在 block 結束。每次 method call 都會有新的 parameter values。

parameter and local 
public int bonusScore(int amount)
{
    int result = score + amount;
    return result;
}

public void other()
{
    System.out.println(amount); // compile error
    System.out.println(result); // compile error
}

Block Scope

Curly braces 建立 block scope

if block、loop block、普通 nested block 都會限制 local variable 的 scope。 尤其 for (int i = ...) 宣告的 i，通常只能在 loop 裡使用。

block and loop scope 
int total = 0;

for (int i = 0; i < 4; i++)
{
    total += i;
}

System.out.println(total); // OK
System.out.println(i);     // compile error

若 loop 後還需要 i，就要在 loop 前宣告：int i;，再在 loop header 裡使用已存在的 variable。

Default Values

Fields 有 default values；local variables 沒有可直接使用的 default value

Field

private int score;
private boolean active;
private String name;

若沒有 explicit initialization，分別預設為 0、false、null。

Local Variable

public void method()
{
    int x;
    System.out.println(x); // compile error
}

Local variable 使用前必須保證已經被賦值。

Static Variables

static variable 屬於 class，不屬於單一 object

Static variable 也叫 class variable。它只有一份，所有 objects 共享。適合表示 class-wide state， 例如已建立多少個 objects；不適合表示每個 object 自己不同的狀態。

static shared state 
public class Student
{
    private String name;
    private static int count = 0;

    public Student(String name)
    {
        this.name = name;
        count++;
    }

    public static int getCount()
    {
        return count;
    }
}

建立三個 Student objects 後，Student.getCount() 回傳 3。 不是每個 object 各有一份 count。

Static Methods

Static method 屬於 class，沒有 receiver object

Static method 通常用 ClassName.methodName(...) 呼叫，例如 Math.sqrt(25)、Math.abs(-5)。它沒有 receiver object，所以沒有 this。

static utility method 
public class Utility
{
    public static int doubleValue(int x)
    {
        return x * 2;
    }
}

int result = Utility.doubleValue(5); // 10
能力 Instance Method Static Method
有 thisYesNo
直接使用 instance fieldYesNo
直接呼叫 instance methodYesNo
使用 static field/methodYesYes
使用 parameters / localsYesYes

main

main 是 static method，所以不能直接使用 instance fields

Java 必須在還沒有建立你的 class object 時就能開始執行程式，所以 public static void main(String[] args) 是 static context。

main and instance state 
public class Example
{
    private int x = 5;

    public int getX()
    {
        return x;
    }

    public static void main(String[] args)
    {
        Example e = new Example();
        System.out.println(e.getX()); // OK
    }
}

在 static method 中若要使用 instance state，必須先有 object reference，例如 e.getX()。

Name Lookup

Java 找 variable name 的實用順序

AP CSA 解題時可以用這個順序想，不必背 compiler 的完整規格：

  1. 先看目前 block 中是否有 local variable。
  2. 再看 method / constructor parameters。
  3. 如果是 instance context，再看 instance fields。
  4. 再看 static fields。
  5. 若同名造成混淆，用 this.field 明確指定 instance field。
same name different scope 
private int x = 10;

public int sum(int x)
{
    int y = 2;
    return this.x + x + y;
}

this.x 是 field 10；x 是 parameter；y 是 local variable。

考前必背十二句

Scope determines where a variable name can be used.

Local variables are scoped to their enclosing block.

Parameters are scoped to the method or constructor body.

Instance variables belong to objects.

Static variables belong to the class.

Static variables are shared by all instances of the class.

this means the current object.

this cannot be used in a static context.

A static method has no receiver object.

A static method cannot directly access instance variables or instance methods.

A static method can use an object reference to access instance members.

Do not use static as a magic fix for object-state problems.
