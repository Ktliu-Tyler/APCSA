Course Framework

考試範圍與比重

AP CSA 的官方課程架構在 2025-26 學年更新為四個大單元。以下比重是 Multiple-Choice Section 的 approximate weighting，實際題目仍會依 learning objectives 與 skills 出題。

Unit 1

Using Objects and Methods

15%-25%

物件、method calls、String、Math、API 閱讀與基本程式推理。

Unit 2

Selection and Iteration

25%-35%

Boolean、if/else、loops、nested loops、algorithm tracing。

Unit 3

Class Creation

10%-18%

class、fields、constructors、methods、encapsulation、state。

Unit 4

Data Collections

30%-40%

arrays、ArrayList、2D arrays、data traversal、searching/sorting 相關演算法。

Exam Rules

考場規則與 Bluebook 規範

AP 考試當天，學生需要同意 College Board 的 test security 與 administration policies。 沒有遵守規範可能導致分數被取消；刻意作弊或分享安全題目可能導致未來考試資格受限。

要準備

  • 記住 College Board 帳號與密碼，不能只依賴瀏覽器或裝置自動儲存密碼。
  • 確認 testing device 可執行 Bluebook，電量足夠，並帶相容的充電器。
  • 帶鉛筆或筆，在學校提供的 scratch paper 上做筆記。
  • 若不是在自己學校考試，準備政府或學校核發的 photo ID。
  • 若用平板參加 fully digital AP Exam，需要外接鍵盤；外接滑鼠可選。

不能帶或不能用

  • 手機、智慧手錶、智慧眼鏡、穿戴裝置、錄音錄影設備或其他通訊設備。
  • 書、筆記、字典、highlighter、自己帶的 scratch paper 或 reference guide。
  • 未核准的電腦、計算機、獨立計時器、privacy screen、keyboard map。
  • 食物或飲料不能帶進考場，除非有 College Board SSD accommodation。
  • AP CSA 不允許使用計算機，除非有核准的 4-function calculator accommodation。

Bluebook 作答規則

  • 考試中不能使用 Bluebook 以外的程式或 app。
  • 不能從其他程式貼上答案到 Bluebook。
  • 答案必須輸入在 Bluebook 中，只有 Bluebook 內的答案會被提交評分。
  • 可在同一 section 或 part 內回頭檢查，但不能回到前一個 section 或 part。
  • 結束時若網路連線正常會自動提交；若沒有連線，需要依 Bluebook 指示在 submission window 內送出。

題目保密

  • Multiple-choice 題目不會公開，不能在考試中或考後討論內容。
  • Regular testing 的 FRQ 只有在 College Board 公布後才可討論。
  • Late-testing FRQ 與未釋出的 FRQ 不可分享。
  • 考試中或休息時間不能使用網站、AI 工具、手機、筆記或他人協助。
  • 不要拍照、截圖、記錄、背題後轉寫或分享任何安全題目。

Section I

Multiple Choice：怎麼穩定拿分

MCQ 會要求你判斷程式輸出、變數值、錯誤、等價程式片段、條件行為與必要 code segment。 它不是單純背 API，而是考你是否能在有限時間內準確 trace 程式。

1. 每題先分類

先看它是在考 output、錯誤、method call、object alias、loop bounds、String、array 還是 ArrayList。分類後才知道該畫 trace table 還是檢查語法。

2. 用表格追蹤狀態

遇到 loop、nested loop、array 或 object mutation，不要只在腦中想。把 index、condition、更新後的值寫在 scratch paper 上。

3. 看清楚 Java 陷阱

常見陷阱包含 integer division、== vs .equals()、String index、off-by-one、ArrayList remove 後 index shift、reference aliasing。

4. 最後一定填完

官方說明指出 MCQ 分數看答對題數，答錯或空白不倒扣。剩下時間不足時，先排除再作答，不要留下空題。

時間策略：前 30 題不要讓單題卡超過 2 分鐘；不確定先標記。最後 8-10 分鐘回來處理標記題，並確認每題都有答案。

Section II

Free Response：四大題型與 rubric 拿分

官方 AP CSA Exam 頁面列出 4 題 FRQ 的固定方向，且全部評量 Develop Code。 你的目標不是寫出最漂亮的 Java，而是在時間內交出符合 method/class specification 的可評分答案。

Question 1

Methods and Control Structures

通常要求寫 2 個 methods，或 1 個 constructor 加 1 個 method。重點是 conditional、iteration、method calls 與 String methods。

  • 先保留官方提供的 header，不要改參數型別或回傳型別。
  • 所有 loop 都要檢查 initialization、condition、update、termination。
  • String 題要小心 substring 結束位置、indexOf 找不到回傳 -1、以及 .equals()。
Question 2

Class Design

要求你根據 scenario 與規格表設計 class。通常需要 class header、private instance variables、constructor 與 method。

  • 先寫 class header，再列 fields；不要把 instance variable 寫進 method 裡。
  • constructor 必須把每個物件狀態初始化到規格要求的值。
  • method 要更新 state 時，只更新題目要求的 persistent data。
Question 3

Data Analysis with ArrayList

給定 scenario 與相關 class，要求你在 ArrayList 中取得、分析、更新或篩選資料。

  • 使用 size()、get(i)、set(i, value)、add、remove，不要把 ArrayList 當 array 用。
  • 若要 remove，多半從後往前走，或在移除後正確調整 index。
  • 先取出物件，再呼叫題目提供的方法，例如 list.get(i).getCost()。
Question 4

2D Array

要求你建立、走訪、分析或操作 2D array。核心是 row/column 的 nested loop 與邊界條件。

  • arr.length 是 row 數；arr[0].length 是 column 數。
  • 每換一列或一欄時，該重設的 count、sum、flag 必須重設。
  • 題目要求 column 時，不要把 row 當 column；這是常見失分點。

Scoring Guidelines 要怎麼讀

Algorithm points

這類分數看的是必要步驟是否齊全、順序是否合理、整體演算法是否達成規格。若漏掉核心步驟、把步驟組錯、加入會破壞結果的額外程式碼，通常很難拿到。

Non-algorithm points

這類分數範圍比較窄。就算其他地方錯，只要某個指定元素正確，例如正確宣告 class header、正確呼叫指定 method，仍可能拿到該點。

Minor errors

官方範例 scoring guidelines 說明，有些小錯可能不影響該點，例如可明確推斷的拼字大小寫、少分號但結構清楚、局部變數宣告瑕疵等。不要因此放棄寫完整邏輯。

Partial credit mindset

FRQ 的分數是拆開給的。卡住時先寫出你確定的 header、初始化、loop skeleton、條件判斷、方法呼叫與 return，讓 reader 有可給分的結構。

Java Quick Reference

考試提供的 Java Reference 要會用

Java Quick Reference 列出 AP CSA 考試可能使用的 Java library 方法。它不是課本，也不是完整 Java 文件； 它是考試中可以查的 reference table。真正的能力是看到方法名稱後，能正確判斷回傳值、index 範圍與 side effect。

String

length、substring、indexOf、equals、compareTo 是 MCQ 與 FRQ Q1 高頻核心。

Math

abs、pow、sqrt、random 要知道回傳型別與常見 casting 寫法。

ArrayList

size、add、get、set、remove 要熟到不用查也知道 index 怎麼變。

Arrays

array 使用 length 欄位，不是 length()；2D array 要分清楚 row 與 column。
