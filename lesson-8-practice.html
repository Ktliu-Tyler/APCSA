A. Concepts

概念確認

先確認 compound Boolean expression 與三個主要 operators。

Q1Definition

Compound Boolean Expression 是什麼？

把兩個以上 Boolean expressions 用 &&、||、! 組合成更複雜的 Boolean expression。

Q2AND

&& 代表什麼？

AND。兩邊都必須是 true，整體才是 true。

Q3OR

|| 代表什麼？

OR。至少一邊是 true，整體就是 true。Java OR 是 inclusive OR。

Q4NOT

! 代表什麼？

NOT，將 Boolean 結果取反。!true 是 false，!false 是 true。

Q5Inclusive OR

如果 A 和 B 都是 true，A || B 是什麼？

true。Java 的 OR 是 inclusive OR，兩個都 true 也算 true。

B. Operators

Operators / Truth Table

先把每個基本 condition 算成 true / false，再合成結果。

Q6AND

true && false 的結果是什麼？

false。AND 需要兩邊都 true。

Q7AND

true && true 的結果是什麼？

true。這是 AND 唯一為 true 的情況。

Q8OR

false || false 的結果是什麼？

false。OR 只有兩邊都是 false 時才 false。

Q9OR

true || false 的結果是什麼？

true。OR 至少一個 true 就 true。

Q10NOT

!false 的結果是什麼？

true。

Q11Trace

預測 output。

int age = 20;
boolean hasTicket = true;

System.out.println(age >= 18 && hasTicket);

20 >= 18 true，hasTicket true，所以 output 是 true。

Q12Trace

預測 output。

int score = 120;

System.out.println(score < 0 || score > 100);

120 < 0 false，120 > 100 true，所以 output 是 true。

Q13NOT

預測 output。

boolean gameOver = false;

System.out.println(!gameOver);

!false 是 true。

Q14Negation

!(x > 5) 等價於哪個 condition？

等價於 x <= 5，不是 x < 5，因為 boundary x == 5 也要包含。

Q15Negation

!(x >= 5) 等價於哪個 condition？

x < 5。

C. Range

Range Conditions

範圍內通常要同時符合上下界；範圍外只要超出任一邊。

Q16Inside range

「score 在 0 到 100，包含兩端」應寫成？

score >= 0 && score <= 100。

Q17Outside range

「score 不在 0 到 100」應寫成？

score < 0 || score > 100。

Q18Bug

這個條件想檢查 valid score，錯在哪？

score >= 0 || score <= 100

應使用 &&。這個錯誤條件幾乎永遠 true，例如 500 >= 0 已經 true。

Q19Bug

這個條件想檢查 outside range，錯在哪？

score < 0 && score > 100

應使用 ||。一個數字不可能同時小於 0 又大於 100。

Q20Chained comparison

0 <= x <= 100 在 Java 合法嗎？

不合法。Java 會先算 0 <= x 得到 boolean，接著無法做 true <= 100。

Q21Open range

「x 大於 10 且小於 20」應寫成？

x > 10 && x < 20。

Q22Half-open

合法 index 範圍 0 <= index < length 應寫成？

index >= 0 && index < length。上界通常不是 <= length。

Q23Boundary

對 x >= 10 && x <= 20，x = 20 結果是什麼？

true，因為 <= 20 包含 20。

D. Precedence

Precedence / Boolean Tracing

沒有括號時，通常先算 !，再 &&，最後 ||。

Q24Precedence

true && false || true 的結果是什麼？

先算 true && false 得 false，再 false || true 得 true。

Q25Parentheses

假設 A = true、B = false、C = false，(A || B) && C 是什麼？

A || B 是 true，true && C 是 false。

Q26Parentheses

同樣 A = true、B = false、C = false，A || (B && C) 是什麼？

B && C 是 false，A || false 是 true。和上一題不同。

Q27Trace

預測 output。

int x = 8;
int y = 12;

if (x > 5 && y < 20)
{
    System.out.println("A");
}
else
{
    System.out.println("B");
}

8 > 5 true，12 < 20 true，所以 output 是 A。

Q28Trace

預測 output。

int x = 3;

if (x < 0 || x > 10)
{
    System.out.println("Outside");
}
else
{
    System.out.println("Inside");
}

3 < 0 false，3 > 10 false，所以 output 是 Inside。

E. Short-Circuit

Short-Circuit Evaluation

判斷右側 expression 是否真的會被執行。不要假設兩邊都會算。

Q29AND short-circuit

false && methodCall() 中 methodCall() 會被呼叫嗎？

不會。AND 左邊 false，整體一定 false。

Q30OR short-circuit

true || methodCall() 中 methodCall() 會被呼叫嗎？

不會。OR 左邊 true，整體一定 true。

Q31Division

這段程式會發生 division by zero 嗎？

int x = 0;

if (x != 0 && 100 / x > 1)
{
    System.out.println("Yes");
}

不會。x != 0 是 false，所以右側 100 / x 不執行。

Q32Order matters

這段如果 x = 0，會怎樣？

if (100 / x > 1 && x != 0)
{
    System.out.println("Yes");
}

會先算 100 / x，因此 division by zero。short-circuit 只有在已經算完左側後才可能發生。

Q33null

這段是否安全？

String name = null;

if (name != null && name.equals("Tom"))
{
    System.out.println("Tom");
}

安全。左邊 false，右邊 name.equals(...) 不執行。

Q34OR side effect

預測 output。

int x = 5;

if (x == 5 || ++x > 10)
{
    System.out.println(x);
}

Output 是 5。左邊 true，右側 ++x 不執行。

Q35AND side effect

預測 output。

int x = 5;

if (x != 5 && ++x > 0)
{
    x += 10;
}

System.out.println(x);

Output 是 5。左邊 false，++x 不執行，if body 也不執行。

F. De Morgan

De Morgan / Equivalent Expressions

NOT 穿過括號時，operator 要交換，每個 condition 都要取反。

Q36De Morgan

!(A && B) 等價於什麼？

!A || !B。

Q37De Morgan

!(A || B) 等價於什麼？

!A && !B。

Q38De Morgan

化簡：!(x > 10 && y <= 5)

x <= 10 || y > 5。

Q39De Morgan

化簡：!(x == 0 || y != 3)

x != 0 && y == 3。

Q40Range De Morgan

化簡：!(x >= 1 && x <= 100)

x < 1 || x > 100。

Q41Equivalent

!(x < 10 || x > 20) 等價於什麼？

x >= 10 && x <= 20。

Q42Not equivalent

!(A && B) 和 !A && !B equivalent 嗎？

不 equivalent。反例：A = true、B = false 時，左邊 true，右邊 false。

Q43English

「neither A nor B」應寫成？

!A && !B，也就是 !(A || B)。

Q44English

「not both A and B」應寫成？

!(A && B)，等價於 !A || !B。這和 neither 不同。

G. Coding

程式練習

把複合 Boolean expression 放進 if 或直接作為 Boolean return。

Q45Coding

Valid Score：判斷 score 是否在 0 到 100。

public class Main {
    public static void main(String[] args) {
        int score = 87;

        if (score >= 0 && score <= 100) {
            System.out.println("Valid");
        } else {
            System.out.println("Invalid");
        }
    }
}
Q46Coding

Outside Range：temperature 小於 0 或大於 40 時輸出 Extreme。

public class Main {
    public static void main(String[] args) {
        int temperature = 45;

        if (temperature < 0 || temperature > 40) {
            System.out.println("Extreme");
        }
    }
}
Q47Coding

Login：username 是 admin 且 password 是 1234 時成功。

public class Main {
    public static void main(String[] args) {
        String username = "admin";
        String password = "1234";

        if (username.equals("admin") && password.equals("1234")) {
            System.out.println("Login successful");
        } else {
            System.out.println("Login failed");
        }
    }
}
Q48Coding

Game Requirement：level 至少 10、有 key、且沒有 banned 才能開門。

public class Main {
    public static void main(String[] args) {
        int level = 12;
        boolean hasKey = true;
        boolean banned = false;

        if (level >= 10 && hasKey && !banned) {
            System.out.println("Open door");
        }
    }
}
Q49Boolean return

把這段簡化成直接 return Boolean expression。

public static boolean isValidScore(int score)
{
    if (score >= 0 && score <= 100)
    {
        return true;
    }
    else
    {
        return false;
    }
}
public static boolean isValidScore(int score)
{
    return score >= 0 && score <= 100;
}
Q50Final Challenge

預測 output。

int x = 5;
int y = 12;
boolean ready = false;

if ((x >= 1 && x <= 10) && (y > 10 || !ready))
{
    System.out.println("A");
}
else
{
    System.out.println("B");
}

if (!(x < 0 || y < 0))
{
    System.out.println("C");
}
A
C

x 在 1 到 10 之間；y > 10 true，所以第一個 if 成立。第二個是 !(false || false)，也成立。
