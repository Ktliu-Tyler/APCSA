Lesson Flow

本課路線

Basic Structure

Nested loop：一個 loop 的 body 裡面再放一個 loop

最典型的 nested loop 會用兩個變數：外層變數控制「第幾列」或「第幾輪」， 內層變數控制這一列裡面的每一格。

Outer / Inner Loop

for (int row = 0; row < 3; row++)
{
    for (int col = 0; col < 4; col++)
    {
        System.out.println(row + " " + col);
    }
}
部分 常見名稱 通常負責
for (int row = 0; row < 3; row++) Outer loop 控制有幾列、幾組、幾個主要項目。
for (int col = 0; col < 4; col++) Inner loop 控制每一列內有幾欄、幾次細部處理。

Execution Rule

最重要的一句：outer 每跑一次，inner 都重新完整跑一次

Trace the Order

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 2; j++)
    {
        System.out.println(i + " " + j);
    }
}
i = 1
    j = 1
    j = 2
i = 2
    j = 1
    j = 2
i = 3
    j = 1
    j = 2

所以輸出是 1 1、1 2、2 1、2 2、 3 1、3 2。注意：j 不會從上一輪的 3 繼續， 每次 outer 進入 body 都會重新建立 j = 1。

AP 題最常考的不是語法，而是你是否理解 inner loop 會重跑。遇到 nested trace， 先固定 outer 的一個值，再把 inner 完整走完。

Row / Column Thinking

把 nested loops 想成表格：outer 是 row，inner 是 column

很多 nested loop 題目都能翻譯成「有幾列？每列有幾欄？」。這種想法會讓 pattern、 乘法表、座標、pair 題更穩。

問題 Outer Inner 總次數
印 3 列，每列 5 顆星 3 rows 5 columns 15 顆星
列出 4 個學生與 6 次測驗 4 students 6 quizzes 24 個成績位置
1 到 9 乘法表 9 rows 9 columns 81 個乘積

Counting Iterations

固定範圍：總次數通常是外層次數乘內層次數

3 × 4 = 12

int count = 0;

for (int r = 0; r < 3; r++)
{
    for (int c = 0; c < 4; c++)
    {
        count++;
    }
}

System.out.println(count);

外層跑 3 次；每一次外層，內層跑 4 次。總共 3 * 4 = 12。

Code Outer 次數 Inner 次數 Total
r < 5, c < 2 5 2 10
r <= 4, c <= 4 4 4 16
i = 2; i <= 6, j = 1; j <= 3 5 3 15

Pattern Output

Pattern 題核心：inner 負責同一列，outer 結束後換行

System.out.print 不換行，適合在同一列印很多個符號。 System.out.println 會換行，通常放在 inner loop 結束之後。

Dependent Bounds

當 inner bound 用到 outer variable，就不是矩形，而是三角形

如果 inner loop 的結束條件依賴 outer variable，例如 col <= row， 每一列的長度會改變。這就是三角形 pattern 和 pair counting 的核心。

Increasing Triangle

for (int row = 1; row <= 5; row++)
{
    for (int col = 1; col <= row; col++)
    {
        System.out.print("*");
    }
    System.out.println();
}

Multiplication Table

乘法表是 row / column 思維最直接的應用

1 to 9 Multiplication Table

for (int row = 1; row <= 9; row++)
{
    for (int col = 1; col <= 9; col++)
    {
        System.out.print(row * col + "\t");
    }
    System.out.println();
}

外層決定第幾列，內層決定第幾欄。每一格的值就是 row * col。 這種結構之後會直接延伸到 2D arrays。

Pair Algorithms

Nested loops 很適合列出所有配對

如果每個 i 都要和每個 j 配對，就是 ordered pairs。 如果只想要不重複、不自己跟自己配對，inner loop 的起點就要改。

All Ordered Pairs

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        System.out.println(i + "," + j);
    }
}

這會印出 9 組，包含 1,1、2,2、3,3，也包含方向不同的 1,2 與 2,1。

Unique Pairs

for (int i = 1; i <= 4; i++)
{
    for (int j = i + 1; j <= 4; j++)
    {
        System.out.println(i + "," + j);
    }
}
1,2
1,3
1,4
2,3
2,4
3,4

j = i + 1 代表 j 永遠在 i 後面。 這會避免 self-pair，也避免 1,2 和 2,1 重複算。

Nested Trace

Trace nested loops 時，要同時追蹤 outer、inner、state

Trace Sum

int sum = 0;

for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= i; j++)
    {
        sum += i + j;
    }
}

System.out.println(sum);
i j values 加入的值 sum
1 1 2 2
2 1, 2 3, 4 9
3 1, 2, 3 4, 5, 6 24

Accumulator Scope

變數放在哪裡，決定它累積的是「每列」還是「全部」

Row Sum vs Total

int total = 0;

for (int row = 1; row <= 3; row++)
{
    int rowSum = 0;

    for (int col = 1; col <= 4; col++)
    {
        rowSum += col;
        total += col;
    }

    System.out.println("row sum: " + rowSum);
}

System.out.println("total: " + total);

rowSum 在 outer loop 裡面初始化，所以每一列重新歸零。 total 在 outer loop 外面初始化，所以一路累積全部。

Runtime Intuition

Nested loops 常讓演算法變慢：一層 n，兩層常是 n²

Loop shape 大概次數 直覺
單層 for (i = 0; i < n; i++) n O(n)
兩層都跑 n 次 n * n O(n^2)
外層 n，內層 m n * m O(nm)
內層跑 1 + 2 + ... + n 大約一半的 n^2 仍然是 O(n^2)

AP CSA 不要求嚴格證明 Big-O，但你要有直覺：nested loops 會讓每個外層項目都做很多內層工作。

Common Errors

Nested loop 常見錯誤

錯誤 常見樣子 修正想法
inner condition 用錯變數 for (int j = 0; i < 5; j++) inner condition 通常要檢查 j。
inner update 改錯變數 for (int j = 0; j < 5; i++) inner loop 要更新 j，否則可能無限迴圈或跳錯。
println 放錯位置 每印一顆星就換行 同一列用 print，一列結束才 println。
把 row accumulator 放錯 scope rowSum 沒有每列歸零 每列要重算的變數放在 outer body 裡、inner loop 前。
pair 重複或 self-pair i,j 與 j,i 都算，或 i == j unique pair 常用 j = i + 1。
dependent bound 算成矩形 1 + 2 + 3 + 4 被算成 4 * 4 逐列列出 inner 次數，再加總。

考前必背十二句

Nested loop means a loop inside another loop.

The inner loop runs completely for each iteration of the outer loop.

The inner loop variable is reinitialized each time the inner loop starts.

Outer loop often controls rows; inner loop often controls columns.

For a rectangle, total iterations are rows times columns.

For a triangle, count each row and add them.

Use print for items on the same row.

Use println after the inner loop to move to the next row.

j = i + 1 is useful for unique pairs.

Trace nested loops by fixing the outer value first.

Accumulator scope decides whether it resets per row or keeps a total.

Nested loops often suggest quadratic runtime.
