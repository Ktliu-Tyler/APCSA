for 是 counted while 的集中寫法

int i = 1;

while (i <= 5)
{
    System.out.println(i);
    i++;
}

三個控制元素：從哪開始、什麼時候繼續、每輪怎麼更新。

Counted Loop

明確次數的工作，通常適合 for

重複 n 次
從 1 through n
從 10 倒數到 1
處理每個 index
做 100 次 random trial
計算 sum、product、count

Syntax

for header 的三個部分

for (initialization; condition; update)
{
    body;
}
Initialization只執行一次
Condition每輪 body 前檢查
Update每輪 body 後執行

Execution Order

順序不是 init → condition → update → body

Initialization Condition Body Update Condition again

Update 在 body 後才發生，所以第一次看到的是初始值。

First Check

預測 output

for (int i = 1; i <= 3; i++)
{
    System.out.print(i + " ");
}
A. 0 1 2 B. 1 2 3 C. 2 3 4 D. Infinite loop

答案是 B。第一次 body 看到 i = 1；update 在 body 後。

Count Check

這個 loop body 執行幾次？

for (int i = 0; i <= 10; i++)
{
    // work
}
A. 9 B. 10 C. 11 D. 12

答案是 C。i 是 0 到 10，共 11 個值。

Inclusive / Exclusive

英文題目的 bounds

from 1 through n

i = 1; i <= n

0 up to but not including n

i = 0; i < n

a through b, inclusive

i = a; i <= b

Counting Down

倒數時，condition 和 update 方向要一致

for (int i = 10; i >= 1; i--)
{
    System.out.println(i);
}

錯誤方向：for (int i = 10; i >= 1; i++) 通常不會停止。

Custom Step

Update 不一定只能 i++

i += 2：每次加 2
i -= 3：每次減 3
i *= 2：每次乘 2
i /= 2：每次除 2

Step 不為 1 時，直接列出 i 的值最穩。

Custom Step Check

這個 loop body 執行幾次？

for (int i = 1; i <= 10; i += 3)
{
    // work
}
A. 3 B. 4 C. 5 D. 10

答案是 B。i 是 1、4、7、10，共 4 次。

Accumulator

for 搭配 sum / product / count

Sum

Product

int product = 1; then product *= i;

Count

int count = 0; then count++;

Count Matches

Loop 次數和 statement 次數可能不同

int count = 0;

for (int i = 0; i < 10; i++)
{
    if (i % 3 == 0)
    {
        count++;
    }
}

i = 0, 3, 6, 9 符合，所以 count = 4。注意 0 也符合 0 % 3 == 0。

Loop Variable Scope

在 header 宣告的 i，通常 loop 外不能用

for (int i = 0; i < 5; i++)
{
    System.out.println(i);
}

System.out.println(i);
A. 印 5 B. 印 4 C. Compile error D. Infinite loop

答案是 C。i 的 scope 只在這個 for loop 中。

Index Pattern

String / Array index 通常是 0 ... length - 1

String word = "JAVA";

for (int i = 0; i < word.length(); i++)
{
    String letter = word.substring(i, i + 1);
    System.out.println(letter);
}

i <= word.length() 會多跑到非法 index。

AP Trap

Body 修改 i 時，一定 trace

for (int i = 0; i < 10; i++)
{
    i++;
}

Body 執行幾次？

A. 5 B. 9 C. 10 D. Infinite loop

答案是 A。Body 裡加一次，header update 再加一次，所以 i 以 0、2、4、6、8 進 body。

Bound Changes

Bound 被改，也不能只看 header

int n = 8;

for (int i = 0; i < n; i++)
{
    n -= 2;
}

Trace: (i,n) = (0,8), (1,6), (2,4)，之後 i = 3、n = 2 停止。共 3 次。

Common Errors

今天最常見的錯誤

i < n 誤以為跑到 n
i <= n 從 0 開始多一次
倒數時 update 方向錯
忘記 update 在 body 後
loop 外使用 header 裡宣告的 i
for (...); 造成 empty body
body 偷改 i
把 length 當最後 index
