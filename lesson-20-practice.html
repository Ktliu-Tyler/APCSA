A. Concepts

Q1Core Idea

Lesson 20 和 Lesson 19 最大的差異是什麼？

Lesson 19 重點是 ArrayList methods；Lesson 20 重點是把 methods 放進 loop，並正確處理 traversal、filter、remove、index shift。

Q2Mutation

哪兩個 ArrayList operations 會改變 size()？

add 會讓 size 增加；remove 會讓 size 減少。set 不會改變 size。

Q3Traversal

Q4Enhanced For

Enhanced for loop 最適合哪一類 ArrayList algorithm？

最適合 read-only traversal，例如 sum、count、print、boolean search。它不適合需要 index 或 add/remove/set by index 的任務。

Q5Loop Choice

題目要求回傳第一個符合條件的 index，應該用 enhanced for 還是 traditional for？

用 traditional for，因為需要 i 作為 index。

Q6Index Shift

list.remove(i) 之後，原本在 i + 1 的元素會發生什麼事？

它會左移到 index i。這就是 forward remove 可能跳過元素的原因。

Q10First Index

寫出 method：回傳 target 第一次出現在 words 的 index，若不存在回傳 -1。

public static int indexOf(ArrayList<String> words, String target)
{
    for (int i = 0; i < words.size(); i++)
    {
        if (words.get(i).equals(target))
        {
            return i;
        }
    }

}

Q12Max

假設 nums 保證非空，寫出找最大值的 method。

public static int max(ArrayList<Integer> nums)
{
    int largest = nums.get(0);
    for (int i = 1; i < nums.size(); i++)
    {
        if (nums.get(i) > largest)
        {
            largest = nums.get(i);
        }
    }
    return largest;
}

若題目沒有保證非空，就不能直接 get(0)。

Q13Average

若 scores 非空，計算平均時為什麼常寫 (double) total / scores.size()？

為了避免整數除法。把 total cast 成 double 後，結果會是小數。

D. Remove / Index Shift

直接刪除原本 List

這組題目是 Lesson 20 最重要的部分：remove 後 index shift 會怎麼影響 loop。

Q22Bug Trace

以下程式最後 nums 是什麼？

ArrayList<Integer> nums = new ArrayList<Integer>();
nums.add(2);
nums.add(2);
nums.add(3);

for (int i = 0; i < nums.size(); i++)
{
    if (nums.get(i) == 2)
    {
        nums.remove(i);
    }
}

[2, 3]。第一個 2 被刪後，第二個 2 左移到 index 0；接著 i++ 讓 loop 去檢查 index 1 的 3。

Q23Explain

為什麼 forward remove 後如果直接 i++，可能會跳過元素？

remove(i) 會讓後面的元素左移到目前 index；但 for loop 結尾又讓 i 增加，導致剛移過來的元素沒有被檢查。

Q24Backward Code

寫出安全刪除 nums 中所有負數的 backward traversal。

for (int i = nums.size() - 1; i >= 0; i--)
{
    if (nums.get(i) < 0)
    {
        nums.remove(i);
    }
}
Q25While Code

用 forward while loop 安全刪除所有負數。

int i = 0;
while (i < nums.size())
{
    if (nums.get(i) < 0)
    {
        nums.remove(i);
    }
    else
    {
        i++;
    }
}

重點：remove 後不要增加 i。

Q26Backward Trace

以下程式最後印出什麼？

ArrayList<Integer> nums = new ArrayList<Integer>();
nums.add(1);
nums.add(4);
nums.add(4);
nums.add(7);

for (int i = nums.size() - 1; i >= 0; i--)

[1, 7]。從後往前刪，兩個 4 都會被檢查並刪除。

Q29All Remove

若 list 是 [5, 5, 5]，以下程式能刪掉全部 5 嗎？

for (int i = 0; i < list.size(); i++)
{
    if (list.get(i) == 5)
    {
        list.remove(i);
    }
}

不能。最後會留下一個 5，因為每次 remove 後都跳過移到目前 index 的下一個 5。

Q30Empty List

若 list.size() 是 0，以下 backward loop 會執行嗎？

for (int i = list.size() - 1; i >= 0; i--)
{
    list.remove(i);
}

不會。i 一開始是 -1，條件 i >= 0 為 false。

Q31Add Shift

list.add(i, value) 對 index 有什麼影響？

它會把原本 index i 和後方元素全部往右移，size 增加 1。這也可能讓 traversal 變複雜。

Q32i-- Pattern

以下 pattern 中 i-- 的目的為何？

for (int i = 0; i < list.size(); i++)
{
    if (shouldRemove(list.get(i)))
    {
        list.remove(i);
        i--;
    }
}

i-- 用來抵消 for loop 結尾的 i++，讓下一輪繼續檢查目前 index。

E. Enhanced For / Transform

Enhanced for 的限制與 set

這組題目確認什麼時候不能使用 enhanced for，以及如何用 set 修改元素。

Q33Enhanced For Remove

為什麼不建議在 enhanced for loop 中對同一個 list 做 remove？

Enhanced for 是用來逐一讀取元素；在走訪時改變 list structure 會讓 traversal 狀態不穩定。AP 題中遇到 add/remove，應改用 index-based loop。

Q34Loop Variable

以下程式會把 nums 裡所有值改成 0 嗎？

for (int n : nums)
{
    n = 0;
}

不會。n 是 loop variable，改它不等於改 list 裡的元素。

Q35Correct Set

要把 nums 裡每個位置改成 0，應該怎麼寫？

for (int i = 0; i < nums.size(); i++)
{
    nums.set(i, 0);
}
Q36Replace Negatives

寫出 method：把 nums 中所有負數改成 0，不刪除元素。

public static void replaceNegatives(ArrayList<Integer> nums)
{
    for (int i = 0; i < nums.size(); i++)
    {
        if (nums.get(i) < 0)
        {
            nums.set(i, 0);
        }
    }
}
Q37set vs remove

set 和 remove 對 size 的影響有何不同？

set 取代某個 index 的值，size 不變；remove 刪掉元素，size 減 1，後方元素左移。

Q38Need Index

寫出 code：把偶數 index 的元素都加 10。

for (int i = 0; i < nums.size(); i++)
{
    if (i % 2 == 0)
    {
        nums.set(i, nums.get(i) + 10);
    }
}

這題需要 index，因此不適合 enhanced for。

Q39Above Average

寫出 method：回傳成績中大於平均的數量。假設 scores 非空。

public static int countAboveAverage(ArrayList<Integer> scores)
{
    int total = 0;
    for (int score : scores)
    {
        total += score;
    }

    double average = (double) total / scores.size();

    int count = 0;
    for (int score : scores)
    {
        if (score > average)
        {
            count++;
        }
    }
    return count;
}
Q40Clean Data

寫出 method：從 temps 中移除所有小於 -50 或大於 60 的讀數。

public static void removeInvalidTemps(ArrayList<Integer> temps)
{
    for (int i = temps.size() - 1; i >= 0; i--)
    {
        int temp = temps.get(i);
        if (temp < -50 || temp > 60)
        {
            temps.remove(i);
        }
    }
}

這是 remove original list，所以使用 backward traversal。

Q41Valid Copy

若題目改成「回傳所有有效溫度，原 list 不改變」，應該怎麼寫？

public static ArrayList<Integer> getValidTemps(ArrayList<Integer> temps)
{
    ArrayList<Integer> valid = new ArrayList<Integer>();
    for (int temp : temps)
    {
        if (temp >= -50 && temp <= 60)
        {
            valid.add(temp);
        }
    }
    return valid;
}

Q43First vs Last

若 words 是 [a, b, a, c, a]，target 是 a，first index 和 last index 分別是多少？

First index 是 0；last index 是 4。找 first 從前往後；找 last 從後往前最直接。

Q44Duplicates

進階：寫出 method，移除 list 中重複的字串，只保留每個字串第一次出現。

public static void removeDuplicates(ArrayList<String> list)
{
    for (int i = 0; i < list.size(); i++)
    {
        String current = list.get(i);
        for (int j = list.size() - 1; j > i; j--)
        {
            if (list.get(j).equals(current))
            {
                list.remove(j);
            }
        }
    }
}

內層從後面往前刪，避免刪除 duplicate 時發生 index shift 問題。

Q45Final Trace

以下程式最後印出什麼？

ArrayList<Integer> nums = new ArrayList<Integer>();
nums.add(4);
nums.add(4);
nums.add(5);
nums.add(4);

for (int i = 0; i < nums.size(); i++)
{
    if (nums.get(i) == 4)
    {
        nums.remove(i);
    }
}

nums.add(0, 9);
System.out.println(nums);

Forward remove 會留下中間被跳過的 4。remove loop 後是 [4, 5]，再 add(0, 9) 變成 [9, 4, 5]。
