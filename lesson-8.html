Compound Boolean

Compound Boolean Expression 把多個 Boolean expressions 合在一起

單一 condition 像 age >= 18 或 hasTicket，只能描述一件事。 實際條件常需要同時描述多件事：年齡至少 18 而且有票、不合法分數是小於 0 或大於 100、 不是 ready。Java 用三個 Boolean operators 來組合。

Operator 名稱 意思 例子
&&AND而且；全部都要 true。age >= 18 && hasTicket
||OR或者；至少一個 true。score < 0 || score > 100
!NOT不是；取反。!gameOver

Logical AND

&&：兩邊都必須成立

AND Example

int age = 20;
boolean hasTicket = true;

if (age >= 18 && hasTicket)
{
    System.out.println("Enter");
}

age >= 18 是 true，hasTicket 也是 true， 所以 true && true 得到 true。

&& 只有 true && true 才是 true；其他全部 false。

Logical OR

||：至少一邊成立即可

OR Example

int score = 120;

if (score < 0 || score > 100)
{
    System.out.println("Invalid");
}

120 < 0 是 false，但 120 > 100 是 true，所以 false || true 得到 true。

falsetruetrue
truefalsetrue
truetruetrue

Java 的 || 是 inclusive OR：兩邊都 true 時，整體仍然 true。

Logical NOT

!：把 Boolean 結果反過來

Boolean variable

boolean gameOver = false;

if (!gameOver)
{
    System.out.println("Continue playing");
}

!false 是 true，所以會執行。

Whole expression

int x = 8;
boolean result = !(x > 5);

x > 5 是 true，取反後 result 是 false。

Negation

Comparison 取反時，邊界也要反過來

!(x > 5) 不是 x < 5，而是 x <= 5。 因為「不大於 5」包含 x == 5。

Range Conditions

範圍內通常用 &&；範圍外通常用 ||

數學可以寫 0 <= score <= 100，但 Java 不支援 chained comparison。 Java 要把上下界分成兩個 Boolean expressions。

Inside range

score >= 0 && score <= 100

Outside range

score < 0 || score > 100

Half-open range

index >= 0 && index < length

Valid Score

int score = 87;

if (score >= 0 && score <= 100)
{
    System.out.println("Valid");
}
else
{
    System.out.println("Invalid");
}
想表達 錯誤 正確
score 在 0 到 100score >= 0 || score <= 100score >= 0 && score <= 100
score 不在 0 到 100score < 0 && score > 100score < 0 || score > 100
x 在 10 到 20，不含兩端x >= 10 && x <= 20x > 10 && x < 20

Precedence

Boolean operator precedence：!、&&、||

Java 會先算 comparisons，再處理 Boolean operators。Boolean operators 之間的常用優先順序是 ! 先，&& 再來，|| 最後。

Precedence Example

boolean result = true && false || true;
true && false || true

(true && false) || true
false || true
true

即使 Java 有 precedence，遇到 A || B && C 這類 expression，建議使用 parentheses 讓意圖清楚。

Short-Circuit Evaluation

右側 condition 不一定會被執行

Java 的 && 和 || 會 short-circuit：如果左邊已經足以決定整個結果， 右邊完全不 evaluation。這是 AP CSA 很常考的行為。

Expression 左邊 右邊會算嗎？
A && BA == false不會，整體已經 false。
A && BA == true會，需要 B 決定結果。
A || BA == true不會，整體已經 true。
A || BA == false會，需要 B 決定結果。

Safe division

if (x != 0 && 10 / x > 2)
{
    System.out.println("Yes");
}

如果 x == 0，左邊 false，右邊 10 / x 不執行。

Safe String method

if (name != null && name.equals("Tom"))
{
    System.out.println("Hello Tom");
}

如果 name == null，右邊 name.equals(...) 不執行，因此安全。

OR short-circuit

int x = 5;

if (x == 5 || ++x > 10)
{
    System.out.println(x);
}

左邊 true，右邊 ++x 不執行，所以輸出仍是 5。

De Morgan's Laws

NOT 穿過括號時，operator 交換且每個 condition 取反

!(A && B)

!A || !B

!(A || B)

!A && !B

口訣

&& 變 ||，|| 變 &&，每個小條件都取反。

原式 等價式
!(x > 10 && y <= 5)x <= 10 || y > 5
!(x == 0 || y != 3)x != 0 && y == 3
!(x >= 1 && x <= 100)x < 1 || x > 100
!(age < 18 || age > 65)age >= 18 && age <= 65

常見錯誤：!(A && B) 變成 !A && !B。這少做了 operator 交換，錯。

Equivalent Expressions

判斷 equivalent：用 De Morgan、boundary 或反例

AP CSA 常問「哪個 expression 等價」。不要只看它像不像，要用規則或找反例。

Equivalent

!(x < 10 || x > 20)

x >= 10 && x <= 20

兩者等價，都是 x 在 10 到 20 之間，包含兩端。

Not equivalent

!(x > 5 && y > 5)

x <= 5 && y <= 5

第一個正確展開是 x <= 5 || y <= 5，第二個太嚴格。

Counterexample

!(A && B)  vs  !A && !B

A = true
B = false

左邊 true，右邊 false，所以不 equivalent。

英文 Java
A and B / bothA && B
A or B / at least oneA || B
neither A nor B!A && !B
not both A and B!A || !B
not at least one!A && !B
