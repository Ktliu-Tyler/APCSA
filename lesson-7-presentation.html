Single Selection

if：condition true 才執行 body

int temperature = 35;

if (temperature > 30)
{
    System.out.println("Hot");
}

35 > 30 是 true，所以 output 是 Hot。

Boolean Condition

if 括號中必須是 boolean

if (x > 5)

合法

if (name.equals("Tom"))

合法

if (isReady)

合法

if (x)

若 x 是 int，不合法

Java 不把 0 / 非 0 當 Boolean。

Trace

condition false 只是跳過 body

int x = 3;

if (x > 10)
{
    System.out.println("Large");
}

System.out.println("Done");

Output 是什麼？

A. Large B. Done C. Large / Done D. 沒有輸出

答案是 B。x > 10 false，所以跳過 Large，但繼續印 Done。

Trace

AP tracing 先寫出 execution path

int x = 8;

System.out.println("A");

if (x > 5)
{
    System.out.println("B");
}

System.out.println("C");

Output 是什麼？

A. A C B. A B C C. B C D. A B

答案是 B。8 > 5 true，所以三行都會印。

Two-way Selection

if / else：二選一

if (score >= 60)
{
    System.out.println("Pass");
}
else
{
    System.out.println("Fail");
}
condition true Pass condition false Fail

不可能同時執行 if branch 和對應的 else branch。

Execution Path

Branch 中改變變數後，後面用新值

int x = 7;

if (x > 5)
{
    x += 2;
}
else
{
    x -= 2;
}

x *= 3;
System.out.println(x);

Output 是什麼？

A. 15 B. 21 C. 27 D. 9

7 > 5 true，x = 9，最後 9 * 3 = 27。答案 C。

Multi-way Selection

else if 從上往下檢查

int score = 85;

if (score >= 90)
{
    System.out.println("A");
}
else if (score >= 80)
{
    System.out.println("B");
}
else
{
    System.out.println("C");
}

85 >= 90 false；85 >= 80 true，所以 output 是 B。

First True Wins

第一個 true 後，後面全部跳過

int score = 95;

if (score >= 90)
{
    System.out.println("A");
}
else if (score >= 80)
{
    System.out.println("B");
}
else
{
    System.out.println("C");
}

Output 是什麼？

A. A B. B C. A B D. C

答案是 A。雖然 95 >= 80 也 true，但不會再檢查。

Order Matters

threshold 順序錯，結果就錯

int score = 95;

if (score >= 60)
{
    System.out.println("D");
}
else if (score >= 90)
{
    System.out.println("A");
}

Output 是什麼？

A. A B. D C. A D D. 沒有輸出

答案是 B。95 >= 60 已經 true，後面的 A branch 到不了。

Independent if

兩個 if 是兩次獨立判斷

int x = 10;

if (x >= 5)
{
    System.out.print("A");
}

if (x >= 10)
{
    System.out.print("B");
}

Output 是什麼？

A. A B. B C. AB D. 沒有輸出

答案是 C。兩個 if 都會各自檢查。

if vs else if

AP 超常考：結構不同，結果不同

多個 if

每個都是獨立 decision，可能多個都執行。

if / else if

同一條 chain，最多只執行一個 branch。

Trace rule

先看 braces 和 else 到底接在哪個 if。

Nested if

outer true 後，inner 才有機會判斷

int age = 20;
boolean hasTicket = true;

if (age >= 18)
{
    if (hasTicket)
    {
        System.out.println("Enter");
    }
}
age >= 18 hasTicket Enter

Nested Trace

先 outer，再 inner

int x = 4;

if (x > 0)
{
    System.out.print("A");

    if (x > 5)
    {
        System.out.print("B");
    }
    else
    {
        System.out.print("C");
    }
}

System.out.print("D");

Output 是什麼？

A. AD B. ACD C. CD D. ABD

答案是 B。外層 true 印 A，內層 false 走 else 印 C，最後印 D。

Dangling else

else 配最近尚未配對的 if

if (x > 0)
    if (x > 10)
        System.out.println("A");
    else
        System.out.println("B");

else 配的是 if (x > 10)。建議永遠使用 braces { }。

Range Checking

常見英文與比較運算子

English Java
at least 10x >= 10
at most 10x <= 10
greater than 10x > 10
less than 10x < 10
exactly 10x == 10

AP 題目常用英文測 boundary。

Boundary

> 和 >= 差一個邊界

int score = 80;

if (score > 90)
{
    System.out.println("A");
}
else if (score > 80)
{
    System.out.println("B");
}
else if (score > 70)
{
    System.out.println("C");
}

Output 是什麼？

A. A B. B C. C D. 沒有輸出

答案是 C。80 > 80 false，但 80 > 70 true。

Case Analysis

好的分類要 cover all cases

if (x > 0)
{
    System.out.println("Positive");
}
else if (x == 0)
{
    System.out.println("Zero");
}
else
{
    System.out.println("Negative");
}

最後的 else 不需要再寫 x < 0，因為剩下唯一可能就是 negative。

Unreachable Branch

找永遠到不了的 branch

if (x >= 50)
{
    System.out.println("A");
}
else if (x >= 70)
{
    System.out.println("B");
}
else
{
    System.out.println("C");
}

哪個 branch 永遠不會執行？

A branch B branch C branch 都可能

B 永遠到不了，因為 x >= 70 一定也先符合 x >= 50。

AP SOP

if / else tracing 固定流程

Write values Evaluate condition Choose branch Update variables Next condition Output

每遇到新的 condition，都要用目前最新的 variable values。

AP-style Trace

綜合追蹤

int x = 10;
int y = 5;

if (x > y)
{
    x -= 5;

    if (x == y)
    {
        y *= 2;
    }
}
else
{
    x += 10;
}

System.out.println(x + " " + y);

Output 是 5 10。外層 true，x 變 5；內層 true，y 變 10。
