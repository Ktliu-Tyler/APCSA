From Lessons 13-15

我們已經會寫 class，但還要知道每個名字屬於誰

public class Student
{
    private String name;
    private int score;

    public Student(String name, int score)
    {
        this.name = name;
        this.score = score;
    }
}

今天的核心問題：score 到底是哪一個 score？

Scope

Scope 是名字可以被直接使用的程式碼範圍

public void method()
{
    int x = 5;
    System.out.println(x); // OK
}

public void other()
{
    System.out.println(x); // compile error
}

Scope vs Lifetime

Scope 和 lifetime 不是同一件事

Scope

程式碼在哪裡可以使用這個名字。

Lifetime

Variable 或 object 存在多久。

AP CSA 最常考的是 scope、shadowing、static context。

Four Variable Kinds

先辨認 variable 的種類

public class Example
{
    private int value;          // instance variable
    private static int count;   // static variable

    public void method(int x)   // parameter
    {
        int result = x + value; // local variable
    }
}

Instance Variable

Instance variable 屬於 object

Student a own name own score receiver state

同一個 class 建出的不同 objects，各自有自己的 instance fields。

Receiver State

Instance method 中的 field 通常是 receiver 的 field

public int getScore()
{
    return score;
}

a.getScore(); // score means a's score
b.getScore(); // score means b's score

this

this means the current receiver object

public void setScore(int score)
{
    this.score = score;
}

若執行 a.setScore(90)，this 就是 a 指到的 object。

Quick Check

若執行 b.setScore(70)，this.score 是誰的 score？

this.score 是 b 指到的 object 的 score。

Shadowing

Parameter 和 field 同名時，單獨寫名稱會先找到 parameter

private int score;

public void brokenSetScore(int score)
{
    score = score; // parameter = parameter
}

這段通常沒有 compile error，但有 logic bug。

Fix Shadowing

this.field 明確指定 instance field

public void setScore(int score)
{
    this.score = score;
}

this.score 是 field；score 是 parameter。

Quick Check

obj.sum(5) 回傳什麼？

private int x = 10;

public int sum(int x)
{
    return this.x + x;
}

15。this.x 是 field 10；x 是 parameter 5。

Parameters

Parameter scope 是 method / constructor body

public void addPoints(int amount)
{
    score += amount; // OK
}

public void other()
{
    System.out.println(amount); // compile error
}

Local Variables

Local variable 從宣告後到所在 block 結束前可用

public int doubledScore()
{
    int result = score * 2;
    return result;
}

宣告前不能用，block 外不能用。

Block Scope

Curly braces 建立 block scope

int x = 1;

if (x > 0)
{
    int y = 2;
}

System.out.println(x); // OK
System.out.println(y); // compile error

For Loop Scope

for (int i ...) 的 i 通常只能在 loop 裡用

for (int i = 0; i < 4; i++)
{
}

System.out.println(i); // compile error

Defaults

Fields 有 default values；local variables 沒有可直接用的 default value

Fields

int → 0

boolean → false

object reference → null

Locals

使用前必須被賦值。

int x; println(x); compile error。

Quick Check

這段合法嗎？

int x;
if (score > 0)
{
    x = 5;
}
System.out.println(x);

通常不合法。若 condition 不成立，x 可能還沒被賦值就使用。

static

static means class-level

public class Student
{
    private String name;        // per object
    private int score;          // per object
    private static int count;   // shared by class
}

Static variable 也叫 class variable。

Static Shared State

Static field 所有 objects 共用一份

private static int count = 0;

public Student(String name)
{
    this.name = name;
    count++;
}
new Student count 1 new Student count 2

Design Rule

每個 object 自己不同的 state，不要隨便 static

public class Student
{
    private static int score; // usually bad design
}

如果每個 Student 應該有不同 score，score 應該是 instance variable。

Static Method

Static method belongs to class and has no receiver object

public class Utility
{
    public static int square(int x)
    {
        return x * x;
    }
}

int n = Utility.square(5);

Static Context Rule

Static method 不能直接使用 instance members

Can directly use

parameters

local variables

static fields/methods

Cannot directly use

instance fields

instance methods

this

Quick Check

這段合法嗎？

private int score;

public static int getScore()
{
    return score;
}

不合法。score 是 instance field；static method 沒有 receiver object。

Static Can Use Object References

Static method 若有 object reference，就能指定要用哪個 object

public static int readScore(Student s)
{
    return s.getScore();
}

關鍵是 s 明確指出 receiver object。

main

main 是 static method

public static void main(String[] args)
{
    Example e = new Example();
    System.out.println(e.getX());
}

在 main 裡要使用 instance state，通常先建立 object。

Quick Check

Static method 可以使用 this 嗎？

不可以。this 只存在 constructor 和 instance method 的 instance context。
