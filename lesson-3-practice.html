A. Method Vocabulary

Method 名詞與 API Reading

這一區確認你是否能分辨 method call、argument、parameter、return value 與 signature。

Q1Method call

在下列 method call 中，method name 是什麼？

Math.pow(2, 5)
A. Math B. pow C. 2 D. 5

答案是 B。Math 是 class name，pow 是 method name，2 和 5 是 arguments。

Q2Argument

Math.sqrt(36) 的 argument 是什麼？

Argument 是 36，也就是呼叫 method 時實際傳入的資料。

Q3Parameter vs Argument

請指出 parameter 與 argument。

public static int square(int n)
{
    return n * n;
}

int value = square(6);

int n 是 parameter，因為它出現在 method 定義。6 是 argument，因為它出現在 method call square(6)。

Q4Return value

下列哪一個說法最精確？

A. Return value 一定會自動印出來。 B. Return value 可以被存進變數或放進 expression。 C. 所有 methods 都有 return value。 D. println 回傳 String。

答案是 B。Return value 不會自動印出；需要 System.out.println(...) 才會輸出。有些 methods 的 return type 是 void，沒有 return value。

Q5void

這段程式是否合法？

int x = System.out.println("Hello");

不合法。System.out.println 的 return type 是 void，它沒有可以存進 int x 的 return value。

Q6API Reading

讀下面 method header。

double pow(double base, double exponent)

請回答 return type、method name、parameter types。

Return type 是 double。Method name 是 pow。Parameter types 是 double、double。

B. Math Methods

Math.abs、Math.pow、Math.sqrt

這一區練習 Math methods 的結果與型別。

Q7Math.abs

求 expression 的值。

Math.abs(-12)

答案是 12。abs 是 absolute value。

Q8Math.abs

最後 difference 是多少？

int score = 76;
int target = 90;
int difference = Math.abs(score - target);

score - target = 76 - 90 = -14，所以 Math.abs(-14) = 14。

Q9Math.pow

求 expression 的值與型別。

Math.pow(3, 2)

值是 9.0，型別是 double。不是 9。

Q10Return type

這段程式是否合法？

int x = Math.pow(2, 3);

不合法。Math.pow 回傳 double，不能直接存進 int。可以改成 double x = Math.pow(2, 3); 或 int x = (int)Math.pow(2, 3);。

Q11Math.sqrt

求 expression 的值與型別。

Math.sqrt(49)

值是 7.0，型別是 double。即使答案看起來是整數，sqrt 仍回傳 double。

Q12Casting

最後 x 是多少？

int x = (int)Math.sqrt(50);

Math.sqrt(50) 約為 7.071，(int) 會 truncate 成 7。

Q13Expression

求 x。

double x = Math.pow(3, 2) + Math.sqrt(49);

Math.pow(3, 2) = 9.0，Math.sqrt(49) = 7.0，所以 x = 16.0。

Q14Compile-time Error

這段程式的錯誤是什麼？

double x = Math.Sqrt(25, 36);

有兩個問題。第一，Java 大小寫敏感，應該是 Math.sqrt。第二，sqrt 只接收一個 argument，不是兩個。

C. Nested Tracing

巢狀 method call 與 expression tracing

從最內層開始，把每個 method call 換成它的 return value。

Q15Nested

求 result。

double result =
    Math.sqrt(Math.pow(3, 2) + Math.pow(4, 2));

Math.pow(3, 2) = 9.0，Math.pow(4, 2) = 16.0，總和 25.0，所以 Math.sqrt(25.0) = 5.0。

Q16Integer Division

最後 x 約是多少？

double x = Math.sqrt(9 / 4);

9 / 4 是 integer division，先得到 2。所以 x = Math.sqrt(2)，約 1.414。不是 1.5。

Q17Integer Division

最後 x 是多少？

double x = Math.sqrt(9.0 / 4);

9.0 / 4 = 2.25，所以 Math.sqrt(2.25) = 1.5。

Q18Trace

預測 output。

int x = 7;
int y = (int)Math.pow(x - 5, 3);
System.out.println(y);

x - 5 = 2，Math.pow(2, 3) = 8.0，(int)8.0 = 8。Output 是 8。

Q19Trace

求 expression 的值。

Math.abs((int)Math.pow(2, 3) - 10)

Math.pow(2, 3) = 8.0，cast 成 8，8 - 10 = -2，Math.abs(-2) = 2。

Q20Trace

預測 output。

int n = 20;

double result =
    Math.sqrt(
        Math.pow(n / 5, 2)
        +
        Math.abs(n - 29)
    );

System.out.println(result);

n / 5 = 4，Math.pow(4, 2) = 16.0，Math.abs(20 - 29) = 9，總和 25.0，所以 output 是 5.0。

Q21Trace

最後 y 是多少？

int x = 3;
double y = Math.pow(x + 1, 2) - Math.sqrt(16);

x + 1 = 4，Math.pow(4, 2) = 16.0，Math.sqrt(16) = 4.0，所以 y = 12.0。

D. Random Range

Math.random() 與指定範圍整數

先判斷乘以多少，再判斷 cast 後的整數，再做位移。

Q22Math.random

Math.random() 的範圍是什麼？

A. 0.0 < r < 1.0 B. 0.0 <= r < 1.0 C. 0.0 <= r <= 1.0 D. 1.0 <= r < 10.0

答案是 B。Math.random() 可能是 0.0，但不會是 1.0。

Q23Random

下面 expression 可能產生哪些整數？

(int)(Math.random() * 10)

可能產生 0 through 9。不是 1 through 10。

Q24Dice

寫出一個 expression，產生 1 through 6。

(int)(Math.random() * 6) + 1

先產生 0 through 5，再加 1。

Q25Range

下面 expression 可能產生哪些整數？

(int)(Math.random() * 5) + 2

(int)(Math.random() * 5) 產生 0 through 4，加 2 後是 2 through 6。

Q26Reverse Design

寫出一個 expression，產生 10 through 15。

(int)(Math.random() * 6) + 10

因為 15 - 10 + 1 = 6。

Q27Reverse Design

寫出一個 expression，產生 -3 through 4。

(int)(Math.random() * 8) - 3

因為 4 - (-3) + 1 = 8。先產生 0 through 7，再減 3。

Q28Casting Trap

下面 expression 可能產生哪些值？

(int)Math.random() * 10

永遠是 0。因為先做 (int)Math.random()，而 Math.random() 一定小於 1.0，cast 後是 0。

Q29Formula

完整填空。

// min through max, inclusive
(int)(Math.random() * (_____)) + _____
(int)(Math.random() * (max - min + 1)) + min

第一格是數字個數，第二格是起點位移。

Q30Range

下面程式中 x 可能有哪些值？

int min = 4;
int max = 9;

int x = (int)(Math.random() * (max - min + 1)) + min;

max - min + 1 = 6，所以先產生 0 through 5，再加 4。x 可能是 4, 5, 6, 7, 8, 9。

E. AP-style MCQ

AP 風格選擇題

這一區混合 return type、integer division、random range 與 method tracing。

Q31AP-style

What is printed?

int x = 3;
double y = Math.pow(x + 1, 2) / 2;
System.out.println(y);
A. 8 B. 8.0 C. 4.0 D. 16.0

答案是 B。x + 1 = 4，Math.pow(4, 2) = 16.0，16.0 / 2 = 8.0。

Q32AP-style

Which expression generates an integer from 5 through 12, inclusive?

A. (int)(Math.random() * 7) + 5 B. (int)(Math.random() * 8) + 5 C. (int)(Math.random() * 12) + 5 D. (int)Math.random() * 8 + 5

答案是 B。12 - 5 + 1 = 8，所以乘以 8 再加 5。

Q33AP-style

What value is assigned to x?

double x = Math.sqrt(16 / 9);
A. 1.0 B. 1.333... C. 4.0 D. Compile-time error

答案是 A。16 / 9 是 integer division，先得到 1。Math.sqrt(1) 是 1.0。

Q34AP-style

Which set contains all possible values of x?

int x = (int)(Math.random() * 3) + 6;
A. 0, 1, 2 B. 3, 4, 5 C. 6, 7, 8 D. 6, 7, 8, 9

答案是 C。乘以 3 後 cast 得到 0, 1, 2，加 6 後是 6, 7, 8。

Q35AP-style

What values can x have?

int x = (int)Math.random() * 10;
A. 0 only B. 0 through 9 C. 1 through 10 D. Compile-time error

答案是 A。(int)Math.random() 永遠是 0，所以整個 expression 永遠是 0。

Q36AP-style

What happens when this code is compiled?

int value = Math.sqrt(49);
A. It stores 7 B. It stores 7.0 C. It stores 49 D. Compile-time error

答案是 D。Math.sqrt(49) 回傳 double，不能直接 assignment 給 int。

Q37Coding

Distance From Origin

設定 double x = 6; 與 double y = 8;，使用公式 sqrt(x^2 + y^2) 計算到原點距離。

public class Main
{
    public static void main(String[] args)
    {
        double x = 6;
        double y = 8;

        double distance = Math.sqrt(Math.pow(x, 2) + Math.pow(y, 2));

        System.out.println("Distance: " + distance);
    }
}

Math.pow(6, 2) = 36.0，Math.pow(8, 2) = 64.0，總和 100.0，平方根是 10.0。

Q38Coding

Two Dice Simulator

產生兩顆六面骰，輸出每顆骰子與總和。

public class Main
{
    public static void main(String[] args)
    {
        int die1 = (int)(Math.random() * 6) + 1;
        int die2 = (int)(Math.random() * 6) + 1;

        int total = die1 + die2;

        System.out.println("Die 1: " + die1);
        System.out.println("Die 2: " + die2);
        System.out.println("Total: " + total);
    }
}

每顆骰子的公式都是 (int)(Math.random() * 6) + 1，產生 1 through 6。

Q39Coding

Random Four-Digit Code

產生一個 1000 through 9999 的四位數驗證碼。

public class Main
{
    public static void main(String[] args)
    {
        int code = (int)(Math.random() * 9000) + 1000;

        System.out.println("Code: " + code);
    }
}

9999 - 1000 + 1 = 9000，所以乘以 9000，再加 1000。

Q40Debugging

這段程式想要模擬骰子，但永遠只會印出 1。請修正。

int roll = (int)Math.random() * 6 + 1;
System.out.println(roll);

問題是 casting 位置太早。(int)Math.random() 永遠是 0。

int roll = (int)(Math.random() * 6) + 1;
Q41Debugging

這段程式無法 compile。請修正。

int x = Math.pow(2, 3);
System.out.println(x);

Math.pow 回傳 double。如果保留 double：

double x = Math.pow(2, 3);

如果真的需要 int：

int x = (int)Math.pow(2, 3);
Q42Final Challenge

完整 trace，回答四個問題。

int a = 11;
int b = 4;

double x = Math.sqrt(a / b + Math.pow(b - 1, 2));
int y = (int)(Math.random() * (b + 2)) + 3;
int z = Math.abs((int)x - y);

1. x 約是多少？ 2. y 可能有哪些值？ 3. z 可能有哪些值？ 4. 若 y 是 6，z 是多少？

a / b = 11 / 4 = 2。b - 1 = 3，Math.pow(3, 2) = 9.0。所以 x = Math.sqrt(11.0)，約 3.3166。

b + 2 = 6，所以 (int)(Math.random() * 6) 是 0 through 5，y 是 3 through 8。

(int)x = 3，所以 z = Math.abs(3 - y)。當 y 是 3, 4, 5, 6, 7, 8 時，z 是 0, 1, 2, 3, 4, 5。若 y = 6，z = 3。
