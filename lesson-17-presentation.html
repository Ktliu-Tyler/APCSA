Arrays

今天正式進入 Java 的 array：固定長度、相同型別、0-based index、 .length、default values、bounds、reference copy 和 enhanced for。

開啟 OneCompiler Lesson 17 課後練習

Why Arrays

如果有很多同類資料，不該寫一堆獨立變數

int score1 = 90;
int score2 = 85;
int score3 = 73;

30 位學生、365 天氣溫、1000 筆測驗結果，都需要更好的表示法。

Array Definition

Array stores a fixed number of values of the same type

int[] scores = {90, 85, 73, 100};
index 0: 90 index 1: 85 index 2: 73 index 3: 100

Three Rules

Array 的三個基本規則

所有 elements 型別相同。
建立後 length 固定。
第一個 index 是 0。

Declaration

宣告 array variable

int[] numbers;
double[] prices;
boolean[] answers;
String[] names;

這些只是 reference variables，還沒有建立 array object。

Create With new

new int[5] 建立 5 個元素

int[] nums = new int[5];
length = 5 indexes 0, 1, 2, 3, 4 max index = 4

Quick Check

若 int[] nums = new int[8];，最後一個合法 index 是多少？

7。最後一個合法 index 永遠是 arr.length - 1。

Initializer List

一開始知道所有元素，可以直接列出來

int[] nums = {10, 20, 30, 40};
String[] names = {"Amy", "Bob", "Chris"};

Java 會自動決定 array length。

Length

Array 使用 arr.length，沒有括號

Array

nums.length

String

word.length()

這是 AP CSA 非常常考的語法陷阱。

Index

用 arr[index] 讀取或修改元素

int[] nums = {10, 20, 30};

nums[1] = 100;
nums[0]++;
nums[2] = nums[0] + nums[1];

Array element 可以像普通變數一樣被 assign 和更新。

Index Expression

Index 可以是 expression，先算完再取元素

int[] nums = {4, 8, 12, 16, 20};
int x = 1;

System.out.println(nums[x + 2]);

x + 2 是 3，所以印出 nums[3]，也就是 16。

Default Values

new 型別[size] 會自動填入預設值

int[] → 0
double[] → 0.0
boolean[] → false
object array → null

Object Array

String[] names = new String[3] 預設是三個 null

String[] names = new String[3];

System.out.println(names[0]); // null

這不是三個空字串，也不是三個已建立的 String object。

Bounds

合法 index：0 <= index < arr.length

int[] nums = {10, 20, 30};

System.out.println(nums[2]); // OK
System.out.println(nums[3]); // runtime error

ArrayIndexOutOfBoundsException 是常見 runtime error。

Off-by-One

最經典錯誤：i <= arr.length

for (int i = 0; i <= nums.length; i++)
{
    System.out.println(nums[i]);
}

最後一圈會讀 nums[nums.length]，但最後一格是 nums[nums.length - 1]。

Traversal

正向走訪所有元素的標準 pattern

for (int i = 0; i < arr.length; i++)
{
    System.out.println(arr[i]);
}

這個 loop 會走過 index 0 到 arr.length - 1。

Reference Type

Array variable 存的是 reference

int[] a = {10, 20, 30};
int[] b = a;
a same array object b

這叫 aliasing：兩個 reference 指向同一個 object。

Aliasing Trace

修改元素會被另一個 reference 看見

int[] a = {2, 4, 6};
int[] b = a;
b[1] = 9;

System.out.println(a[1]);

9。a 和 b 指向同一個 array。

Reassignment

改 reference 和改 element 是兩件事

int[] a = {1, 2};
int[] b = a;

b = new int[2];
b[0] = 10;

System.out.println(a[0]);

1。b 已經改指向新的 array，沒有修改 a 的 array。

null Array Reference

null 代表沒有指向 array object

int[] nums = null;

System.out.println(nums.length);

這會造成 NullPointerException。

Enhanced For

For each value in the array

int[] nums = {10, 20, 30, 40};

for (int value : nums)
{
    System.out.println(value);
}

適合只需要依序讀取每個 element value。

Enhanced For Limitation

Enhanced for 沒有 index

Good fit

讀取每個 value、印出、加總、計數。

Use traditional for

需要 index、修改元素、反向走訪、跳著走、相鄰比較。

Primitive Copy Trap

Enhanced for 不能直接修改 primitive array elements

int[] nums = {1, 2, 3};

for (int x : nums)
{
    x = 100;
}

nums 仍然是 {1, 2, 3}。x 只是 element value 的 copy。

Correct Mutation

要修改 array element，使用 index

for (int i = 0; i < nums.length; i++)
{
    nums[i] = 100;
}

nums[i] 才是 array 裡真正那一格。

Type Recognition

分清楚 reference、element、length

int[] nums 型別是 int[]
nums[0] 型別是 int
nums.length 型別是 int
String[] names 的元素型別是 String

Common Mistakes

Lesson 17 最常見錯誤

arr[arr.length]
i <= arr.length
arr.length()
index 從 1 開始
reference copy 當成 array copy
enhanced for 修改 primitive element

Final Trace

這段最後印出什麼？

int[] nums = {4, 8, 12, 16};

for (int i = 0; i < nums.length; i++)
{
    nums[i] = nums[i] + i;
}

for (int value : nums)
{
    System.out.print(value + " ");
}

4 9 14 19 。每一格都加上自己的 index。
